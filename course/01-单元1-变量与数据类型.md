## 二、核心知识点讲解

### 2.1 变量：一个贴了标签的盒子

变量不是"存储数据的空间"，更准确的说法是：**一个指向某个数据的名字**。

生活化类比：你有一支笔，笔身上贴了一张标签写着"会议记录"。变量 `pen` 就是那张标签，而笔（数据）是真实存在的东西。你可以换一支笔，只要把标签重新贴一下——这就是"重新赋值"：

```python
color = "红"
color = "蓝"   # 换了一支笔，标签上现在写"蓝"
```

Python 的重要特点：**先赋值，后使用**。如果变量还没有被赋值就被使用，会报 `NameError`。这就像你还没买笔就想用"会议记录"这个标签去柜子里拿东西——柜子里空无一物。

### 2.2 命名规则：为什么 `my-var` 和 `2var` 不行

变量名只能包含三类字符：字母、数字、下划线，且**不能以数字开头**。除此之外还有一批 Python 关键字被系统保留了，不能用作变量名（`if`、`for`、`while`、`class`、`def`、`import`、`True`、`False`、`None` 等）。

PEP 8 是 Python 官方风格指南，对变量命名的核心建议是：**全小写 + 多词用下划线分隔**。
- 好：`user_name`、`total_price`、`item2`
- 差：`UserName`、`userName`、`用户名`

另外一条来自本书的实践建议：**名字要够长、够具体**。`a`、`x`、`data`、`temp` 这类短名字在一周后你自己都看不懂，而 `current_user_score` 一眼就懂。这项习惯对零基础学习者尤其重要。

### 2.3 字符串 str：带引号的文字

字符串必须被引号包起来，可以是单引号 `'abc'` 或双引号 `"abc"`。两者的区别在于**当字符串本身含引号时**：

```python
msg1 = "I'm happy"    # 双引号包住里面的单引号 → 合法
msg2 = 'He said "hi"' # 单引号包住里面的双引号 → 合法
```

**不可变性**是字符串最重要的性质：字符串一旦创建就不能原地修改。所有"看起来在改"的方法，实际上都是**返回了一个新的字符串**。

生活化类比：一张打印好的纸条。你不能把纸条上的字擦掉重写；但你可以**复印一份，在复印件上改**。`.upper()` 就是"复印一份并把字改成大写"。

```python
name = "tom"
print(name.upper())   # 输出 TOM
print(name)           # 输出 tom —— 原纸条没变！
```

所以正确用法是**接住返回值**：

```python
name = name.upper()   # 现在 name 才是 "TOM"
```

### 2.4 整数 int 与浮点数 float

`int` 是整数（`-3`、`0`、`42`），`float` 是小数（`3.14`、`-0.5`）。

一个必须知道的细节：**Python 的小数是二进制浮点数，会存在精度误差**。所以你会看到：

```python
print(0.1 + 0.2)   # 0.30000000000000004  ← 不是 bug，是浮点表示的本质
```

若必须得到精确结果，教材和工程界的做法是先用 `round()` 保留有效位数：

```python
print(round(0.1 + 0.2, 2))   # 0.3
```

`round(数字, 位数)` 的第二个参数表示保留几位小数。

### 2.5 布尔值 bool：只有两个取值

布尔值只有 `True` 和 `False`，**首字母必须大写**，这是初学者的高频语法错误（写 `true` 会报 `NameError`）。

Python 里有一批"真值判断"规则，在单元 4、6 会大量用到：

| 值为以下情况 | 布尔意义 |
|---|---|
| `0`、`0.0`、空字符串 `""`、空列表 `[]`、空字典 `{}`、`None` | False（假） |
| 其他任何值（含非零数字、非空文本） | True（真） |

生活化类比：问"这个盒子里有东西吗？"——空盒子回答 False，非空盒子回答 True。Python 判断的就是"有没有内容"，不关心内容是什么。

### 2.6 类型转换：把一种类型的标签换成另一种

`input()` 拿回来的**永远是字符串**，即使你输入 `18`，它也是 `"18"` 这个字符串，直接做加法会出错：

```python
age = input("年龄：")   # 用户输入 18，age 是 str "18"
print(age + 1)          # TypeError：can only concatenate str to str
```

解决办法是用转换函数重新贴标签：

```python
age = int(input("年龄："))    # "18" → 18（整数）
print(age + 1)                # 19
```

四个转换函数：`str()` 转字符串、`int()` 转整数、`float()` 转小数、`bool()` 转布尔。

**转换可能失败**，失败会报 `ValueError`：
- `int("abc")` → `ValueError: invalid literal for int()`（abc 不是合法整数）
- `int("3.9")` → `ValueError`（带小数点的字符串不能直接转整数，必须先 `float` 或 `int(float(...))`）
- `float("abc")` → `ValueError`

记住这条链：**`"3.9"` → `float()` 得 `3.9` → `int()` 得 `3`**。字符串到整数没有"一步到位"的捷径，因为 `3.9` 转整数会丢失小数部分，Python 拒绝替你做这个决定。

### 2.7 字符串方法全家桶：拆分、拼接与去掉前后缀

教材 2.3 讲了 `title()` / `upper()` / `lower()` / `strip()`。还有三组在真实代码里出现频率更高的方法，书里分散在示例中没集中讲：`split()` 把一句话拆成列表、`join()` 把列表拼回字符串、`removeprefix()` 去掉开头固定的一段。

```python
line = "张三,18,北京"
print(line.split(","))        # ['张三', '18', '北京']
print(line.split(",", 1))     # ['张三', '18,北京']  ← 最多拆 1 次

words = ["python", "is", "fun"]
print(" ".join(words))        # python is fun
print("-".join(words))        # python-is-fun
```

**`split()` 与 `join()` 是一对反操作**：一个把字符串变列表，一个把列表变字符串。注意 `join()` 的调用方向——分隔符在前、列表是参数。写反成 `words.join(" ")` 会报 `AttributeError: 'list' object has no attribute 'join'`。

```python
filename = "report_2026_final.csv"
print(filename.removeprefix("report_"))   # 2026_final.csv
print(filename.removesuffix(".csv"))      # report_2026_final
```

`removeprefix()` / `removesuffix()`（Python 3.9+）解决的是「前缀固定、后面长度不定」的问题。以前只能写切片 `filename[len("report_"):]`，或者图省事用 `lstrip("report_")`——而 `lstrip` 是按**字符集合**删的，会把 `report.pdf` 删成 `.pdf`，属于高频 bug：

```python
print("report.pdf".lstrip("report_"))         # .pdf        ← r/e/p/o/t/_ 都被当字符删掉
print("report.pdf".removeprefix("report_"))   # report.pdf  ← 前缀不匹配就原样返回
```

查找与替换这一组也常一起出现：

```python
s = "to be or not to be"
print(s.find("be"))            # 3    ← 返回下标
print(s.find("xyz"))           # -1   ← 找不到返回 -1，不报错
print(s.count("be"))           # 2
print(s.replace("be", "BE"))   # to BE or not to BE
print(s.replace("be", "BE", 1))  # to BE or not to be  ← 第三个参数限制次数
```

> **要点**
> - `split()` 不传参数时按「任意连续空白」拆并丢掉空串；传 `","` 时连续逗号会拆出空字符串。
> - `join()` 只能拼**字符串列表**：`",".join([1, 2])` 报 `TypeError`，要先 `",".join(map(str, nums))`。
> - 这几个方法都**返回新字符串**，原字符串不变（同 2.3 的「复印纸条」模型）。
> - `find()` 找不到返回 `-1`，`index()` 找不到才抛 `ValueError`——判断「有没有」优先用 `in`。

### 示例 3：字符串常用方法

```python
# string_methods.py —— 字符串的"复印与改写"

name = "  ada lovelace  "

# .upper() / .lower() 大小写转换
print(name.upper())       # '  ADA LOVELACE  '
print(name.lower())       # '  ada lovelace  '

# .strip() 去掉两端空白（不会去掉中间的空格）
print(repr(name.strip()))# 'ada lovelace'  用 repr() 才能看清首尾有没有空格

# .title() 每个单词首字母大写
print(name.strip().title())   # 'Ada Lovelace'

# .len() 计算长度（算的是字符个数）
print(len(name.strip()))      # 12

# .count() 数某个字符出现几次
print("banana".count("a"))        # 3

# .replace() 替换
print("hello world".replace("world", "python"))   # 'hello python'

# 关键：上面所有方法都"没有改动" name
print(name)                    #  '  ada lovelace  '  ← 原字符串原封不动
print(type(name.strip()))      # <class 'str'>  返回的是一个新字符串

# 想真正保存结果，必须接住返回值
name = name.strip().title()
print(name)                    # 'Ada Lovelace'  ← 现在才是新值
```

### 示例 4：类型转换

```python
# convert.py —— 四种类型之间的转换
```

### 示例 5：f-string 格式化输出

```python
# fstring.py —— f-string：把变量嵌进文字里的最佳方式

product = "机械键盘"
price = 499.5
quantity = 3
discount = 0.85
is_in_stock = True

total = price * quantity * discount

# 基础用法
print(f"商品：{product}")
print(f"单价：{price} 元")

# 花括号里可以放完整的表达式
print(f"总价：{price * quantity * discount:.2f} 元")

# 格式说明符：:.<宽度>.<小数位>f
print(f"|{product:<10}|")# 左对齐，占 10 字符宽
print(f"|{price:>10.2f}|")           # 右对齐，保留两位小数
print(f"|{product:^12}|")            # 居中

# 补零，常用于编号
code = 42
print(f"订单号：{code:05d}")          # 订单号：00042

# 千位分隔符
big = 1234567.891
print(f"金额：{big:,.2f} 元")         # 金额：1,234,567.89 元

# 让布尔值更易读
print(f"是否有货：{is_in_stock}")     # 是否有货：True
print(f"是否有货：{'有' if is_in_stock else '无'}")  # 是否有货：有

# 多行 f-string：括号里可以换行，不用反复 print
print(f"商品：{product}\n"
      f"单价：{price} 元\n"
      f"总价：{total:.2f} 元")
```

### 示例 8：拆一行日志，再拼回去

`split()` / `join()` 最典型的用法是处理「一行一条记录」的文本。下面这行是服务器访问日志，六段用空格隔开：

```python
# log_line.py —— 拆开、取字段、换格式、再拼回去
line = "2026-10-26 09:15:33 GET /lessons/29.html 200 4213"

parts = line.split(" ")                 # 空格分隔，正好 6 段
print("段数  ", len(parts))
print("原始  ", parts)

date, clock, method, path, status, size = parts       # 解包，顺序必须对上
print(f"日期  {date} {clock}")
print(f"请求  {method} {path}")

pure = path.split("?")[0]               # 去掉查询串；没有 ? 时只有一段
print("纯路径", pure)
print("文件名", pure.removeprefix("/lessons/"))

print("CSV   ", ",".join([date, method, pure, status]))

kb = int(size) / 1024                   # size 现在是字符串，必须先转 int
print(f"大小  {kb:.1f} KB")
print("成功？", status.startswith("2"))
```

运行结果（`print` 会按逗号自动加空格，所以对齐看起来是参差的，这是 `print` 的行为不是 bug）：

```text
段数   6
原始   ['2026-10-26', '09:15:33', 'GET', '/lessons/29.html', '200', '4213']
日期   2026-10-26 09:15:33
请求   GET /lessons/29.html
纯路径 /lessons/29.html
文件名 29.html
CSV    2026-10-26,GET,/lessons/29.html,200
大小   4.1 KB
成功？ True
```

三个值得记住的点：

1. **`split()` 的段数必须和解包变量个数一致**，多一个少一个都会 `ValueError: too many values to unpack`。不确定段数时先 `print(len(parts))`。
2. **`split("?")[0]` 是「取问号前那段」的惯用法**——没有问号时返回整串，不会报错，所以比 `index("?")` 安全。
3. **`join()` 只吃字符串**：`size` 是从 `split()` 出来的字符串，要算数必须先 `int(size)`；反过来，数字要拼回 CSV 必须先 `str()`。

**练习 1-2【BMI 计算】**
已知 `weight = 70`（千克，int）、`height = 1.75`（米，float）。计算 BMI = weight / height²，用 f-string 输出一句话，BMI 保留两位小数。
输出示例：
```
你的身高是 1.75 米，体重是 70 千克，BMI 是 22.86。
```

## 六、本单元验收自测

**1. 判断题**：`name = "Alice"` 然后 `print(name.upper())` 之后，`name` 的值变成了 `"ALICE"`。
> **要点**：错误。`name` 仍是 `"Alice"`。字符串不可变，`.upper()` 返回一个**新字符串**，必须写 `name = name.upper()` 才能把新值存回变量。

**2. 简答题**：`int("3.9")` 会返回什么？为什么不能直接转？
> **要点**：会报 `ValueError`。因为把字符串转成 int 要求这个字符串**整体**是一个合法整数，而 `"3.9"` 带小数点，不满足要求。正确做法是分两步：`int(float("3.9"))` 得 `3`。

**3. 判断题**：`bool("False")` 的结果是 `False`。
> **要点**：错误，结果是 `True`。Python 只看"是否为空"，`"False"` 是一个非空字符串（里面恰好有 5 个字母），所以为真。Python **不解析**字符串内容。

**4. 简答题**：下面代码输出什么？
```python
x = 5
x = str(x)
x = x + "5"
print(x * 2)
```
> **要点**：输出 `5555`。逐步跟踪：第 2 行 `x` 变成字符串 `"5"`；第 3 行 `x + "5"` 是字符串拼接，得 `"55"`；第 4 行 `"55" * 2` 是字符串重复，得 `"5555"`。同一个运算符 `+` 和 `*`，对字符串和对数字的含义完全不同——这正是"Python 根据类型决定行为"的体现。

**5. 简答题**：说出下面三种变量名为什么非法（各写一句理由）。
`2nd_place`、`my name`、`class`
> **要点**：`2nd_place` 以数字开头（语法层面名称必须以字母或下划线开头）；`my name` 中间有空格（名称是一个整体，不能拆开）；`class` 是 Python 关键字，已被语言本身占用（正确写法 `class_name = "三班"`）。
