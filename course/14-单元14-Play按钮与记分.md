## 二、核心知识点讲解

小节映射：2.1–2.3 对应教材 14.1「添加 Play 按钮」，2.4 对应 14.3「记分」，2.5 对应 14.2「提高难度」，2.6 对应 14.3「显示余下的飞船数」。

### 2.1 游戏状态机：从「一启动就玩」到「有开始界面」

现在的游戏一运行，飞船就能动、子弹就能打：玩家还没准备好就开始了；结束后想再来一局，只能重启程序。解决办法是加一个**状态开关**：

```text
        点击 Play 按钮
inactive ─────────────▶ active
   ▲                      │
   │   飞船全部被摧毁       │
   └──────────────────────┘
        game over
```

- **inactive**：刚启动或上一局结束，屏幕上只有 Play 按钮，飞船不动、外星人不生成。
- **active**：点过 Play，一切正常运转。
- 教材没有单独的 `game_over` 变量——「game over」就是「active 又变回 inactive」，只是这次是因为你输了。核心开关只有一个：`stats.game_active`。

类比**自动售货机**：投币前（inactive）按哪个按钮都不出货，投币后（active）全部有反应。它不需要理解你的每个动作，内部就一盏「是否已投币」的灯。`game_active` 就是这盏灯。有了它，主循环只需判断一次：

```python
game_active = True
score = 0
if game_active:           # 开关打开，游戏逻辑才跑
    score += 50
print("游戏中：", score)      # 50
game_active = False
if game_active:
    score += 50           # 这一段被整体跳过
print("未开始：", score)     # 还是 50
```

这就是**状态机**最简的形态。以后写任何「有开始界面、有结束」的程序，脑子里都要有这张图。

### 2.2 Button 类：Pygame 的文字不是「画」出来的

★ 难点：**Pygame 里没有任何函数能直接把文字画到屏幕上**。`screen.draw_text("Play")` 这样的函数根本不存在。所有文字都必须先用 `font.render()` **渲染成一张图片（Surface）**，再像贴贴纸一样 `blit()` 上去。类比：屏幕是软木板，`blit()` 是贴照片；写着「Play」的纸条必须先**做成照片**——`font.render()` 就是你的照片打印机。这就是 `Button` 类存在的全部理由，完整代码见示例 1。

几个必须记住的点：

- **按钮为什么要自己持有 `screen` 和 `screen_rect`？** 因为它要自己画自己（`draw_button()` 里用 `screen`），还要知道屏幕多大才能把自己放正中间（`screen_rect.center`）。类比：自带胶带的便利贴，拿到手就记住了「我要贴在哪块板子上」。
- **`_prep_msg()` 只在构造时调用一次**：文字不变，每帧重渲染纯属浪费。
- **`render()` 的 `True` 是抗锯齿**，写 `False` 就是马赛克字；参数顺序是「文字、抗锯齿、前景色、（背景色可省）」。
- **前导下划线**按约定表示「内部方法」，Button 只对外暴露 `draw_button()`。

**点击判定 `collidepoint`**：`Rect` 自带这个方法，`button.rect.collidepoint(mouse_pos)` 一行就能判断「鼠标点没点到按钮」。这就是 Pygame 里几乎所有可点击的东西都用 `Rect` 描述位置的原因。

### 2.3 点下 Play 之后：开始、重置、非活动与隐藏光标

教材 14.1 剩下的部分只回答一个问题：**鼠标点中 Play 的那一瞬间，程序要按什么顺序做哪些事？** 答案是五步（完整代码见示例 4）：

1. `initialize_dynamic_settings()`——恢复初始速度（上一局可能已经提速过）；
2. `reset_stats()`——重置得分、等级、剩余飞船数；
3. `game_active = True`——打开总开关，游戏正式开始；
4. 清空上一局残骸：`aliens.empty()`、`bullets.empty()`、重建外星人编队、飞船回中；
5. `pygame.mouse.set_visible(False)`——游戏进行中隐藏光标。

顺序有讲究：`reset_stats()` 里要读 `settings.ship_limit`，速度设置必须先就位。

**「将 Play 按钮切换到非活动状态」**：游戏开始后按钮不该还能点。教材不删按钮，只在判断时加一个条件——`if button.rect.collidepoint(mouse_pos) and not self.stats.game_active:`。进行中再点按钮区域，什么都不会发生。这就是「非活动」：按钮还在，点了没反应。

**「隐藏光标」必须成对**：游戏中 `set_visible(False)`，结束时 `set_visible(True)`。只写前者，游戏结束后玩家会找不到鼠标——「我的光标呢？？」是被问过一万遍的问题。

反过来，游戏结束时（`_ship_hit()` 里命数耗尽）要做相反的一组动作：命数减一 → `prep_ships()` 更新左上角图标 → 清空编组、飞船居中、重建外星人编队；命数归零则 `game_active = False` 并把光标设回可见。**`_check_play_button()` 负责 inactive → active，`_ship_hit()` 负责 active → inactive**，两张门票各管一段，这就是状态机在代码里的样子。

### 2.4 记分牌：数据与显示分离、格式化与最高分

记分牌听起来简单，但这里藏着一个**通用 UI 套路**，比记分牌本身重要得多。`Scoreboard` 一构造就把四样东西全部「准备好」（完整代码见示例 3）：

```python
self.prep_score()          # 得分：右上角
self.prep_high_score()     # 最高分：顶部居中
self.prep_level()          # 等级：得分下方
self.prep_ships()          # 命数图标：左上角
```

每个 `prep_*` 都是同样的三步：**从 `stats` 取出数据 → 渲染成图像 → 把图像放到该放的位置**。以得分为例：

```python
score_str = "{:,}".format(round(self.stats.score, -1))   # 1. 取数据并格式化
self.score_image = self.font.render(score_str, True, self.text_color, self.settings.bg_color)  # 2. 渲染成图像
self.score_rect = self.score_image.get_rect()            # 3. 定位
self.score_rect.right = self.screen_rect.right - 20
self.score_rect.top = 20
```

类比**餐厅的水牌**：`stats.score` 是厨房账本（数据），`score_image` 是水牌上的菜价（显示）。菜价不会自己变——改完账本必须派小二**重写水牌**，`prep_score()` 就是那个小二。★ 本单元最容易踩的坑就是改了数据忘了 prep：

```python
stats = {"score": 0, "score_image": "（空）"}   # score_image 假装是屏幕上的图像
stats["score"] += 100                          # 数据涨了
print(stats["score"], stats["score_image"])    # 100 （空） —— 图像还是旧的！
# 少了 prep_score()，屏幕上的数字永远不会动
```

为什么拆成四个 `prep_*` 方法？因为**位置各不相同**：得分靠右用 `right` 锚点、最高分居中用 `centerx`、等级贴着得分下方、飞船图标在左上角。一个方法管一样，谁改了就重新调用谁。`show_score()` 则把几张图无脑贴到屏幕上，`_update_screen()` 里调用它一行就够。

**格式化两招**：`round(1234567, -1)` 舍入到十位得 1234570；`"{:,}".format(1234570)` 加千分位得 `'1,234,570'`（等价 f-string：`f"{1234570:,}"`）。舍到十位是因为外星人一只 50 分，个位永远是 0。

**最高分为什么不能在重置时清零**，这是本章的重点思想：

```python
class GameStats:
    def __init__(self, ai_game):
        self.settings = ai_game.settings
        self.reset_stats()
        self.high_score = 0        # 只在创建实例时初始化一次
        self.game_active = False   # 游戏一开始不应该是活动状态

    def reset_stats(self):
        """只重置一局内部的数据"""
        self.ships_left = self.settings.ship_limit
        self.score = 0
        self.level = 1
```

`reset_stats()` 在两个时机被调用：① 游戏启动；② 点 Play 再来一局。`high_score` 写进去，每局纪录都归零，纪录墙形同虚设。类比：**最高分是「全国纪录」，score 是「本次成绩」**——新赛季清零的是自己的成绩，纪录不会因为换赛季消失。击落外星人后顺手检查：`check_high_score()` 里 `if score > high_score` 就更新，并重新 `prep_high_score()`。

★ 这个最高分有致命缺陷：**只活在内存里，程序一关就丢**。真正的游戏要写进文件，下次启动读出来——单元 9 学的 `json.dump()` / `json.load()` 终于等到了用武之地（教材未涉及，练习 14-4 带你实现）。

### 2.5 动态难度：speedup_scale 与 score_scale

游戏太难了，而且永远那么难：高手 3 分钟通关，新手 30 秒去世。把 `Settings` 的设置拆成**静态**（整局不变：屏幕尺寸、`ship_limit`、两个成长系数）和**动态**（会变：三种速度、`alien_points`）两组，完整代码见示例 2。

- `speedup_scale = 1.1`：每升一级，`ship_speed` / `bullet_speed` / `alien_speed` 都乘 1.1。
- `score_scale = 1.5`：每升一级，`alien_points` 乘 1.5。
- `initialize_dynamic_settings()`：取初始值，**点 Play 重置时调用**。
- `increase_speed()`：往上加，**清空一波外星人升级时调用**。

**为什么拆成两个方法？** 「取初始值」和「往上加」是两个不同时机。不拆的话，重置点要把每个初始值重复抄一遍，容易漏。★ 记住：**一组初始值单独抽成一个方法，重置时调用它。**

**`alien_points` 为什么要 `int()`？** `50 * 1.5 = 75.0`（float），再乘得 `112.5`。小数分显示出来很怪（「112.5 分」），`int()` 一刀切只留整数：`int(112.5)` = 112（截断不是四舍五入，游戏里无所谓）。

**难度曲线**：1.1 的指数增长「先温和后陡峭」——第 1 级速度 1.0、第 5 级约 1.46、第 10 级约 2.36；分值 50 → 75 → 112 → 168 → 252，越往后每级涨得越多。**风险越高，回报越高**，玩家才有动力冲更高等级。

### 2.6 余下的飞船数：Group + Ship 的复用

左上角显示「你还剩几条命」，教材的实现非常优雅——**直接复用 Ship 类**（完整演示见示例 5）：

```python
def prep_ships(self):
    self.ships = Group()
    for ship_number in range(self.stats.ships_left):
        ship = Ship(self.ai_game)
        ship.rect.x = 10 + ship_number * ship.rect.width
        ship.rect.y = 10
        self.ships.add(ship)
```

- `Group()` 是 Pygame 的**精灵编组**，像一艘航空母舰，把一堆 Sprite 装进去统一管理，`self.ships.draw(self.screen)` 一行画出所有小图标。
- 每个小图标都是一个**完整的 Ship 对象**——有图片、有 `rect`、有速度，只是不更新位置，纯粹借它的「长相」。这就是复用：不为图标单独写类。
- `ship.rect.width` 是图片宽度，用它当间距，图标之间刚好不重叠。

你已经见过 `bullets = Group()` 和 `aliens = Group()`——同一个工具，同一套用法；将来统一更新、检测碰撞（`update()`、`groupcollide()`）也都是现成的。★ `prep_ships()` 每次调用都 `self.ships = Group()` **重建编组**：命数会变，旧编组里装着旧数量的图标，必须整个扔掉重来；往旧编组里增增减减才是真的乱。

### 示例 1：完整的 Button 类 + 点击判定

```python
# button_demo.py —— Button 类完整实现，演示居中、绘制、点击判定
import os
os.environ.setdefault("SDL_VIDEODRIVER", "dummy")

import pygame


class Button:
    """居中的矩形按钮，自己渲染文字、自己绘制自己。"""

    def __init__(self, screen, msg):
        self.screen = screen
        self.screen_rect = screen.get_rect()
        self.width, self.height = 200, 50
        self.button_color = (0, 135, 0)
        self.text_color = (255, 255, 255)
        self.font = pygame.font.SysFont(None, 48)
        self.rect = pygame.Rect(0, 0, self.width, self.height)
        self.rect.center = self.screen_rect.center
        self._prep_msg(msg)

    def _prep_msg(self, msg):
        self.msg_image = self.font.render(
            msg, True, self.text_color, self.button_color)
        self.msg_image_rect = self.msg_image.get_rect()
        self.msg_image_rect.center = self.rect.center

    def draw_button(self):
        self.screen.fill(self.button_color, self.rect)
        self.screen.blit(self.msg_image, self.msg_image_rect)


pygame.init()
screen = pygame.display.set_mode((600, 400))
button = Button(screen, "Play")

screen.fill((230, 230, 230))
button.draw_button()
pygame.image.save(screen, "button_demo.png")

print(f"按钮矩形：{button.rect}")
print(f"按钮中心：{button.rect.center}，屏幕中心：{button.screen_rect.center}")
print(f"文字图像类型：{type(button.msg_image).__name__}（render 的产物，不是字符串）")

print("\n--- 点击判定 collidepoint ---")
for pos in [(300, 200), (300, 210), (10, 10), (400, 200)]:
    hit = button.rect.collidepoint(pos)
    print(f"鼠标在 {pos}：{'点中了按钮' if hit else '没点到'}")

pygame.quit()
# 跑完可以删掉 button_demo.png
```

**预期输出**：

```text
按钮矩形：<rect(200, 175, 200, 50)>
按钮中心：(300, 200)，屏幕中心：(300, 200)
文字图像类型：Surface（render 的产物，不是字符串）

--- 点击判定 collidepoint ---
鼠标在 (300, 200)：点中了按钮
鼠标在 (300, 210)：点中了按钮
鼠标在 (10, 10)：没点到
鼠标在 (400, 200)：没点到
```

> `rect(200, 175, 200, 50)` 是「左 200、上 175、宽 200、高 50」，右边缘 399、下边缘 224。`(399, 199)` 在边缘上算命中，`(400, 200)` 差 1 像素算没命中——矩形判定就是这么精确。打开 `button_demo.png` 能看到真正画出来的按钮。

### 示例 2：动态难度——initialize_dynamic_settings 与 increase_speed

```python
# dynamic_settings.py —— Settings 的"难度控制"部分 + 得分格式化


def format_score(score):
    """舍入到十位 + 千分位。"""
    return "{:,}".format(round(score, -1))


class Settings:
    def __init__(self):
        self.speedup_scale = 1.1     # 每升一级，速度 ×1.1
        self.score_scale = 1.5       # 每升一级，外星人分值 ×1.5
        self.initialize_dynamic_settings()

    def initialize_dynamic_settings(self):
        """随游戏重置的动态设置，点 Play 时调用。"""
        self.ship_speed = 1.5
        self.bullet_speed = 3.0
        self.alien_speed = 1.0
        self.alien_points = 50

    def increase_speed(self):
        """外星人编队被清空后调用：提速 + 加分。"""
        self.ship_speed *= self.speedup_scale
        self.bullet_speed *= self.speedup_scale
        self.alien_speed *= self.speedup_scale
        # int() 截断小数：50 ×1.5 = 75.0，再 ×1.5 = 112.5 -> 112
        self.alien_points = int(self.alien_points * self.score_scale)


print("=== 得分格式化：round(x, -1) + 千分位 ===")
for score in [0, 50, 1230, 1234567, 999999990]:
    print(f"  stats.score = {score:>10}  ->  屏幕显示: {format_score(score)}")

print("\n=== 难度曲线：每级调用一次 increase_speed ===")
settings = Settings()
print(f"{'等级':>4}{'alien_speed':>14}{'bullet_speed':>15}{'alien_points':>14}")
print("-" * 50)
print(f"{1:>4}{settings.alien_speed:>14.2f}{settings.bullet_speed:>15.2f}"
      f"{settings.alien_points:>14}")
for level in range(2, 11):
    settings.increase_speed()
    print(f"{level:>4}{settings.alien_speed:>14.2f}{settings.bullet_speed:>15.2f}"
          f"{settings.alien_points:>14}")

settings.initialize_dynamic_settings()
print(f"\n重置后：alien_speed={settings.alien_speed}，"
      f"alien_points={settings.alien_points}（点 Play 再来一局）")
```

### 示例 3：Scoreboard 的「准备图像」模式

```python
# scoreboard_demo.py —— 数据与显示分离：prep_* 模式
import os
os.environ.setdefault("SDL_VIDEODRIVER", "dummy")

import pygame


class Settings:
    def __init__(self):
        self.bg_color = (230, 230, 230)
        self.ship_limit = 3
        self.alien_points = 50


class GameStats:
    """score/level/ships_left 每局重置，high_score 不清零。"""

    def __init__(self, settings):
        self.settings = settings
        self.reset_stats()
        self.high_score = 0
        self.game_active = False

    def reset_stats(self):
        self.ships_left = self.settings.ship_limit
        self.score = 0
        self.level = 1


class Scoreboard:
    """把 stats 里的数据翻译成屏幕上的图像。"""

    def __init__(self, screen, settings, stats):
        self.screen = screen
        self.screen_rect = screen.get_rect()
        self.settings = settings
        self.stats = stats
        self.font = pygame.font.SysFont(None, 48)
```

```python
import pygame


class Settings:

        self.game_active = False

    def reset_stats(self):
        self.ships_left = self.settings.ship_limit
        self.score = 0
        self.level = 1


class Game:
    """迷你状态机游戏：点 Play 开始，被撞 3 次结束，可重开。"""

    def __init__(self):
        pygame.init()
        self.screen = pygame.display.set_mode((800, 500))
        self.settings = Settings()
        self.stats = GameStats(self.settings)
        self.font = pygame.font.SysFont(None, 48)
        self.clock = pygame.time.Clock()
        # 按钮就是一个 Rect：屏幕正中的 200x50 矩形
        self.button_rect = pygame.Rect(0, 0, 200, 50)
        self.button_rect.center = self.screen.get_rect().center

    def _check_play_button(self, mouse_pos):
        """点 Play 且游戏未激活 -> 开始新的一局。"""
        if self.button_rect.collidepoint(mouse_pos) and not self.stats.game_active:
            self.settings.initialize_dynamic_settings()
            self.stats.reset_stats()
            self.stats.game_active = True
            pygame.mouse.set_visible(False)
            print("  -> 游戏开始！game_active = True，光标已隐藏")

    def _ship_hit(self):
        self.stats.ships_left -= 1
        print(f"  -> 飞船被撞！剩余 {self.stats.ships_left} 条命")
        if self.stats.ships_left <= 0:
            self.stats.game_active = False
            pygame.mouse.set_visible(True)
            print("  -> 命用完了，game_active = False，光标恢复显示")

    def _check_events(self):
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                return False
            elif event.type == pygame.MOUSEBUTTONDOWN:
                self._check_play_button(event.pos)
            elif event.type == pygame.KEYDOWN and event.key == pygame.K_q:
                return False
        return True

        self.screen.fill((230, 230, 230))
        if self.stats.game_active:
            text = self.font.render(
                f"SCORE: {self.stats.score}", True, (30, 30, 30))
            self.screen.blit(text, (20, 20))
        else:

            msg = self.font.render("Play", True, (255, 255, 255), (0, 135, 0))
            self.screen.blit(msg, msg.get_rect(center=self.button_rect.center))
        pygame.display.flip()

        print("游戏启动：game_active = False，等待玩家点 Play\n")
        # dummy 驱动收不到真实事件，预排 30 帧做演示；
        # 在你自己电脑上删掉 setdefault 两行，就能用真鼠标真键盘玩。
        plan = [

            (12, "click", (50, 50)),     # 点空白处（不该有反应）
            (14, "hit", None),
            (16, "hit", None),
            (18, "hit", None),           # 撞三次 -> game over
            (20, "click", (400, 250)),   # 再点 Play -> 重开
        ]
        frame = 0
        running = True
        while running and frame < 30:
            for when, what, arg in plan:
                if frame == when:
                    if what == "click":
                        pygame.event.post(pygame.event.Event(
                            pygame.MOUSEBUTTONDOWN,
                            {"pos": arg, "button": 1}))
                        print(f"[第 {frame} 帧] 模拟鼠标点击 {arg}")
                    elif what == "hit" and self.stats.game_active:
                        print(f"[第 {frame} 帧] 模拟一次撞击")
                        self._ship_hit()
            running = self._check_events()
            if self.stats.game_active:
                self.stats.score += self.settings.alien_points
                if self.stats.score > self.stats.high_score:
                    self.stats.high_score = self.stats.score
            self._update_screen()
            self.clock.tick(60)
            frame += 1
        print(f"\n游戏循环结束：最终得分 {self.stats.score}，"
              f"最高分 {self.stats.high_score}")
        pygame.quit()
```

```python
# place_rect.py —— 按钮定位函数
import os
os.environ.setdefault("SDL_VIDEODRIVER", "dummy")

import pygame


def place_rect(rect, screen_rect, position):
    """把 rect 摆到 screen_rect 的对应位置，四周留 20 像素边距。"""
    if position == "center":
        rect.center = screen_rect.center
    elif position == "bottom_right":
        rect.right = screen_rect.right - 20
        rect.bottom = screen_rect.bottom - 20
    elif position == "top_left":
        rect.left = 20
        rect.top = 20
    else:
        raise ValueError(f"未知位置: {position}")
    return rect


pygame.init()
screen_rect = pygame.display.set_mode((800, 600)).get_rect()

play = place_rect(pygame.Rect(0, 0, 200, 50), screen_rect, "center")
quit_btn = place_rect(pygame.Rect(0, 0, 200, 50), screen_rect, "bottom_right")
help_btn = place_rect(pygame.Rect(0, 0, 200, 50), screen_rect, "top_left")

buttons = [("Play", play), ("Quit", quit_btn), ("Help", help_btn)]
for name, rect in buttons:
    print(f"{name}: rect={rect}, 中心={rect.center}")

print("\n--- 点击判定 ---")
for name, rect in buttons:
    hit_self = rect.collidepoint(rect.center)
    others = [r for n, r in buttons if r is not rect]
    hit_other = any(r.collidepoint(rect.center) for r in others)
    print(f"  点 {name} 中心：命中自己={hit_self}，误伤别人={hit_other}")

# 无法识别的位置必须报错
try:
    place_rect(pygame.Rect(0, 0, 10, 10), screen_rect, "middle")
except ValueError as error:
    print(f"\n错误处理正常：{error}")

pygame.quit()
```

## 六、常见错误清单（务必逐条自查）

### 错误 1：★ 改了 score 忘了 prep_score()


### 错误 3：font.render() 参数写错

## 七、本单元验收自测

**1. 简答题**：为什么 Pygame 里不能直接「画文字」？`_prep_msg()` 做了什么？如果游戏运行期间要把按钮文字从 Play 改成 Resume，代码该怎么写？
> **要点**：Pygame 只能操作 Surface（图像），文字必须先用 `font.render(text, True, text_color, bg_color)` 渲染成一张 Surface，再 `blit()` 到屏幕上——这就是 `_prep_msg()` 做的事：渲染文字图像 + 把图像矩形和按钮矩形居中对齐。文字要变，不能只改字符串，必须**重新调用 `_prep_msg()` 生成新的 `msg_image`**，否则屏幕上还是旧照片。这正是「数据与显示分离」的体现。

**2. 判断题**：`reset_stats()` 应该负责把 `high_score` 也清零，因为「重置就是要全部归零」。
> **要点**：错误。`reset_stats()` 管理「一局内部的数据」（`ships_left`、`score`、`level`），`high_score` 是「跨局记忆」，生命周期是整个程序运行期间（要持久化还要跨进程）。同理 `game_active` 也不归 `reset_stats()` 管——它由「点 Play」和「命耗尽」两个事件驱动。

**3. 简答题**：`round(1234567, -1)` 和 `"{:,}".format(1234570)` 的结果分别是什么？为什么先舍入再加千分位，顺序反过来行不行？
> **要点**：分别是 `1234570` 和 `'1,234,570'`。先舍入到十位让显示短、齐整（个位永远是 0，没有信息量），再加千分位让人一眼看清数量级。反过来**不行**——`"{:,}".format(1234567)` 得到的是字符串 `'1,234,567'`，字符串没法 `round()`。教材的顺序是「数值上舍入 → 转字符串 → 加逗号」，不能乱。

**4. 改错题**：下面代码击落外星人后，`print(stats.score)` 是对的，但屏幕上得分永远不变。只补两行修好它。

```python
# INTENTIONALLY-BROKEN 演示用：数据变了，但屏幕上的图像没更新
if collisions:
    for aliens in collisions.values():
        self.stats.score += self.settings.alien_points * len(aliens)
    # 屏幕上得分不更新
```

> **要点**：缺 `self.sb.prep_score()` 和 `self.sb.check_high_score()`。修正后：

```python
if collisions:
    for aliens in collisions.values():
        self.stats.score += self.settings.alien_points * len(aliens)
    self.sb.prep_score()          # 数据变了，图像要重做
    self.sb.check_high_score()    # 顺手检查新纪录
```

> 深层原因：`stats.score` 是数据，`score_image` 是图像，`prep_score()` 是两者之间唯一的桥。（这两行是项目里的片段，直接粘到 `alien_invasion.py` 的 `_update_bullets()` 里用。）

**5. 简答题**：`speedup_scale` 和 `score_scale` 分别控制什么？为什么 `alien_points` 要 `int()`？为什么 `initialize_dynamic_settings()` 和 `increase_speed()` 必须拆成两个方法？
> **要点**：`speedup_scale`（1.1）同时缩放 `ship_speed` / `bullet_speed` / `alien_speed`，让整体节奏越来越快；`score_scale`（1.5）缩放 `alien_points`，让高风险对应高回报。`int()` 是因为 `50 * 1.5 = 75.0` 是 float，继续乘会出现 `112.5` 这样的小数分，显示难看。拆两个方法是因为「取初始值」和「往上加」是两个不同时机：点 Play 重置时调 `initialize_dynamic_settings()`，清空一波外星人升级时调 `increase_speed()`；不拆的话重置点要重复抄一遍所有初始值，容易漏。

**6. 简答题**：`prep_ships()` 为什么用 `Group` 装一整排 `Ship` 对象表示剩余命数？为什么每次都要重建 `Group`？
> **要点**：用 `Group` + `Ship` 是「复用」：不为小图标单独造类，直接借飞船的长相和管理方式，`self.ships.draw(screen)` 一行画完，将来要统一更新、检测碰撞也有现成方法（`update()`、`groupcollide()`）。每次重建 `self.ships = Group()` 是因为命数会变，旧编组里装着旧数量的图标，必须整个扔掉重来；往旧编组里增增减减会出现「旧图标没清干净」的 bug。
