### 2.2 六个"选什么"的高频决策

做项目时反复遇到的问题，答案都在这里：

| 场景 | 选择 | 判断依据 |
|---|---|---|
| 一组会变化的数据 | 列表 `list` | 有顺序、会增删、按位置访问 |
| 按名字查找的映射 | 字典 `dict` | 需要快速定位、键唯一 |
| 数量固定、值不会变 | 元组 `tuple` | 如坐标、日期、配置 |
| 次数已知 | `for` | 能遍历一个序列 |
| 次数未知 / 依赖用户输入 | `while` | 条件为真就一直转 |
| 把一段逻辑命名复用 | 函数 | 行为，不需要状态 |
| 把数据 + 行为打包成"一类事物" | 类 | 需要多个对象各持状态 |
| "是一个"（is-a） | 继承 | `Dog is a Animal` |
| "有一个"（has-a） | 组合 | `Car has an Engine` |
| 用逗号分隔的表格 | CSV | 能用 Excel 打开 |
| 有嵌套结构的数据 | JSON | 字典套列表、列表套字典 |
| 可能出错的操作 | `try/except` | 且要**明确**捕获异常类型 |

### 2.3 一个完整项目的骨架

不管是哪个项目，结构都长这样：

```python
# main.py —— 项目骨架

# 1）导入
import json
import os

# 2）常量配置
DATA_FILE = "data.json"

# 3）数据模型（类）
class Item:
    """一条数据。"""
    def __init__(self, title, value=0):
        self.title = title
        self.value = value

    def __str__(self):
        return f"{self.title} ({self.value})"


# 4）业务逻辑（函数）—— 核心逻辑必须是纯函数，方便测试
def add_items(items, new_items):
    """合并两个列表，返回新列表。"""
    return items + new_items


def summarize(items):
    """统计数据，返回字典。"""
    if not items:
        return {"count": 0, "total": 0, "max": None}
    values = [item.value for item in items]
    return {
        "count": len(items),
        "total": sum(values),
        "max": max(values),
    }


# 5）持久化层
def load_data(filename=DATA_FILE):
    """从文件加载，失败时返回空列表而不是崩溃。"""
    try:
        with open(filename, "r", encoding="utf-8") as f:
            data = json.load(f)
        return [Item(d["title"], d["value"]) for d in data]
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        return []


def save_data(items, filename=DATA_FILE):
    """保存到文件。"""
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(
            [{"title": i.title, "value": i.value} for i in items],
            f,
            ensure_ascii=False,
            indent=2,
        )


# 6）用户交互层
def main():
    """程序入口。"""
    items = load_data()
    print(f"已加载 {len(items)} 条数据")

    while True:
        print("\n1. 查看统计  2. 添加数据  3. 保存退出")
        choice = input("请选择：")

        if choice == "1":
            stats = summarize(items)
            for key, value in stats.items():
                print(f"  {key}: {value}")
        elif choice == "2":
            try:
                title = input("标题：")
                value = int(input("数值："))
                items.append(Item(title, value))
                print(f"已添加：{items[-1]}")
            except ValueError:
                print("数值必须是整数")
        elif choice == "3":
            save_data(items)
            print("已保存，再见！")
            break
        else:
            print("无效选项")


# 7）入口保护：只有直接运行这个文件时才执行 main
if __name__ == "__main__":
    main()
```

**这个骨架的四个设计要点**（每个都是阶段 1 的知识点）：

1. **核心逻辑与 I/O 分离**：`add_items` 和 `summarize` 不碰文件、不碰 `input`，所以能直接写单元测试；只有 `load_data`/`save_data`/`main` 负责 I/O。
2. **类负责承载状态，函数负责处理逻辑**：`Item` 只管存数据，`summarize` 只管算统计。
3. **加载失败降级而不是崩溃**：`except FileNotFoundError: return []`，让程序第一次运行时也能正常开始。
4. **`if __name__ == "__main__"`**：让文件既能当模块被导入（测试用），又能当脚本直接运行。这是 Python 的标准惯例。

### 2.4 排错思路（最实用的一节）

遇到报错时，**按这个顺序查，不要乱试**：

```
第1 步：读报错的最后一行
        异常类型名告诉你"哪一类问题"
        IndentationError  → 缩进
        NameError         → 名字拼错/没用过
        SyntaxError       → 语法（漏冒号、括号不匹配）
        TypeError         → 类型不对（str 和 int 加在一起）
        ValueError        → 类型对但值不合法
        IndexError        → 越界
        KeyError          → 字典里没这个键
        AttributeError    → 对象没这个方法/属性
        ZeroDivisionError → 除以 0
        FileNotFoundError → 文件不存在
        ModuleNotFoundError → import 的模块找不到

第 2 步：看报错中间的行号和箭头 ^
        定位到出问题的**具体那一行**

第 3 步：把这一行逐段拆开看
        括号配对了吗？冒号写了吗？缩进对了吗？
        变量名和上面定义的一致吗？

第 4 步：往上找"这个名字定义了吗"
        NameError 90% 是这里出了问题

第 5 步：print 出来看中间值
        在出错行**之前**插一行 print，观察变量到底是什么
```

**三个最高频报错的快速定位**：

**① `IndentationError`**
```python
# INTENTIONALLY-BROKEN 演示
def greet(name)
    print(name)        # 少冒号
```
```
  File "x.py", line 2
    print(name)
IndentationError: expected an indented block
```
查两处：`def` 行末有没有冒号；函数体的缩进是不是 4 个空格。

**② `NameError`**
```python
# INTENTIONALLY-BROKEN 演示
print(total)          # 先用了，还没定义
total = 100
```
```
NameError: name 'total' is not defined
```
查一处：这个名字定义了吗？定义在使用**之后**了吗？大小写拼错了吗？（`Total` 和 `total` 是两个名字）

**③ `TypeError`**
```
TypeError: can only concatenate str (not "int") to str
```
查一处：`input()` 的结果要用 `int()` / `float()` 转；或者两个操作数类型不匹配。

```python
# self_check.py —— 用代码把前 11 章串起来

def check_basics():
    """检查基础语法：变量、类型、格式化。"""
    name = "小明"
    age = 18
    height = 1.75
    is_student = True

    # 类型转换
    age_str = str(age)
    age_int = int(age_str)

    # f-string格式化
    message = f"{name} 今年 {age} 岁，身高 {height:.2f} 米"
    return message, age_int, is_student


def check_collections():
    """检查列表和字典操作。"""
    # 列表
    fruits = ["苹果", "香蕉"]
    fruits.append("橙子")
    fruits.insert(1, "葡萄")
    fruits.remove("香蕉")
    first = fruits[0]
    last = fruits[-1]
    sliced = fruits[1:3]
    reversed_list = fruits[::-1]

    # 列表推导式
    numbers = [1, 2, 3, 4, 5]
    evens = [n for n in numbers if n % 2 == 0]
    squares = [n ** 2 for n in numbers]

    # 字典
    scores = {"语文": 90}
    scores["数学"] = 85
    got = scores.get("英语", 0)
    keys = list(scores.keys())
    items = list(scores.items())

    # 元组
    point = (3, 5)
    x, y = point

    return {
        "列表": fruits, "首元素": first, "末元素": last,
        "切片": sliced, "反转": reversed_list,
        "偶数": evens, "平方": squares,
        "字典": scores, "默认值": got,
        "键": keys, "键值对": items, "元组": point, "x": x,
    }


def check_control_flow():
    """检查条件与循环。"""
    # if / elif / else
    def grade(score):
        if score >= 90:
            return "A"
        elif score >= 80:
            return "B"
        elif score >= 60:
            return "C"
        else:
            return "F"

    # for + range
    total = 0
    for i in range(1, 6):
        total += i

    # while + break
    count = 0
    while True:
        count += 1
        if count >= 3:
            break

    # continue
    skipped = []
    for i in range(6):
        if i % 2 == 0:
            continue
        skipped.append(i)

    return {
        "等级": [grade(s) for s in [95, 85, 65, 45]],
        "1到5之和": total,
        "循环次数": count,
        "奇数": skipped,
    }


def check_functions():
    """检查函数与参数。"""
    def calc(*args, **kwargs):
        """可变参数。"""
        return sum(args), kwargs

    def with_default(a, b=10, *rest, **extra):
        """默认参数 + 可变参数。"""
        return a, b, rest, extra

    def pure_function(data):
        """不修改传入列表的纯函数。"""
        return data + [999]

    original = [1, 2, 3]
    result = pure_function(original)

    return {
        "可变参数": calc(1, 2, 3, x=1, y=2),
        "默认参数": with_default(1),
        "纯函数原数据": original,   # [1, 2, 3] 没被改
        "纯函数结果": result,       # [1, 2, 3, 999]
    }


# 展示
if __name__ == "__main__":
    for title, func in [
        ("基础语法", check_basics),
        ("集合类型", check_collections),
        ("流程控制", check_control_flow),
        ("函数", check_functions),
    ]:
        print("=" * 50)
        print(f"【{title}】")
        print("=" * 50)
        result = func()
        if isinstance(result, tuple):
            for i, item in enumerate(result, 1):
                print(f"  {i}. {item}")
        elif isinstance(result, dict):
            for key, value in result.items():
                print(f"  {key}: {value}")
        print()
```

### 示例 2：类 + 继承的完整复习

```python
# class_review.py —— 类的全部要素复习

class Shape:
    """抽象基类。"""
    def __init__(self, name):
        self.name = name

    def area(self):
        """子类必须重写。"""
        raise NotImplementedError("子类必须重写 area()")

    def describe(self):
        """共有的方法，所有子类都能用。"""
        return f"{self.name}的面积是 {self.area():.2f}"


class Rectangle(Shape):
    """矩形。"""
    def __init__(self, width, height):
        super().__init__("矩形")
        self.width = width
        self.height = height

    def area(self):
        """重写父类方法。"""
        return self.width * self.height


class Circle(Shape):
    """圆形。"""
    PI = 3.14159

    def __init__(self, radius):
        super().__init__("圆形")
        self.radius = radius

    def area(self):
        return self.PI * self.radius ** 2


class Square(Rectangle):
    """正方形 —— 多层继承。"""
    def __init__(self, side):
        super().__init__(side, side)

    def describe(self):
        """重写父类的方法。"""
        return f"正方形，边长 {self.width}"


# 多态验证
shapes = [Rectangle(3, 4), Circle(2), Square(5)]

for shape in shapes:
    print(shape.describe())

print()

# 属性名与方法名不能重名（常见错误）
class BadDemo:
    """INTENTIONALLY-BROKEN 演示：属性名和方法名重名会互相覆盖"""
    def __init__(self):
        self.perimeter = 10      # 属性

    def perimeter(self):         # 同名方法覆盖了属性
        return 20

# 正确做法：给属性加前缀区分
class GoodDemo:
    def __init__(self, width, height):
        self._perimeter_value = 2 * (width + height)

    def perimeter(self):
        return self._perimeter_value


good = GoodDemo(3, 4)
print(f"正确写法：perimeter() = {good.perimeter()}")   # 14
```

```python
# file_review.py —— 文件与异常的完整复习

import json
import csv
import os
import tempfile


def file_basics_demo():
    """读写文件与三种模式。"""
    filename = "复习_文件.txt"

    # w：写入并清空
    with open(filename, "w", encoding="utf-8") as f:
        f.write("第一行\n")

    # a：追加
    with open(filename, "a", encoding="utf-8") as f:
        f.write("第二行\n")

    # r：读取全部
    with open(filename, "r", encoding="utf-8") as f:
        content = f.read()

    # 逐行读（推荐方式）
    lines = []
    with open(filename, "r", encoding="utf-8") as f:
        for line in f:
            lines.append(line.strip())

    os.remove(filename)
    return content, lines


def json_demo():
    """JSON 读写。"""
    filename = "复习_data.json"
    data = {"name": "小明", "scores": [90, 85, 92], "active": True}

    # 写
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

    # 读
    with open(filename, "r", encoding="utf-8") as f:
        loaded = json.load(f)

    os.remove(filename)
    return loaded, loaded == data


def csv_demo():
    """CSV 读写。"""
    filename = "复习_data.csv"
    rows = [["姓名", "成绩"], ["小明", 92], ["小红", 88]]

    # 写
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        for row in rows:
            writer.writerow(row)

    # 读
    with open(filename, "r", newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        data = list(reader)

    os.remove(filename)
    return data


def exception_demo():
    """四种异常结构。"""
    results = []

    # try / except
    try:
        int("abc")
    except ValueError as error:
        results.append(f"捕获异常：{error}")

    # try / except / else
    try:
        value = int("42")
    except ValueError:
        results.append("不该走到这里")
    else:
        results.append(f"else 分支：转换成功 {value}")

    # try / finally
    def with_finally():
        try:
            return "try 的返回值"
        finally:
            results.append("finally 一定会执行")

    with_finally()

    # 主动抛出
    def validate(age):
        if age < 0:
            raise ValueError("年龄不能为负")
        return True

    try:
        validate(-1)
    except ValueError as error:
        results.append(f"主动抛出被捕获：{error}")

    return results


if __name__ == "__main__":
    print("【文件读写】")
    print(file_basics_demo())

    print("\n【JSON】")
    print(json_demo())

    print("\n【CSV】")
    print(csv_demo())

    print("\n【异常】")
    for item in exception_demo():
        print(" ", item)
```

### 示例 4：pytest 复习（可直接运行的测试文件）

```python
# test_review.py —— 这是一个可以直接运行的 pytest 测试文件

import json
import os
import tempfile

import pytest


# ===== 被测函数 =====
def add(a, b):
    """两数相加。"""
    return a + b


def divide(a, b):
    """两数相除，除零抛异常。"""
    return a / b


class Account:
    """账户类。"""
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须大于 0")
        self.balance += amount
        return self.balance


class SavingsAccount(Account):
    """储蓄账户，比普通账户多一个利率。"""
    def __init__(self, owner, balance=0, rate=0.03):
        super().__init__(owner, balance)
        self.rate = rate

    def add_interest(self):
        """计算利息。"""
        interest = self.balance * self.rate
        self.balance += interest
        return interest


# ===== 测试函数 =====
def test_add():
    """正常用例。"""
    assert add(2, 3) == 5
    assert add(-1, 1) == 0


@pytest.mark.parametrize("a,b,expected", [
    (10, 2, 5.0),
    (9, 3, 3.0),
    (-10, 2, -5.0),
])
def test_divide(a, b, expected):
    """参数化测试。"""
    assert divide(a, b) == expected


def test_divide_by_zero():
    """异常用例。"""
    with pytest.raises(ZeroDivisionError):
        divide(10, 0)


# ===== 测试类 =====
class TestAccount:
    def test_default_balance(self):
        assert Account("小明").balance == 0

    def test_deposit(self):
        account = Account("小明", 100)
        account.deposit(50)
        assert account.balance == 150

    @pytest.mark.parametrize("amount", [0, -1, -100])
    def test_invalid_deposit(self, amount):
        """异常用例：非法金额。"""
        with pytest.raises(ValueError):
            Account("小明").deposit(amount)


class TestSavingsAccount:
    """测试继承。"""
    def test_inherits_account_attributes(self):
        account = SavingsAccount("小红", 1000)
        assert account.owner == "小红"
        assert account.balance == 1000

    def test_default_rate(self):
        assert SavingsAccount("小红").rate == 0.03

    def test_add_interest(self):
```

### 示例 5：一个小而完整的项目（类 + JSON + 异常）

阶段 1 学的东西能不能串起来，用一个 40 行的记账本就看得出来：类负责状态，JSON 负责持久化，
异常负责「文件不在」「文件坏了」「输入非法」这三种现实情况。

```python
# ledger.py —— 换成你自己的路径也能直接跑
import json
import os
import tempfile


class Ledger:
    def __init__(self, path):
        self.path = path
        self.items = []
        self.load()

    def load(self):
        try:
            with open(self.path, encoding="utf-8") as f:
                self.items = json.load(f)
        except FileNotFoundError:
            self.items = []          # 第一次运行：没有文件是正常的
        except json.JSONDecodeError:
            self.items = []          # 文件坏了：不崩，从空账本开始
            print("！账本文件损坏，已重置")

    def add(self, kind, amount, note=""):
        if kind not in ("收", "支"):
            raise ValueError("kind 只能是「收」或「支」")
        if amount <= 0:
            raise ValueError("金额必须大于 0")
        self.items.append({"kind": kind, "amount": amount, "note": note})

    def income(self):
        return sum(i["amount"] for i in self.items if i["kind"] == "收")

    def spend(self):
        return sum(i["amount"] for i in self.items if i["kind"] == "支")

    def balance(self):
        return self.income() - self.spend()

    def save(self):
        with open(self.path, "w", encoding="utf-8") as f:
            json.dump(self.items, f, ensure_ascii=False, indent=2)


path = os.path.join(tempfile.mkdtemp(), "ledger.json")
book = Ledger(path)
print("空账本：", book.items, "余额", book.balance())

book.add("收", 8000, "工资")
book.add("支", 1200, "房租")
book.add("支", 35.5, "午饭")
print(f"收入 {book.income()} 支出 {book.spend()} 余额 {book.balance()}")

book.save()
print("写入文件：", os.path.basename(path), os.path.getsize(path), "字节")

again = Ledger(path)             # 重新读一次，验证真的落盘了
print("重新读入条数：", len(again.items), "余额", again.balance())

for kind, amount in (("借", 100), ("支", 0)):
    try:
        again.add(kind, amount)
    except ValueError as e:
        print("拒绝：", e)
```

运行结果：

```text
空账本： [] 余额 0
收入 8000 支出 1235.5 余额 6764.5
写入文件： ledger.json 225 字节
重新读入条数： 3 余额 6764.5
拒绝： kind 只能是「收」或「支」
拒绝： 金额必须大于 0
```

四个值得注意的设计点：

- **`load()` 在 `__init__` 里调**，所以「新建对象」永远等于「拿到当前磁盘状态」，调用方不用记得先加载。
- **两个 `except` 分开写**：`FileNotFoundError` 是正常的第一次运行，`JSONDecodeError` 是异常情况——
  虽然处理方式都是「空账本」，但后者要打印提示，合成一个 `except` 就把这两种情况混在一起了。
- **`add()` 主动抛 `ValueError`**：与其让非法数据进账本、后面算错总额，不如在入口就拦住。
- **`save()` 用 `ensure_ascii=False`**：否则文件里存的是 `\u5de5\u8d44` 这种转义，肉眼没法校对。

## 五、参考答案

### 参考答案 11-1（知识自查答案）

| 考点 | 答案 |
|---|---|
| 索引 | `lst[-1]` 是最后一个元素。因为负索引从末尾往回数，`lst[len(lst)]` 会越界（合法下标只到 `len(lst)-1`） |
| 切片 | `[1:4]` 长度是 3。因为左闭右开，长度 = `stop - start` = 4 - 1 = 3 |
| 短路求值 | `and` 从左往右求值。`if x and x[0]==1` 先判断 `x` 是否为空列表（空列表为假直接短路），安全；反过来的写法会先访问 `x[0]`，空列表立刻 IndexError |
| 副本语义 | **会改到**。列表是可变对象，Python 传参传的是地址，函数内的 `append` 修改的就是原列表。整数/字符串这类不可变类型则不会 |
| 默认参数 | 因为默认参数在**函数定义时**只求值一次，那个列表被所有调用共享，会导致第二次调用出现第一次的数据。要用 `todo=None` 再在函数内 `if todo is None: todo = []` |
| `self` | 因为调用对象方法时（如 `obj.method()`），Python 会自动把 `obj` 作为第一个参数传入。不写 `self` 就会参数数量不匹配，或函数内访问 `self.xxx` 时报 NameError |
| 继承 | 父类的 `__init__` **不会自动执行**。不调用的话父类设置的属性（如 `self.name`）永远不存在，访问时会报 `AttributeError` |
| `is None` | 因为 `None` 是唯一的单例对象，`is` 判断的是身份，语义准确且快。而 `==` 比较内容，如果某个类重写了 `__eq__` 允许自己等于 `None`，那 `== None` 就会意外成立 |
| `w` 模式 | 会**清空原文件的所有内容**，然后从零开始写。如果本意是"追加"，就会无声地丢失所有旧数据。要追加必须用 `a` |
| `with` | ① 自动关闭文件，且即使块内抛异常也保证关闭（防文件句柄泄漏）；② 出块后 `f` 变量本身失效，强制你把内容存到别的变量，养成好习惯 |
| `except` | 裸 `except:` 会捕获一切，包括 `KeyboardInterrupt`（导致 Ctrl+C 失效）和 `SystemExit`，还会静默吞掉真正的代码 bug（NameError、TypeError），让问题在别处才暴露，排查成本极高 |
| pytest | 文件必须是 `test_*.py`，函数必须是 `test_*`，测试类是 `Test*` 且不能有 `__init__`。命名错了 pytest 显示 `collected 0 items`，**不报错但完全不执行** |
| PEP 8 | 一行不超过 79 字符（现代代码库放宽到 99）；缩进统一 4 个空格，绝不混用 Tab；运算符两侧加空格，逗号后加一个空格 |

### 参考答案 11-2（综合项目 1：待办管理器完整实现）

```python
# todo_manager.py —— 综合项目 1：命令行待办事项管理器

import json
import os
import csv

TODO_FILE = "todos.json"
PRIORITY_ORDER = {"高": 0, "中": 1, "低": 2}
STOP_WORDS = set()


class Task:
    """一个待办任务。"""
    def __init__(self, title, priority="中", done=False, created_at=None):
        if priority not in PRIORITY_ORDER:
            raise ValueError("优先级必须是高、中、低之一")
        self.title = title
        self.priority = priority
        self.done = done
        self.created_at = created_at or self._now()

    @staticmethod
    def _now():
        from datetime import datetime
        return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    def complete(self):
        """标记完成，返回自身支持链式调用。"""
        self.done = True
        return self

    def undo(self):
        """取消完成。"""
        self.done = False
        return self

    def toggle(self):
        """切换完成状态。"""
        self.done = not self.done
        return self

    def matches(self, keyword):
        """是否包含关键字（不区分大小写）。"""
        return keyword.lower() in self.title.lower()

    def to_dict(self):
        return {
            "title": self.title,
            "priority": self.priority,
            "done": self.done,
            "created_at": self.created_at,
        }

    @classmethod
    def from_dict(cls, data):
        return cls(
            title=data["title"],
            priority=data.get("priority", "中"),
            done=data.get("done", False),
            created_at=data.get("created_at"),
        )

    def __str__(self):
        mark = "✓" if self.done else "○"
        return f"{mark} [{self.priority}] {self.title}"


class TodoManager:
    """待办管理器：负责所有业务逻辑与数据持久化。"""

    def __init__(self, filename=TODO_FILE):
        self.filename = filename
        self.tasks = []
        self.load()

    # ===== 持久化 =====
    def load(self):
        """从文件加载，失败时降级为空列表。"""
        try:
            with open(self.filename, "r", encoding="utf-8") as f:
                data = json.load(f)
            self.tasks = [Task.from_dict(item) for item in data]
            print(f"已从 {self.filename} 加载 {len(self.tasks)} 个任务")
        except FileNotFoundError:
            self.tasks = []
            print(f"{self.filename} 不存在，从空列表开始")
        except json.JSONDecodeError:
            self.tasks = []
            print(f"{self.filename} 内容损坏，已重置为空列表")
        except Exception as error:
            self.tasks = []
            print(f"加载失败：{error}")

    def save(self):
        """保存到文件。"""
        try:
            data = [task.to_dict() for task in self.tasks]
            with open(self.filename, "w", encoding="utf-8") as f:
                json.dump(data, f, ensure_ascii=False, indent=2)
            print(f"已保存到 {self.filename}")
        except Exception as error:
            print(f"保存失败：{error}")

    # ===== 增删改查 =====
    def add(self, title, priority="中"):
        """添加任务，标题重复时返回 False。"""
        title = title.strip()
        if not title:
            print("标题不能为空")
            return False
        if any(task.title == title for task in self.tasks):
            print(f"任务 '{title}' 已存在")
            return False
        try:
            self.tasks.append(Task(title, priority))
            print(f"已添加：{self.tasks[-1]}")
            return True
        except ValueError as error:
            print(f"添加失败：{error}")
            return False

    def find(self, title):
        """按标题找任务，找不到返回 None。"""
        for task in self.tasks:
            if task.title == title:
                return task
        return None

    def toggle(self, title):
        task = self.find(title)
        if task is None:
            print(f"未找到任务：{title}")
            return False
        task.toggle()
        status = "已完成" if task.done else "已取消完成"
        print(f"'{title}' 已标记为{status}")
        return True

    def delete(self, title):
        original = len(self.tasks)
        self.tasks = [t for t in self.tasks if t.title != title]
        if len(self.tasks) < original:
            print(f"已删除：{title}")
            return True
        print(f"未找到任务：{title}")
        return False

    # ===== 查询与统计（纯函数，不做 I/O）=====
    def list_all(self, show_done=True):
        """按优先级列出任务。"""
        visible = [t for t in self.tasks if show_done or not t.done]
        visible.sort(key=lambda t: (PRIORITY_ORDER[t.priority], t.created_at))
        if not visible:
            print("  （没有任务）")
            return []
        print(f"  共 {len(visible)} 个任务：")
        for task in visible:
            print(f"    {task}")
        return visible

    def search(self, keyword):
        """按关键字搜索。"""
        found = [t for t in self.tasks if t.matches(keyword)]
        if not found:
            print(f"  没有包含 '{keyword}' 的任务")
            return []
        print(f"  找到 {len(found)} 个任务：")
        for task in found:
            print(f"    {task}")
        return found

    def statistics(self):
        """统计信息。"""
        total = len(self.tasks)
        done = len([t for t in self.tasks if t.done])
        by_priority = {}
        for priority in PRIORITY_ORDER:
            count = len([t for t in self.tasks if t.priority == priority])
            by_priority[priority] = count
        return {
            "总数": total,
            "已完成": done,
            "待办": total - done,
            "高优先级": by_priority["高"],
            "中优先级": by_priority["中"],
            "低优先级": by_priority["低"],
            "完成率": f"{done / total * 100:.1f}%" if total else "0.0%",
        }

    def export_csv(self, filename="todos.csv"):
        """导出为 CSV。"""
        try:
            with open(filename, "w", newline="", encoding="utf-8-sig") as f:
                writer = csv.writer(f)
                writer.writerow(["标题", "优先级", "状态", "创建时间"])
                for task in self.tasks:
                    writer.writerow([
                        task.title,
                        task.priority,
                        "已完成" if task.done else "待办",
                        task.created_at,
                    ])
            print(f"已导出到 {filename}")
            return True
        except Exception as error:
            print(f"导出失败：{error}")
            return False


# ===== 用户交互 =====
MENU = """
```

```python
# 设计要点：分析逻辑是纯函数（不碰文件、不碰 input），所以最容易测试

import json
import csv
import os

DATA_FILE = "scores.json"
REPORT_FILE = "report.csv"


# ===== 数据加载 =====
def load_scores(filename=DATA_FILE):
    """读取成绩数据。文件不存在或损坏时返回空列表。"""
    try:
        with open(filename, "r", encoding="utf-8") as f:
            data = json.load(f)
    except FileNotFoundError:
        print(f"找不到文件 {filename}，将使用空数据集")
        return []
    except json.JSONDecodeError:
        print(f"{filename} 不是合法的 JSON 文件")
        return []
    except OSError as error:
        print(f"读取失败：{error}")
        return []

    # 校验每一项：必须有 name，且各科成绩是数字
    valid = []
    for index, item in enumerate(data):
        try:
            record = {
                "name": str(item["name"]),
                "math": float(item["math"]),
                "english": float(item["english"]),
            }
            valid.append(record)
        except (KeyError, TypeError, ValueError):
            print(f"  第 {index + 1} 条数据格式有误，已跳过")
    return valid


# ===== 纯函数：所有分析逻辑都在这里 =====
def subject_stats(scores, subject):
    """返回某科目的平均分、最高分、最低分。

    subject: "math" 或 "english"
    """
    values = [s[subject] for s in scores]
    if not values:
        return {"平均分": 0.0, "最高分": 0.0, "最低分": 0.0, "人数": 0}
    return {
        "平均分": sum(values) / len(values),
        "最高分": max(values),
        "最低分": min(values),
        "人数": len(values),
    }


def add_total(scores):
    """返回带总分字段的成绩列表（不修改入参）。"""
    return [
        {**s, "total": s["math"] + s["english"]}
        for s in scores
    ]


def ranking(scores):
    """总分排名榜（降序）。"""
    with_total = add_total(scores)
    return sorted(with_total, key=lambda s: s["total"], reverse=True)


def subject_toppers(scores, subject):
    """某科目的第一名（并列时返回全部）。"""
    if not scores:
        return []
    best = max(s[subject] for s in scores)
    return [s["name"] for s in scores if s[subject] == best]


def failed_students(scores, pass_line=60):
    """需要补考的学生（任一科 < 60）。"""
    failed = []
    for s in scores:
        subjects = [name for name in ("math", "english") if s[name] < pass_line]
        if subjects:
            failed.append({
                "name": s["name"],
                "failed_subjects": subjects,
            })
    return failed


def class_overview(scores):
    """班级总览。"""
    if not scores:
        return {"人数": 0, "班级平均总分": 0.0}
    with_total = add_total(scores)
    return {
        "人数": len(scores),
        "班级平均总分": sum(s["total"] for s in with_total) / len(scores),
        "最高总分": max(s["total"] for s in with_total),
        "最低总分": min(s["total"] for s in with_total),
    }


# ===== 报告导出 =====
def export_report(scores, filename=REPORT_FILE):
    """把排名导出为 CSV。"""
    try:
        with open(filename, "w", newline="", encoding="utf-8-sig") as f:
            writer = csv.writer(f)
            writer.writerow(["排名", "姓名", "数学", "英语", "总分"])
            for rank, s in enumerate(ranking(scores), 1):
                writer.writerow([
                    rank, s["name"], s["math"], s["english"], s["total"],
                ])
        print(f"报告已导出到 {filename}")
        return True
    except Exception as error:
        print(f"导出失败：{error}")
        return False


def generate_sample_data(filename=DATA_FILE):
    """生成一份示例数据，方便演示。"""
    data = [
        {"name": "小明", "math": 92, "english": 88},

    with open(filename, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    print(f"已生成示例数据：{filename}")
    return data


# ===== 主流程 =====
```

```python
# text_analyzer.py —— 综合项目 3：文本统计工具

import json
import os
import re
import sys

STOP_WORDS = {
    "的", "了", "是", "在", "和", "有", "我", "你", "他", "她", "它",
    "这", "那", "就", "都", "而", "及", "与", "着", "或", "一个", "没有",
    "我们", "你们", "他们", "这个", "那个", "什么", "可以", "因为", "所以",
    "但是", "如果", "这样", "那样", "自己", "已经", "还是", "就是", "不是",
    # 英文常见停用词
    "the", "a", "an", "is", "are", "was", "were", "and", "or", "of",
    "to", "in", "on", "at", "it", "this", "that",
}


def clean_text(text):
    """清洗文本：去掉多余空白，统一为单个空格分隔。"""
    return re.sub(r"\s+", " ", text).strip()


def count_chars(text, include_spaces=False):
    """统计字符数。"""
    if include_spaces:
        return len(text)
    return len(text.replace(" ", "").replace("\n", "").replace("\t", ""))


def count_words(text):
    """统计单词数（中文按连续汉字计为一个词，英文按空格切分）。

    这是本项目的核心难点：用正则把中英文分别处理。
    """
    # 英文单词：连续字母
    english = re.findall(r"[a-zA-Z]+", text)
    # 中文：连续的汉字串算一个"词"
    chinese = re.findall(r"[\u4e00-\u9fff]+", text)
    return len(english) + len(chinese)


def count_lines(text):
    """统计行数。"""
    if not text:
        return 0
    return len(text.split("\n"))


def count_sentences(text):
    """统计句子数（按中英文句号、问号、感叹号划分）。"""
    sentences = re.split(r"[。！？.!?]+", text)
    # 过滤掉空白片段
    return len([s for s in sentences if s.strip()])


def tokenize(text):
    """把文本切分成词列表（中英文都处理）。"""
    tokens = re.findall(r"[a-zA-Z]+|[\u4e00-\u9fff]+", text)
    return [t.lower() for t in tokens]


def word_frequency(text, remove_stop_words=True, min_length=1):
    """统计词频，返回 {词: 次数}。"""
    tokens = tokenize(text)
    counts = {}
    for token in tokens:
        if len(token) < min_length:
            continue
        if remove_stop_words and token in STOP_WORDS:
            continue
        counts[token] = counts.get(token, 0) + 1
    return counts


def top_words(text, n=10, remove_stop_words=True):
    """返回出现频率最高的 n 个词。"""
    counts = word_frequency(text, remove_stop_words)
    # 先按次数降序，次数相同时按词本身排序，保证结果稳定
    return sorted(counts.items(), key=lambda x: (-x[1], x[0]))[:n]


def analyze_text(text):
    """综合分析，返回完整结果字典。这是核心的纯函数。"""
    cleaned = clean_text(text)
    counts = word_frequency(cleaned)
    return {
        "字符数": count_chars(cleaned),
        "字符数_含空格": count_chars(cleaned, include_spaces=True),
        "单词数": count_words(cleaned),
        "句子数": count_sentences(cleaned),
        "行数": count_lines(text),
        "不同词数": len(counts),
        "总词频": sum(counts.values()),
        "高频词": dict(top_words(cleaned, 10)),
        "平均句长": (
            round(count_words(cleaned) / count_sentences(cleaned), 2)
            if count_sentences(cleaned) > 0 else 0.0
        ),
    }


def analyze_file(filepath, remove_stop_words=True):
    """分析单个文件，容错处理各种异常。"""
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            text = f.read()
    except FileNotFoundError:
        return {"错误": f"文件不存在：{filepath}"}
    except UnicodeDecodeError:
        # 尝试其他编码
        for encoding in ("gbk", "utf-8-sig", "latin-1"):
            try:
                with open(filepath, "r", encoding=encoding) as f:
                    text = f.read()
                break
            except UnicodeDecodeError:
                continue
        else:
            return {"错误": f"无法解码文件（编码不匹配）：{filepath}"}
    except IsADirectoryError:
        return {"错误": f"这是一个目录，不是文件：{filepath}"}
    except PermissionError:
        return {"错误": f"没有读取权限：{filepath}"}
    except OSError as error:
        return {"错误": f"读取失败：{error}"}

    if not text.strip():
        return {"错误": f"文件是空的：{filepath}"}

    result = analyze_text(text)
    result["文件"] = filepath
    result["文件名"] = os.path.basename(filepath)
    result["过滤停用词"] = remove_stop_words
    return result


def save_report(results, filename="text_report.json"):
    """把分析结果保存为 JSON。"""
    try:
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(results, f, ensure_ascii=False, indent=2)
        print(f"报告已保存到 {filename}")
        return True
    except Exception as error:
        print(f"保存失败：{error}")
        return False


def print_report(result):
    """格式化打印分析结果。"""
    if "错误" in result:
        print(f"  [错误] {result['错误']}")
        return

    print(f"\n{'=' * 46}")
    print(f"文件：{result['文件名']}")
    print(f"{'=' * 46}")
    print(f"  字符数（不含空格）：{result['字符数']}")
    print(f"  字符数（含空格）：  {result['字符数_含空格']}")
    print(f"  单词数：    {result['单词数']}")
    print(f"  句子数：    {result['句子数']}")
    print(f"  行数：      {result['行数']}")
    print(f"  不同词数：  {result['不同词数']}")
    print(f"  平均句长：  {result['平均句长']}")
    print(f"  高频词 Top 10：")
    for word, count in result["高频词"].items():
        bar = "█" * min(count, 20)
        print(f"    {word:<12}{count:>4} 次 {bar}")


def main():
    print("=" * 50)
    print("文本统计工具")
    print("=" * 50)

    # 命令行参数传入文件，或者交互式输入
    if len(sys.argv) > 1:
        files = sys.argv[1:]
        print(f"\n分析 {len(files)} 个文件：")
    else:
        print("\n请输入要分析的文件路径（多个用空格分隔）：")
        user_input = input("> ").strip()
        files = user_input.split() if user_input else []

    if not files:
        print("没有指定文件。示例：python text_analyzer.py article.txt")
        # 用示例文本演示
        demo = "Python 是一种编程语言。它简单易学，功能强大。Python 在数据科学领域应用广泛。"
        print("\n=== 示例文本分析 ===")
        result = analyze_text(demo)
        result["文件名"] = "（内置示例）"
        result["文件"] = "内存"
        result["过滤停用词"] = True
        print_report(result)
        return

    results = []
    for filepath in files:
        result = analyze_file(filepath)
        print_report(result)
        results.append(result)

    # 汇总
    successful = [r for r in results if "错误" not in r]
    if successful:
        print(f"\n{'=' * 46}")
        print(f"汇总：成功分析 {len(successful)} 个文件，"
              f"失败 {len(results) - len(successful)} 个")
        total_words = sum(r["单词数"] for r in successful)
        print(f"总单词数：{total_words}")

        if input("\n是否保存报告到 JSON？(y/n)：").lower() == "y":
            save_report(results)


if __name__ == "__main__":
    main()
```

```python
# 关卡验收 2：含继承的三层类设计

class Vehicle:
    """交通工具基类。"""
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __str__(self):
        return f"{self.name}（{type(self).__name__}，{self.price} 元）"

    def describe(self):
        """基类的通用描述，子类可以重写。"""
        return f"这是一辆 {self.name}"


class Car(Vehicle):
    """汽车。"""
    def __init__(self, name, price, fuel_consumption):
        super().__init__(name, price)
        self.fuel_consumption = fuel_consumption    # 每百公里耗油量

    def fuel_cost(self, distance, price_per_liter=8):
        """计算行驶指定距离的油费。"""
        liters = distance / 100 * self.fuel_consumption
        return liters * price_per_liter


class ElectricCar(Car):
    """电动汽车 —— 继承 Car，但重写相关方法。"""
    def __init__(self, name, price, battery_capacity):
        super().__init__(name, price, fuel_consumption=0)
        self.battery_capacity = battery_capacity      # 电池容量 kWh
        self.charge = 100                             # 剩余电量百分比

    def fuel_cost(self, distance, price_per_liter=0):
        """★ 重写：电动车不用油，用电。"""
        electricity_per_100km = 15                   # 百公里耗电 15 度
        kwh = distance / 100 * electricity_per_100km
        return kwh * 0.6                             # 电价 0.6 元/度

    def describe(self):
        """★ 重写：用父类信息 + 自己的信息。"""
        return f"{super().describe()}，纯电动，电池 {self.battery_capacity} kWh"
```

## 七、本单元验收自测（综合 10 题）

**1.** `lst = [1,2,3,4,5]`，`lst[1:4]` 和 `lst[1:4:2]` 分别是什么？
> **要点**：`lst[1:4]` = `[2, 3, 4]`（含索引 1 不含 4）；`lst[1:4:2]` = `[2, 4]`（每 2 个取一个）。

**2.** `def f(a, b=[]): b.append(a); return b`，连续调 `f(1)`、`f(2)`、`f(3)` 分别返回什么？
> **要点**：`[1]`、`[1, 2]`、`[1, 2, 3]`。因为默认参数 `[]` 在函数定义时只求值一次，被所有调用共享。这是最隐蔽的 bug 之一。

**3.** 下面代码输出什么？
```python
def modify(lst):
    lst = lst[:]
    lst.append(4)

data = [1, 2, 3]
modify(data)
print(data)
```
> **要点**：`[1, 2, 3]`。函数内先造了副本（`lst = lst[:]`），后面的 `append` 只改了副本，外部的 `data` 不受影响。这是防止"函数修改原列表"的标准手法。

**4.** `class A: def __init__(self): self.x = 1` 换成多行写法时，最容易漏掉什么？
> **要点**：漏掉冒号 `:` 和缩进。正确写法是：
```python
class A:
    def __init__(self):
        self.x = 1
```
> `class` 体是 4 空格缩进，方法 `def` 同为 4 空格，方法体为 8 空格。

**5.** 子类的 `__init__` 里不写 `super().__init__()`，父类设置的属性会怎样？
> **要点**：父类的 `__init__` 根本不会执行，它设置的属性（如 `self.name`）在对象上根本不存在，访问时抛 `AttributeError: 'Child' object has no attribute 'name'`。

**6.** 用 `open("f.txt", "w")` 打开一个已有文件然后写一行，会发生什么？
> **要点**：文件被**清空**，原内容全部丢失。`"w"` 是"清空后重写"。想追加必须用 `"a"`。这是最容易造成数据丢失的操作。

**7.** 为什么不能写 `except:` ？
> **要点**：它会捕获一切，包括 `KeyboardInterrupt`（导致 Ctrl+C 失效）和 `SystemExit`，还会静默吞掉真正的代码 bug。应明确写出异常类型，如 `except ValueError:`。

**8.** 下面这个 pytest 测试为什么不会被执行？
```python
def check_add():
    assert 1 + 1 == 2
```
> **要点**：函数名不以 `test_` 开头。pytest 靠命名约定发现测试，命名不对会显示 `collected 0 items`——不报错，但什么都不跑。

**9.** 判断下面每个 `self.count = self.count + 1` 的执行结果，如果原代码是 `count = self.count + 1` 会怎样？
> **要点**：原写法（漏 `self.`）只创建了一个局部变量，函数结束就消失，`self.count` 永远是 0。这是最常见的类编写错误之一。

**10.** 下面哪一句最能解释「函数传列表会改到原列表、传整数不会」？
> A. 因为 Python 不复制参数
> B. 因为列表是引用类型，修改它就是修改原对象；整数赋值只是让局部名字指向了新对象
> **要点**：**B** 更准确。A 是对的但不完整——真正的原因是：Python 传递的是"指向对象的引用"。列表这个对象可变，改它的内容 = 改原件；整数不可变，`n = n + 1` 只是让局部变量 `n` 指向了一个**新**的整数对象，原来的整数完全没动。
