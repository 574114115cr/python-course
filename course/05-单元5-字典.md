## 二、核心知识点讲解

### 2.1 列表按位置找，字典按名字找

列表的局限很明显：想找"小明的电话"，你必须记住小明在第几个位置。

```python
contacts = ["小明", "小红", "小刚"]
phones = ["13800138000", "13900139000", "13700137000"]
# 小明的电话在 phones[0]，这个"0"是隐性的、靠人脑维护的约定
```

字典把这种约定变成语言的一部分：

```python
contacts = {"小明": "13800138000", "小红": "13900139000"}
print(contacts["小明"])      # 13800138000
```

生活化类比：
- **列表 = 一排有编号的抽屉**。找东西靠数编号（第 3 个、第 7 个）。
- **字典 = 一个巨大的储物柜，每个柜门上都贴着标签**。找东西靠读标签（"小明" → 拿到他的号码）。

这个差别在数据量大时是决定性的：列表找第 100 万项要数 100 万下，字典找任何一项都是"读标签 → 命中"，**耗时基本不随数据量增长**。

### 2.2 键值对：key → value

字典里的每一项是**一个键值对**：
- **键（key）**：唯一的标签，充当索引
- **值（value）**：这个标签下存的东西

```python
user = {
    "name": "小明",     # "name" 是键，"小明" 是值
    "age": 18,
    "city": "杭州",
}
```

三条硬规则：
1. **键必须唯一**——同一个键只能有一个值，重复赋值会**覆盖**旧值。
2. **键必须不可变**——所以只能用字符串、数字、元组、布尔值、`None`，**不能用列表**（因为列表可以修改）。
3. **值可以是任何类型**，包括另一个字典、列表，甚至另一个字典。

### 2.3 新增 vs 修改：同一行代码，两种含义

这是字典最容易困惑的一点：

```python
scores = {"语文": 90}

scores["数学"] = 85# 键"数学"不存在 -> 新增一对
scores["语文"] = 95     # 键"语文"已存在 -> 修改值

print(len(scores))      # 2，只有两对，不是三对
```

Python 用最优雅的方式处理了这个问题：**赋值语句不关心是新增还是修改，它只看这个键在不在。** 你不需要写 `add()` 或 `update()`，一条 `=` 走天下。

删除键值对用 `del`：
```python
del scores["数学"]
print(scores)      # {'语文': 95}
```

### 2.4 三种遍历方式

```python
user = {"name": "小明", "age": 18, "city": "杭州"}

# 只看键
for key in user:              # 等价于 for key in user.keys():
    print(key)

# 只看值
for value in user.values():
    print(value)

# 键和值都要 —— 最常用
for key, value in user.items():
    print(f"{key}: {value}")

# 遍历字典默认只给键，这是最容易踩的坑
for item in user:
    print(item)      # 输出 "name"，不是 "name: 小明"
```

**`for key in dict` 实际等于 `for key in dict.keys()`**，因为 `dict.keys()` 返回的对象在遍历行为上等同于键本身（它是一个"视图对象"，会随字典变化而变化，这点比列表拷贝更安全）。

### 2.5 `.get()`：不 crash 的取值方式

```python
# INTENTIONALLY-BROKEN 演示：直接用方括号取不存在的键会抛 KeyError
scores = {"语文": 90, "数学": 85}

print(scores["语文"])# 90   安全
print(scores["英语"])          # KeyError: '英语'   崩了

# .get() 提供默认值，键不存在也不崩
print(scores.get("语文"))       # 90
print(scores.get("英语"))       # None（键不存在时返回 None）
print(scores.get("英语", 0))    # 0    第二个参数是默认值
```

生活化类比：`scores["英语"]` 像**直接拉开一个可能不存在的抽屉**（柜子会"咔哒"响一声表示没有）；`.get("英语", 0)` 像**先问柜管理员"有没有英语这格？没有的话给我 0"**。

`.get()` 还有一个更妙的地方：**链式访问**

```python
users = {"u1": {"name": "小明", "age": 18}}

# 传统写法：每一层都要判断是否存在，非常啰嗦
if "u1" in users:
    if "name" in users["u1"]:
        name = users["u1"]["name"]

# .get() 链式写法：简洁且永不崩溃
name = users.get("u1", {}).get("name", "未知")
#                        ↑键不存在时给一个空字典，后面的 .get() 就有东西可操作了
```

最后那个空字典 `{}` 是这个技巧的灵魂——它保证链条不会因为某层缺失而断掉。

### 2.6 遍历时能修改字典吗

**不能。** 遍历过程中修改字典会报 `RuntimeError: dictionary changed size during iteration`。

```python
d = {"a": 1, "b": 2}
# for k in d:
#     del d[k]           # RuntimeError!
```

生活化类比：你在**点名册上边点名边划掉名字**——划掉之后册子的页数变了，念到后面就会跳行出错。

正确做法：先遍历，再修改（分两步）：
```python
d = {"a": 1, "b": 2, "c": 3}
for key in list(d.keys()):      # 先复制一份键的列表
    if d[key] < 2:
        del d[key]
print(d)      # {'b': 2, 'c': 3}
```
（注意：`list(d.keys())` 是**浅拷贝键列表**，够用了，因为键本身是不可变的。）

### 2.7 嵌套结构：字典的真正威力

真实数据几乎都是嵌套的：

```python
users = {
    "u1": {"name": "小明", "age": 18, "skills": ["Python", "SQL"]},
    "u2": {"name": "小红", "age": 22, "skills": ["Java"]},
}
```

提取数据时用**连续取值**：

```python
# 取出 u1 的名字
name = users["u1"]["name"]              # 小明

# 安全取出
name = users.get("u9", {}).get("name", "查无此人")   # 查无此人

# 遍历两层
for uid, info in users.items():
    print(f"【{uid}】{info['name']}，{info['age']} 岁，会 {'、'.join(info['skills'])}")

# 统计：多少人会 Python
python_users = [
    info["name"]
    for uid, info in users.items()
    if "Python" in info["skills"]
]
print(python_users)     # ['小明']
```

这一段代码就是单元 11 那个"投票分析器"的核心结构。现在多花点时间理解它，后面会省很多力气。

### 示例 2：新增、修改、删除

```python
# dict_crud.py —— 字典的增删改查

scores = {"语文": 90, "数学": 85}

# 新增：键不存在时赋值 = 添加一对
scores["英语"] = 78
print("新增后：", scores)      # {'语文': 90, '数学': 85, '英语': 78}
print("长度：", len(scores))   # 3

# 修改：键已存在时赋值 = 改值（覆盖）
scores["数学"] = 92
print("修改后：", scores)      # {'语文': 90, '数学': 92, '英语': 78}
print("长度依然是：", len(scores))   # 3，没有变长！

# 删除：用 del
del scores["英语"]
print("删除后：", scores)      # {'语文': 90, '数学': 92}

# 删除的第二种写法：pop()，能拿到被删的值
removed = scores.pop("语文")
print("pop 出来的分数：", removed)     # 90
print("现在剩下：", scores)             # {'数学': 92}

# popitem()：删除最后加入的那一对，返回 (键, 值) 元组
scores = {"语文": 90, "数学": 92}
pair = scores.popitem()
print("popitem 返回：", pair)         # ('数学', 92)

# 清空
scores.clear()
print("清空后：", scores, "长度", len(scores))   # {} 长度 0
```

### 示例 3：三种遍历方式

```python
# dict_traverse.py —— keys / values / items

user = {"name": "小明", "age": 18, "city": "杭州"}

# 1）遍历键 —— 直接 for 就是遍历键
print("--- 遍历键 ---")
for key in user:
    print(key)
for key in user.keys():    # 等价写法，更显式
    print(key)

# 2）遍历值
print("--- 遍历值 ---")
for value in user.values():
    print(value)

# 3）遍历键值对 —— 最常用
print("--- 遍历键值对 ---")
for key, value in user.items():
    print(f"{key}: {value}")

# 常见坑：for item in user 拿到的是键，不是键值对
print("--- 陷阱演示 ---")
for item in user:
    print(f"item = {item}")
# 输出的是 name / age / city，不含值

# 想同时拿到键和值，必须用 items()
for item in user.items():
    print(f"item = {item}")        # ('name', '小明') 这种元组形式

# 综合运用：统计每个键的值是数字还是字符串
for key, value in user.items():
    print(f"{key} 的类型是{type(value).__name__}")
```

### 示例 4：get() 安全取值

```python
# dict_get.py —— .get() 的价值

scores = {"语文": 90, "数学": 85}

# 方括号取值：键不存在直接崩
print(scores["语文"])# 90
# print(scores["英语"])   # KeyError: '英语'

# .get() 取值：键不存在返回 None
print(scores.get("语文"))    # 90
print(scores.get("英语"))    # None
# 注意：返回 None 说明"键不存在"，

print(scores.get("英语", "缺考"))         # 缺考
print(scores.get("语文", 0))            # 90  键存在时忽略默认值

# 判断键是否存在
print("英语" in scores)         # False
print("语文" in scores)         # True

# 区分"不存在"和"值为 None"
data = {"a": None}
print(data.get("a"))                # None
print("a" in data)                  # True   键存在，只是值是 None
print(data.get("b", "没有这个键"))    # 没有这个键

# ===== .get() 链式访问：处理嵌套数据的利器 =====
users = {"u1": {"name": "小明", "age": 18}}

# 传统写法：啰嗦
if "u1" in users:
    if "name" in users["u1"]:
        name = users["u1"]["name"]
print(name)

# .get() 链式写法：简洁且永不崩溃
name = users.get("u9", {}).get("name", "查无此人")
print(name)      # 查无此人
# 关键在那个 {} —— u9 不存在时给一个空字典，
# 这样后面的 .get("name") 就有东西可操作，链条不断裂
```

### 示例 5：遍历与修改的正确姿势

```python
# dict_modify.py —— 遍历时能不能改字典

scores = {"语文": 90, "数学": 85, "英语": 78}

# 遍历过程中删除键值对 -> RuntimeError
# for key in scores:
#     if scores[key] < 80:
#         del scores[key]     # RuntimeError: dictionary changed size during iteration

# 正确做法一：先复制一份键的列表，再遍历副本
for key in list(scores.keys()):
    if scores[key] < 80:
        del scores[key]
print("删除低于 80 的：", scores)   # {'语文': 90, '数学': 85}

# 正确做法二：用 .items() 复制元组列表
scores = {"语文": 90, "数学": 85, "英语": 78}
for key, value in list(scores.items()):
    if value < 80:
        del scores[key]
print("结果一样：", scores)         # {'语文': 90, '数学': 85}

# 修改键的值（不改变字典大小）是允许的
scores = {"语文": 90, "数学": 85}
for key in scores:
    if scores[key] < 90:
        scores[key] += 10
print("提分后：", scores)           # {'语文': 90, '数学': 95}
# 注意：改值不改长度，所以不需要复制

# 翻面理解这个规则：
# 遍历是"照着名单念名字"，而删除会让名单页数变少，后面就念乱了。
# 但改名字内容不影响名单长度，所以是安全的。
```

```python
users = {
    "u1": {
        "name": "小明",
        "age": 18,
        "skills": ["Python", "SQL"],

total_age = 0
for uid, info in users.items():
    total_age += info["age"]

# 找出技能最多的用户
most_skilled = ""
max_count = 0
for uid, info in users.items():
    if len(info["skills"]) > max_count:
        max_count = len(info["skills"])
        most_skilled = info["name"]
print(f"技能最多的是{most_skilled}，有 {max_count} 项")
```

### 示例 7：字典的常用"全家桶"方法

```python
# dict_methods.py —— 字典常用方法速查

config = {"host": "localhost", "port": 8080, "debug": True}

# get：安全取值
print(config.get("port"))            # 8080
print(config.get("timeout", 30))     # 30

# pop：取值并删除
port = config.pop("port")
print(f"取出的端口：{port}，剩余：{config}")

# setdefault：键不存在时才设置并返回
config.setdefault("timeout", 30)
print("timeout：", config["timeout"])    # 30  新增了
config.setdefault("timeout", 60)
print("再设一次：", config["timeout"])# 30  没变，因为已存在

# update：用另一个字典批量合并
config.update({"host": "127.0.0.1", "level": "info"})
print("更新后：", config)

# 键和值的视图
print("所有键：", list(config.keys()))
print("所有值：", list(config.values()))
print("所有对：", list(config.items()))

# 计数小技巧：用字典统计出现次数
# （这比 collections.Counter 更基础，务必掌握）
fruits = ["苹果", "香蕉", "苹果", "橙子", "苹果", "香蕉"]
counts = {}
for fruit in fruits:
    if fruit in counts:
        counts[fruit] += 1# 已出现过，计数 +1
    else:
        counts[fruit] = 1     # 第一次出现，计数为 1
print("统计结果：", counts)   # {'苹果': 3, '香蕉': 2, '橙子': 1}

# 反向字典：值 -> 键
scores = {"小明": 95, "小红": 88, "小刚": 72}
name_by_score = {score: name for name, score in scores.items()}
print("反向字典：", name_by_score)   # {95: '小明', 88: '小红', 72: '小刚'}
```

### 示例 8：列表套字典——真实数据的标准形状

单个字典只能描述一个对象。真实数据几乎都是**一个列表装很多个字典**（接口返回的 JSON 也是这个形状）：

```python
# users.py —— 列表套字典：遍历、分组、筛选
users = [
    {"name": "alice", "age": 30, "city": "上海"},
    {"name": "bob",   "age": 17, "city": "北京"},
    {"name": "carol", "age": 24, "city": "上海"},
]

# ① 逐条读取 + 条件判断
for u in users:
    status = "成年" if u["age"] >= 18 else "未成年"
    print(f"{u['name']}（{u['city']}）{u['age']} 岁 · {status}")

# ② 按城市分组：字典的值是列表
by_city = {}
for u in users:
    city = u["city"]
    if city not in by_city:        # 第一次遇到这个城市，先建空列表
        by_city[city] = []
    by_city[city].append(u["name"])
print("按城市", by_city)

# ③ 从字典列表里挑出符合条件的名字
adults = [u["name"] for u in users if u["age"] >= 18]
print("成年人", adults)
```

运行结果：

```text
alice（上海）30 岁 · 成年
bob（北京）17 岁 · 未成年
carol（上海）24 岁 · 成年
按城市 {'上海': ['alice', 'carol'], '北京': ['bob']}
成年人 ['alice', 'carol']
```

三个要点：

1. **`u["city"]` 用的是方括号，不是 `.city`**。字典不是对象，没有属性访问；写 `u.city` 会报 `AttributeError`。
2. **分组必须先判断键在不在**：直接 `by_city[city].append(...)` 会 `KeyError`，因为第一次遇到某个城市时还没有这个键。`by_city.setdefault(city, []).append(name)` 是一行版写法，效果相同。
3. **字典列表天然适合推导式**：`[u["name"] for u in users if ...]` 就是「筛选 + 取字段」，比 `for + append` 少两行。

## 六、本单元验收自测

**1. 简答题**：
```python
d = {"a": 1}
d["b"] = 2
d["a"] = 3
print(len(d), d)
```
输出什么？为什么？
> **要点**：输出 `2 {'a': 3, 'b': 2}`。第二行新增了一对（长度 1→2），第三行只是把已存在的 `a` 的值从 1 改成 3（长度不变）。字典赋值语句不区分新增和修改，只看键在不在。

**2. 判断题**：`d = {}` 之后直接执行 `print(d["name"])` 会打印 `None`。
> **要点**：错误。会报 `KeyError: 'name'`。要拿到 `None` 必须用 `d.get("name")`。

**3. 简答题**：下面代码输出什么？为什么会报错？
```python
scores = {"语文": 90}
for key in scores:
    if scores[key] < 60:
        del scores[key]
print(scores)
```
> **要点**：会报 `RuntimeError: dictionary changed size during iteration`。因为循环正按顺序遍历键，一旦 `del` 删掉一个键，字典内部结构发生改变，迭代器的位置就和实际内容错位了。修复方法：`for key in list(scores.keys()):`，先复制一份键列表再遍历副本。

**4. 简答题**：`.get()` 相比 `dict[键]` 的两个核心优势是什么？各举一例。
> **要点**：① **不会崩溃**：键不存在时 `.get()` 返回默认值，而 `dict[键]` 抛 `KeyError`。例：`d.get("年龄", 0)` 安全返回 0。② **支持链式访问嵌套数据**：因为缺键时可以返回一个空字典，链条不会断。例：`users.get("u9", {}).get("name", "查无此人")`，即使 u9 不存在也能安全返回兜底值。

**5. 判断题**：下面两行代码的作用完全一样。
```python
for key in d:
    print(key)

for key in d.keys():
    print(key)
```
> **要点**：作用完全一样。`for key in d` 是 `for key in d.keys()` 的简写形式，Python 允许直接遍历字典的键。这不是巧合——`dict.keys()` 返回的视图对象本身就代表键。
