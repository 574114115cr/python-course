## 二、核心知识点讲解

### 2.1 项目回顾：现在的代码里有什么（13.1）

单元 12 结束时，项目是三个文件：`alien_invasion.py`（主循环）、`settings.py`（设置）、`ship.py`（飞船）。本单元要往里加三样东西：**子弹、外星人、游戏状态**，于是项目长成了六个文件：

```text
外星人入侵（单元 13 结束时）
├── alien_invasion.py   主循环 + 所有 _update/_check 方法（最忙的文件）
├── settings.py         所有会变的数值（新增子弹、外星人、舰队设置）
├── ship.py             飞船（新增：继承 Sprite、center_ship）
├── bullet.py           子弹（新增）
├── alien.py            外星人（新增）
└── game_stats.py       游戏统计信息（新增：ships_left、game_active）
```

先认清每个类的职责，后面才不容易晕：

| 类 | 一句话职责 | 关键属性/方法 |
|---|---|---|
| `Settings` | 存所有可调数值 | `bullet_speed`、`alien_speed`、`fleet_direction` |
| `Ship` | 飞船的位置和移动 | `moving_right`、`update()`、`center_ship()` |
| `Bullet` | 一颗子弹的位置和移动 | `rect`、`y`、`update()`、`draw_bullet()` |
| `Alien` | 一个外星人的位置和移动 | `rect`、`x`、`check_edges()`、`update()` |
| `GameStats` | 游戏进行到哪一步了 | `ships_left`、`game_active` |

注意一个规律：**除了 Settings 和 GameStats，每个可见的东西都是一个类**。屏幕上有几个「会自己动的东西」，就有几个类——这就是面向对象在游戏里的落地方式。

### 2.2 编组 `Group` 与精灵 `Sprite`：为什么不用普通列表 ★

本单元的核心工具是**编组（Group）**。新手的第一反应是：「子弹和外星人我用 list 装不就行了？」可以，但你会立刻遇到三堵墙：

1. **批量更新**：每颗子弹都要 `update()`，用列表得自己写 `for bullet in self.bullets: bullet.update()`；编组直接 `self.bullets.update()`，它替你遍历。
2. **批量绘制**：`self.aliens.draw(self.screen)` 一行画完整个舰队；用列表得自己写循环调 `blit`。
3. **碰撞检测**：`groupcollide()`、`spritecollideany()` 只认编组，列表没有这些方法。

生活化类比：**编组像班长，精灵像学生**。班长手里有一份名单，喊一声「所有人 update」，名单上每个人都动一下；喊一声「draw」，每个人都把自己画到黑板上。你要新增一个学生，只需 `group.add(student)`；要清空重来，`group.empty()` 一键搞定。

那什么是「精灵（Sprite）」？可以理解成**参加过军训的学生**：Pygame 要求被编组管理的对象必须继承 `pygame.sprite.Sprite`，并且有两样装备——

- `image`：长相（一张表面，决定绘制时画什么）；
- `rect`：站位（矩形，决定画在哪、碰撞时怎么比）。

```python
import pygame
from pygame.sprite import Sprite


class Bullet(Sprite):
    def __init__(self, ai_game):
        super().__init__()          # ★ 必须先调用，否则编组不认这个对象
        self.screen = ai_game.screen
        self.rect = pygame.Rect(0, 0, 3, 15)   # 装备一：站位
        # 子弹没有 image（它是个色块），所以不用 Group.draw()，改成手动画
```

★ **这里为什么难**：`super().__init__()` 这行看起来「什么都没做」，但它是 Sprite 内部注册机制的一部分，漏掉它不会立刻报错，而是让你遇到「加进编组后 `update()` 不生效」这种诡异症状。**记住：继承 Sprite 的类，`__init__` 第一行永远是 `super().__init__()`。**

编组常用方法一览：

| 方法 | 作用 | 本单元用在哪 |
|---|---|---|
| `group.add(obj)` | 加入一个精灵 | 开火时加入子弹、创建外星人 |
| `group.update()` | 全员执行 `update()` | 每帧更新子弹和外星人 |
| `group.draw(surface)` | 全员把自己画到 surface 上 | 画外星舰队 |
| `group.sprites()` | 返回全员列表 | 遍历检查边缘、碰撞 |
| `group.copy()` | 返回副本 | **遍历时安全删除**（见 2.3） |
| `group.remove(obj)` | 移除一个精灵 | 删除消失的子弹 |
| `group.empty()` | 清空 | 重置游戏、击落全部外星人后 |

### 2.3 射击：`Bullet` 类与开火（12.8）

子弹和飞船最大的区别是：**子弹会不断地产生和消失**。这一节的所有设计都是围绕「一批会生灭的对象」展开的。

**（1）子弹长什么样。** 教材没有给子弹找图片，而是用 `pygame.Rect` 画一个细长条，再用 `pygame.draw.rect()` 上色：

```python
import pygame
from pygame.sprite import Sprite


class Bullet(Sprite):
    """管理飞船发射的子弹的类。"""

    def __init__(self, ai_game):
        super().__init__()
        self.screen = ai_game.screen
        self.settings = ai_game.settings
        self.color = self.settings.bullet_color

        # 在 (0, 0) 处创建子弹矩形，再移到飞船顶部
        self.rect = pygame.Rect(0, 0, self.settings.bullet_width,
                                self.settings.bullet_height)
        self.rect.midtop = ai_game.ship.rect.midtop

        # 用浮点数记录纵坐标：Rect 的 y 只能是整数
        self.y = float(self.rect.y)

    def update(self):
        """向上移动子弹。"""
        self.y -= self.settings.bullet_speed
        self.rect.y = self.y

    def draw_bullet(self):
        """在屏幕上绘制子弹。"""
        pygame.draw.rect(self.screen, self.color, self.rect)
```

`midtop` 这个锚点用得很巧：子弹的「顶边中点」对齐飞船的「顶边中点」，看起来正是从炮口射出去的。

**（2）存到编组里。** 在主文件的 `__init__` 里建一个空编组 `self.bullets = Group()`，开火时往里加：

```python
def _fire_bullet(self):
    """创建一颗新子弹，并加入编组。"""
    if len(self.bullets) < self.settings.bullets_allowed:
        new_bullet = Bullet(self)
        self.bullets.add(new_bullet)
```

`len(self.bullets)` 就是屏幕上现存子弹数，和 `bullets_allowed` 比较，实现「限制子弹数量」——不然按住空格会瞬间刷出几百颗，游戏失去挑战。

**（3）删除已消失的子弹。** 子弹飞出屏幕顶部后要删掉，否则编组越涨越大，最终拖慢游戏。判断条件是 `bullet.rect.bottom <= 0`（整个矩形都离开屏幕了）。但删除的写法藏着一个大坑：

```python
# INTENTIONALLY-BROKEN 演示用：边遍历边删除，会漏删
for bullet in self.bullets:
    if bullet.rect.bottom <= 0:
        self.bullets.remove(bullet)
```

★ **这就是本单元最重要的一条红线**，和阶段 1「遍历字典时不能删键」是同一个坑。原因：迭代器（`for` 背后的东西）手里攥着一份**序号表**，它从 0 开始一个个数。你在第 2 号位置删掉一个元素，后面所有元素往前补一位——原本排在第 3 号的现在排第 2 号，而迭代器已经「走过」第 2 号了，于是它被永久跳过。多颗子弹同一帧消失时，就会漏删一半。

正确写法是先复制一份再遍历：

```python
for bullet in self.bullets.copy():
    if bullet.rect.bottom <= 0:
        self.bullets.remove(bullet)
```

`copy()` 返回一个**新编组**（内容相同但相互独立），遍历副本、删除原件，补位影响不到迭代器，一颗都不会漏。阶段 1 我们说过「要删就先把目标收集到列表，遍历结束再删」——`copy()` 就是官方给的等价方案。

**（4）把更新逻辑收进 `_update_bullets()`。** 和单元 12 的重构思路一致：主循环只写 `self._update_bullets()`，更新位置、删除消失子弹、检测碰撞都下沉到这个方法里。

### 2.4 创建第一个外星人（13.2）

`Alien` 和 `Ship` 结构几乎一样，都是「加载图片 → 拿 rect → 放位置」：

```python
import pygame
from pygame.sprite import Sprite


class Alien(Sprite):
    """表示单个外星人的类。"""

    def __init__(self, ai_game):
        super().__init__()
        self.screen = ai_game.screen
        self.settings = ai_game.settings

        self.image = pygame.image.load("images/alien.bmp")
        self.rect = self.image.get_rect()

        # 初始位置在屏幕左上角附近，留出一个身位
        self.rect.x = self.rect.width
        self.rect.y = self.rect.height

        # 用浮点数记录水平位置
        self.x = float(self.rect.x)
```

两个细节：起始坐标用 `self.rect.width` 而不是 0，是故意留出一个外星人的宽度当边距，看起来不贴边；`self.x` 存浮点，理由和飞船一样——`alien_speed` 可能是小数。

### 2.5 创建外星舰队（13.3）

一个外星人好办，一整支舰队要解决两个问题：**每行放几个**和**放几行**。教材的思路是「拿一个外星人当尺子量屏幕」：

```text
屏幕宽 800，外星人宽 60：
可用宽度 = 800 - 2×60 = 680      （左右各留一个身位）
每个外星人占位 = 2×60 = 120      （自己一个 + 间距一个）
每行个数 = 680 // 120 = 5
```

对应代码：

```python
def _create_fleet(self):
    """创建外星舰队。"""
    # 先造一个外星人当"尺子"（它只是用来量尺寸，不加进编组）
    alien = Alien(self)
    alien_width, alien_height = alien.rect.size

    # 计算每行能放几个：左右各留一个身位，每个占两个身位
    available_space_x = self.settings.screen_width - (2 * alien_width)
    number_aliens_x = available_space_x // (2 * alien_width)

    # 创建第一行外星人
    for alien_number in range(number_aliens_x):
        self._create_alien(alien_number)
```

注意这里做了一次小重构：创建舰队分成两个方法，`_create_fleet()` 负责算账，`_create_alien()` 负责造人。这样等会儿加「多行」时，只需要在算账部分加几行，造人的逻辑一行不用动：

```python
def _create_alien(self, alien_number):
    """创建一个外星人，并把它放到当前行的对应位置。"""
    alien = Alien(self)
    alien_width = alien.rect.width
    alien.x = alien_width + 2 * alien_width * alien_number
    alien.rect.x = alien.x
    self.aliens.add(alien)
```

多加几行的思路完全一样——先算垂直方向能放几行（**底部要留给飞船**，不能让它一出生就被撞死），再双层循环：

```python
def _create_fleet(self):
    """创建外星舰队（多行版）。"""
    alien = Alien(self)
    alien_width, alien_height = alien.rect.size

    available_space_x = self.settings.screen_width - (2 * alien_width)
    number_aliens_x = available_space_x // (2 * alien_width)

    # 垂直方向：给飞船留一个身位，上下再各留一个
    ship_height = self.ship.rect.height
    available_space_y = (self.settings.screen_height
                         - (3 * alien_height) - ship_height)
    number_rows = available_space_y // (2 * alien_height)

    # 逐行逐列创建整个舰队
    for row_number in range(number_rows):
        for alien_number in range(number_aliens_x):
            self._create_alien(alien_number, row_number)
```

为什么强调「用一个外星人量尺寸」而不要硬编码 `alien_width = 60`？因为图片一换，所有间距都自动跟着变——这也是 `Settings` 之外另一种「不为未来挖坑」的习惯。

### 2.6 让外星舰队移动（13.4）

舰队移动的规则听起来简单，实现时有一个关键设计：**方向不存每个外星人身上，而是全队共用的一个标志位** `fleet_direction`（存在 `Settings` 里，`1` 向右、`-1` 向左）。

每个外星人的 `update()` 都乘上这个方向：

```python
def update(self):
    """向左或向右移动外星人。"""
    self.x += self.settings.alien_speed * self.settings.fleet_direction
    self.rect.x = self.x
```

生活化类比：**课间操队列**。队列整体向左转，每个人只是跟着挪一步；决定「往哪转」的是体育老师（`fleet_direction`），不是每个同学自己。如果方向存在每个人身上，就会出现「有人往左有人往右」的乱局。

那谁当体育老师？答案是「最先撞到边缘的那个人」。每帧检查所有外星人，只要有任何一个到达边缘，就命令整队下移并反向：

```python
def check_edges(self):
    """如果外星人位于屏幕边缘，就返回 True。"""
    screen_rect = self.screen.get_rect()
    return (self.rect.right >= screen_rect.right) or (self.rect.left <= 0)
```

```python
def _check_fleet_edges(self):
    """有外星人到达边缘时，改变整个舰队的方向。"""
    for alien in self.aliens.sprites():
        if alien.check_edges():
            self._change_fleet_direction()
            break                      # ★ 只需要一个外星人触发，必须 break

def _change_fleet_direction(self):
    """将整队外星人下移，并改变移动方向。"""
    for alien in self.aliens.sprites():
        alien.rect.y += self.settings.fleet_drop_speed
    self.settings.fleet_direction *= -1
```

★ `break` 是这里最容易漏的一行。如果漏了，一行里每个到边缘的外星人都会触发一次「下移 + 反向」——下移距离翻几倍、方向被反转奇数次变回原方向，表现为外星人**在边缘抽搐式抖动**。改成 `break` 后，一帧只处理一次。

`fleet_direction *= -1` 这行也很值得体会：方向在 `1` 和 `-1` 之间反复横跳，而所有外星人的 `update()` 都无需改动——**用一个数字的符号编码「方向」，是游戏编程里极其常用的技巧**。

### 2.7 碰撞检测与游戏结束（13.5–13.7）

**（1）子弹打中外星人。** Pygame 把「两个编组互相检测碰撞」做成了一个函数：

```python
collisions = pygame.sprite.groupcollide(self.bullets, self.aliens, True, True)
```

四个参数的含义：

| 参数 | 值 | 含义 |
|---|---|---|
| 第 1 个 | `self.bullets` | 编组 A（子弹） |
| 第 2 个 | `self.aliens` | 编组 B（外星人） |
| 第 3 个 | `True` | 碰撞后**删除子弹** |
| 第 4 个 | `True` | 碰撞后**删除外星人** |

返回值是个字典：键是「撞到人的子弹」，值是「被这颗子弹撞到的外星人列表」。所以「这一帧击落几个」可以直接 `len(collisions)` 算出来。

击落全部外星人后要生成新舰队，顺便把残留子弹清掉：

```python
def _check_bullet_alien_collisions(self):
    """响应子弹和外星人的碰撞。"""
    collisions = pygame.sprite.groupcollide(
        self.bullets, self.aliens, True, True)
    if not self.aliens:
        # 外星人死光了：清空子弹，再来一队
        self.bullets.empty()
        self._create_fleet()
```

**（2）「为测试创建大子弹」的调试思维。** 教材在这里专门讲了一个调试技巧：怀疑碰撞检测有 bug 时，临时把 `bullet_width` 从 3 改成 300——子弹粗到不可能打不中。如果这样能击落了，说明碰撞逻辑没问题，只是正常尺寸下命中率低；如果还不能击落，才说明真有 bug。**把偶发问题变成必现问题，是调试的第一生产力。** 验证完记得改回 3。

**（3）外星人撞到飞船。** 检测「一个精灵 vs 整个编组」用另一个函数：

```python
if pygame.sprite.spritecollideany(self.ship, self.aliens):
    self._ship_hit()
```

`spritecollideany()` 只要有任意一个外星人碰到飞船就返回那个外星人（否则返回 `None`），用作条件判断正合适。注意它要求飞船也是精灵，所以 13.6 节要把 `Ship` 改成继承 `Sprite` 并调用 `super().__init__()`。

被撞之后不是「游戏结束」，而是「少一条命、重置局面」：

```python
def _ship_hit(self):
    """响应飞船被外星人撞到。"""
    if self.stats.ships_left > 0:
        self.stats.ships_left -= 1        # 少一条命
        self.aliens.empty()               # 清空现存外星人
        self.bullets.empty()              # 清空现存子弹
        self._create_fleet()              # 重新放一队
        self.ship.center_ship()           # 飞船回底部中央
        sleep(0.5)                        # 暂停半秒，让玩家看清发生了什么
    else:
        self.stats.game_active = False    # 没命了，游戏结束
```

外星人碰到屏幕下边缘也算「被撞」，处理完全相同（`_check_aliens_bottom()`）——敌人突破防线，和你主动撞上去，后果一样。

**（4）游戏状态。** 到这里出现了第一个「不是屏幕上可见对象、却决定游戏怎么跑」的类：`GameStats`。它只存两样东西——还剩几条命（`ships_left`），以及游戏是否正在进行（`game_active`）。

```python
class GameStats:
    """跟踪游戏统计信息的类。"""

    def __init__(self, ai_game):
        self.settings = ai_game.settings
        self.reset_stats()
        self.game_active = True           # 游戏一开始是活动状态

    def reset_stats(self):
        """初始化在游戏运行期间可能变化的信息。"""
        self.ships_left = self.settings.ship_limit
```

**（5）13.7 节：确定应运行游戏的哪些部分。** 最后给主循环加一道闸门——游戏结束后，只画屏幕、收事件，不再更新任何游戏对象：

```python
def run_game(self):
    """开始游戏的主循环。"""
    while True:
        self._check_events()
        if self.stats.game_active:
            self.ship.update()
            self._update_bullets()
            self._update_aliens()
        self._update_screen()
        self.clock.tick(60)
```

为什么`_update_screen()` 在闸门外面？因为游戏结束后画面要**停在最后那一帧**（残局），而不是黑屏或继续动。这种「用状态位控制每帧跑多少逻辑」的写法，是后面做「开始按钮」「暂停」的地基。

### 示例 2：group_demo.py——不打开窗口，把编组的核心行为演示一遍

这个示例把 `Group` 的添加、批量更新、批量绘制、两种碰撞检测、清空全部跑一遍，而且**不需要显示器**。

```python
# group_demo.py —— 用 dummy 驱动演示 Group 的核心行为（无需真实显示器）
import os

os.environ["SDL_VIDEODRIVER"] = "dummy"

import pygame
from pygame.sprite import Group, Sprite, groupcollide, spritecollideany

pygame.init()
screen = pygame.display.set_mode((800, 600))


class Block(Sprite):
    """一个彩色小方块精灵：有 image（长相）和 rect（站位）。"""

    def __init__(self, color, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill(color)
        self.rect = self.image.get_rect(topleft=(x, y))
        self.vx = 0

    def update(self):
        """Group.update() 会自动调用每个成员的 update()。"""
        self.rect.x += self.vx

    def __repr__(self):
        return f"Block(x={self.rect.x}, y={self.rect.y})"


# 1）创建编组，放入 5 个精灵
blocks = Group()
for i in range(5):
    blocks.add(Block((200, 60, 60), 100 + i * 90, 100))
print("① 编组建好，成员数：", len(blocks))

# 2）批量更新：改一次速度，一次 update 全员生效
for block in blocks:
    block.vx = 10
blocks.update()
print("② update 后第一个方块的 x：", blocks.sprites()[0].rect.x)

# 3）批量绘制：把每个精灵的 image 画到屏幕上（dummy 下不可见但不报错）
blocks.draw(screen)
print("③ draw() 调用成功")

# 4）spritecollideany：单个精灵 vs 整个编组
runner = Block((60, 60, 200), 150, 100)
runner.vx = 20
for _ in range(10):
    runner.update()
    if spritecollideany(runner, blocks):
        break
print("④ spritecollideany 撞到了吗：", spritecollideany(runner, blocks) is not None)

# 5）groupcollide：两个编组互撞，两个 True 表示"碰撞后双方都消失"
enemies = Group()
for i in range(3):
    enemies.add(Block((60, 200, 60), 140 + i * 90, 100))
collisions = groupcollide(blocks, enemies, True, True)
print("⑤ groupcollide 撞掉了", len(collisions), "个；",
      "blocks 剩", len(blocks), "个，enemies 剩", len(enemies), "个")

# 6）empty()：一键清空
blocks.empty()
enemies.empty()
print("⑥ empty() 之后剩：", len(blocks), len(enemies))
```

运行结果：

```text
① 编组建好，成员数： 5
② update 后第一个方块的 x： 110
③ draw() 调用成功
④ spritecollideany 撞到了吗： True
⑤ groupcollide 撞掉了 3 个； blocks 剩 2 个，enemies 剩 0 个
⑥ empty() 之后剩： 0 0
```

注意第 ⑤ 步：`groupcollide()` 的返回值是**字典**——键是被撞掉的 blocks 成员，值是撞上它的 enemies 成员列表。所以 `len(collisions)` 就是「被撞掉了几个人」。

```python
import pygame
from pygame.sprite import Sprite


class Ship(Sprite):                      # 改动一：继承 Sprite
    """管理飞船的类。"""

    def __init__(self, ai_game):
        super().__init__()               # 改动一（续）：必须调用
        self.screen = ai_game.screen
        self.screen_rect = ai_game.screen.get_rect()
        self.settings = ai_game.settings

        try:
            self.image = pygame.image.load("images/ship.bmp")
        except (FileNotFoundError, pygame.error):
            self.image = pygame.Surface((60, 48))
            self.image.fill((70, 130, 180))
        self.rect = self.image.get_rect()
        self.rect.midbottom = self.screen_rect.midbottom

        self.x = float(self.rect.x)
        self.moving_right = False
        self.moving_left = False

    def update(self):
        """根据移动标志调整飞船的位置，并限制在屏幕内。"""
        if self.moving_right and self.rect.right < self.screen_rect.right:
            self.x += self.settings.ship_speed
        if self.moving_left and self.rect.left > 0:
            self.x -= self.settings.ship_speed
        self.rect.x = self.x

    def blitme(self):
        """在指定位置绘制飞船。"""
        self.screen.blit(self.image, self.rect)

    def center_ship(self):               # 改动二：新增
        """让飞船回到屏幕底部中央。"""
        self.rect.midbottom = self.screen_rect.midbottom
        self.x = float(self.rect.x)
```

### 示例 6：alien_invasion.py——完整版（13 章终态）

把示例 1、3、4、5 的五个文件放在同一目录，运行 `SDL_VIDEODRIVER=dummy python alien_invasion.py`，就得到一个完整可玩的外星人入侵：左右移动、空格射击、击落外星人、撞三次游戏结束。

```python
# alien_invasion.py —— 《外星人入侵》主文件（第 13 章完成时）
import sys
from time import sleep

import pygame
from pygame.sprite import Group

from alien import Alien
from bullet import Bullet
from game_stats import GameStats
from settings import Settings
from ship import Ship


class AlienInvasion:
    """管理游戏资源和行为的类。"""

    def __init__(self):
        """初始化游戏并创建资源。"""
        pygame.init()
        self.settings = Settings()
        self.clock = pygame.time.Clock()
        self.screen = pygame.display.set_mode(
            (self.settings.screen_width, self.settings.screen_height))
        pygame.display.set_caption("Alien Invasion")

        self.stats = GameStats(self)     # 游戏统计信息
        self.ship = Ship(self)
        self.bullets = Group()           # 装子弹的编组
        self.aliens = Group()            # 装外星人的编组
        self._create_fleet()

    def run_game(self):
        """开始游戏的主循环。"""
        while True:
            self._check_events()
            if self.stats.game_active:
                self.ship.update()
                self._update_bullets()
                self._update_aliens()
            self._update_screen()
            self.clock.tick(60)

    # —— 事件处理 ——

    def _check_events(self):
        """响应按键和鼠标事件。"""
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                sys.exit()
            elif event.type == pygame.KEYDOWN:
                self._check_keydown_events(event)
            elif event.type == pygame.KEYUP:
                self._check_keyup_events(event)

    def _check_keydown_events(self, event):
        """响应按键。"""
        if event.key == pygame.K_RIGHT:
            self.ship.moving_right = True
        elif event.key == pygame.K_LEFT:
            self.ship.moving_left = True
        elif event.key == pygame.K_q:
            sys.exit()
        elif event.key == pygame.K_SPACE:
            self._fire_bullet()

    def _check_keyup_events(self, event):
        """响应松键。"""
        if event.key == pygame.K_RIGHT:
            self.ship.moving_right = False
        elif event.key == pygame.K_LEFT:
            self.ship.moving_left = False

    def _fire_bullet(self):
        """创建一颗新子弹，并加入编组（受数量限制）。"""
        if len(self.bullets) < self.settings.bullets_allowed:
            new_bullet = Bullet(self)
            self.bullets.add(new_bullet)

    # —— 子弹 ——

    def _update_bullets(self):
        """更新子弹位置，并删除消失的子弹。"""
        self.bullets.update()
        for bullet in self.bullets.copy():      # 遍历副本，安全删除
            if bullet.rect.bottom <= 0:
                self.bullets.remove(bullet)
        self._check_bullet_alien_collisions()

    def _check_bullet_alien_collisions(self):
        """响应子弹和外星人的碰撞。"""
        collisions = pygame.sprite.groupcollide(
            self.bullets, self.aliens, True, True)
        if not self.aliens:
            # 外星人全部被击落：清空子弹，再来一队
            self.bullets.empty()
            self._create_fleet()

    # —— 外星人 ——

    def _create_fleet(self):
        """创建外星舰队。"""
        alien = Alien(self)                     # 先造一个当"尺子"
        alien_width, alien_height = alien.rect.size

        available_space_x = self.settings.screen_width - (2 * alien_width)
        number_aliens_x = available_space_x // (2 * alien_width)

        ship_height = self.ship.rect.height
        available_space_y = (self.settings.screen_height
                             - (3 * alien_height) - ship_height)
        number_rows = available_space_y // (2 * alien_height)

        for row_number in range(number_rows):
            for alien_number in range(number_aliens_x):
                self._create_alien(alien_number, row_number)

    def _create_alien(self, alien_number, row_number):
        """创建一个外星人，并把它放进舰队。"""
        alien = Alien(self)
        alien_width = alien.rect.width
        alien.x = alien_width + 2 * alien_width * alien_number
        alien.rect.x = alien.x
        alien.rect.y = alien.rect.height + 2 * alien.rect.height * row_number
        self.aliens.add(alien)

    def _update_aliens(self):
        """更新舰队位置，并处理与飞船的碰撞。"""
        self._check_fleet_edges()
        self.aliens.update()
        if pygame.sprite.spritecollideany(self.ship, self.aliens):
            self._ship_hit()
        self._check_aliens_bottom()

    def _check_fleet_edges(self):
        """有外星人到达边缘时，改变整个舰队的方向。"""
        for alien in self.aliens.sprites():
            if alien.check_edges():
                self._change_fleet_direction()
                break

    def _change_fleet_direction(self):
        """将整队外星人下移，并改变移动方向。"""
        for alien in self.aliens.sprites():
            alien.rect.y += self.settings.fleet_drop_speed
        self.settings.fleet_direction *= -1

    def _ship_hit(self):
        """响应飞船被外星人撞到。"""
        if self.stats.ships_left > 0:
            self.stats.ships_left -= 1
            self.aliens.empty()
            self.bullets.empty()
            self._create_fleet()
            self.ship.center_ship()
            sleep(0.5)
        else:
            self.stats.game_active = False

    def _check_aliens_bottom(self):
        """检查是否有外星人到达屏幕下边缘。"""
        screen_rect = self.screen.get_rect()
        for alien in self.aliens.sprites():
            if alien.rect.bottom >= screen_rect.bottom:
                self._ship_hit()      # 像飞船被撞一样处理
                break

    # —— 画面 ——

    def _update_screen(self):
        """更新屏幕上的图像，并切换到新屏幕。"""
        self.screen.fill(self.settings.bg_color)
        for bullet in self.bullets.sprites():
            bullet.draw_bullet()      # 子弹没有 image，手动绘制
        self.aliens.draw(self.screen)  # 外星人有 image，整编组一次画完
        self.ship.blitme()
        pygame.display.flip()


if __name__ == "__main__":
    ai = AlienInvasion()
    ai.run_game()
```

`_update_screen()` 里两种画法放在一起正好对比：外星人走 `Group.draw()`（因为它们有 `image`），子弹只能手动循环 `draw_bullet()`（因为它是色块，没有 `image`）——这就是 2.2 节说的「装备不齐，编组帮不了你」。

```python
# iteration_bug.py —— 复现"边遍历边删除"的漏删 bug


def make_bullets():
    """y <= 0 表示已飞出屏幕；故意让多个消失的子弹相邻。"""
    return [{"id": i, "y": y}
            for i, y in enumerate([100, -5, -5, 80, 60, -5, -5, -5, 40])]


# 错误写法：直接遍历并删除
bullets = make_bullets()
print("删除前：", [b["y"] for b in bullets])
for bullet in bullets:
    if bullet["y"] <= 0:
        bullets.remove(bullet)
print("错误写法删除后：", [b["y"] for b in bullets])
print("还剩几个 -5：", sum(1 for b in bullets if b["y"] <= 0))

# 正确写法：遍历副本
bullets = make_bullets()
for bullet in bullets.copy():
    if bullet["y"] <= 0:
        bullets.remove(bullet)
print("正确写法删除后：", [b["y"] for b in bullets])

print("结论：迭代器按序号走，删除会让后面的元素往前补位、被跳过；"
      "这和阶段 1 遍历字典时不能删键是同一个坑。")
```

```text
正确写法删除后： [100, 80, 60, 40]
```

```python
# edge_check.py —— 边缘检测逻辑（无需 pygame）


class FakeRect:
    """模拟 pygame.Rect 的 x / right / left。"""

    def __init__(self, x, width):
        self.x = float(x)
        self.width = width

    @property
    def right(self):
        return self.x + self.width

    @property
    def left(self):
        return self.x


class Alien:
    def __init__(self, x):
        self.rect = FakeRect(x, 60)      # 外星人宽 60

    def check_edges(self, screen_width=800):
        screen_rect = FakeRect(0, screen_width)
        return (self.rect.right >= screen_rect.right) or (self.rect.left <= 0)


for x, expect in [(0, True), (740, True), (370, False), (741, True)]:
    result = Alien(x).check_edges()
    print(f"x={x:>3} → check_edges={result}（期望 {expect}）",
          "PASS" if result == expect else "FAIL")

print("解释：用 >= 和 <= 是因为'刚好贴上边缘'也算到边；"
      "速度大于 1 时可能一步跨过精确坐标，用 == 会漏判。")
```

运行结果：

```text
x=  0 → check_edges=True（期望 True）PASS
x=740 → check_edges=True（期望 True）PASS
x=370 → check_edges=False（期望 False）PASS
x=741 → check_edges=True（期望 True）PASS
解释：用 >= 和 <= 是因为'刚好贴上边缘'也算到边；速度大于 1 时可能一步跨过精确坐标，用 == 会漏判。
```

## 六、本单元验收自测

**1. 判断题**：子弹列表可以用 `self.bullets.pop()` 直接删除，因为它就是个普通列表。
> **要点**：错误。`self.bullets` 不是 list 而是 `pygame.sprite.Group`（编组）。Group 的 `pop()` 接受的是**精灵对象**不是下标，删完也不自动维护内部列表。要删子弹必须走 `self.bullets.remove(bullet)` 或 `self.bullets.empty()`。这题专门考「编组和列表不是一回事」——阶段 1 学列表时形成的直觉在这里会骗人。

**2. 简答题**：为什么删除子弹的代码要写 `for bullet in self.bullets.copy():`，而不是 `for bullet in self.bullets:`？
> **要点**：因为在遍历过程中删除元素会漏删。遍历 `self.bullets` 时拿到的是一个「正在被遍历的列表」的快照式访问，一旦你在循环体里删元素，遍历指针会错位——后面的子弹被跳过，明明还在屏幕上也消失了。`.copy()` 先复制一份快照，遍历副本、删除原件，两边互不干扰。这和阶段 1「遍历字典时不能删键」是同一条红线，只是这次的对象换成了编组。

**3. 简答题**：`groupcollide(self.bullets, self.aliens, True, True)` 后面两个 `True` 分别是什么意思？改成 `False` 会怎样？
> **要点**：第一个 `True` 是 `kill_bullets`——命中的子弹会被移除；第二个 `True` 是 `kill_aliens`——命中的外星人会被移除。都改成 `False` 的话，碰撞依然会被检测到并返回列表，但什么都不删，于是同一个外星人在原地反复被同一颗子弹判定命中、反复加分。这是新手最常见的「打不死外星人」bug 根因。

**4. 判断题**：检测边缘时可以写 `if self.rect.left == 0:`，和教材用的 `>=` / `<=` 效果完全一样。
> **要点**：错误，只在一种情况下碰巧一样。舰队的移动步长由 `aliens_speed` 决定，一旦速度大于 1，`rect.left` 可能一步跨过 0 变成负数，`==` 就永远匹配不上，舰队会飞出屏幕外再也不掉头。教材用 `>=` / `<=` 是为了「越过或刚好贴上边缘」都能抓住。这个 bug 的表现是「玩着玩着整队消失」，很难查，所以要一开始就写对。

**5. 简答题**：`Alien.check_edges()` 里为什么要拿<b>任意一个</b>外星人来判断，而不是所有外星人？
> **要点**：因为整支舰队是<b>同速同向</b>整体移动的。同一时刻所有外星人的 x 坐标差值固定，谁先到边缘一定是左端或右端那个。所以只要拿一个代表（教材里取 `self.aliens.sprites()[0]`，靠 Group 按加入顺序排序保证它是最左的）就够了。对每个人都调一次方法是 O(n) 的无用功，而且一旦有外星人被击落，代表就换人了，反而更乱。

**6. 改错题**：下面这段代码有什么问题？运行后飞船会怎样？
```python
def _update_bullets(self):
    self.bullets.update()
    for bullet in self.bullets.copy():
        bullet.update()
        if bullet.rect.top <= 0:
            self.bullets.remove(bullet)
        if pygame.sprite.groupcollide(self.bullets, self.aliens, True, True):
            self._create_fleet()
            self.settings.aliens_speed *= 1.1
```
> **要点**：**检查了碰撞，却没把子弹挪出循环**。命中判定已经把子弹和外星人移出编组了，但 `for` 仍在遍历这份**快照**。此时 `bullet` 对象虽然已不在 `self.bullets` 里，循环体却还会继续对它调 `bullet.update()`。更要命的是 `self._create_fleet()` 在每次碰撞时都会执行——如果同一颗子弹在同一帧击落多个外星人，或者子弹数量多，就会连续重建舰队。正确写法见正文：拿到碰撞列表后先判断 `if collisions:`，只在确实命中时才重建舰队并加速。
