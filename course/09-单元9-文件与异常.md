## 二、核心知识点讲解

### 2.1 为什么需要文件：变量活不过程序结束

```python
name = "小明"
print(name)
# 程序结束后，name 就彻底消失了。关掉终端，什么都没留下。
```

变量只活在**内存**里，程序一结束就没了。要让数据**留下来**，就必须写到磁盘上。

生活化类比：
- **变量 = 草稿纸上的字**——写完一扔就没了。
- **文件 = 写在笔记本上的字**——合上本子，明天还在。

### 2.2 `open()` 与三种模式

```python
# INTENTIONALLY-BROKEN 语法示意：下面这行只是告诉你 open() 长什么样，
# 括号里的"文件路径"和"模式"是占位文字，真跑起来 open() 会报 ValueError: invalid mode
file_object = open("文件路径", "模式")
```

最关键的就是**模式**，它决定了这个文件被打开后你打算干什么：

| 模式 | 名称 | 文件不存在时 | 文件已存在时 |
|---|---|---|---|
| `"r"` | read 读 | **报错** `FileNotFoundError` | 从头读 |
| `"w"` | write 写 | 新建 | **清空！** |
| `"a"` | append 追加 | 新建 | 在末尾加 |

**`w` 模式的陷阱必须重点记住**：它不是"写进文件"，而是"**把文件清空，然后从零开始写**"。如果你只是想往文件末尾加内容却用了 `w`，原数据会被无声地抹掉：

```python
# 大错特错！
with open("日志.txt", "w") as f:
    f.write("新增一行")     # 原文件里所有的旧内容都没了！
```

这也是为什么单元 0 强调要用 `git`——任何"数据没了"的事故，Git 都能救回来（如果提交过的话）。

> Python 3 里 `r` 是默认模式，`open("f.txt")` 等于 `open("f.txt", "r")`。

### 2.3 `with open(...)`：不只是语法糖

```python
# 先准备一个要读的文件（真实项目里这文件是别人给你的，或上一段代码写出来的）
with open("文件.txt", "w", encoding="utf-8") as f:
    f.write("第一行内容\n第二行内容\n")

with open("文件.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 出了 with 块，文件自动关闭
print(content)
```

**`with` 做了两件普通写法做不到的事**：

**① 自动关闭文件，而且保证一定会关。**
```python
# 先准备一个要读的文件
with open("文件.txt", "w", encoding="utf-8") as f:
    f.write("第一行内容\n")

# 普通写法：必须记得手动关
f = open("文件.txt", encoding="utf-8")
content = f.read()
f.close()       # 忘了这行，文件句柄就泄漏了

# with 写法：到块末尾自动关闭，就算中途报错也会关
with open("文件.txt", encoding="utf-8") as f:
    content = f.read()
print(content)
```

生活化类比：普通写法像"借了本书，记得自己还回去"，忘了还就一直占着。`with` 像"进了图书馆的借阅室，出门自动归还，无论你在里面待多久、发生了什么"。

**② 出块后 `f` 变量本身失效。**
```python
# INTENTIONALLY-BROKEN 演示：出了 with 块之后 f 已经关闭，再读会报 ValueError
with open("文件.txt", "w", encoding="utf-8") as f:
    f.write("第一行内容\n")

with open("文件.txt", encoding="utf-8") as f:
    content = f.read()
print(content)      # OK，content 还在
print(f.read())      # ValueError: I/O operation on closed file
```
这个特性能**预防一整类 bug**：把 `with` 块的内容赋值给 `f` 的习惯是不良的，因为出了块就访问不到了。规范做法是在块内把内容读到一个变量里：

```python
with open("文件.txt", "w", encoding="utf-8") as f:
    f.write("第一行内容\n")

with open("文件.txt", encoding="utf-8") as f:
    content = f.read()      # 把内容存到 content
# 之后用 content，不用 f
print(content)
```

### 2.4 四种读取方式

假设文件内容是：
```
小明
小红
小刚
```

```python
# 先准备好要读的示例文件
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("小明\n小红\n小刚\n")

# ① .read()：全部读成一个字符串
with open("a.txt", encoding="utf-8") as f:
    content = f.read()      # "小明\n小红\n小刚\n"

# ② .readline()：只读一行（第二次调用接着往下读）
with open("a.txt", encoding="utf-8") as f:
    first = f.readline()    # "小明\n"（带换行符！）
    second = f.readline()   # "小红\n"

# ③ .readlines()：读成列表
with open("a.txt", encoding="utf-8") as f:
    lines = f.readlines()   # ["小明\n", "小红\n", "小刚\n"]

# ④ for 循环（最推荐）：逐行处理大文件
with open("a.txt", encoding="utf-8") as f:
    for line in f:
        print(line, end="")

print(content, first, second, lines, sep=" | ")
```

**`readline()` 的两个细节**：
- 读到的行**末尾带换行符 `\n`**（除非是文件最后一行）。所以经常要 `line.strip()` 或 `line.rstrip()`。
- 文件末尾没有换行符时，最后一行就不带 `\n`。

**该用哪一种？**

| 场景 | 推荐方式 |
|---|---|
| 整个文件不大，要一次性处理 | `.read()` |
| 整个文件很大，装不进内存 | **逐行 for 循环** |
| 需要按行处理（如统计行数、逐行转换） | `for line in f` |
| 只要第一行/最后一行 | `.readline()` |

生活化类比：`.read()` 是"把整本书背下来"；`for line in f` 是"一行一行读，从不贪多"。一本 1GB 的书，只有后者能读得动。

### 2.5 写文件

```python
# 写入文本
with open("output.txt", "w") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# 追加
with open("output.txt", "a") as f:
    f.write("第三行\n")

# 写入多行（用 writelines 或先 join）
lines = ["甲\n", "乙\n", "丙\n"]
with open("output.txt", "a") as f:
    f.writelines(lines)
```

**关键：自己写 `\n`。** `write()` 不会自动换行。想写表格那样的多行内容，必须在每行末尾加上 `\n`。

### 2.6 异常：让程序优雅地摔倒而不是死掉

程序运行中会遇到各种"意外"：

```python
# INTENTIONALLY-BROKEN 演示：下面四行每一行都会抛异常，运行它会在第一行就中断
print(int("abc"))        # ValueError：无法把 abc 转成整数
open("不存在.txt")        # FileNotFoundError：文件不存在
[1, 2, 3][10]            # IndexError：索引越界
10 / 0                   # ZeroDivisionError：除以零
```

**异常处理的骨架**：

```python
try:
    # 可能出错的代码
    risky_operation()
except 某类异常:
    # 出错后的补救措施
    handle_problem()
else:
    # 没出错时才执行
    print("一切正常")
finally:
    # 无论出错与否都执行
    cleanup()
```

四个部分的执行关系（务必记牢）：

| 情况 | try | except | else | finally |
|---|---|---|---|---|
| 顺利 | 执行 | 跳过 | **执行** | 执行 |
| 出错且被捕获 | 执行 | **执行** | 跳过 | 执行 |
| 出错且没被捕获 | 执行 | 跳过 | 跳过 | **先执行**再崩溃 |

**为什么不要用裸 `except:`？**

```python
# 极其危险
try:
    do_something()
except:              # 捕获一切，包括你没预料到的
    pass             # 而且什么都不做，把错误彻底吞掉
```

问题在于：
1. **会捕获你不该捕获的东西**——比如 `KeyboardInterrupt`（用户按 Ctrl+C 想中止）和 `SystemExit`（程序退出）。按 Ctrl+C 却没反应，是裸 except 最常见的后果。
2. **会掩盖真正的 bug**。你写的代码逻辑错了（`NameError`），结果被静默吞掉，程序带着错误继续跑，最后问题出现在一个完全无关的地方，排查成本极高。
3. **调试时你会完全瞎掉**。

正确做法是**明确指定要捕获的异常类型**：

```python
try:
    age = int(input("年龄："))
except ValueError:
    print("输入的不是有效整数")
```

### 2.7 异常处理的实用模式

**模式一：输入重试**（单元 6 用过，现在正式理解它）
```python
while True:
    try:
        age = int(input("请输入年龄："))
        break                       # 成功就跳出
    except ValueError:
        print("输入无效，请重新输入")   # 失败就重来
```

**模式二：多个异常分别处理**
```python
try:
    result = int(a) / int(b)
except ValueError:
    print("必须是数字")
except ZeroDivisionError:
    print("除数不能为 0")
```

**模式三：获取异常信息**（用 `as` 接收异常对象）
```python
try:
    int("abc")
except ValueError as error:
    print(f"出错了：{error}")      # 出错了：invalid literal for int() with base 10: 'abc'
```

**模式四：主动抛出异常**
```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("余额不足")     # 主动"制造"一个异常
    return balance - amount
```

这个模式极其重要：它是"**用异常报告错误**"的标准方式。`raise` 让错误信息沿着调用链向上传播，谁需要处理谁就 `try` 住它。这让"发现问题的地方"和"处理问题的地方"可以分离。

### 2.8 JSON：让数据能被记住

程序里的字典和列表**不能直接存进文件**（它们不是纯文本）。`json` 模块负责翻译。

```python
import json

data = {"name": "小明", "age": 18, "skills": ["Python", "SQL"]}

# 字典/列表 -> JSON 字符串
text = json.dumps(data)
print(text)     # {"name": "\u5c0f\u660e", "age": 18, ...}
# 中文乱码了，加上 ensure_ascii=False
print(json.dumps(data, ensure_ascii=False, indent=2))

# JSON 字符串 -> 字典
back = json.loads('{"name": "小明", "age": 18}')
print(back["name"])       # 小明
```

**JSON 与 Python 的对应关系**（这张表要背下来）：

| JSON | Python |
|---|---|
| `object`（`{}`） | dict |
| `array`（`[]`） | list |
| `string`（`"..."`） | str |
| `number`（没有引号） | int / float |
| `true` / `false` | True / False |
| `null` | None |

**注意一个坑**：JSON 的 `true/false` 和 Python 的 `True/False` 大小写不同。Python 的 `json` 模块能自动转换，但**其他语言的 JSON 解析库往往要求严格的 JSON 语法**（用小写 `true`）。所以自己手写 JSON 时要用小写。

**读写 JSON 文件**：
```python
# 写
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
```

> **`encoding="utf-8"` 必须写！** 不写的话，在 Windows 上读写中文可能报 `UnicodeEncodeError` 或 `UnicodeDecodeError`，或者写成乱码。这是中文用户最常踩的文件坑。

### 2.9 CSV：读写表格

CSV（逗号分隔值）是最常见的表格格式，可以用 Excel 打开：

```python
import csv

# 写
with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "年龄", "城市"])        # 写表头
    writer.writerow(["小明", 18, "杭州"])           # 写一行
    writer.writerow(["小红", 22, "北京"])

# 读
with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)          # ['姓名', '年龄', '城市']
```

**两个必写的参数**：
- `newline=""`：没有它，Windows 上会写出空行（Python 会在 `\r\n` 之间再加一个 `\n`）。这是标准写法，记住就行。
- `encoding="utf-8"`：同上，中文必需。

### 示例 1：`with open` 读写

```python
# file_basics.py —— 文件读写基础（用 with 语句）

# ===== 写文件 =====
filename = "示例文件.txt"

with open(filename, "w", encoding="utf-8") as f:
```

### 示例 2：三种模式的区别

```python
# modes_demo.py —— r / w / a 三种模式的区别

filename = "模式测试.txt"

# 先创建一个有内容的文件
with open(filename, "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n第三行\n")

def show(title):
    """读取并显示文件内容。"""
    try:
        with open(filename, "r", encoding="utf-8") as f:
            lines = f.readlines()
        print(f"  {title}: {len(lines)} 行 -> {[l.strip() for l in lines]}")
    except FileNotFoundError:
        print(f"  {title}: 文件不存在")


show("初始状态")

# "a" 追加：保留原有内容
with open(filename, "a", encoding="utf-8") as f:
    f.write("追加的行\n")
show("a 追加后")

# "w" 写入：清空原内容！
with open(filename, "w", encoding="utf-8") as f:
    f.write("全新的内容\n")
show("w 覆盖后")            # 只剩1 行，前面的都没了！

# "r" 读取不存在的文件 -> FileNotFoundError
try:
    with open("根本不存在.txt", "r", encoding="utf-8") as f:
        f.read()
except FileNotFoundError as error:
    print("r 读取不存在的文件：", error)

# "w" 和 "a" 都会在文件不存在时自动创建
with open("新建的文件.txt", "w", encoding="utf-8") as f:
    f.write("用 w 创建的新文件")
with open("新建的文件.txt", "a", encoding="utf-8") as f:
    f.write("\n用 a 追加的内容")

print("新建的文件是否存在于当前目录：是（w 和 a 都能自动创建）")
```

### 示例 3：四种读取方式

```python
# read_ways.py —— 四种读取文件的方式

filename = "读取测试.txt"
with open(filename, "w", encoding="utf-8") as f:
    f.write("小明\n小红\n小刚\n")# 注意最后一行没有 \n

# ① read()：全部读成一个字符串
with open(filename, "r", encoding="utf-8") as f:
    content = f.read()
print("① read():")
print(f"   类型={type(content).__name__} 内容={content!r}")

# ② readline()：一次读一行
print("\n② readline():")
with open(filename, "r", encoding="utf-8") as f:
    print(f"   第1次={f.readline()!r}")
    print(f"   第2次={f.readline()!r}")
    print(f"   第3次={f.readline()!r}")     # 最后一行的 \n 就是 \n

# ③ readlines()：读成列表
print("\n③ readlines():")
with open(filename, "r", encoding="utf-8") as f:
    lines = f.readlines()
print(f"   类型={type(lines).__name__} 内容={lines}")

# ④ for 循环逐行读（推荐方式，能处理超大文件）
print("\n④ for 逐行读:")
with open(filename, "r", encoding="utf-8") as f:
    for line in f:
        print(f"   读到: {line.strip()}")   # strip() 去掉首尾空白和换行

# readline() 的换行符细节
print("\n--- 换行符的细节 ---")
with open(filename, "r", encoding="utf-8") as f:
    for line in f:
        print(f"   {line!r}  -> strip 后 {line.strip()!r}")

# 清理
import os
for name in [filename]:
    if os.path.exists(name):
        os.remove(name)
        print(f"已清理临时文件：{name}")
```

### 示例 4：异常处理

```python
# exceptions_demo.py —— try/except/else/finally

# ===== 1）最基础的 try/except =====
print("=== 1. 基础异常处理 ===")
try:
    number = int("abc")
except ValueError:
    print("捕获到 ValueError：'abc' 不是有效整数")

# ===== 2）多种异常分别处理 =====
print("\n=== 2. 多种异常 ===")
def divide(a, b):
    try:
        return float(a) / float(b)
    except ValueError:
        return "错误：必须输入数字"
    except ZeroDivisionError:
        return "错误：除数不能为 0"


print(divide(10, 2))# 5.0
print(divide("x", 2))      # 错误：必须输入数字
print(divide(10, 0))       # 错误：除数不能为 0

# ===== 3）捕获异常对象，读取错误信息 =====
print("\n=== 3. 用 as 获取异常信息 ===")
try:
    int("abc")
except ValueError as error:
    print(f"异常信息：{error}")

try:
    with open("不存在的文件.txt", "r", encoding="utf-8") as f:
        f.read()
except FileNotFoundError as error:
    print(f"文件错误信息：{error}")

# ===== 4）else：没出错才执行 =====
print("\n=== 4. else 的作用 ===")
for text in ["100", "abc"]:
    try:
        value = int(text)
    except ValueError:
        print(f"  {text!r} -> 转换失败")
    else:
        # 只有 try 块完全成功才会走这里
        print(f"  {text!r} -> 转换成功：{value * 2}")

# ===== 5）finally：无论如何都执行 =====
print("\n=== 5. finally 的作用 ===")


def process(raw):
    """演示 finally：无论成功失败都会打印收尾日志。"""
    try:
        index = int(raw)
        return ["甲", "乙", "丙"][index]     # 成功：返回对应元素
    except ValueError:
        return "输入无效"
    except IndexError:
        return "下标超出范围"
    finally:
        # 无论成功失败都会执行，常用于释放资源、记录日志
        print(f"  finally: 正在处理 {raw!r}")


print("成功的情况：", process("1"))# 乙
print("输入无效：", process("abc"))
print("下标越界：", process("99"))   # 返回友好提示而不是崩溃
```

```python
import csv
import os

FILENAME = "scores.csv"
FIELDS = ["姓名", "数学", "英语", "总分"]


def init_file(filename=FILENAME):
    """创建文件并写入表头（覆盖已有文件）。"""
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(FIELDS)
    print(f"已初始化 {filename}")


def add_student(name, math, english, filename=FILENAME):
    """追加一名学生，总分自动计算。"""
    total = math + english
    with open(filename, "a", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow([name, math, english, total])
    print(f"已添加：{name}（总分 {total}）")


def read_all(filename=FILENAME):
    """返回所有学生数据（字典列表），文件不存在时返回空列表。"""
    try:
        with open(filename, "r", newline="", encoding="utf-8") as f:
            return list(csv.DictReader(f))
    except FileNotFoundError:
        print(f"  {filename} 不存在，返回空列表")
        return []


def class_average(subject, filename=FILENAME):
    """返回某科目的班级平均分。"""
    students = read_all(filename)
    if not students:
        return 0
    total = sum(float(s[subject]) for s in students)
    return total / len(students)


def ranking(filename=FILENAME):
    """返回按总分降序排好的学生列表。"""
    students = read_all(filename)
    return sorted(students, key=lambda s: float(s["总分"]), reverse=True)


def delete_student(name, filename=FILENAME):
    """删除指定学生：读出 -> 过滤 -> 重写文件。"""
    students = read_all(filename)
    remaining = [s for s in students if s["姓名"] != name]

    if len(remaining) == len(students):
        print(f"  未找到学生 {name}")
        return False

    # 重写整个文件
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(FIELDS)
        for student in remaining:
            writer.writerow([
                student["姓名"],
                student["数学"],
                student["英语"],
                student["总分"],
            ])

    print(f"  已删除 {name}，剩余 {len(remaining)} 人")
```

```python
# robust_input.py —— 健壮的用户输入处理

print("=== 读取 1-100 的整数 ===")

MAX_ATTEMPTS = 3
attempts = 0

while attempts < MAX_ATTEMPTS:
    raw = input("请输入 1-100 的整数：")
    attempts += 1
    try:
        value = int(raw)
    except ValueError as error:
        print(f"  '{raw}' 不是有效整数：{error}")
    else:
        # else 块：只有转换成功才会执行
        print(f"  转换成功：{value}")
        if 1 <= value <= 100:
            print(f"✓ 数字在有效范围内：{value}")
            break
        else:
            print(f"  {value} 不在 1-100 范围内，请重新输入")
    finally:
        print(f"  （第 {attempts}/{MAX_ATTEMPTS} 次尝试结束）")

print("\n=== 读取一个正数（float）===")

while True:
    try:
        raw = input("请输入一个正数：")
        price = float(raw)
    except ValueError as error:

    except KeyboardInterrupt:

    else:

    finally:
```

```python
# todo.py —— 待办事项管理器（综合练习）

import json
import os

TASKS_FILE = "tasks.json"


class Task:
    """一个待办任务。"""
    PRIORITY_ORDER = {"高": 0, "中": 1, "低": 2}

    def __init__(self, title, priority="中", done=False):
        self.title = title
        self.priority = priority
        self.done = done

    def complete(self):
        """标记为已完成。"""
        self.done = True
        return self

    def to_dict(self):
        """转成字典，用于 JSON 序列化。"""
        return {
            "title": self.title,
            "priority": self.priority,
            "done": self.done,
        }

    @classmethod
    def from_dict(cls, data):
        """从字典还原成 Task 对象（反向操作）。"""
        return cls(
            title=data["title"],
            priority=data.get("priority", "中"),
            done=data.get("done", False),
        )

    def __str__(self):
        mark = "[已完成]" if self.done else "[待办]"
        return f"{mark} {self.title}（优先级：{self.priority}）"


class TodoManager:
    """待办事项管理器。"""

    def __init__(self, filename=TASKS_FILE):
        self.filename = filename
        self.tasks = []
        self.load()

    # ===== 文件读写 =====
    def load(self):
        """从 JSON 文件加载任务。文件不存在或损坏都不报错。"""
        try:
            with open(self.filename, "r", encoding="utf-8") as f:
                data = json.load(f)
            self.tasks = [Task.from_dict(item) for item in data]
            print(f"  已加载 {len(self.tasks)} 个任务")
        except FileNotFoundError:
            self.tasks = []
            print(f"  {self.filename} 不存在，从空列表开始")
        except json.JSONDecodeError:
            self.tasks = []
            print(f"  {self.filename} 内容损坏，从空列表开始")
        except OSError as error:
            self.tasks = []
            print(f"  读取失败：{error}")

    def save(self):
        """把所有任务保存到 JSON 文件。"""
        try:
            data = [task.to_dict() for task in self.tasks]
            with open(self.filename, "w", encoding="utf-8") as f:
                json.dump(data, f, ensure_ascii=False, indent=2)
            print(f"  已保存 {len(data)} 个任务到 {self.filename}")
        except OSError as error:
            print(f"  保存失败：{error}")

    # ===== 任务操作 =====
    def add(self, title, priority="中"):
        """添加一个任务。"""
        if any(task.title == title for task in self.tasks):
            print(f"  任务 '{title}' 已存在，跳过")
            return False
        self.tasks.append(Task(title, priority))
        print(f"  已添加：{title}")
        return True

    def complete(self, title):
        """标记指定任务为已完成。"""
        for task in self.tasks:
            if task.title == title:
                task.complete()
                print(f"  已完成：{title}")
                return True
        print(f"  未找到任务：{title}")
        return False

    def delete(self, title):
        """删除指定任务。"""
        original_count = len(self.tasks)
        self.tasks = [t for t in self.tasks if t.title != title]
        if len(self.tasks) < original_count:
            print(f"  已删除：{title}")
            return True
        print(f"  未找到任务：{title}")
        return False

    def list_all(self, show_done=True):
        """列出任务，可选择是否显示已完成的。"""
        visible = [
            task for task in self.tasks
            if show_done or not task.done
        ]
        # 按优先级排序：高 -> 中 -> 低
        visible.sort(key=lambda t: Task.PRIORITY_ORDER.get(t.priority, 9))

        if not visible:
            print("  （没有任务）")
            return []

        print(f"  共 {len(visible)} 个任务：")
        for task in visible:
            print(f"    {task}")
        return visible

    def stats(self):
        """统计任务数量。"""
        total = len(self.tasks)
        done = len([t for t in self.tasks if t.done])
        return {
            "总数": total,
            "已完成": done,
            "待办": total - done,
            "完成率": f"{done / total * 100:.1f}%" if total else "0%",
        }


# ===== 测试 =====
```

## 六、本单元验收自测

**1. 简答题**：
```python
with open("test.txt", "w") as f:
    f.write("第一行\n")
with open("test.txt", "w") as f:
    f.write("第二行\n")
with open("test.txt", encoding="utf-8") as f:
    print(f.read())
```
输出什么？
> **要点**：只输出 `第二行`。第二次用 `"w"` 模式打开文件时，文件被**清空**，所以第一次写入的"第一行"被彻底丢弃。`"w"` 是"清空后重写"，不是"写进去"。如果想在末尾追加必须用 `"a"`。

**2. 简答题**：`with open(...)` 的两个主要好处是什么？为什么 `f.read()` 的内容要存到变量里再用？
> **要点**：① 进入 `with` 块时打开文件，**离开块时自动关闭**，而且即使块内代码抛异常也保证会关闭（普通写法忘了 `close()` 会泄漏文件句柄）。② 出块后 `f` 本身失效（访问会报 `ValueError: I/O operation on closed file`）。所以必须在块内把内容读进 `content` 这样的变量，出了块用 `content`。

**3. 判断题**：写 `try: ... except:` （不带任何异常类型）是可以的推荐做法。
> **要点**：错误，应该尽量避免。裸 `except:` 会捕获一切异常，包括 `KeyboardInterrupt`（导致 Ctrl+C 失效）和 `SystemExit`，还会静默吞掉真正的代码 bug（`NameError`、`TypeError` 等），让问题在别处才暴露，排查成本极高。正确做法是明确指定类型，如 `except ValueError:` 或 `except (ValueError, KeyError):`。

**4. 简答题**：为什么读写文件时几乎总要写 `encoding="utf-8"`？CSV 的 `newline=""` 又是为了什么？
> **要点**：`encoding="utf-8"` 是为了保证中文正确读写。不指定时 Python 会用操作系统默认编码（Windows 上是 GBK/cp936），会导致中文写出乱码，或读取时报 `UnicodeDecodeError`。`newline=""` 是 `csv` 模块的标准要求：不写它，在 Windows 上 Python 会在 `\r\n` 之间再插入一个 `\n`，导致文件里出现空行。CSV 文件推荐搭配 `encoding="utf-8-sig"`，这样 Excel 打开时中文不乱码。

**5. 简答题**：JSON 和 Python 的类型是怎么对应的？`json.dumps(data)` 不加 `ensure_ascii=False` 会有什么现象？
> **要点**：对应关系是 `object → dict`、`array → list`、`string → str`、`number → int/float`、`true/false → True/False`、`null → None`。不加 `ensure_ascii=False` 时，中文字符会被转义成 `\u5c0f\u660e` 这样的形式——程序能正常读回，但人完全看不懂，文件体积也更大。注意 JSON 用**小写** `true/false/null`，与 Python 的 `True/False/None` 不同。
