## 二、核心知识点讲解

### 2.1 类：从"一堆变量"到"一类事物"

先看不用类的时候，一个"汽车"要占多少变量：

```python
car_make = "丰田"
car_model = "卡罗拉"
car_color = "红色"
car_year = 2020

car2_make = "本田"
car2_model = "雅阁"
car2_color = "蓝色"
car2_year = 2021
# 变量名越来越长，重复的劳动越来越多
```

而且如果你想让汽车"做点事"，还得写一堆名字别扭的函数：

```python
def car1_describe(): ...
def car2_describe(): ...
```

类的本质是：**给"同一类事物"造一个统一的模板**。

生活化类比：
- **类 = 建筑图纸**（规定了所有房子有什么：几室几厅、什么材料）
- **对象 = 按图纸盖出来的具体房子**（小明家的房子、小红家的房子）
- **属性 = 房子的固有特征**（面积、楼层、朝向）
- **方法 = 房子能做的事**（开门、关灯）

一张图纸可以盖出无限多栋房子，而且每栋房子都自带"开门"这个能力——这就是类比函数的复用，但更强大：它复用的不只是"行为"，而是**行为 + 数据打包在一起**。

### 2.2 `self`：整个 Python 面向对象的核心

```python
class Dog:
    def __init__(self, name, age):
        self.name = name      # 把参数存到"这个对象自己身上"
        self.age = age


dog1 = Dog("旺财", 3)
dog2 = Dog("咪咪", 5)
```

**`self` 到底是什么？** 它就是**"当前这个对象自己"**的引用。

生活化类比（最贴切的一个）：`self` 就像**"我自己"**这个词。

你在描述自己的时候会说"我今年 18 岁，我有 3 个爱好"。在类里：
- `self` = 说话的那个人（"我"）
- `self.age` = "我的年龄"
- `self.name` = "我的名字"

所以：
```python
self.name = name
# 左边：当前对象的名字属性
# 右边：传进来的参数值
```

**为什么每个方法都必须写 `self`？** 因为一个类可以造出成千上万个对象，每个对象的属性值都不同。方法必须通过 `self` 知道"我现在操作的是哪一个对象"。

```python
dog1 = Dog("旺财", 3)
dog2 = Dog("咪咪", 5)

dog1.bark()      # 这个调用背后，Python 自动传入 dog1 作为 self
dog2.bark()      # 这里自动传入的是 dog2
```

实际上当你写 `dog1.bark()` 时，Python 自动做了 `Dog.bark(dog1)`。**这个自动传递就是必须写 `self` 的唯一原因。**

**创建对象的完整过程**：
```python
dog1 = Dog("旺财", 3)
# 背后发生：1) 创建一个空的 Dog 对象  2) 调用 __init__(这个空对象, "旺财", 3)
#           3) __init__ 里的 self 就指向那个空对象，于是属性被挂上去
```

### 2.3 `__init__`：对象的出生证明

`__init__`（前后各有两个下划线，读作"双下划线 init"）在**对象创建时自动执行一次**，作用是给每个对象设置初始属性。

```python
class Car:
    def __init__(self, make, model, color, year=2020):
        self.make = make        # 实例属性：每个对象各有一份
        self.model = model
        self.color = color
        self.year = year
        self.odometer = 0       # 初始里程固定为 0
```

注意 `year=2020` 也可以有默认值——**这和函数的默认参数规则完全一样**。

**实例属性 vs 类属性**（了解即可）：
```python
class Car:
    wheels = 4          # 类属性：所有 Car 共享，修改会影响全部

    def __init__(self, make):
        self.make = make  # 实例属性：每个对象独有
```

生活化类比：**类属性是"这一类事物共有的规格"**（所有汽车都是 4 个轮子，除非你改整个类的定义）；**实例属性是"这一辆车特有的信息"**（这辆是红色的，那辆是蓝色的）。

初学阶段主要用实例属性，类属性用得少。

### 2.4 属性 vs 方法

```python
class Car:
    def __init__(self, make, model):
        self.make = make        # 属性：无括号，直接存数据
        self.model = model
        self.odometer = 0

    def drive(self, miles):     # 方法：有括号，是行为
        self.odometer += miles  # 方法内部通过 self 改属性

    def get_odometer(self):     # 方法：读取属性
        return self.odometer


car = Car("丰田", "卡罗拉")
car.drive(100)                 # 调用方法：obj.method(参数)
car.drive(50)
print(car.odometer)            # 访问属性：obj.属性，不要写括号
print(car.get_odometer())      # 调用方法：要写括号
```

### 2.5 `__str__`：让对象能被读懂地打印

默认情况下打印对象会得到一段谁也看不懂的东西：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age


dog = Dog("旺财", 3)
print(dog)
# 输出：<__main__.Dog object at 0x000001F8E3D2A410>  ← 内存地址，毫无意义
```

定义 `__str__` 方法来控制它：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"我的狗叫{self.name}，今年{self.age}岁"


dog = Dog("旺财", 3)
print(dog)      # 我的狗叫旺财，今年3岁
```

生活化类比：`__str__` 就是给这个类**准备一份"自我介绍模板"**。默认自我介绍是"我是内存 0x... 号的那个东西"，你写了自己的版本，它就会说人话。

### 2.6 继承：不重复造轮子

设想你有两个类 `ElectricCar`（电动车）和 `Car`（普通车）。电动车**几乎**是汽车，只是电池和续航不一样。

如果没有继承，你要把 Car 的所有属性和方法**复制粘贴**一遍。能用，但只要 Car 加一个新功能，两个类都得记得同步改——迟早会漏。

**继承解决的是这个问题**：

```python
class Car:
    """普通汽车。"""
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer = 0

    def __str__(self):
        return f"{self.year} 年 {self.make} {self.model}"


class ElectricCar(Car):
    """电动汽车 —— 继承自 Car，额外有电池信息。"""
    def __init__(self, make, model, year, battery_size):
        super().__init__(make, model, year)   # 调用父类的 __init__
        self.battery_size = battery_size     # 加上自己的新属性
        self.charge = 100                    # 初始电量

    def __str__(self):
        parent = super().__str__()           # 复用父类的字符串
        return f"{parent}，电池 {self.battery_size} kWh，电量 {self.charge}%"
```

**三个要点**：

1. **括号里的 `Car` 叫"父类"**（也叫基类），`ElectricCar` 叫**子类**（也叫派生类）。
2. **子类自动拥有父类的一切**：属性、方法、`__str__` 全都能用。
3. **`super().__init__(...)`** 是"打个电话给爸爸，问他该怎么初始化基础信息"。

**关于 `super()` 的一个实用提醒**：`super().__init__()` 必须放在**自己赋值属性之前**。因为父类的 `__init__` 会设置父类需要的那些属性，如果你先改了 `self.make`，可能覆盖掉父类设好的值。这不是绝对必须，但在有继承的类里，**先调 `super()` 再写自己的逻辑**是好习惯。

### 2.7 方法重写与多态

子类可以**重新定义**父类已有的方法，这叫**方法重写（override）**：

```python
class Car:
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

    def __str__(self):
        return f"{self.year} 年 {self.make} {self.model}"

    def fill_gas_tank(self):
        """普通车加油。"""
        print(f"已为 {self} 加满油箱")


class ElectricCar(Car):
    """电动车没有油箱，所以必须重写这个方法。"""

    def __init__(self, make, model, year, battery_size):
        # 先让父类把 make / model / year 存好
        super().__init__(make, model, year)
        # 再加自己的新属性
        self.battery_size = battery_size

    def fill_gas_tank(self):
        """重写：电动车不用加油。"""
        print(f"{self} 是电动车，不需要加油，请充电")


my_car = Car("丰田", "卡罗拉", 2020)
my_electric = ElectricCar("特斯拉", "Model 3", 2024, 75)

my_car.fill_gas_tank()         # 已为 2020 年 丰田 卡罗拉 加满油箱
my_electric.fill_gas_tank()    # 2024 年 特斯拉 Model 3 是电动车，不需要加油
```

注意：ElectricCar **根本没定义 `__str__`**，但 `f"{self}"` 照样能用父类的版本——这就是继承。

**多态（polymorphism）** 是重写带来的最大好处：**调用代码不需要知道对象的真实类型**。

```python
# 同一段代码，对不同类型的对象都能正常工作
for vehicle in [my_car, my_electric]:
    vehicle.fill_gas_tank()
```

生活化类比：你对着一群"交通工具"喊"报上你的名字"，汽车回答"我是卡车，能拉货"，电动车回答"我是电动车，能充电"，轮船回答"我是船，能潜水"。**你完全不需要先判断对方是哪一类**——每个人自己会报出适合自己的一句话。这个"因人而异"就是多态。

这就是为什么**方法重写时参数签名必须兼容**（参数个数、顺序、默认值要对得上）：因为调用方是按父类的接口来调用的。

### 2.8 导入类与 Python 标准库（教材 9.4 / 9.5）

**一、类也可以拆到文件里。** 和第 7 单元的函数模块完全一样，一个 `.py` 文件放一个类（或一组相关类），文件名就是模块名：

```python
# （片段）car.py
class Car:
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

    def describe(self):
        return f"{self.year} {self.make} {self.model}"


class ElectricCar(Car):
    def __init__(self, make, model, year, battery=75):
        super().__init__(make, model, year)
        self.battery = battery
```

```python
# （片段）my_cars.py —— 四种取用方式
from car import Car                        # ① 只导入一个类
from car import Car, ElectricCar           # ② 导入多个类
import car                                 # ③ 导入整个模块，用 car.Car
from car import ElectricCar as EV          # ④ 导入并起别名

print(Car("比亚迪", "汉", 2024).describe())
print(ElectricCar("特斯拉", "Model 3", 2024).describe())
print(car.Car("大众", "高尔夫", 2020).describe())
print(EV("蔚来", "ET5", 2023).battery)
```

什么时候用哪种？和第 7 单元判断标准一致：**用的类少就 `from ... import`，用的多就 `import car`**，别名留给名字长或会冲突的类。`from car import *` 依旧不推荐——你没法一眼看出 `Car` 是从哪来的。

**二、标准库：不用装，import 就能用。** 教材 9.5 只举了 `random` 一个例子，但它是理解标准库的最好入口：Python 自带几百个模块，`random`、`datetime`、`json`、`pathlib` 都在里面，**不需要 pip 安装**。

```python
import random

print("randint ", random.randint(1, 6))        # 1–6，两端都包含
print("choice  ", random.choice(["石头", "剪刀", "布"]))
print("choices ", random.choices("abc", k=3))  # 有放回，可能重复
print("sample  ", random.sample(range(1, 11), 3))  # 不放回，一定不重复
```

四个函数最容易混的是 `choices` 和 `sample`：

| 函数 | 抽几个 | 会不会重复 | 返回 |
|---|---|---|---|
| `random.choice(seq)` | 1 个 | — | 单个元素 |
| `random.choices(seq, k=n)` | n 个 | **会**（有放回） | 列表 |
| `random.sample(seq, k=n)` | n 个 | **不会**（不放回） | 列表 |
| `random.shuffle(seq)` | 打乱整个序列 | — | **None**（原地改） |

最后一个坑值得单独记：`shuffle` 是**原地打乱**，返回值是 `None`。

```python
# （片段）
deck = [1, 2, 3, 4, 5]
deck = random.shuffle(deck)      # ✗ deck 变成 None，牌全丢了
random.shuffle(deck)             # ✓ 直接调用，不要接返回值
```

**三、随机要能复现。** `random.seed(n)` 固定随机序列，同一个 seed 每次跑出来的结果完全一样——调试、写测试、做课堂演示都必须先 seed，否则「上次明明是对的」。

```python
import random

random.seed(42)
print(random.randint(1, 6))      # 6
random.seed(42)
print(random.randint(1, 6))      # 6  ← 同一个 seed，结果相同
```

> **要点**
> - 类文件与调用方**同目录**才能直接 `import car`；文件名别和标准库重名（写 `random.py` 会让 `import random` 导入你自己，第 7 单元练习 7-10 讲过）。
> - `random` 是**伪随机**，可预测；做密码、令牌、抽奖公证要用 `secrets` 模块。
> - `sample(seq, k)` 在 `k` 大于序列长度时抛 `ValueError`，`choices` 不会。
> - 标准库清单看官方文档「The Python Standard Library」，不用背，知道「大概有什么」就够查。

### 2.9 `__repr__`：给开发者看的那个字符串

2.5 讲的 `__str__` 是给**用户**看的（"2024 款比亚迪 汉"）。还有一个 `__repr__`，是给**开发者**看的，它的目标是：

> 理想情况下，把它复制粘贴回代码里，能重建出同一个对象。

```python
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year

    def __str__(self):
        return f"{self.year} 款{self.brand} {self.model}"

    def __repr__(self):
        # 注意：字符串要带引号，否则重建不出来
        return f"Car({self.brand!r}, {self.model!r}, {self.year!r})"


c = Car("比亚迪", "汉", 2024)
print(c)          # 2024 款比亚迪 汉          ← 调 __str__
print(repr(c))    # Car('比亚迪', '汉', 2024)  ← 调 __repr__

# 关键差别在这里：容器里打印用的是 repr
garage = [c]
print(garage)     # [Car('比亚迪', '汉', 2024)]  ← 不是"2024 款比亚迪 汉"
```

`!r` 是 f-string 的"用 repr 格式化"，对字符串来说就是**加上引号**。少了引号你写出来的就是 `Car(比亚迪, 汉, 2024)`，那已经不是一个能运行的表达式了。

**只写 `__repr__` 不写 `__str__` 也可以**：这时 `print` 会自动用 `__repr__`。所以有个省事的策略：

> 小类只写 `__repr__`（调试时更实用）；需要给用户看漂亮文字时，再加 `__str__`。

调试时你几乎总是看 `repr`——列表里、字典里、pdb 里、日志里。**`__str__` 只影响 `print` 和 `str()`，`__repr__` 影响所有"顺带打印对象"的地方。**

### 2.10 `@property`：把方法当属性用

先把问题摆出来。这个类允许把年龄改成负数：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age          # 在 __init__ 里检查过，但之后呢？


p = Person("小明", 18)
p.age = -5                      # 没人拦得住
print(p.age)                    # -5
```

`__init__` 里加判断没用，因为**属性是可直接赋值的**。老办法是改成方法 `set_age()`，但那样调用就变成 `p.get_age()`——用起来别扭，而且老代码 `p.age` 全得改。

`@property` 的解法：**对外看起来还是属性，内部走的却是方法**。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age              # 走下面的 setter

    @property
    def age(self):
        """读的时候执行这里。"""
        return self._age

    @age.setter
    def age(self, value):
        """写的时候执行这里——校验就放在这。"""
        if not isinstance(value, int):
            raise TypeError("年龄必须是整数")
        if not 0 <= value <= 150:
            raise ValueError("年龄必须在 0–150 之间")
        self._age = value


p = Person("小明", 18)
print(p.age)            # 18        ← 看起来是属性，其实调了方法

p.age = 20              # 合法，正常写入
print(p.age)            # 20

try:
    p.age = -5          # 非法，被 setter 拦住
except ValueError as e:
    print("拦住了：", e)
```

三个要点：

1. **内部用 `self._age`**（一个下划线表示"内部用，别直接动"）。如果 setter 里写 `self.age = value`，会无限递归调用自己。
2. **`@property` 同名定义两次**：先 `@property` 定义 getter，再 `@age.setter` 定义 setter。
3. **只写 `@property` 不写 setter，就是只读属性**——赋值会抛 `AttributeError: can't set attribute`。这在配置类、常量类里特别有用：

```python
class Circle:
    def __init__(self, r):
        self.r = r

    @property
    def area(self):
        """面积是算出来的，不该被赋值。"""
        return 3.14159 * self.r ** 2


c = Circle(2)
print(f"{c.area:.2f}")     # 12.57
# c.area = 100             # AttributeError: property 'area' has no setter
```

**什么时候该用 property**：属性之间有关系（面积由半径算）、需要校验、或者以后可能要从"存字段"改成"算出来"。
**什么时候别用**：只是 `return self.x` / `self.x = x` 的转发——那不叫封装，只叫多打几行字（单元 8 的 2.4 讲过：Python 不做私有字段，直接暴露属性是常态）。

### 2.11 `@classmethod` 与 `@staticmethod`

类里能定义三种方法，区别就在第一个参数：

| 写法 | 第一个参数 | 能访问什么 | 典型用途 |
|---|---|---|---|
| 普通方法 | `self`（实例） | 实例属性 + 类属性 | 绝大多数情况 |
| `@classmethod` | `cls`（类本身） | 类属性，拿不到实例 | **替代构造函数** |
| `@staticmethod` | 没有 | 什么都不自动给 | 与类相关但不需要对象的工具函数 |

**`@classmethod` 最实用的场景是"从别的格式造对象"**：

```python
class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, text):
        """从 '2026-10-31' 造一个 Date——cls 就是 Date 本身。"""
        y, m, d = text.split("-")
        return cls(int(y), int(m), int(d))      # 用 cls 而不是写死 Date

    def __repr__(self):
        return f"Date({self.year}, {self.month}, {self.day})"


d1 = Date(2026, 10, 31)
d2 = Date.from_string("2026-10-31")
print(d1, d2)          # Date(2026, 10, 31) Date(2026, 10, 31)
```

写 `cls(...)` 而不是 `Date(...)`，好处是**子类继承时自动用子类**：

```python
class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, text):
        y, m, d = text.split("-")
        return cls(int(y), int(m), int(d))


class Holiday(Date):
    pass


h = Holiday.from_string("2027-01-01")
print(type(h).__name__)     # Holiday ← 不是 Date
```

**`@staticmethod` 就是"放在类里的普通函数"**，不自动传 self 或 cls。它的价值只是**归属清晰**：这个函数逻辑上属于这个类，就放进来。

```python
class Temperature:
    @staticmethod
    def c_to_f(c):
        """摄氏转华氏——不需要任何实例数据。"""
        return c * 9 / 5 + 32


print(Temperature.c_to_f(100))      # 212.0
```

**判断顺序**：需要实例数据 → 普通方法；需要类本身（造对象、读类属性）→ classmethod；都不需要 → staticmethod。
新手最常见的错误是**所有方法都写成普通方法，连不需要 self 的也强塞一个 self**。

### 2.12 `__eq__`：为什么两个"看起来一样"的对象不相等

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y


a = Point(1, 2)
b = Point(1, 2)
print(a == b)          # False  ← 坐标一模一样，却说不等
print(a is b)          # False
```

**因为默认的 `==` 比较的是"是不是同一个对象"**（等价于 `is`），而不是"内容是否相同"。
列表、字符串、数字能比内容，是因为它们都实现了 `__eq__`。你自己写的类没有，就退化成比身份。

想按内容比较，自己定义：

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        if not isinstance(other, Point):        # 类型不同就别硬比
            return NotImplemented               # 让 Python 去试对方的 __eq__
        return (self.x, self.y) == (other.x, other.y)

    def __repr__(self):
        return f"Point({self.x}, {self.y})"


print(Point(1, 2) == Point(1, 2))     # True
print(Point(1, 2) == Point(3, 4))     # False
print(Point(1, 2) == (1, 2))          # False（类型不同，不报错）
```

**这里有个必须知道的连带后果**：一旦你定义了 `__eq__`，这个类就**不能再当字典的键或放进集合**了：

```text
TypeError: unhashable type: 'Point'
```

原因是 Python 要求"相等的对象必须有相同的哈希值"，而自定义 `__eq__` 之后默认的哈希实现就不敢用了，于是把 `__hash__` 设成 `None`。要修就一起定义：

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        return hash((self.x, self.y))       # 用同样的字段算哈希


cache = {Point(1, 2): "值"}
print(cache[Point(1, 2)])                   # 值  ← 能当键了，且按内容找得到
```

顺带一提，想让对象能排序（`sorted()` 或 `<`），就实现 `__lt__`：

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __lt__(self, other):
        """先比 x，x 相同再比 y。"""
        return (self.x, self.y) < (other.x, other.y)

    def __repr__(self):
        return f"Point({self.x}, {self.y})"


print(sorted([Point(2, 1), Point(1, 5), Point(1, 2)]))
# [Point(1, 2), Point(1, 5), Point(2, 1)]
```

> 如果你只是想要一个"存数据、自动带 `__init__`/`__repr__`/`__eq__`"的类，标准库有个现成的
> `dataclasses.dataclass` 装饰器，一条装饰器就把上面这些都生成好。
> 阶段 1 不用急着用，但值得知道它存在——单元 21 会用到。

```python
    """银行账户。"""

        self.owner = owner
        self.balance = balance
        self.history = []

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须大于 0")
        self.balance += amount
        self.history.append(f"存款 {amount}")

        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount
        self.history.append(f"取款 {amount}")
        return self.balance
```

### 示例 8：随机点名器（seed 可复现）

`random` 的四个函数放在一个例子里对比，用 `seed(7)` 固定结果，所以你跑出来应该和下面完全一致。

```python
# roll_call.py —— 随机点名：抽一个、抽三个、打乱顺序
import random

names = ["张三", "李四", "王五", "赵六", "钱七", "孙八"]

random.seed(7)                          # 固定随机序列 → 结果可复现
print("抽一个  ", random.choice(names))
print("抽三个  ", random.sample(names, 3))     # 不放回，三人不重复

random.shuffle(names)                   # 原地打乱，不要接返回值
print("排队    ", names)
```

运行结果：

```text
抽一个   王五
抽三个   ['李四', '赵六', '张三']
排队     ['王五', '赵六', '李四', '孙八', '钱七', '张三']
```

三处值得注意：

1. **`seed(7)` 之后所有结果都固定**。删掉这一行，每次运行结果都不一样——写测试时这会让人误以为代码坏了。
2. **`sample` 抽出的三个人不会重复**，`choices` 会（有放回）。点名、抽奖用 `sample`，模拟掷骰子用 `choices`。
3. **`shuffle` 之后 `names` 本身变了**，因为它是原地修改；如果还要保留原始顺序，先 `order = names[:]` 复制一份再打乱。

```python
    """矩形。"""
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        """返回面积。"""
        return self.width * self.height

    def perimeter(self):
        """返回周长。"""
        return 2 * (self.width + self.height)

        """返回是否是正方形（宽等于高）。"""
```

```python
# student_class.py —— 学生类

class Student:
    """学生。"""
    def __init__(self, name, scores=None):
        self.name = name
        # 注意：这里用 None 然后再造列表，避免直接引用外部列表
        self.scores = list(scores) if scores else []

    def add_score(self, score):
        """添加一次成绩。"""
        self.scores.append(score)
        return self.scores

    def average(self):
        """返回平均分，没有成绩时返回 0。"""
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

    def highest(self):
        """返回最高分，没有成绩时返回 None。"""
        if not self.scores:
            return None
        return max(self.scores)

    def lowest(self):
        """返回最低分。"""
        if not self.scores:
            return None
        return min(self.scores)

    def is_pass(self):
        """平均分 60 分以上算及格。"""
        return self.average() >= 60

    def __str__(self):
        return f"{self.name} 的平均分是 {self.average():.2f}"


# ===== 测试 =====
student = Student("小明")
for score in [88, 92, 76, 95, 61]:
    student.add_score(score)

print(student)
print(f"最高分：{student.highest()}")
print(f"最低分：{student.lowest()}")

print(f"全部成绩：{student.scores}")
```

```python
class Shape:
    """形状基类：定义所有形状共有的东西。"""

        self.name = name

    def area(self):
        """计算面积 —— 由子类各自重写。"""

        return None

    def perimeter(self):
        """计算周长 —— 由子类各自重写。"""
        print(f"警告：{self.name} 没有实现 perimeter()，父类返回 None")
        return None

    def __str__(self):
        return f"{self.name}（{type(self).__name__}）"


class Rectangle(Shape):
    """矩形。"""
    def __init__(self, width, height):
        # 先调用父类的 __init__ 设置共有的 name 属性
        super().__init__("矩形")
        # 再设置自己的属性
        self.width = width
        self.height = height

    def area(self):
        """重写：矩形的面积。"""
        return self.width * self.height

    def perimeter(self):
        """重写：矩形的周长。"""
        return 2 * (self.width + self.height)


class Circle(Shape):
    """圆形。"""
    PI = 3.14159      # 类属性：圆周率

    def __init__(self, radius):
        super().__init__("圆形")
        self.radius = radius

    def area(self):
        """重写：圆的面积。"""
        return self.PI * self.radius ** 2

    def perimeter(self):
        """重写：圆的周长。"""
        return 2 * self.PI * self.radius


class Triangle(Shape):
    """三角形。"""
    def __init__(self, base, height):
        super().__init__("三角形")
        self.base = base
        self.height = height

    def area(self):
        return self.base * self.height / 2

    def perimeter(self):
        # 假设是等腰三角形，两腰长为 sqrt((base/2)^2 + height^2)
        side = ((self.base / 2) ** 2 + self.height ** 2) ** 0.5
        return self.base + 2 * side


class Square(Rectangle):
    """正方形 —— 继承矩形，只需要一个边长。"""
    def __init__(self, side):
        # 直接调用父类（矩形）的 __init__
        super().__init__(side, side)
```

```python
# hierarchy.py —— 三层继承

class Person:
    """人。"""
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        """打招呼。"""
        print(f"你好，我是{self.name}")

    def birthday(self):
        """过生日。"""
        self.age += 1

    def __str__(self):
        return f"{self.name}，{self.age} 岁"


class Employee(Person):
    """员工 —— 继承 Person。"""
    def __init__(self, name, age, company, salary):
        # 先让父类设置共有的 name 和 age
        super().__init__(name, age)
        self.company = company
        self.salary = salary            # 年薪

    def get_monthly(self):
        """返回月薪。"""
        return self.salary / 12

    def get_daily(self):
        """返回日薪（按 22 个工作日算）。"""
        return self.salary / 12 / 22

    def raise_salary(self, amount):
        """加薪。"""
        self.salary += amount
        return self.salary

    def __str__(self):
        # 用 super() 复用父类的字符串，再追加自己的信息
        return f"{super().__str__()}，在 {self.company} 工作，年薪 {self.salary} 元"


class Manager(Employee):
    """经理 —— 继承 Employee。"""
    def __init__(self, name, age, company, salary, team_size):
        # 调用祖父类的初始化（super() 会自动找对正确的父类）
        super().__init__(name, age, company, salary)
        self.team_size = team_size

    def __str__(self):
        # 复用 Employee 的 __str__，再追加团队信息
        return f"{super().__str__()}，管理 {self.team_size} 人团队"

    def performance_review(self):
        """经理独有的方法。"""
        return f"{self.name} 对 {self.team_size} 名下属进行了考核"


# ===== 测试 =====
print("--- 第一层：Person ---")
p = Person("张三", 30)
print(p)
p.greet()
p.birthday()
print(f"过完生日：{p}")

print("\n--- 第二层：Employee ---")
e = Employee("李四", 28, "腾讯", 240000)
print(e)
e.greet()                     # 继承自 Person
```

## 六、常见错误清单（务必逐条自查）

> 以下 6 类是写类时最高频的错误。类比单元 7 的错误清单一起对照效果更好。

### 错误 1：★ 方法忘记写 `self`

```python
class Counter:
    def __init__(self):
        self.count = 0

    # INTENTIONALLY-BROKEN 演示 3 种相关错误
    def increment_bad(self):
        # 错误 1a：赋值时左边忘了 self —— 这行创建了一个"局部变量"，
        # 函数一结束就没了，self.count 完全没变
        count = self.count + 1
        print(count)      # 打印 1，但 self.count 永远是 0

    def increment_worse(self, value):
        # 错误 1b：右边用 self，左边不用 —— 局部变量，出了函数就没了
        value = self.count + value
        print(value)

    def increment_wrong(self):
        # 错误 1c：干脆忘了加 1，结果永远不变
        print(self.count + 1)
```

**症状**：
- `NameError: name 'count' is not defined`（左边忘了写）
- 属性值永远不变 / 方法结束后"数据丢了"
- 属性变成 None 或 0

**原因**：`self.` 前缀是"把值存到**这个对象**身上"；漏了它就是在函数内部建了个临时变量。
**修法**：**给每一处属性读写都加上 `self.`**，然后检查这个类里有没有"出现了属性名但前面没有 `self.`"的地方。

### 错误 2：方法定义时忘了第一个参数 `self`

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    # INTENTIONALLY-BROKEN 演示：忘了 self 参数
    def area():
        return self.width * self.height     # NameError: name 'self' is not defined

    def perimeter(self):                    # 这个是对的
        return 2 * (self.width + self.height)


r = Rectangle(3, 4)
print(r.perimeter())     # 14
# print(r.area())        # TypeError: area() takes 0 positional arguments but 1 was given
```

**症状**：`TypeError: area() takes 0 positional arguments but 1 was given`，或 `NameError: name 'self' is not defined`
**原因**：定义时少写了 `self`，但调用时 Python 会自动传入对象，结果参数数量对不上。
**修法**：**每个方法（除了 `__init__`、`__str__` 等双下划线方法）定义时，第一个参数必须是 `self`**。判断标准很简单——方法体内如果出现了 `self.`，定义时必须有 `self` 参数。

### 错误 3：忘记冒号或缩进（和函数一样，但更隐蔽）

```python
# INTENTIONALLY-BROKEN 演示类的缩进错误
class Dog:
    def __init__(self, name):
    # 错误 3a：冒号后面必须有函数体，这里直接换了行
        self.name = name

    def bark(self)          # 错误 3b：括号后漏冒号
        print("汪汪")

    def age(self):
        return self.name    # 错误 3c：属性赋给了参数名，写成了 self.name = ...
```

**症状**：`SyntaxError: expected ':'` / `IndentationError: expected an indented block`
**原因**：`def` 行末必须有 `:`；`class` 体内所有代码（包括方法）必须有缩进。
**修法**：注意 `class` 层级比 `def` 层级多一层缩进——`class` 体是 4 空格，方法 `def` 也是 4 空格，但**方法体**是 8 空格：

```python
class Dog:
    def __init__(self, name):   # 4 空格（属于 class 体）
        self.name = name        # 8 空格（属于 def 体）
```

### 错误 4：属性名和方法名重名

```python
class Rectangle:
    def __init__(self, width, height):
        # INTENTIONALLY-BROKEN 演示属性名冲突
        self.perimeter = 2 * (width + height)   # 错误：perimeter 是属性

    def perimeter(self):       # 错误：同名方法把属性覆盖了
        return 2 * (self.width + self.height)


r = Rectangle(3, 4)
print(r.perimeter)       # 输出 <bound method...>  拿到的是方法不是数字
print(r.perimeter())     # 报错：用了 width 属性，但width 不存在 -> AttributeError
```

**症状**：拿到的是 `<bound method ...>` 而不是期望的数值；或者 `AttributeError: 'Rectangle' object has no attribute 'width'`（因为 `__init__` 里的属性被同名方法覆盖了）
**原因**：属性和方法都存在实例的命名空间里，**同名会互相覆盖**。后定义的 `def perimeter` 在类体里把之前的赋值干掉了。
**修法**：让名字有区分度：
```python
self._perimeter_value = 2 * (width + height)   # 属性加下划线前缀
def perimeter(self):                            # 方法保持好读的短名
    return self._perimeter_value
```

### 错误 5：`__init__` 里赋值目标写错（赋值给了参数，不是属性）

```python
class User:
    # INTENTIONALLY-BROKEN 演示三种常见笔误
    def __init__(self, name, age):
        self.name = name
        age = age        # 错误 5a：漏了 self.，age 只是个局部变量
                          # 后果：user.age 会 AttributeError
        self.age1 = age  # 错误 5b：属性名打错（age1），user.age 依然不存在
        self.nmae = name # 错误 5c：属性名拼写颠倒

    def show(self):
        print(self.name, self.age)     # 这里就崩了


u = User("小明", 18)
# print(u.age)      # AttributeError: 'User' object has no attribute 'age'
u.show()             # 同样崩在这里
```

**症状**：`AttributeError: 'User' object has no attribute 'age'`
**原因**：`age = age` 只是让局部变量 `age` 指向了自己的值，什么也没存进对象。
**修法**：`__init__` 里**每一行赋值左边必须有 `self.`**。养成习惯后可以这样自查——读完 `__init__`，检查"哪些属性应该存在"，然后在类的其他地方确认它们都能通过 `self.xxx` 访问到。

### 错误 6：子类忘了调 `super().__init__()`

```python
class Animal:
    def __init__(self, name):
        self.name = name          # 名字是父类设置的

    def speak(self):
        print(f"{self.name} 发出声音")


class Dog(Animal):
    # INTENTIONALLY-BROKEN 演示：忘了 super().__init__()
    def __init__(self, name, breed):
        # 如果这里不调用 super().__init__(name)，
        # 父类的 self.name 永远不会被设置
        self.breed = breed
        # 正确写法应该是在这一行：
        # super().__init__(name)

    def speak(self):
        print(f"{self.name} 说：汪汪")    # 这里访问 self.name 会崩


# d = Dog("旺财", "柴犬")
# d.speak()        # AttributeError: 'Dog' object has no attribute 'name'
```

**症状**：`AttributeError: 'Dog' object has no attribute 'name'` —— 属性明明在父类的 `__init__` 里设置了，为什么没有？
**原因**：父类的 `__init__` **不会自动执行**。你必须在子类的 `__init__` 里显式调用 `super().__init__(...)`，父类的代码才会跑。
**修法**：子类的 `__init__` 第一件事就是 `super().__init__(需要传给父类的参数)`，然后再设置子类自己的属性。顺序上**先 super 再自己的**，这是稳妥的习惯。

## 七、本单元验收自测

**1. 简答题**：下面代码的 `count` 属性最后是多少？为什么？
```python
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        count = self.count + 1


c = Counter()
c.increment()
print(c.count)
```
> **要点**：输出 `0`。`count = self.count + 1` 这一行左边**漏了 `self.`**，所以它只是创建了一个局部变量 `count`，函数一结束就消失了。对象上的 `self.count` 从未被修改过，仍然是 0。正确写法是 `self.count = self.count + 1`。

**2. 判断题**：定义方法时，`self` 是 Python 的关键字，不写会报语法错误。
> **要点**：错误。`self` **不是关键字**，它只是函数的第一个普通参数，Python 完全允许你叫它别的名字（比如 `this`，能正常运行）。但它也不写会报 `TypeError: area() takes 0 positional arguments but 1 was given`（因为调用对象时 Python 会自动传入对象，参数数量对不上）。约定俗成必须写 `self`，是为了让所有 Python 代码保持一致、别人能读懂。

**3. 简答题**：

```python
    def __str__(self):
        return f"这是一辆{self.make}"


class ElectricCar(Car):
    def __init__(self, make, battery):
        self.battery = battery


c = ElectricCar("特斯拉", 75)
print(c.make)
```
会输出什么？应该怎么修？
> **要点**：报 `AttributeError: 'ElectricCar' object has no attribute 'make'`。子类的 `__init__` 里没有调用 `super().__init__(make)`，所以父类设置 `self.make` 的那段代码根本没执行。修复方法：在子类 `__init__` 里加上 `super().__init__(make)`，并且**最好放在 `self.battery = battery` 之前**。

**4. 简答题**：下面这段代码输出什么？为什么是这个结果？
```python
class Dog:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name}：汪汪")


class Puppy(Dog):
    def speak(self):
        print(f"{self.name}：呜呜")


d = Dog("旺财")
p = Puppy("豆豆")
for animal in [d, p]:
    animal.speak()
```
> **要点**：输出两行——`旺财：汪汪` 和 `豆豆：呜呜`。注意 `Puppy` **没有定义 `__init__`**，但 `self.name` 依然可用——因为它继承了 `Dog.__init__`，创建 `Puppy("豆豆")` 时会自动调用父类的初始化方法。同时 `Puppy` 重写了 `speak()`，`animal.speak()` 会根据对象的真实类型调用对应版本，这正是多态。

**5. 简答题**：什么时候该用继承，什么时候该用组合？举一个各自的例子。
> **要点**：判断标准是关系的性质。**"是一个"（is-a）用继承**：`Dog` 是一种 `Animal`，`ElectricCar` 是一种 `Car`，它们天然共享父类的属性和行为。**"有一个"（has-a）用组合**：`Car` 有**一个** `Engine`，`BankAccount` 有**一个** `Owner`，这些是"组成部分"关系而不是"种类"关系。经验法则是拿不准时优先用组合，因为它更灵活、耦合更低，也不容易因为继承层次太深而失控。
