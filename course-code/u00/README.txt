单元 0 · 00-单元0-环境与工具.md
============================================================

先从这个开始：hello.py

本目录的 .py 文件全部抽自讲义，可直接用 Python 运行。
snippets/ 里是「片段」——属于某个文件的一部分，不能单独运行。
.v2/.v3 是同一文件的其它版本（教材练习的参考答案），按需查看。

  hello.py                           ← 示例 1：第一个脚本
  order_demo.py                      ← 示例 2：先写后跑的顺序演示（体会"从上到下"）
  calc_demo.py                       ← 示例 3：用变量做一次简单计算
  print_demo.py                      ← 示例 4：认识 print 的分隔符与注释
  fstring_demo.py                    ← 示例 5：用 f-string 把变量嵌进文字里
  type_demo.py                       ← 示例 6：初识类型与打印类型
  me.py                              ← 参考答案 0-2
  intro.py                           ← 参考答案 0-3（两种写法）
  types.py                           ← 参考答案 0-4
  ask_name.py                        ← 参考答案 0-5
  practice.py                        ← 参考答案 0-6
  fix_me.py                          ← 参考答案 0-7

运行：在终端执行  python 文件名.py
缺库时先装：python -m pip install 包名
