Python 学习路线图

依据《Python 编程：从入门到实践（第 3 版）》· 中文版全 20 章 + 附录 A–E · 零基础 → 能独立完成并交付完整项目

配套： 课程课件 23 页 111 节课节页 总课表
目标独立做小项目
当前基础零基础
节奏不设期限 · 每周 1 单元
预计总周期约 29 周（按每周 6–8 小时；时间少就顺延，第 13 周左右与最后一周各有一道关卡）

阶段 0 · 环境与工具

Week 0 · 只花一个下午，但跳过它后面每一步都会疼

阶段 1 · 语法基础（第 1–11 章）

约 11–13 周 · 每周 1 章 · 占比 ~35%

每章固定闭环：读章节 → 敲完全部代码 → 做完全部「动手练 Try it yourself」→ 完成「动手项目」→ 合上书自测 5 问。四项缺一不可。

关卡 1 · 不达标别进阶段 2

  1. 合上书，10 分钟内手写一个"猜数字"游戏（while + input + if + 随机数）
  2. 手写一个含 __init__、方法、继承的类，并能解释 self 是什么
  3. 用 pytest 给第 11 章的函数写 3 条测试并全部通过
  4. 能读懂并修复一个 30 行 Python 脚本里的 IndentationError / NameError

阶段 2 · 项目实践（第 12–20 章）

约 14–20 周 · 教材主战场 · 占比 ~50%

每个项目统一走工程流程：读需求 → 自己先拆解（别急着抄）→ 查官方文档 → 编码 → git 提交 → 写 README → 重构。每个小节一次 commit。

项目一 · 外星人入侵（第 12–14 章）· 建议 6–8 周

项目二 · 数据可视化（第 15–17 章）· 建议 4–5 周

项目三 · Web 应用「学习笔记」（第 18–20 章）· 建议 6–8 周

关卡 2 · 判定"能独立做项目"

  1. 3 个项目全部跑通，且已推到公开仓库，每个都有 README + requirements.txt
  2. 学习笔记已部署上线，公网可访问，错误页已定制
  3. 能用 pytest 给自己的函数写测试并跑过
  4. 接手一个没写过的 500 行 Python 项目，能读懂结构并定位一个 bug

阶段 3 · 工程能力补齐

与阶段 2 并行穿插 · 占比 ~15% · 教材刻意不讲，但决定你是"会写代码的人"还是"会交付软件的人"

常见卡点与对策

卡在哪为什么怎么办
第 4–7 章（列表→if→while）语法密度陡增，缩进错误多回头重做"动手练"，一道题写三遍
第 8 章 函数抽象思维跳跃，卡在"不知道该拆成几个函数"先抄 3 个教材例子，再自己改需求
第 9 章 类零基础最劝退的一章允许慢 2 周；照着"学生/购物车/账户"自己造 3 个类
外星人入侵卡住pygame 报错信息难读、代码量大执行 13.7 节：逐模块单跑；先跑示例项目
Django 安装报错版本/依赖冲突建虚拟环境再装；严格按教材版本；查附录 E
