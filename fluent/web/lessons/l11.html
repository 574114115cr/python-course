变量不是盒子：引用、别名与拷贝

本节目标：能用「标签—对象」模型解释赋值、`is`/`==`、别名、浅拷贝与深拷贝，并预测一段代码的输出。

讲解

把变量想成盒子，是绝大多数引用 bug 的源头。正确的模型是：对象在堆上，变量是贴在对象上的标签。赋值只是贴新标签，不复制对象。

Pythona = [1, 2, 3]
b = a                 # 同一个对象的两个标签
b.append(4)
print(a)              # [1, 2, 3, 4]

print(a is b)         # True：身份相同
print(a == [1, 2, 3, 4])   # True：值相同

is 比较 id()，== 调用 __eq__。判断 None 用 is None，因为 None 是单例；判断数值、字符串内容用 ==。

浅拷贝只复制最外层容器，内部元素仍是共享引用：

Pythonimport copy

grid = [[1, 2], [3, 4]]
shallow = copy.copy(grid)      # 或 grid[:] / list(grid)
shallow[0][0] = 99
print(grid)                    # [[99, 2], [3, 4]]  ← 内层共享

deep = copy.deepcopy(grid)     # 递归复制，互不影响

延伸：浅拷贝返回自身，参数是引用

copy.copy() 对不可变对象常常直接返回自身，因为没必要复制：

Pythonimport copy
t = (1, 2, 3)
print(copy.copy(t) is t)          # True
l = [[1], [2]]
c = copy.copy(l)
print(c is l, c[0] is l[0])       # False True，内层仍共享

函数参数也是引用：在函数里 x += [1] 会改到调用方的 list，x = x + [1] 只是本地重绑定，外面看不到。要不要防御性复制，取决于这个参数是不是「你的所有物」——如果是调用方传进来、还要继续用的对象，就地修改必须写进文档，否则就是隐形副作用。

关键点

  • 赋值永不复制，b = a 只是多一个引用。
  • 浅拷贝复制容器，不复制元素；嵌套结构要用 deepcopy。
  • 不可变对象也可能共享：小整数、短字符串会被驻留（interning），所以 a is b 偶尔为 True，但不要依赖。
  • 函数传参是「对象引用传递」：在函数里改可变参数会影响调用方，重新绑定形参则不会。

动手

  1. 预测下面代码的输出，再运行验证：
Pythondef f(xs):
    xs.append(1)
    xs = [9]
    return xs

data = []
print(f(data), data)
  1. 用 id() 打印 a、b = a、copy.copy(a) 三个对象的身份，标出哪些相同。
  2. 构造三层嵌套列表，分别用浅拷贝和深拷贝修改最内层，比较原数据。
