泛型：TypeVar、Generic 与型变

本节目标：能定义泛型类与泛型函数，用 `bound` 限制类型参数，并解释协变、逆变、不变。

讲解

TypeVar 是类型变量，让「输入类型」与「输出类型」建立关系：

Pythonfrom typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]

first([1, 2]) 推出 int，first(["a"]) 推出 str。带约束时用 bound：

Pythonfrom typing import TypeVar
from collections.abc import Sized

S = TypeVar("S", bound=Sized)

def longest(a: S, b: S) -> S:
    return a if len(a) >= len(b) else b

泛型类：

Pythonfrom typing import Generic, TypeVar

T = TypeVar("T")

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

型变描述「子类型关系能否传递到容器」：

  • 不变（invariant）：list[Dog] 不是 list[Animal]，因为往里塞猫会破坏原列表。
  • 协变（covariant）：只读容器可以，Sequence[Dog] 是 Sequence[Animal]。
  • 逆变（contravariant）：只作为输入的 Callable 参数可以。

延伸：TypedDict 的可选键与重载的实现体

TypedDict 描述「带固定键名的 dict」，默认所有键必需；可选键有两种写法：

Pythonfrom typing import TypedDict, NotRequired, Required   # 3.11+

class Movie(TypedDict):
    title: str
    year: NotRequired[int]        # 3.11+；3.10 用 total=False 再补 Required

m: Movie = {"title": "Alien"}     # 合法，year 可省

3.10 及更早只有 total=False（全部可选），要用 Required[...] 逐个标回必需。TypedDict 只约束静态形状，运行时就是普通 dict，多余键不会报错。

关于重载：@overload 的多个签名只是给检查器看的，最后一个实现体的参数必须能接受所有重载的组合（通常用联合类型或 *args, **kwargs），返回类型也要能覆盖。写错实现体签名时检查器会明确报「实现与重载不兼容」，这是最常踩的坑。

关键点

  • list 是不变的，Sequence 是协变的；只读场景优先注解为 Sequence。
  • TypeVar 只在同一次调用内保持类型一致，不是全局绑定。
  • 能用 Protocol 就别造基类，泛型 + 协议能覆盖大多数约束。
  • 别给 TypeVar 加无意义的 bound=object，等于没约束。

动手

  1. 写 pair(a: T, b: T) -> tuple[T, T]，用 mypy 验证混合类型会报错。
  2. 实现 Stack[T]，分别 push 三个 int，验证 pop() 的返回类型被推断为 int。
  3. 用 Sequence 与 list 各写一版 first，比较 mypy 对 list[Dog] 的接受度。

验收清单

  • 能写出带 bound 的 TypeVar 并解释约束作用
  • 能解释 list[Dog] 为什么不能传给 list[Animal]
  • 知道只读场景该用 Sequence 而不是 list
