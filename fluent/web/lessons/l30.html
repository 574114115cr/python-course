TypedDict、重载与运行时读取注解

本节目标：能用 TypedDict 描述固定键字典，用 `@overload` 描述多签名，用 `get_type_hints` 在运行时读取注解。

讲解

TypedDict 适合「本质是 dict，但键固定」的数据，比如 API 响应：

Pythonfrom typing import TypedDict

class Movie(TypedDict):
    title: str
    year: int
    rating: float

m: Movie = {"title": "Alien", "year": 1979, "rating": 8.5}

total=False 让所有键可选；Required / NotRequired 可以逐键控制。

重载用于「同一个函数，不同输入返回不同类型」：

Pythonfrom typing import overload

@overload
def parse(x: str) -> int: ...
@overload
def parse(x: bytes) -> str: ...
def parse(x):
    if isinstance(x, str):
        return int(x)
    return x.decode()

实现体的签名不对外暴露，调用方只看重载签名；但 mypy 会检查实现体与重载是否兼容。@overload 只在静态检查时生效。

运行时读取注解用 typing.get_type_hints（会解析字符串注解与前向引用）：

Pythonfrom typing import get_type_hints

def f(x: "int", y: list["str"]) -> None:
    ...

print(get_type_hints(f))
# {'x': <class 'int'>, 'y': list[str], 'return': NoneType}

延伸：型变只影响静态检查

Pythonfrom typing import TypeVar, Generic

T_co = TypeVar("T_co", covariant=True)      # 只读产出，协变
T_contra = TypeVar("T_contra", contravariant=True)   # 只消费，逆变

class Producer(Generic[T_co]):
    def get(self) -> T_co: ...

class Consumer(Generic[T_contra]):
    def put(self, x: T_contra) -> None: ...

规则的直觉：只往外给的容器可以协变（Producer[Dog] 是 Producer[Animal]），只往里收的可以逆变，既读又写的必须不变（list 就是不变，所以 list[Dog] 不能当 list[Animal] 用）。这些声明只在静态检查时生效，运行时 TypeVar 不产生任何行为差异，也不能据此做 isinstance 判断。

关键点

  • TypedDict 不做运行时校验，它只是给检查器看的形状。
  • 重载签名必须与实现兼容，否则 mypy 报 overload 错误。
  • __annotations__ 可能是字符串（from __future__ import annotations），要用 get_type_hints 求值。
  • 运行时读注解可以驱动校验、序列化、依赖注入，但要注意循环导入。

动手

  1. 用 TypedDict 描述一个 API 响应，写一个函数返回该类型，并让 mypy 检查。
  2. 用 @overload 实现 double(x)：int 返回 int，str 返回重复字符串。
  3. 写一个 validate(obj)，用 get_type_hints 读取 dataclass 字段类型并做简单校验。

验收清单

  • 能用 TypedDict 替代「键名靠猜」的 dict
  • 能写出两个重载签名 + 一个实现体
  • 会用 get_type_hints 处理字符串注解
