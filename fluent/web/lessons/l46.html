描述符：把属性访问变成可复用逻辑

本节目标：能写出数据描述符与非数据描述符，解释属性查找优先级，并用描述符实现一个「惰性属性」。

讲解

描述符是实现了 __get__、__set__、__delete__ 中至少一个的类。它挂在类上，控制实例的属性访问。

Pythonclass Positive:
    def __set_name__(self, owner, name):
        self.name = "_" + name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return getattr(obj, self.name)

    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError("must be positive")
        setattr(obj, self.name, value)

class Order:
    qty = Positive()
    price = Positive()

查找优先级（简化）：

  1. 类型上的数据描述符（有 __set__ 或 __delete__）
  2. 实例 __dict__
  3. 类型上的非数据描述符（只有 __get__）
  4. 类属性
  5. __getattr__

非数据描述符适合做惰性属性，因为第一次计算后写进实例字典，后续直接命中字典：

Pythonclass Lazy:
    def __init__(self, fn):
        self.fn = fn
        self.name = fn.__name__

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        value = self.fn(obj)
        setattr(obj, self.name, value)
        return value

class Report:
    @Lazy
    def total(self):
        print("computing")
        return 42

延伸：函数就是非数据描述符

函数只实现 __get__（没有 __set__），属于非数据描述符，被存在类上；实例访问时 __get__ 返回绑定方法。这解释了两件事：

Pythonclass C:
    def m(self): return "method"

c = C()
print(c.m())                 # method
c.m = lambda: "instance"
print(c.m())                 # instance ← 实例字典盖住了方法
  1. 为什么实例属性可以「盖住」方法（非数据描述符优先级低于实例字典）。
  2. 为什么 property 盖不住（它是数据描述符，优先级最高）。

完整优先级：数据描述符 > 实例字典 > 非数据描述符 > 类属性。这条规则是所有「属性拦截」方案的地基：想拦住赋值就必须实现 __set__（或 __delete__）。

__set_name__（3.6+）在类创建时被调用，描述符靠它知道自己叫 name，不用再手动传名字：

Pythonclass Field:
    def __set_name__(self, owner, name):
        self.name = name

关键点

  • property 本身就是数据描述符，所以它能覆盖实例字典。
  • 数据描述符优先于实例字典，非数据描述符不优先。
  • __set_name__ 在类创建时调用，用来拿到属性名，避免手写字符串。
  • 描述符是类属性，每个实例共享同一个描述符对象，状态要存在实例上。

动手

  1. 实现 Positive，给 Order 的两个字段加校验，测试非法值。
  2. 实现 Lazy，验证第二次访问不再打印 computing。
  3. 把 Lazy 改成数据描述符（加 __set__），观察惰性缓存是否失效，并解释原因。

验收清单

  • 能背出属性查找的五步优先级
  • 能区分数据描述符与非数据描述符
  • 会用 __set_name__ 避免硬编码属性名
