集合与不可变映射：用集合运算替代循环

本节目标：能用集合运算完成去重、交并差与成员测试，并知道什么时候该用 frozenset 或 MappingProxyType。

讲解

集合的核心价值是成员测试 O(1) 和集合代数。很多「两层 for 循环 + if」的代码，都可以压成一次集合运算：

Pythona = {"alice", "bob", "cid"}
b = {"bob", "dave"}

print(a | b)      # 并集
print(a & b)      # 交集
print(a - b)      # 差集：在 a 不在 b
print(a ^ b)      # 对称差
print(a <= {"alice", "bob", "cid", "dave"})   # 子集判断

去重并保序是常见需求，标准写法是 list(dict.fromkeys(items))——利用 dict 的去重与插入顺序，而不是 list(set(...))（后者会打乱顺序）：

Pythonitems = ["b", "a", "b", "c", "a"]
print(list(dict.fromkeys(items)))   # ['b', 'a', 'c']

集合本身可变，因此不可哈希，不能作为 dict 的键；frozenset 不可变、可哈希，适合做「键」或「缓存标识」：

Pythoncache = {}
key = frozenset({"read", "write"})
cache[key] = "permission-set"

只读映射用 types.MappingProxyType 包一层，外部拿不到写接口：

Pythonfrom types import MappingProxyType
CONFIG = MappingProxyType({"debug": False})
# CONFIG["debug"] = True   → TypeError

延伸：视图做集合运算的前提

d.items() 返回视图，支持 &、|、- 做集合运算，但要求每个键值对可哈希——值里放 list 就直接 TypeError：

Pythona = {"x": 1, "y": 2}; b = {"y": 2, "z": 3}
print(a.items() & b.items())    # {('y', 2)}
print(a.keys() | b.keys())      # {'x', 'y', 'z'}

MappingProxyType 是只读代理，不是快照：底层 dict 一变，代理看到的就是新值。

Pythonfrom types import MappingProxyType
cfg = {"debug": True}
ro = MappingProxyType(cfg)
cfg["debug"] = False
print(ro["debug"])      # False

要真快照得 dict(cfg) 复制一份。

关键点

  • 集合元素必须可哈希，所以不能把 list 放进 set；需要放就用 tuple 或 frozenset。
  • &、| 对 set 是集合运算，对 dict 的键视图也能用：d1.keys() & d2.keys() 直接求共同键。
  • in 在 set 上是 O(1)，在 list 上是 O(n)；循环里做成员测试时先转 set。
  • 空集合只能写 set()，{} 是空字典。

动手

  1. 有两份用户名单（老用户、新用户），求「新增」「流失」「两边都有」三个集合。
  2. 用 frozenset 做缓存键，缓存「两个单词的字母集合是否相同」的判断结果。
  3. 把一个 10 万元素的 list 去重并保持原顺序，比较两种写法的耗时与结果差异。

验收清单

  • 能用集合运算重写一段「双层循环找共同元素」的代码
  • 知道 list(set(x)) 会丢顺序，并知道替代写法
  • 能解释为什么 frozenset 能当 dict 的键而 set 不能
