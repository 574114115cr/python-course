比较、增量赋值与一致性

本节目标：能用 `total_ordering` 补齐比较运算符，实现语义正确的 `+=`，并检查相等/哈希/排序三者是否自洽。

讲解

只需要定义 __eq__ 和一个顺序方法，total_ordering 会补齐其余：

Pythonfrom functools import total_ordering

@total_ordering
class Version:
    def __init__(self, text):
        self.parts = tuple(int(x) for x in text.split("."))

    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts == other.parts

    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts < other.parts

增量赋值 += 优先调用 __iadd__；没有则退化为 a = a + b。可变类型应实现 __iadd__ 并返回 self：

Pythonclass Bag:
    def __init__(self, items=()):
        self.items = list(items)

    def __iadd__(self, other):
        self.items.extend(other)
        return self

一致性检查清单：

  • a == b 为真时，hash(a) == hash(b) 必须为真；
  • a < b 与 b > a 必须一致；
  • a == a 必须为真（除非对象是 NaN 这类特例）；
  • 排序结果不能依赖调用顺序（稳定排序另说）。

延伸：iadd 返回 self 才算原地

c += d 的语义是「重新绑定 c」，但你可以在 __iadd__ 里选择原地改再返回 self，也可以新建对象返回。前者调用方看到的别名会一起变，后者不会：

Pythonclass Score:
    def __init__(self, v): self.v = v
    def __iadd__(self, n):
        self.v += n
        return self                 # 原地：别名同步可见
    def __repr__(self): return f"Score({self.v})"

a = Score(1); b = a; a += 2
print(a, b)                         # Score(3) Score(3)

如果 __iadd__ 忘了 return，a += 2 会把 a 绑成 None，这是最隐蔽的 bug 之一。可变对象（list、set、numpy 数组）通常原地，不可变对象（tuple、str、int）必然新建——判断标准就是「这个类型能不能改内容」。

关键点

  • total_ordering 要求 __eq__ 与 __lt__ 同时存在，否则报错。
  • __iadd__ 必须返回 self，返回 None 会让 a 变成 None。
  • 浮点 NaN 破坏自反性，涉及 NaN 的比较要单独处理。
  • 比较运算符不要做副作用操作，调用方默认它是纯函数。

动手

  1. 用 total_ordering 实现 Version("1.2.3") 的比较，验证 <=、>、>= 全部可用。
  2. 实现 Bag.__iadd__，验证 b += [1, 2] 后 b 仍是原对象（用 id 检查）。
  3. 写一个测试，检查相等、哈希、排序三者在 10 组数据上是否自洽。

验收清单

  • 能用 total_ordering 补齐四个比较运算符
  • 知道 __iadd__ 的返回值要求
  • 能列出相等/哈希/排序一致性的至少三条规则
