迭代协议：iter、next 与 StopIteration

本节目标：能解释 `for` 的展开过程，区分可迭代对象与迭代器，并手写一个只遍历一次的迭代器类。

讲解

for x in obj 的等价展开：

Pythonit = iter(obj)          # 调 obj.__iter__()
while True:
    try:
        x = next(it)    # 调 it.__next__()
    except StopIteration:
        break
    ...

两个概念要分清：

  • 可迭代对象（iterable）：实现 __iter__，能返回迭代器；list、str、dict 都是。
  • 迭代器（iterator）：实现 __next__，并且 __iter__ 返回 self；只能遍历一次。
Pythonclass Countdown:
    """可迭代对象：每次 iter() 都返回一个新的迭代器。"""
    def __init__(self, start):
        self.start = start

    def __iter__(self):
        return CountdownIter(self.start)

class CountdownIter:
    def __init__(self, current):
        self.current = current

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        n = self.current
        self.current -= 1
        return n

print(list(Countdown(3)))   # [3, 2, 1]
print(list(Countdown(3)))   # [3, 2, 1]，可重复遍历

延伸：iter(callable, sentinel) 与接口泛化

iter(callable, sentinel) 反复调用直到返回哨兵值，适合「读一块、到 EOF 停」这类没有现成迭代器的场景：

Pythonimport io
f = io.StringIO("a\nb\n")
for line in iter(f.readline, ""):
    print(repr(line))          # 'a\n' 'b\n'

比手写 while True: line = f.readline(); if not line: break 短，而且能直接进 for、list()、生成器表达式。常和 functools.partial 配合：iter(partial(input, "> "), "quit")。

泛化层面：函数签名收 Iterable[T] 而不是 list[T]，返回 Iterator[T] 而不是具体容器。调用方传生成器、视图、数据库游标都能接，而且不承诺「可重复遍历」——承诺了就得先 list()，那是调用方的选择。

关键点

  • 迭代器一定可迭代，可迭代对象不一定是迭代器。
  • __next__ 用 raise StopIteration 表示结束，不要返回 None 当哨兵。
  • 迭代器耗尽后不会重置，需要重新遍历就重新 iter()。
  • 在生成器里 return value 会成为 StopIteration.value，一般不用。

动手

  1. 手写 Countdown 与 CountdownIter，用 list() 与 for 各遍历一次。
  2. 只实现 __iter__ 返回 self 且没有 __next__，观察 for 的报错。
  3. 用 iter(callable, sentinel) 读取一个「直到空字符串为止」的输入序列。

验收清单

  • 能写出 for 的等价 while 展开
  • 能区分可迭代对象与迭代器，并各举一例
  • 知道迭代器耗尽后的行为
