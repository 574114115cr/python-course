模式匹配与 else 块

本节目标：能用 `match` 解构序列、映射与类实例，写出带 guard 的分支，并正确使用 `for/while/try` 的 `else`。

讲解

match 不是 switch，它做的是结构解构 + 绑定：

Pythondef handle(command):
    match command.split():
        case ["go", direction]:
            return f"moving {direction}"
        case ["drop", *items]:
            return f"dropping {items}"
        case ["look"]:
            return "looking around"
        case _:
            return "unknown"

可以匹配映射、类实例，并加守卫条件：

Pythonmatch point:
    case {"x": 0, "y": 0}:
        print("origin")
    case Point(x=0, y=y) if y > 0:
        print("positive y-axis", y)
    case Point(x=x, y=y):
        print("point", x, y)

else 块在循环正常结束（没 break）时执行，在 try 没抛异常时执行：

Pythonfor x in data:
    if x == target:
        print("found")
        break
else:
    print("not found")     # 只有没 break 才执行

try:
    risky()
except ValueError:
    print("bad value")
else:
    print("no exception")  # 只有 try 成功才执行

延伸：for/else、try/else 与模式匹配解构

for ... else 的 else 在「循环正常跑完、没被 break」时执行，找第一个匹配项时最省：

Pythondef find(xs, target):
    for i, x in enumerate(xs):
        if x == target:
            print("found at", i)
            break
    else:
        print("not found")

try ... else 的 else 只在 try 没抛异常时执行，作用是把「不希望在异常处理范围内的代码」挪出去，避免误捕自己逻辑里的同名异常。while ... else 同理。

模式匹配写解释器时，case [op, *args] 直接解构列表，比 isinstance + 下标清晰得多：

Pythondef evaluate(expr):
    match expr:
        case ["+", a, b]: return a + b
        case ["-", a, b]: return a - b
        case ["neg", a]:  return -a
        case n:           return n        # 兜底：变量名绑定任意值

print(evaluate(["+", 1, ["neg", 2]]))

注意 case n 是捕获而不是比较，要比较常量得用 case 1: 或 case Color.RED:；捕获模式永远不会失败，所以必须放最后。

关键点

  • case _ 是兜底，没有它且无匹配时什么都不做（不报错）。
  • 绑定变量只在分支内有效，分支结束后不要依赖。
  • 序列模式区分 tuple/list：case [a, b] 匹配任何序列，case (a, b) 也是。
  • 循环 else 容易误读，团队代码里建议加注释，或改用标志变量。

动手

  1. 用 match 写一个命令解析器，支持 go/drop/look/未知四类。
  2. 用 match 匹配 Point 实例，覆盖原点、x 轴、y 轴、普通点。
  3. 用 for...else 实现「查找第一个满足条件的元素，找不到返回 None」。

验收清单

  • 能用 match 解构序列、映射、类实例三种结构
  • 知道 case _ 缺失时的行为
  • 能正确解释并写出 for...else 与 try...else
