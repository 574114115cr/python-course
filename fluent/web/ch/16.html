运算符重载

原书这一章的写法，Python 为什么这样选、换别的要付什么代价。

运算符是方法调用的语法糖，必须遵守「返回新对象」与「NotImplemented」两条约定。

项 内容
选择 __add__/__mul__/__matmul__ 返回新对象；类型不匹配返回 NotImplemented
主要替代 只提供 add() 方法；或就地修改操作数
替代为何落选 运算符能参与表达式与链式写法；就地修改违反直觉
付出的代价 每个运算符都要写反射版本（__radd__）；组合爆炸

当时的约束

数值与向量类需要 a + b、2 * v、a @ b 这类写法。如果只有方法，表达式会变成嵌套调用，可读性差。

候选方案

只给方法、重载运算符但就地修改、重载并返回新对象。选第三种：与内置数值类型保持一致。

为什么选它

因为「不可变值 + 返回新对象」是最不容易出错的语义：c = a + b 之后 a、b 不变，别名不会互相污染。NotImplemented 则让 Python 有机会尝试对方的反射方法。

代价与反例

__iadd__ 忘了 return self，a += b 会把 a 变成 None；返回 NotImplemented 与 raise NotImplementedError 是两件事，前者是协议、后者是异常；@ 的优先级和 * 相同，容易读错。

如果重来

只在「值类型」上重载运算符；可变类型最多提供 += 这类明确的就地方法，不重载算术。
