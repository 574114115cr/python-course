第 29 课 · 目标与要点

泛型：TypeVar、Generic 与型变

能定义泛型类与泛型函数，用 bound 限制类型参数，并解释协变、逆变、不变。
  • list 是不变的，Sequence 是协变的；只读场景优先注解为 Sequence。
  • TypeVar 只在同一次调用内保持类型一致，不是全局绑定。
  • 能用 Protocol 就别造基类，泛型 + 协议能覆盖大多数约束。
  • 别给 TypeVar 加无意义的 bound=object，等于没约束。

第 30 课 · 目标与要点

TypedDict、重载与运行时读取注解

能用 TypedDict 描述固定键字典，用 @overload 描述多签名，用 get_type_hints 在运行时读取注解。
  • TypedDict 不做运行时校验，它只是给检查器看的形状。
  • 重载签名必须与实现兼容，否则 mypy 报 overload 错误。
  • __annotations__ 可能是字符串（from __future__ import annotations），要用 get_type_hints 求值。
  • 运行时读注解可以驱动校验、序列化、依赖注入，但要注意循环导入。

第 31 课 · 目标与要点

运算符重载：一元、算术与 @

能为自定义类型实现 -、+、*、@，处理反射运算，并在类型不匹配时返回 NotImplemented。
  • 返回 NotImplemented，不要抛异常，让解释器有机会尝试另一侧。
  • @ 是矩阵乘法，NumPy 用得多；自己实现时要明确维度规则。
  • + 不应修改操作数，返回新对象；原地修改交给 +=。
  • 运算符语义要符合直觉：+ 表示合并/相加，不要拿来表示「删除」。
第 31 课 · 代码与实操

看一段，改一段

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        if not isinstance(scalar, (int, float)):
            return NotImplemented
        return Vector(self.x * scalar, self.y * scalar)

    __rmul__ = __mul__

    def __neg__(self):
        return Vector(-self.x, -self.y)
# ...
动手：实现 Vector 的 +、*、-，验证 3 * v 与 v * 3 都可用。
第 32 课 · 目标与要点

比较、增量赋值与一致性

能用 total_ordering 补齐比较运算符，实现语义正确的 +=，并检查相等/哈希/排序三者是否自洽。
  • total_ordering 要求 __eq__ 与 __lt__ 同时存在，否则报错。
  • __iadd__ 必须返回 self，返回 None 会让 a 变成 None。
  • 浮点 NaN 破坏自反性，涉及 NaN 的比较要单独处理。
  • 比较运算符不要做副作用操作，调用方默认它是纯函数。
第 32 课 · 代码与实操

看一段，改一段

from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, text):
        self.parts = tuple(int(x) for x in text.split("."))

    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts == other.parts

    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts < other.parts
动手：用 total_ordering 实现 Version("1.2.3") 的比较，验证 <=、>、>= 全部可用。
