第 9 课 · 目标与要点

数据类三件套：namedtuple、NamedTuple、dataclass

能为一个「只有字段」的类选出合适的数据类工具，并说清三者在可变性、类型提示、扩展性上的差异。
  • namedtuple 不可变，改字段要用 _replace() 生成新对象。
  • NamedTuple 的字段默认值必须放在最后，和函数参数规则一致。
  • dataclass 的 eq=True 默认开启，会比较所有字段；不想参与比较的字段用 field(compare=False)。
  • dataclass 不是「免费」的：字段多、创建频繁时，生成的 __eq__ 和 __repr__ 有成本，热路径要评估。
第 9 课 · 代码与实操

看一段，改一段

from collections import namedtuple

Point = namedtuple("Point", "x y")
p = Point(3, 4)
print(p.x, p[0], p)          # 3 3 Point(x=3, y=4)
print(p._replace(x=10))      # Point(x=10, y=4)

第 10 课 · 目标与要点

dataclass 进阶：默认值、校验、冻结与模式匹配

能用 field(default_factory=...) 处理可变默认值，用 __post_init__ 做校验，用 frozen 与 slots 控制可变性和内存。
  • 默认值工厂每个实例调用一次，field(default_factory=list) 不会共享列表。
  • frozen=True 是浅冻结：字段本身不可重新赋值，但字段指向的 list 仍可修改。
  • __post_init__ 在 __init__ 末尾调用，此时所有字段都已赋值，适合校验和派生。
  • slots=True 与 frozen=True 可以同时用，但继承时会受限制，别在会扩展的基类上开 slots。
第 10 课 · 代码与实操

看一段，改一段

from dataclasses import dataclass, field

@dataclass
class Article:
    title: str
    tags: list[str] = field(default_factory=list)
    views: int = field(default=0, compare=False)   # 不参与相等比较

第 11 课 · 目标与要点

变量不是盒子：引用、别名与拷贝

能用「标签—对象」模型解释赋值、is/==、别名、浅拷贝与深拷贝，并预测一段代码的输出。
  • 赋值永不复制，b = a 只是多一个引用。
  • 浅拷贝复制容器，不复制元素；嵌套结构要用 deepcopy。
  • 不可变对象也可能共享：小整数、短字符串会被驻留（interning），所以 a is b 偶尔为 True，但不要依赖。
  • 函数传参是「对象引用传递」：在函数里改可变参数会影响调用方，重新绑定形参则不会。

第 12 课 · 目标与要点

可变性、默认参数与对象生命周期

能识别可变默认参数、类属性共享、del 的真实语义，并在需要时用 weakref 管理缓存。
  • 默认参数只求值一次，可变默认值必须用 None 哨兵。
  • del x 删的是名字，其他引用仍然有效；del lst[0] 才是删元素。
  • 循环引用靠分代 GC 回收，不是引用计数；大量创建对象时可用 gc.collect() 观测。
  • 弱引用适合做缓存：WeakValueDictionary 让缓存项在外部不再使用时自动消失。
第 12 课 · 代码与实操

看一段，改一段

def add(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add(1))    # [1]
print(add(2))    # [1, 2]  ← 不是 [2]
