第 33 课 · 目标与要点

迭代协议：iter、next 与 StopIteration

能解释 for 的展开过程，区分可迭代对象与迭代器，并手写一个只遍历一次的迭代器类。
  • 迭代器一定可迭代，可迭代对象不一定是迭代器。
  • __next__ 用 raise StopIteration 表示结束，不要返回 None 当哨兵。
  • 迭代器耗尽后不会重置，需要重新遍历就重新 iter()。
  • 在生成器里 return value 会成为 StopIteration.value，一般不用。

第 34 课 · 目标与要点

生成器与 yield from

能写生成器函数、用 yield from 委派子生成器，并用 itertools 组合惰性管道。
  • 生成器只能遍历一次，需要重复使用就物化成 list。
  • yield 会暂停整个函数，包括局部变量；恢复时从暂停点继续。
  • yield from 不是 for ... yield 的简写：它还负责 send、throw、close 的委派。
  • 生成器里的异常在 next() 时抛出，try/except 要包在迭代处。
第 34 课 · 代码与实操

看一段，改一段

def countdown(n):
    while n > 0:
        yield n
        n -= 1

g = countdown(3)
print(next(g), next(g), next(g))   # 3 2 1

第 35 课 · 目标与要点

上下文管理器与 with

能实现 __enter__/__exit__，用 @contextmanager 简化写法，并用 ExitStack 动态管理多个资源。
  • __exit__ 的三个参数是异常类型、异常对象、traceback；无异常时全是 None。
  • return True 会吞异常，这是很多「静默失败」的来源。
  • @contextmanager 的 yield 只能出现一次，且必须放在 try/finally 里保证清理。
  • 上下文管理器可以复用，但每次 with 都是一次新的进入/退出。
第 35 课 · 代码与实操

看一段，改一段

class Timer:
    def __enter__(self):
        import time
        self.t0 = time.perf_counter()
        return self

    def __exit__(self, exc_type, exc, tb):
        import time
        self.elapsed = time.perf_counter() - self.t0
        return False        # False 表示不吞异常

with Timer() as t:
    sum(range(1_000_000))
print(f"{t.elapsed:.4f}s")

第 36 课 · 目标与要点

模式匹配与 else 块

能用 match 解构序列、映射与类实例，写出带 guard 的分支，并正确使用 for/while/try 的 else。
  • case _ 是兜底，没有它且无匹配时什么都不做（不报错）。
  • 绑定变量只在分支内有效，分支结束后不要依赖。
  • 序列模式区分 tuple/list：case [a, b] 匹配任何序列，case (a, b) 也是。
  • 循环 else 容易误读，团队代码里建议加注释，或改用标志变量。

def handle(command):

        case ["go", direction]:
