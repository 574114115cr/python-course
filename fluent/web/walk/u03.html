数据类与对象语义：一个发票类踩完五个坑

一个可以整段复制运行的完整程序 + 逐段讲解 + 真实输出。 先跑一遍，再对着输出读讲解，最后做文末的三处改动。

原书第 5 章把 dataclass 讲完，第 6 章才讲「Python 里的变量是标签不是盒子」。这里合成一个类，把默认值、可变默认、哈希、拷贝、相等一次踩完。

程序

Pythonimport copy
from dataclasses import dataclass, field, asdict, replace, FrozenInstanceError


@dataclass(frozen=True, slots=True)
class Money:
    """不可变值对象：金额 + 币种。frozen 让它可哈希，slots 让它更省内存。"""
    amount: int
    currency: str = "CNY"

    def __post_init__(self):
        if self.amount < 0:
            raise ValueError("金额不能为负")
        if self.currency not in ("CNY", "USD"):
            raise ValueError(f"不支持的币种：{self.currency}")

    def __add__(self, other):
        if not isinstance(other, Money) or other.currency != self.currency:
            return NotImplemented
        return Money(self.amount + other.amount, self.currency)


@dataclass
class Line:
    sku: str
    price: Money
    qty: int = 1
    tags: list = field(default_factory=list)      # 可变默认值必须用 factory

    @property
    def total(self):
        return Money(self.price.amount * self.qty, self.price.currency)


@dataclass
class Invoice:
    no: str
    lines: list = field(default_factory=list)

    @property
    def total(self):
        cur = self.lines[0].price.currency if self.lines else "CNY"
        return Money(sum(l.total.amount for l in self.lines), cur)


a = Money(1990)
b = Money(1010)
print("值对象  ", a, "| 相加", a + b, "| 相等", a + b == Money(3000))
try:
    a.amount = 1
except FrozenInstanceError as e:
    print("不可变  ", type(e).__name__)

l1 = Line("KB-01", Money(29900), 2, ["机械键盘"])
l2 = Line("MS-01", Money(8900))
inv = Invoice("INV-001", [l1, l2])
print("发票合计", inv.total)
print("asdict  ", asdict(l2))

# ② 两个 Line() 的 tags 不是同一个 list
print("独立列表", Line("A", Money(1)).tags is Line("B", Money(1)).tags)

# ③ 浅拷贝 vs 深拷贝：Invoice 的浅拷贝仍然共享 lines
shallow = copy.copy(inv)
deep = copy.deepcopy(inv)
shallow.lines.append(Line("X", Money(1)))
print("浅拷贝  ", len(inv.lines), "行（原对象被改到了）")
deep.lines.append(Line("Y", Money(1)))
print("深拷贝  ", len(inv.lines), "行（原对象没被动）")

# ④ 替换字段：dataclasses.replace 走一遍 __init__ 与 __post_init__
print("replace ", replace(a, amount=5000))

# ⑤ slots 的代价：实例没有 __dict__，加不了新属性
print("slots   ", "有 __dict__？", hasattr(a, "__dict__"), "| 字段", Money.__slots__)
try:
    a.discount = 10
except AttributeError as e:
    print("加字段  ", str(e)[:46])

逐段走读

  1. frozen=True 同时解决三件事。 属性不可写、自动获得 __hash__、可以放进 set 和当 dict 的键。__post_init__ 里仍可校验，因为它在冻结之前执行；一旦冻结，连 self.x = ... 都会抛 FrozenInstanceError。

  2. slots=True 是省内存的开关，不是免费的。 每个实例不再带 __dict__（hasattr(a, "__dict__") 为 False），属性固定，因此给 a.discount 赋值会失败（最后一段；frozen 会先拦下，抛的是 FrozenInstanceError，它是 AttributeError 的子类）。数据量大时它省下的内存很可观，代价是灵活性。

  3. 可变默认值必须 field(default_factory=list)。 直接写 tags: list = [] 会被 dataclass 直接拒绝（ValueError: mutable default）——这是它在帮你拦 bug。对照第二段输出：两个 Line() 的 tags 是不同对象，因为每次构造都调用一次 list()。

  4. __add__ 要检查币种。 币种不同返回 NotImplemented，Python 会再试对方的 __radd__，最终抛 TypeError，而不是把 100 元加 100 美元算出 200。值对象的运算必须守住语义边界。

  5. 浅拷贝只复制容器本身。 copy.copy(inv) 得到的 Invoice 是新的，但 lines 指向同一个 list，所以往里 append 会改到原对象；deepcopy 会递归复制，代价是慢，而且遇到不可复制的对象（文件句柄、锁）会失败。

  6. asdict 是深拷贝。 它不是简单地把 __dict__ 转成 dict，而是递归展开嵌套的数据类；replace(a, amount=5000) 则重新走一遍构造函数和 __post_init__，因此校验依然生效——这两点和「手写 __dict__ 复制」有本质区别。

跑通之后改三处

  • 把 frozen=True 去掉：a.amount = 1 不再报错，但 Money 也不能再放进 set（__hash__ 变 None）。
  • 把 field(default_factory=list) 改回 = []：构造 Line 时直接抛 ValueError。
  • 把 copy.copy(inv) 换成 copy.deepcopy：第三段输出的行数会变回 2，说明原对象没被改到。
