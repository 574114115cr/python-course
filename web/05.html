单元 5：字典

原书对照对应教材第 6 章「字典」

关键词：字典 dict、键值对、{} 创建、.keys() / .values() / .items()、get()、遍历字典、in 判断键、嵌套字典、OrderedDict 思维

这套课覆盖了教材哪些章 →

一、学习目标

完成本单元后，你应该能够：

  1. 解释「字典用键值对存储，查找速度与数据量无关」，并说清它和列表的根本区别。
  2. 用 {} 创建字典、添加/修改/删除键值对，正确区分「新增键」和「修改已有键」两种赋值。
  3. 熟练使用 .keys() .values() .items() 三种遍历方式，并能说出各自的适用场景。
  4. 用 .get() 安全地取值，并解释它相比 dict[键] 的优势。
  5. 用 in 判断键是否存在，并能遍历嵌套字典完成两层数据提取。
  6. 处理「列表套字典」这种真实数据形状：逐条读取、按字段分组、按条件筛出字段。

二、核心知识点讲解

2.1 列表按位置找，字典按名字找

列表的局限很明显：想找"小明的电话"，你必须记住小明在第几个位置。

Pythoncontacts = ["小明", "小红", "小刚"]
phones = ["13800138000", "13900139000", "13700137000"]
# 小明的电话在 phones[0]，这个"0"是隐性的、靠人脑维护的约定

字典把这种约定变成语言的一部分：

Pythoncontacts = {"小明": "13800138000", "小红": "13900139000"}
print(contacts["小明"])      # 13800138000

生活化类比： - 列表 = 一排有编号的抽屉。找东西靠数编号（第 3 个、第 7 个）。 - 字典 = 一个巨大的储物柜，每个柜门上都贴着标签。找东西靠读标签（"小明" → 拿到他的号码）。

这个差别在数据量大时是决定性的：列表找第 100 万项要数 100 万下，字典找任何一项都是"读标签 → 命中"，耗时基本不随数据量增长。

2.2 键值对：key → value

字典里的每一项是一个键值对： - 键（key）：唯一的标签，充当索引 - 值（value）：这个标签下存的东西

Pythonuser = {
    "name": "小明",     # "name" 是键，"小明" 是值
    "age": 18,
    "city": "杭州",
}

三条硬规则： 1. 键必须唯一——同一个键只能有一个值，重复赋值会覆盖旧值。 2. 键必须不可变——所以只能用字符串、数字、元组、布尔值、None，不能用列表（因为列表可以修改）。 3. 值可以是任何类型，包括另一个字典、列表，甚至另一个字典。

2.3 新增 vs 修改：同一行代码，两种含义

这是字典最容易困惑的一点：

Pythonscores = {"语文": 90}

scores["数学"] = 85# 键"数学"不存在 -> 新增一对
scores["语文"] = 95     # 键"语文"已存在 -> 修改值

print(len(scores))      # 2，只有两对，不是三对

Python 用最优雅的方式处理了这个问题：赋值语句不关心是新增还是修改，它只看这个键在不在。 你不需要写 add() 或 update()，一条 = 走天下。

删除键值对用 del：

Pythondel scores["数学"]
print(scores)      # {'语文': 95}

2.4 三种遍历方式

Pythonuser = {"name": "小明", "age": 18, "city": "杭州"}

# 只看键
for key in user:              # 等价于 for key in user.keys():
    print(key)

# 只看值
for value in user.values():
    print(value)

# 键和值都要 —— 最常用
for key, value in user.items():
    print(f"{key}: {value}")

# 遍历字典默认只给键，这是最容易踩的坑
for item in user:
    print(item)      # 输出 "name"，不是 "name: 小明"

for key in dict 实际等于 for key in dict.keys()，因为 dict.keys() 返回的对象在遍历行为上等同于键本身（它是一个"视图对象"，会随字典变化而变化，这点比列表拷贝更安全）。

2.5 .get()：不 crash 的取值方式

故意写错 · 先跑一遍看报错scores = {"语文": 90, "数学": 85}

print(scores["语文"])# 90   安全
print(scores["英语"])          # KeyError: '英语'   崩了

# .get() 提供默认值，键不存在也不崩
print(scores.get("语文"))       # 90
print(scores.get("英语"))       # None（键不存在时返回 None）
print(scores.get("英语", 0))    # 0    第二个参数是默认值
这是故意写错的示例——先自己跑一遍看报错，再对照下面的解析弄清错在哪

生活化类比：scores["英语"] 像直接拉开一个可能不存在的抽屉（柜子会"咔哒"响一声表示没有）；.get("英语", 0) 像先问柜管理员"有没有英语这格？没有的话给我 0"。

.get() 还有一个更妙的地方：链式访问

Pythonusers = {"u1": {"name": "小明", "age": 18}}

# 传统写法：每一层都要判断是否存在，非常啰嗦
if "u1" in users:
    if "name" in users["u1"]:
        name = users["u1"]["name"]

# .get() 链式写法：简洁且永不崩溃
name = users.get("u1", {}).get("name", "未知")
#                        ↑键不存在时给一个空字典，后面的 .get() 就有东西可操作了

最后那个空字典 {} 是这个技巧的灵魂——它保证链条不会因为某层缺失而断掉。

2.6 遍历时能修改字典吗

不能。 遍历过程中修改字典会报 RuntimeError: dictionary changed size during iteration。

Pythond = {"a": 1, "b": 2}
# for k in d:
#     del d[k]           # RuntimeError!

生活化类比：你在点名册上边点名边划掉名字——划掉之后册子的页数变了，念到后面就会跳行出错。

正确做法：先遍历，再修改（分两步）：

Pythond = {"a": 1, "b": 2, "c": 3}
for key in list(d.keys()):      # 先复制一份键的列表
    if d[key] < 2:
        del d[key]
print(d)      # {'b': 2, 'c': 3}

（注意：list(d.keys()) 是浅拷贝键列表，够用了，因为键本身是不可变的。）

2.7 嵌套结构：字典的真正威力

真实数据几乎都是嵌套的：

Pythonusers = {
    "u1": {"name": "小明", "age": 18, "skills": ["Python", "SQL"]},
    "u2": {"name": "小红", "age": 22, "skills": ["Java"]},
}

提取数据时用连续取值：

Python# 取出 u1 的名字
name = users["u1"]["name"]              # 小明

# 安全取出
name = users.get("u9", {}).get("name", "查无此人")   # 查无此人

# 遍历两层
for uid, info in users.items():
    print(f"【{uid}】{info['name']}，{info['age']} 岁，会 {'、'.join(info['skills'])}")

# 统计：多少人会 Python
python_users = [
    info["name"]
    for uid, info in users.items()
    if "Python" in info["skills"]
]
print(python_users)     # ['小明']

这一段代码就是单元 11 那个"投票分析器"的核心结构。现在多花点时间理解它，后面会省很多力气。

2.8 按顺序遍历与排序：字典本身不保证顺序

字典的键是按插入顺序保存的（3.7+ 的特性），但它不会自动排序。要按值或按键排好再遍历，得自己排：

Pythonscores = {"小明": 88, "小红": 95, "小刚": 72}

# 按键排序遍历（拼音/字母序）
for name in sorted(scores):
    print(name, scores[name])

# 按值排序遍历（分数从高到低）—— key 参数指定"按第几项排"
for name, score in sorted(scores.items(), key=lambda kv: kv[1], reverse=True):
    print(f"{name}: {score}")

key=lambda kv: kv[1] 的意思是"每个元素（(键, 值) 元组）拿去比较的是第 2 项"。 这是第 8 章 lambda 最常见的实战场景，现在会抄就行，单元 8 会讲透。

如果嫌 lambda 绕，operator.itemgetter 更快也更易读：

Pythonfrom operator import itemgetter

scores = {"小明": 88, "小红": 95, "小刚": 72}
for name, score in sorted(scores.items(), key=itemgetter(1), reverse=True):
    print(f"{name}: {score}")

2.9 计数与合并：两个绕不开的实用技巧

① 计数：字典最常见的用途

Pythonwords = ["apple", "banana", "apple", "cherry", "apple"]

# 朴素写法：先判有没有，再累加
counts = {}
for w in words:
    if w in counts:
        counts[w] += 1
    else:
        counts[w] = 1
print(counts)

# 用 .get() 省掉 if（最常用）
counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
print(counts)

# 用 setdefault 也行（键不存在时先放个默认值）
counts = {}
for w in words:
    counts.setdefault(w, 0)
    counts[w] += 1
print(counts)

# 标准库直接给答案（单元 17 之后会常用）
from collections import Counter
print(Counter(words).most_common(2))     # [('apple', 3), ('banana', 1)]

② 合并两个字典

Pythonbase = {"name": "小明", "age": 18}
extra = {"age": 19, "city": "成都"}

# 老写法：update 原地合并（会改 base）
merged = base.copy()
merged.update(extra)
print(merged)                 # {'name': '小明', 'age': 19, 'city': '成都'}

# Python 3.9+：| 合并成一个新字典，不改原来的（推荐）
merged = base | extra
print(merged)                 # {'name': '小明', 'age': 19, 'city': '成都'}
print(base["age"])            # 18 ← base 没被改

# 反向：右边的字典优先，所以 extra 的 age 覆盖了 base 的
print(extra | base)           # age 变成 18

注意合并时右边的覆盖左边的，这跟"后写的配置覆盖先写的默认值"是同一个直觉。

示例 2：新增、修改、删除

Python# dict_crud.py —— 字典的增删改查

scores = {"语文": 90, "数学": 85}

# 新增：键不存在时赋值 = 添加一对
scores["英语"] = 78
print("新增后：", scores)      # {'语文': 90, '数学': 85, '英语': 78}
print("长度：", len(scores))   # 3

# 修改：键已存在时赋值 = 改值（覆盖）
scores["数学"] = 92
print("修改后：", scores)      # {'语文': 90, '数学': 92, '英语': 78}
print("长度依然是：", len(scores))   # 3，没有变长！

# 删除：用 del
del scores["英语"]
print("删除后：", scores)      # {'语文': 90, '数学': 92}

# 删除的第二种写法：pop()，能拿到被删的值
removed = scores.pop("语文")
print("pop 出来的分数：", removed)     # 90
print("现在剩下：", scores)             # {'数学': 92}

# popitem()：删除最后加入的那一对，返回 (键, 值) 元组
scores = {"语文": 90, "数学": 92}
pair = scores.popitem()
print("popitem 返回：", pair)         # ('数学', 92)

# 清空
scores.clear()
print("清空后：", scores, "长度", len(scores))   # {} 长度 0

示例 3：三种遍历方式

Python# dict_traverse.py —— keys / values / items

user = {"name": "小明", "age": 18, "city": "杭州"}

# 1）遍历键 —— 直接 for 就是遍历键
print("--- 遍历键 ---")
for key in user:
    print(key)
for key in user.keys():    # 等价写法，更显式
    print(key)

# 2）遍历值
print("--- 遍历值 ---")
for value in user.values():
    print(value)

# 3）遍历键值对 —— 最常用
print("--- 遍历键值对 ---")
for key, value in user.items():
    print(f"{key}: {value}")

# 常见坑：for item in user 拿到的是键，不是键值对
print("--- 陷阱演示 ---")
for item in user:
    print(f"item = {item}")
# 输出的是 name / age / city，不含值

# 想同时拿到键和值，必须用 items()
for item in user.items():
    print(f"item = {item}")        # ('name', '小明') 这种元组形式

# 综合运用：统计每个键的值是数字还是字符串
for key, value in user.items():
    print(f"{key} 的类型是{type(value).__name__}")

示例 4：get() 安全取值

Python# dict_get.py —— .get() 的价值

scores = {"语文": 90, "数学": 85}

# 方括号取值：键不存在直接崩
print(scores["语文"])# 90
# print(scores["英语"])   # KeyError: '英语'

# .get() 取值：键不存在返回 None
print(scores.get("语文"))    # 90
print(scores.get("英语"))    # None
# 注意：返回 None 说明"键不存在"，
# 也可能说明"键存在但值就是 None"。要区分用 in

# .get() 带默认值
print(scores.get("英语", 0))            # 0
print(scores.get("英语", "缺考"))         # 缺考
print(scores.get("语文", 0))            # 90  键存在时忽略默认值

# 判断键是否存在
print("英语" in scores)         # False
print("语文" in scores)         # True

# 区分"不存在"和"值为 None"
data = {"a": None}
print(data.get("a"))                # None
print("a" in data)                  # True   键存在，只是值是 None
print(data.get("b", "没有这个键"))    # 没有这个键

# ===== .get() 链式访问：处理嵌套数据的利器 =====
users = {"u1": {"name": "小明", "age": 18}}

# 传统写法：啰嗦
if "u1" in users:
    if "name" in users["u1"]:
        name = users["u1"]["name"]
print(name)

# .get() 链式写法：简洁且永不崩溃
name = users.get("u9", {}).get("name", "查无此人")
print(name)      # 查无此人
# 关键在那个 {} —— u9 不存在时给一个空字典，
# 这样后面的 .get("name") 就有东西可操作，链条不断裂

示例 5：遍历与修改的正确姿势

Python# dict_modify.py —— 遍历时能不能改字典

scores = {"语文": 90, "数学": 85, "英语": 78}

# 遍历过程中删除键值对 -> RuntimeError
# for key in scores:
#     if scores[key] < 80:
#         del scores[key]     # RuntimeError: dictionary changed size during iteration

# 正确做法一：先复制一份键的列表，再遍历副本
for key in list(scores.keys()):
    if scores[key] < 80:
        del scores[key]
print("删除低于 80 的：", scores)   # {'语文': 90, '数学': 85}

# 正确做法二：用 .items() 复制元组列表
scores = {"语文": 90, "数学": 85, "英语": 78}
for key, value in list(scores.items()):
    if value < 80:
        del scores[key]
print("结果一样：", scores)         # {'语文': 90, '数学': 85}

# 修改键的值（不改变字典大小）是允许的
scores = {"语文": 90, "数学": 85}
for key in scores:
    if scores[key] < 90:
        scores[key] += 10
print("提分后：", scores)           # {'语文': 90, '数学': 95}
# 注意：改值不改长度，所以不需要复制

# 翻面理解这个规则：
# 遍历是"照着名单念名字"，而删除会让名单页数变少，后面就念乱了。
# 但改名字内容不影响名单长度，所以是安全的。

示例 6：嵌套字典与综合提取

Python# nested_dict.py —— 嵌套字典：真实数据的形态

users = {
    "u1": {
        "name": "小明",
        "age": 18,
        "skills": ["Python", "SQL"],
    },
    "u2": {
        "name": "小红",
        "age": 22,
        "skills": ["Java", "Python"],
    },
    "u3": {
        "name": "小刚",
        "age": 25,
        "skills": ["C++"],
    },
}

# 连续取值：直接按层往下取
print("u1 的名字：", users["u1"]["name"])
print("u2 的年龄：", users["u2"]["age"])

# 安全取值
print("u9 的名字：", users.get("u9", {}).get("name", "查无此人"))

# 遍历两层：外层 uid 和 info，内层再用 info 的键
for uid, info in users.items():
    print(f"【{uid}】{info['name']}，{info['age']} 岁")

# 提取所有人的名字
all_names = [info["name"] for uid, info in users.items()]
print("所有人：", all_names)

# 筛选：谁会Python
python_users = [
    info["name"]
    for uid, info in users.items()
    if "Python" in info["skills"]
]
print("会 Python 的：", python_users)      # ['小明', '小红']

# 统计平均年龄
total_age = 0
for uid, info in users.items():
    total_age += info["age"]
average = total_age / len(users)
print(f"平均年龄：{average:.1f} 岁")# 21.7 岁

# 找出技能最多的用户
most_skilled = ""

users = [

for u in users:
    city = u["city"]
    if city not in by_city:        # 第一次遇到这个城市，先建空列表
        by_city[city] = []
    by_city[city].append(u["name"])
print("按城市", by_city)

六、本单元验收自测

1. 简答题：

Pythond = {"a": 1}
d["b"] = 2
d["a"] = 3
print(len(d), d)

输出什么？为什么？

要点：输出 2 {'a': 3, 'b': 2}。第二行新增了一对（长度 1→2），第三行只是把已存在的 a 的值从 1 改成 3（长度不变）。字典赋值语句不区分新增和修改，只看键在不在。

2. 判断题：d = {} 之后直接执行 print(d["name"]) 会打印 None。

要点：错误。会报 KeyError: 'name'。要拿到 None 必须用 d.get("name")。

3. 简答题：下面代码输出什么？为什么会报错？

Pythonscores = {"语文": 90}
for key in scores:
    if scores[key] < 60:
        del scores[key]
print(scores)

要点：会报 RuntimeError: dictionary changed size during iteration。因为循环正按顺序遍历键，一旦 del 删掉一个键，字典内部结构发生改变，迭代器的位置就和实际内容错位了。修复方法：for key in list(scores.keys()):，先复制一份键列表再遍历副本。

4. 简答题：.get() 相比 dict[键] 的两个核心优势是什么？各举一例。

要点：① 不会崩溃：键不存在时 .get() 返回默认值，而 dict[键] 抛 KeyError。例：d.get("年龄", 0) 安全返回 0。② 支持链式访问嵌套数据：因为缺键时可以返回一个空字典，链条不会断。例：users.get("u9", {}).get("name", "查无此人")，即使 u9 不存在也能安全返回兜底值。

5. 判断题：下面两行代码的作用完全一样。

Pythonfor key in d:
    print(key)

for key in d.keys():
    print(key)

要点：作用完全一样。for key in d 是 for key in d.keys() 的简写形式，Python 允许直接遍历字典的键。这不是巧合——dict.keys() 返回的视图对象本身就代表键。

七、常见错误清单（务必逐条自查）

错误 1：KeyError: 'name'

症状：取一个不存在的键就崩。 原因：d["name"] 在键缺失时抛异常（这是设计，不是 bug）。 改法：可能缺的键用 d.get("name", "默认值")；确实必须有就让它崩，但要在上层 try/except KeyError 给出可读提示。

错误 2：遍历字典时增删键 → RuntimeError

症状：dictionary changed size during iteration。 原因：迭代器依赖内部结构，边遍历边改会让它失效。 改法：先取快照 for k in list(d):，再改 d；或先用推导式算出要删的键，循环外统一删。

错误 3：拿列表当键 → TypeError: unhashable type

症状：d[[1, 2]] = "x" 报不可哈希。 原因：字典靠 hash 定位，键必须不可变。 改法：用元组 d[(1, 2)]，或把列表 tuple(lst) 转一下。

错误 4：以为 d.keys() 是列表，能下标

症状：d.keys()[0] 报 'dict_keys' object is not subscriptable。 原因：keys()/values()/items() 返回的是视图，不是列表。 改法：要下标就 list(d.keys())[0]；只是遍历直接用 for k in d:。

错误 5：嵌套字典层层 []，中间缺一层就崩

症状：d["a"]["b"]["c"] 里 d["a"] 不存在时 KeyError。 改法：逐层 get：d.get("a", {}).get("b", {}).get("c")；层次深就写个小函数或用 defaultdict。
