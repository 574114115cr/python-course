self 到底是什么？ 它就是**"当前这个对象自己"**的引用。

生活化类比（最贴切的一个）：self 就像**"我自己"**这个词。

你在描述自己的时候会说"我今年 18 岁，我有 3 个爱好"。在类里： - self = 说话的那个人（"我"） - self.age = "我的年龄" - self.name = "我的名字"

所以：

Pythonself.name = name

# 右边：传进来的参数值

为什么每个方法都必须写 self？ 因为一个类可以造出成千上万个对象，每个对象的属性值都不同。方法必须通过 self 知道"我现在操作的是哪一个对象"。

2.3 __init__：对象的出生证明

__init__（前后各有两个下划线，读作"双下划线 init"）在对象创建时自动执行一次，作用是给每个对象设置初始属性。

Pythonclass Car:
    def __init__(self, make, model, color, year=2020):
        self.make = make        # 实例属性：每个对象各有一份
        self.model = model
        self.color = color
        self.year = year
        self.odometer = 0       # 初始里程固定为 0

注意 year=2020 也可以有默认值——这和函数的默认参数规则完全一样。

实例属性 vs 类属性（了解即可）：

Pythonclass Car:
    wheels = 4          # 类属性：所有 Car 共享，修改会影响全部

    def __init__(self, make):
        self.make = make  # 实例属性：每个对象独有

生活化类比：类属性是"这一类事物共有的规格"（所有汽车都是 4 个轮子，除非你改整个类的定义）；实例属性是"这一辆车特有的信息"（这辆是红色的，那辆是蓝色的）。

初学阶段主要用实例属性，类属性用得少。

2.4 属性 vs 方法

Pythonclass Car:
    def __init__(self, make, model):
        self.make = make        # 属性：无括号，直接存数据
        self.model = model
        self.odometer = 0

    def drive(self, miles):     # 方法：有括号，是行为
        self.odometer += miles  # 方法内部通过 self 改属性

    def get_odometer(self):     # 方法：读取属性
        return self.odometer


car = Car("丰田", "卡罗拉")
car.drive(100)                 # 调用方法：obj.method(参数)
car.drive(50)
print(car.odometer)            # 访问属性：obj.属性，不要写括号
print(car.get_odometer())      # 调用方法：要写括号

2.6 继承：不重复造轮子

设想你有两个类 ElectricCar（电动车）和 Car（普通车）。电动车几乎是汽车，只是电池和续航不一样。

如果没有继承，你要把 Car 的所有属性和方法复制粘贴一遍。能用，但只要 Car 加一个新功能，两个类都得记得同步改——迟早会漏。

继承解决的是这个问题：

Pythonclass Car:
    """普通汽车。"""
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year
        self.odometer = 0

    def __str__(self):
        return f"{self.year} 年 {self.make} {self.model}"


class ElectricCar(Car):
    """电动汽车 —— 继承自 Car，额外有电池信息。"""
    def __init__(self, make, model, year, battery_size):
        super().__init__(make, model, year)   # 调用父类的 __init__
        self.battery_size = battery_size     # 加上自己的新属性
        self.charge = 100                    # 初始电量

    def __str__(self):
        parent = super().__str__()           # 复用父类的字符串
        return f"{parent}，电池 {self.battery_size} kWh，电量 {self.charge}%"

三个要点：

  1. 括号里的 Car 叫"父类"（也叫基类），ElectricCar 叫子类（也叫派生类）。
  2. 子类自动拥有父类的一切：属性、方法、__str__ 全都能用。
  3. super().__init__(...) 是"打个电话给爸爸，问他该怎么初始化基础信息"。

关于 super() 的一个实用提醒：super().__init__() 必须放在自己赋值属性之前。因为父类的 __init__ 会设置父类需要的那些属性，如果你先改了 self.make，可能覆盖掉父类设好的值。这不是绝对必须，但在有继承的类里，先调 super() 再写自己的逻辑是好习惯。

2.7 方法重写与多态

子类可以重新定义父类已有的方法，这叫方法重写（override）：

Pythonclass Car:
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

    def __str__(self):
        return f"{self.year} 年 {self.make} {self.model}"

    def fill_gas_tank(self):
        """普通车加油。"""
        print(f"已为 {self} 加满油箱")


class ElectricCar(Car):
    """电动车没有油箱，所以必须重写这个方法。"""

    def __init__(self, make, model, year, battery_size):
        # 先让父类把 make / model / year 存好
        super().__init__(make, model, year)
        # 再加自己的新属性
        self.battery_size = battery_size

    def fill_gas_tank(self):
        """重写：电动车不用加油。"""
        print(f"{self} 是电动车，不需要加油，请充电")


my_car = Car("丰田", "卡罗拉", 2020)
my_electric = ElectricCar("特斯拉", "Model 3", 2024, 75)

my_car.fill_gas_tank()         # 已为 2020 年 丰田 卡罗拉 加满油箱
my_electric.fill_gas_tank()    # 2024 年 特斯拉 Model 3 是电动车，不需要加油

注意：ElectricCar 根本没定义 __str__，但 f"{self}" 照样能用父类的版本——这就是继承。

多态（polymorphism） 是重写带来的最大好处：调用代码不需要知道对象的真实类型。

Python# 同一段代码，对不同类型的对象都能正常工作
for vehicle in [my_car, my_electric]:
    vehicle.fill_gas_tank()

生活化类比：你对着一群"交通工具"喊"报上你的名字"，汽车回答"我是卡车，能拉货"，电动车回答"我是电动车，能充电"，轮船回答"我是船，能潜水"。你完全不需要先判断对方是哪一类——每个人自己会报出适合自己的一句话。这个"因人而异"就是多态。

这就是为什么方法重写时参数签名必须兼容（参数个数、顺序、默认值要对得上）：因为调用方是按父类的接口来调用的。

Pythonimport random

四个函数最容易混的是 choices 和 sample：

函数 抽几个 会不会重复 返回

random.choices(seq, k=n) n 个 会（有放回） 列表
random.sample(seq, k=n) n 个 不会（不放回） 列表
random.shuffle(seq) 打乱整个序列 — None（原地改）

最后一个坑值得单独记：shuffle 是原地打乱，返回值是 None。

三、随机要能复现。 random.seed(n) 固定随机序列，同一个 seed 每次跑出来的结果完全一样——调试、写测试、做课堂演示都必须先 seed，否则「上次明明是对的」。

Pythonimport random

random.seed(42)
print(random.randint(1, 6))      # 6
random.seed(42)
print(random.randint(1, 6))      # 6  ← 同一个 seed，结果相同

要点 - 类文件与调用方同目录才能直接 import car；文件名别和标准库重名（写 random.py 会让 import random 导入你自己，第 7 单元练习 7-10 讲过）。 - random 是伪随机，可预测；做密码、令牌、抽奖公证要用 secrets 模块。 - sample(seq, k) 在 k 大于序列长度时抛 ValueError，choices 不会。 - 标准库清单看官方文档「The Python Standard Library」，不用背，知道「大概有什么」就够查。

    """矩形。"""
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        """返回面积。"""
        return self.width * self.height

        """返回周长。"""
        return 2 * (self.width + self.height)

        """返回是否是正方形（宽等于高）。"""

        if not self.scores:
            return None
        return min(self.scores)

    def is_pass(self):
        """平均分 60 分以上算及格。"""
        return self.average() >= 60

    def __str__(self):
        return f"{self.name} 的平均分是 {self.average():.2f}"

        """重写：圆的面积。"""
        return self.PI * self.radius ** 2

class Triangle(Shape):
    """三角形。"""
    def __init__(self, base, height):
        super().__init__("三角形")
        self.base = base
        self.height = height

    def area(self):
        return self.base * self.height / 2

    def perimeter(self):
        # 假设是等腰三角形，两腰长为 sqrt((base/2)^2 + height^2)

        self.books.append(book)
        print(f"已入库：{book}")

        """按书名查找，找到返回 Book 对象，找不到返回 None。"""
        for book in self.books:

        return None

            return False
        if book.borrow():
            print(f"成功借出《{book.title}》")
            return True
        print(f"《{book.title}》已被借出，无法再次借出")
        return False

        """按书名还书。"""
        book = self.find_book(title)
        if book is None:
            print(f"未找到《{title}》")
            return False
        book.return_book()
        print(f"已归还《{book.title}》")
        return True

class BankAccount:
    """一个银行账户。"""
    def __init__(self, account_number, owner, balance=0.0):
        self.account_number = account_number
        self.owner = owner          # 组合：持有一个 Owner 对象
        self.balance = balance
        self.history = []

    def deposit(self, amount):
        """存款，金额必须大于 0。"""
        if amount <= 0:
            raise ValueError("存款金额必须大于 0")
        self.balance += amount
        self.history.append(f"存款 {amount:.2f} 元")
        return self.balance

    def withdraw(self, amount):
        """取款，余额必须充足。"""
        if amount <= 0:
            raise ValueError("取款金额必须大于 0")
        if amount > self.balance:
            raise ValueError(f"余额不足，当前余额 {self.balance:.2f} 元")
        self.balance -= amount
        self.history.append(f"取款 {amount:.2f} 元")
        return self.balance

    def transfer_to(self, other, amount):
        """转账到另一个账户。"""
        if other is self:
            raise ValueError("不能转账到自己")
        self.withdraw(amount)      # 余额不足时会自动报错
        other.deposit(amount)
        self.history.append(f"转账 {amount:.2f} 元给 {other.account_number}")
        other.history.append(f"收到来自 {self.account_number} 的 {amount:.2f} 元")
        return True

    def statement(self):
        """输出对账单。"""
        lines = [
            "=" * 46,
            f"账户号码：{self.account_number}",
            f"户主：  {self.owner}",
            f"余额：    {self.balance:.2f} 元",
            "-" * 46,
            "交易记录：",
        ]

            lines.append("  （暂无交易）")
        for i, record in enumerate(self.history, 1):
            lines.append(f"  {i}. {record}")
        lines.append("=" * 46)
        return "\n".join(lines)

    def __str__(self):
        return f"账户 {self.account_number}（{self.owner.name}）余额 {self.balance:.2f} 元"

错误 1：★ 方法忘记写 self

Pythonclass Counter:
    def __init__(self):
        self.count = 0

    # INTENTIONALLY-BROKEN 演示 3 种相关错误
    def increment_bad(self):
        # 错误 1a：赋值时左边忘了 self —— 这行创建了一个"局部变量"，
        # 函数一结束就没了，self.count 完全没变
        count = self.count + 1
        print(count)      # 打印 1，但 self.count 永远是 0

    def increment_worse(self, value):
        # 错误 1b：右边用 self，左边不用 —— 局部变量，出了函数就没了
        value = self.count + value
        print(value)

    def increment_wrong(self):
        # 错误 1c：干脆忘了加 1，结果永远不变
        print(self.count + 1)

症状： - NameError: name 'count' is not defined（左边忘了写） - 属性值永远不变 / 方法结束后"数据丢了" - 属性变成 None 或 0

原因：self. 前缀是"把值存到这个对象身上"；漏了它就是在函数内部建了个临时变量。 修法：给每一处属性读写都加上 self.，然后检查这个类里有没有"出现了属性名但前面没有 self."的地方。

错误 2：方法定义时忘了第一个参数 self

Pythonclass Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    # INTENTIONALLY-BROKEN 演示：忘了 self 参数
    def area():
        return self.width * self.height     # NameError: name 'self' is not defined

    def perimeter(self):                    # 这个是对的
        return 2 * (self.width + self.height)


r = Rectangle(3, 4)
print(r.perimeter())     # 14
# print(r.area())        # TypeError: area() takes 0 positional arguments but 1 was given

症状：TypeError: area() takes 0 positional arguments but 1 was given，或 NameError: name 'self' is not defined 原因：定义时少写了 self，但调用时 Python 会自动传入对象，结果参数数量对不上。 修法：每个方法（除了 __init__、__str__ 等双下划线方法）定义时，第一个参数必须是 self。判断标准很简单——方法体内如果出现了 self.，定义时必须有 self 参数。

错误 4：属性名和方法名重名

Pythonclass Rectangle:
    def __init__(self, width, height):
        # INTENTIONALLY-BROKEN 演示属性名冲突
        self.perimeter = 2 * (width + height)   # 错误：perimeter 是属性

    def perimeter(self):       # 错误：同名方法把属性覆盖了
        return 2 * (self.width + self.height)


r = Rectangle(3, 4)
print(r.perimeter)       # 输出 <bound method...>  拿到的是方法不是数字
print(r.perimeter())     # 报错：用了 width 属性，但width 不存在 -> AttributeError

症状：拿到的是 <bound method ...> 而不是期望的数值；或者 AttributeError: 'Rectangle' object has no attribute 'width'（因为 __init__ 里的属性被同名方法覆盖了） 原因：属性和方法都存在实例的命名空间里，同名会互相覆盖。后定义的 def perimeter 在类体里把之前的赋值干掉了。 修法：让名字有区分度：

错误 5：__init__ 里赋值目标写错（赋值给了参数，不是属性）

Pythonclass User:
    # INTENTIONALLY-BROKEN 演示三种常见笔误
    def __init__(self, name, age):
        self.name = name
        age = age        # 错误 5a：漏了 self.，age 只是个局部变量
                          # 后果：user.age 会 AttributeError
        self.age1 = age  # 错误 5b：属性名打错（age1），user.age 依然不存在
        self.nmae = name # 错误 5c：属性名拼写颠倒

    def show(self):
        print(self.name, self.age)     # 这里就崩了


u = User("小明", 18)
# print(u.age)      # AttributeError: 'User' object has no attribute 'age'
u.show()             # 同样崩在这里

症状：AttributeError: 'User' object has no attribute 'age' 原因：age = age 只是让局部变量 age 指向了自己的值，什么也没存进对象。 修法：__init__ 里每一行赋值左边必须有 self.。养成习惯后可以这样自查——读完 __init__，检查"哪些属性应该存在"，然后在类的其他地方确认它们都能通过 self.xxx 访问到。

错误 6：子类忘了调 super().__init__()

Pythonclass Animal:
    def __init__(self, name):
        self.name = name          # 名字是父类设置的

    def speak(self):
        print(f"{self.name} 发出声音")

    # INTENTIONALLY-BROKEN 演示：忘了 super().__init__()
    def __init__(self, name, breed):
        # 如果这里不调用 super().__init__(name)，
        # 父类的 self.name 永远不会被设置
        self.breed = breed
        # 正确写法应该是在这一行：
        # super().__init__(name)

    def speak(self):
        print(f"{self.name} 说：汪汪")    # 这里访问 self.name 会崩


# d = Dog("旺财", "柴犬")
# d.speak()        # AttributeError: 'Dog' object has no attribute 'name'

症状：AttributeError: 'Dog' object has no attribute 'name' —— 属性明明在父类的 __init__ 里设置了，为什么没有？ 原因：父类的 __init__ 不会自动执行。你必须在子类的 __init__ 里显式调用 super().__init__(...)，父类的代码才会跑。 修法：子类的 __init__ 第一件事就是 super().__init__(需要传给父类的参数)，然后再设置子类自己的属性。顺序上先 super 再自己的，这是稳妥的习惯。

要点：判断标准是关系的性质。"是一个"（is-a）用继承：Dog 是一种 Animal，ElectricCar 是一种 Car，它们天然共享父类的属性和行为。"有一个"（has-a）用组合：Car 有一个 Engine，BankAccount 有一个 Owner，这些是"组成部分"关系而不是"种类"关系。经验法则是拿不准时优先用组合，因为它更灵活、耦合更低，也不容易因为继承层次太深而失控。
