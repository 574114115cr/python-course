单元 3：操作列表

对应教材第 4 章「操作列表」 关键词：for 循环、range()、while（本单元仅作对比）、列表推导式、切片 slice、元组 tuple、PEP 8

一、学习目标

完成本单元后，应该能够：

  1. 用 for 循环遍历列表中的每个元素，并说清循环变量每轮的值是怎么变化的。
  2. 掌握 range() 的三种常用形式，并能计算 len(range(a, b, c))。
  3. 用一行列表推导式写出筛选/变换逻辑，并与等价的多行 for 循环对比。
  4. 正确书写切片 list[start:stop:step]，说清「左闭右开」规则，并预测负索引切片的结果。
  5. 说出元组与列表的三点区别，并解释为什么字典的键必须是元组/字符串这类不可变类型。

二、核心知识点讲解

2.1 for 循环：把重复交给机器

没有 for 时，处理 5 个元素要写 5 行：

Pythonprint(cars[0])
print(cars[1])
print(cars[2])
print(cars[3])
print(cars[4])

有 1000 个元素呢？写 1000 行——显然不行。

for 循环的标准结构是三部分：

Pythonfor 变量 in 数据集合:
    循环体

生活化类比：流水线。传送带（数据集合）上一个个送来工件（元素），工人（循环体）在固定工位（缩进块）对每个工件做同样的操作。工人不关心工件长什么样，只管"来了就做一次"。

Pythoncars = ["a", "b", "c"]
for car in cars:
    print(car)
# 第 1 轮：car = "a"
# 第 2 轮：car = "b"
# 第 3 轮：car = "c"
# 循环结束，car 里残留着最后一个值（这点很重要，容易被忽略）

最关键的陷阱：缩进决定循环体。 只有缩进了的行才是循环体：

Pythonfor car in cars:
    print(car)      # 循环体内：执行 3 次
    print("再见")    # 循环体内：也执行 3 次

print("循环结束")     # 循环外：只执行 1 次

忘记写冒号 : 会报 SyntaxError，忘记缩进会报 IndentationError 或 IndentationError: expected an indented block——这两条是本课程后续最常见的报错。

2.2 range()：造出一串数字

有时我们还没有列表，只想"重复 N 次"，这时用 range()：

Pythonrange(5)           # 0, 1, 2, 3, 4        —— 5 个数，从 0 开始，不含 5
range(1, 6)        # 1, 2, 3, 4, 5        —— 含 1 不含 6
range(2, 11, 2)    # 2, 4, 6, 8, 10      —— 步长为 2
range(10, 0, -1)   # 10, 9, ..., 1, 0     —— 负步长，倒着数

三个通用规则，记住就够用一辈子： 1. 含起点，不含终点（左闭右开） 2. 只有一个参数时 = range(0, 参数) 3. 步长的符号决定方向

range 在 Python 3 里是"惰性"的——它不一次性生成所有数字，而是你每要一个它才算一个。所以不会因为 range(1000000000) 而内存爆掉（但循环十亿次会很慢）。

2.3 循环的常见搭档

Python# 只打印奇数
for i in range(1, 10, 2):
    print(i)

# 遍历列表的同时拿到下标：enumerate()
for index, item in enumerate(["a", "b", "c"]):
    print(index, item)

# 遍历字典会拿到键（单元 5 详讲）
# 同时遍历多个列表：zip()
names = ["小明", "小红"]
scores = [88, 95]
for n, s in zip(names, scores):
    print(n, s)

2.4 列表推导式：一行搞定筛选

列表推导式的结构是 [表达式 for 变量 in 集合 if 条件]。

对比两种写法：

Python# 传统写法：4 行
squares = []
for number in range(1, 6):
    squares.append(number ** 2)

# 列表推导式：1 行，完全等价
squares = [number ** 2 for number in range(1, 6)]

生活化类比：传统写法像是"先准备一个空篮子 → 逐个捡东西放进去"；推导式像是"直接摊开一块布，东西落下来就自动摆好"。省掉的不是打字，而是"创建一个空列表 + 逐个 append"这两个中间步骤。

什么时候用推导式：处理单个元素、产出单个值时最清晰。 什么时候不用：需要多步中间变量、需要 break、或者嵌套超过两层时，强行用推导式会写出没人看得懂的代码。这种时候老老实实用普通 for——可读性永远优先。

2.5 切片：一次取出一段

切片语法 list[start:stop:step]，含 start，不含 stop。

生活化类比：切片就像切面包——你要的是"从第 3 片到第 7 片之间"，第 3 片要、第 7 片不要（它属于下一段）。这个"要左边不要右边"的规则叫左闭右开，因为它让 len 天然对得上：len(a[b:c]) == c - b。

Pythonletters = ["a", "b", "c", "d", "e", "f"]
letters[:]      # 全部（浅拷贝）
letters[2:]     # ['c', 'd', 'e', 'f']      从索引2 到末尾
letters[:3]     # ['a', 'b', 'c']           前三个
letters[1:4]    # ['b', 'c', 'd']
letters[::2]    # ['a', 'c', 'e']           步长 2
letters[::-1]   # ['f', 'e', 'd', 'c', 'b', 'a']  反转
letters[-2:]    # ['e', 'f']                最后两个

切片可以用于列表、字符串、元组，这是三种序列类型的共同能力。

切片也是浅拷贝：a[:] 得到新列表，但里面的元素还是同一批对象（嵌套列表时要注意）。

2.6 元组：用括号表示"不可修改"

列表的方括号 [] 表示"可以改"，圆括号 () 表示"不能改"：

Pythonpoint = (3, 5)
# point[0] = 9    # TypeError: 'tuple' object does not support item assignment

生活化类比：列表像活页本，能撕能换；元组像一次性塑封的相片，封好就不能改了。

元组的三点区别：

列表 list 元组 tuple
写法 [1, 2, 3] (1, 2, 3)
能否改元素 能 不能
能否增删 能 不能（只有重新赋值整个变量）
是否有 append 有 没有
长度 变长 固定
用途 一组会变化的数据 一组固定的数据，如坐标、日期 
Python# 元组"看似不能改"，但可以整体重新赋值
point = (3, 5)
# point[0] = 9   # 不行
point = (9, 5)    # 可以：换了一个全新的元组

只有一个元素的元组必须写逗号——这是超级高频的坑：

Pythont = (5)     # 这不是元组！这是整数 5，括号只是分组
t = (5,)    # 这才是长度为1 的元组
type((5))   # <class 'int'>
type((5,))  # <class 'tuple'>

为什么字典的键要用元组这类不可变类型：键必须是"不会变的"，否则你把键改了，就再也找不到对应的值了。列表可以改，所以列表不能当键；元组不能改，所以可以。

2.7 PEP 8：让代码能被人读

PEP 8 是 Python 官方风格指南，与功能无关但直接影响你能不能维护自己的代码。核心三条：

  1. 一行不超过 79（现代放宽到 99）个字符，长了要换行。
  2. 运算符两侧加空格，逗号后加一个空格：
  3. 缩进统一用 4 个空格，永远不要混用 Tab。

对比示例：

Python# 推荐
total = price * quantity + 5
# 不推荐
total=price*quantity+5

还有两条新手常忘：

Python# 括号内逗号后留一个空格
colors = ["red", "green", "blue"]
# 切片冒号两边都留空格（复杂表达式可省略）
squares = [n**2 for n in range(10)]
sub = letters[1:4]

示例 3：常见循环搭档

Python# loop_helpers.py —— for 循环的三个高性价比搭档

letters = ["a", "b", "c"]

# 1）enumerate()：同时拿到下标和元素
for index, letter in enumerate(letters):
    print(f"第 {index} 位是 {letter}")

# start 参数可以指定下标起点

    print(f"第 {index} 个是 {letter}")

scores = [88, 95, 72, 100]#故意多一个
for name, score in zip(names, scores):
    print(f"{name} 得了 {score} 分")
# 小明 88 / 小红 95 / 小刚 72 —— 第 4 个分数因为没有对应名字被忽略

# 3）在循环里做条件筛选
for letter in letters:
    if letter in ["a", "c"]:
        print("找到元音：", letter)

# 累加器模式：循环最常见的用途
total = 0
for score in [88, 95, 72]:
    total += score# 等价于 total = total + score
print("总分：", total)         # 255

示例 4：列表推导式

Python# comprehension.py —— 列表推导式：传统写法 vs 一行写法

# 案例1：计算平方
# 传统写法
squares = []
for number in range(1, 6):
    squares.append(number ** 2)
print("传统写法：", squares)

# 推导式写法（完全等价）

    if number % 2 == 0:

# 推导式 + if 条件
evens = [number for number in range(1, 11) if number % 2 == 0]

# 案例3：字符串统一大写
words = ["python", "is", "fun"]
print("大写：", [word.upper() for word in words])

# 案例4：三元表达式放进推导式
nums = [1, 2, 3, 4, 5, 6]
print("标记奇偶：", [("偶" if n % 2 == 0 else "奇") for n in nums])

# 下面这种嵌套推导式虽然能跑，但没人看得懂：
# print([x * y for x in range(3) for y in range(3) if x != y])
# 可读性优先于行数。

Python# data_cleaning.py —— 数据清洗实战

raw = ["  苹果  ", "香蕉", "", "  ", "橙子", None, "  葡萄"]

# ===== 写法一：列表推导式（简洁）=====
# 注意：`if item` 这个条件能过滤掉 ""，但过滤不掉 None，
# 因为 None 在 if 判断中等于 False，所以其实是能过滤掉的。
# 写两个条件也可以，但一个 if item 就够了。
cleaned = [item.strip() for item in raw if item]
print("推导式结果：", cleaned)
# ['苹果', '香蕉', '橙子', '葡萄']

# ===== 写法二：普通 for 循环（逻辑更清晰时用）=====
cleaned2 = []
for item in raw:
    if item is None:# 先挡掉 None，否则 .strip() 会崩
        continue                     # continue = 跳过本轮，继续下一次循环
    stripped = item.strip()# 去首尾空格
    if stripped:                     # 非空才留下
        cleaned2.append(stripped)

print("循环结果：", cleaned2)
print("两者一致：", cleaned == cleaned2)

# 统计清洗掉了几个
print("原始数量：", len(raw), "清洗后数量：", len(cleaned))
print("清掉了：", len(raw) - len(cleaned), "个")   # 3 个

# 去重（保序）
unique = []
for item in cleaned:
    if item not in unique:
        unique.append(item)
print("去重后：", unique)

六、本单元验收自测

1. 简答题：下面代码输出什么？

Pythonfor i in range(1, 4):
    print(i * 2)
print("i =", i)

要点：先输出 2\n4\n6，再输出 i = 3。因为 range(1, 4) 是 1、2、3 三轮；循环结束后 i 仍保留最后一次的值 3。

2. 判断题：nums = [1, 2, 3, 4, 5, 6]，nums[1:5] 的结果是 [2, 3, 4, 5]。

要点：正确。左闭右开——包含索引 1（值 2），不包含索引 5（值 6），所以结果是 [2, 3, 4, 5]，长度为 5 - 1 = 4。

3. 简答题：t = (5) 和 t = (5,) 的类型分别是什么？

要点：type((5)) 是 <class 'int'>——它就是整数 5，括号只是数学上的分组符号，逗号才是元组的标志。type((5,)) 是 <class 'tuple'>——加了逗号才是长度为 1 的元组。

4. 判断题：字典的键可以用列表，因为列表也能"存多个数据"。

要点：错误。字典的键必须是不可变类型。列表可以 .append() 修改内容，一旦键被修改，Python 就再也定位不到对应的值了。元组不能修改，所以可以当键；元组的长度和内容一旦创建就固定，用它当键才安全。
