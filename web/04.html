单元 4：if 语句

原书对照对应教材第 5 章「if 语句」

关键词：条件测试、布尔表达式、比较运算符、逻辑运算符、if / elif / else、条件表达式、and/or 短路、链式比较、is vs ==

这套课覆盖了教材哪些章 →

一、学习目标

完成本单元后，你应该能够：

  1. 用 if 写单分支条件，并说清「条件为真时执行、为假时跳过」的运行逻辑。
  2. 熟练使用 if / elif / else 三分支结构，并解释为什么 elif 链中顺序很重要。
  3. 掌握 6 个比较运算符和 3 个逻辑运算符，能正确写出包含多个条件的判断。
  4. 解释「短路求值」现象，能举出一个靠它避免崩溃的真实例子。
  5. 用条件表达式把 5 行 if/else 压缩成 1 行，并知道什么场景下不该压缩。
  6. 把 if 和列表一起用：用 if 列表: 判空、用 in 判成员、用推导式按条件筛选。

二、核心知识点讲解

2.1 条件测试：一个只能回答是/否的问题

条件测试就是一个布尔表达式：求值结果不是 True 就是 False。

Pythonage = 18
print(age == 18)     # True
print(age >= 18)      # True
print(age < 18)       # False

生活化类比：条件测试像门禁核验——刷卡机不问你是谁、你想干什么，只问"你是否有权限"，答案只有"放行"或"拒绝"两个。

最常见的语法错误：把 == 写成 =。

Pythonage = 18
# if age = 18:      # SyntaxError：= 是赋值，条件必须用 ==
if age == 18:      # 正确
    print("成年了")

记忆方法：= 是"把右边交给左边"，== 是"左右两边一样吗"。

2.2 六个比较运算符

运算符 含义 记忆口诀
== 等于 一一对应
!= 不等于 ! 就是"否定"
> / < 大于 / 小于
>= / <= 大于等于 / 小于等于 = 是"可以等于"

初学者最容易在数学思维里写出 = 表示"等于"、<= 表示"小于等于"，但 Python 里 <= 只能是"小于等于"，"不等于"必须写 !=。

字符串也能比较：Python 按字符编码逐个比较，所以可以按字母排序：

Pythonprint("apple" < "banana")    # True
print("Zoo" < "apple")       # True，因为大写 Z 的编码比小写 a 小

2.3 三分支结构：if / elif / else

Pythonage = 20
if age >= 18:
    print("已成年")
elif age >= 6:
    print("青少年")
else:
    print("儿童")

三条规则，务必记牢：

  1. 从上往下检查，一旦有一个分支命中，立刻执行它，然后跳过后面的所有分支。 这叫"最多执行一个分支"。
  2. elif 可以写任意多个（零个也行）。
  3. else 最多一个，且必须放最后，可以省略。

顺序为什么重要——这是本单元最核心的洞察：

Python# 错误顺序
age = 20
if age > 6:
    print("青少年")     # 先命中了，else 永远不会执行
elif age > 18:
    print("成年")
else:
    print("儿童")

# 正确顺序：从最严格（范围最窄）的条件开始
if age >= 18:
    print("成年")
elif age > 6:
    print("青少年")
else:
    print("儿童")

生活化类比：你在一个按"年龄段"分的衣架前找衣服。先看哪个标签，就决定了后面还有没有机会被看到。如果先试"青少年"，20 岁的人会立刻被拦在这里，再也走不到"成年"那一格。所以必须从最特殊、最严格的条件开始，逐步放宽。

2.4 逻辑运算符：把条件组合起来

  • and：两边都为真才为真
  • or：两边有一个为真就为真
  • not：取反
Pythonage = 20
income = 5000
if age >= 18 and income >= 3000:
    print("符合条件")

短路求值（short-circuiting） 是逻辑运算符最重要的性质：Python 为了判断整体结果，可能根本不去计算右边。

Python# 这个写法是安全的
if len(numbers) > 0 and numbers[0] == 3:
    print("第一个数是 3")

# 这个写法会崩
if numbers[0] == 3 and len(numbers) > 0:
    print("第一个数是 3")      # 如果 numbers 是空列表，先崩在 numbers[0]

生活化类比：判断"你通过了考试 且 已缴费才能领证"——如果没通过考试，收费这一步根本不会发生。前提不成立时，后面所有耗时的、有风险的动作都被自动跳过。

这条特性在实际编程里价值极高：把"便宜且安全的检查"放前面，"昂贵或危险的检查"放后面。

2.5 链式比较：Python 的贴心语法

Python 支持把比较串起来写，像数学一样：

Pythonif 18 <= age <= 60:
    print("适龄")

# 等价于（但更慢，因为 age 被求值两次）
if age >= 18 and age <= 60:
    print("适龄")

数字能链式比较，字符串也能：

Pythonif "a" <= letter <= "z":
    print("是小写字母")

注意：链式比较不能用于列表，列表不支持大小比较（> 报错）。

2.6 == 还是 is？

新手必问的问题。答案是：99% 的场景用 ==，唯一该用 is 的场景是 is None。

Python# == 比较"内容是否相同"
print("hello" == "hello")          # True，内容一样

# is 比较"是不是同一个对象"（内存地址）
# 这种情况 is 会是 False，但我们要的其实是内容相等
first = "hello"
second = "he" + "llo"
print(first == second)             # True
print(first is second)             # False（可能是两个不同的对象）

# 但判断"是否为空"必须用 is，因为 None 是唯一的单例
result = None
if result is None:                 # 正确：表达"这个变量还没有值"
    print("还没有结果")

为什么不用 if result == None？ 因为 None 只可能是那一个对象，is None 语义明确、速度快；而如果哪天你写了个自定义类，它的 __eq__ 允许自己"等于 None"，那 == None 就真的会成立。

所以：判断"有没有值" → is None / is not None；判断"内容是否一样" → ==。

2.7 条件表达式：把 5 行压成 1 行

Python# 传统写法
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 条件表达式（也叫三元表达式）
status = "成年" if age >= 18 else "未成年"

结构是 真值时的结果 if 条件 else 假值时的结果。

这在单元 3 的列表推导式和单元 9 的写入文件时会大量用到。但有一条使用原则：

超过一层嵌套的条件表达式就该拆开用普通 if。 写成 a if x else b if y else c 虽然合法，但没人能一眼读懂——为了少打两行而牺牲可读性，是很不划算的交换。

2.8 in 与 not in：检查"在不在里面"

前面的条件都是比较两个值。in 换了个角度：判断某个值在不在一个容器里。这是"校验用户输入"最常用的写法。

Python# in：在里面吗？
banned = ["脏话1", "脏话2", "广告"]
word = "广告"
if word in banned:
    print("已拦截：命中禁用词")

# not in：不在里面吗？（等价于 not (x in 容器)，但读起来更顺）
allowed = ["jpg", "png", "gif"]
filename = "photo.bmp"
if "." not in filename:
    print("文件名没有扩展名")
elif filename.rsplit(".", 1)[-1] not in allowed:
    print(f"不支持的格式：{filename}")

# 字符串也能用（判断子串）
email = "user@example.com"
if "@" in email and "." in email.split("@")[-1]:
    print("看起来像个邮箱")

in 对列表、字符串、字典、元组都能用。对字典来说是查键，不是查值：

Pythonuser = {"name": "小明", "age": 18}
print("name" in user)      # True  ← 查的是键
print("小明" in user)      # False ← 不是查值

为什么 not in 值得单独记：新手常写 if not word in banned:，语法上能跑， 但读起来是"不是（word 在里面）"，绕了一下。word not in banned 才是标准写法。

2.9 什么在 if 里算"假"：真假值（truthy / falsy）

if 后面的东西不一定要是 True/False 比较出来的布尔值——Python 会把任何值都当成"真或假"来判断：

Python# 这六种都是「假」，其余一律为真
falsy = [False, 0, 0.0, "", [], {}, None]
for v in falsy:
    print(repr(v), "->", "假" if not v else "真")

print()
# 这些是「真」，包括负数、字符串 "0"、"False"
truthy = [1, -1, 0.1, "0", "False", " ", [0], {"a": 0}]
for v in truthy:
    print(repr(v), "->", "真" if v else "假")

这条规则让代码能写得非常简洁：

Pythonitems = []

# 啰嗦写法
if len(items) > 0:
    print("有数据")

# 惯用写法：空列表本身就当假
if items:
    print("有数据")
else:
    print("没有数据")

# 判空字符串 / None 同理
name = ""
if not name:
    print("名字为空")

data = None
if data is not None:          # 注意：判断 None 要用 is not，不要用 != 
    print("有数据")

两个必须记住的坑：

  1. "0" 和 "False" 是真——非空字符串永远为真。判断数字先转类型。
  2. 判 None 用 is / is not，不用 ==。0 == False 是 True，0 is False 是 False，两者语义不同。

2.10 all() 与 any()：把一串条件收成一句

当条件多到写不下时（比如"这五个字段都不能为空"），用 all() / any() 比连写 and 清楚得多：

Pythonfields = ["小明", "", "成都", "138"]
print(all(fields))          # False ← 全都不为空才 True
print(any(fields))          # True  ← 有一个非空就 True

# 等价于 all() 的啰嗦写法
ok = bool(fields[0]) and bool(fields[1]) and bool(fields[2]) and bool(fields[3])

# 配合生成器表达式：判断"所有分数都及格"
scores = [88, 92, 75, 60]
print(all(s >= 60 for s in scores))     # True
print(any(s >= 95 for s in scores))     # False

# 找第一个不及格的分
first_fail = next((s for s in scores if s < 60), None)
print("第一个不及格：", first_fail)      # None

all([]) 是 True、any([]) 是 False（空集合的"全员满足"天然成立）——这是个常考的小细节。

短路求值：and / or 一旦能确定结果就不再往下算，所以可以把"可能出错"的检查放在前面：

Pythontext = ""
# 先判空再取字符：不会 IndexError
if text and text[0] == "a":
    print("以 a 开头")

# or 常用来给默认值（注意：0 和 "" 也会被替换掉，要小心）
count = 0
n = count or 10            # 10 ← 因为 0 是假
print(n)

# 只想在 None 时给默认值，用这个写法更准确
n2 = count if count is not None else 10
print(n2)                  # 0

三、可运行代码示例

示例 1：if 单分支

Python# if_single.py —— 最简单的条件判断

age = 20

# 缩进的行才是条件成立时执行的
if age >= 18:

if age < 18:

# 多个条件用 and 连接
age = 20
has_ticket = True
if age >= 18 and has_ticket:

# 也可以写成链式比较（数字专用）
if 18 <= age < 60:

示例 2：if / elif / else 三分支

Python# grade_if.py —— 多分支：成绩等级评定

score = 85

# 从最严格的条件开始，逐步放宽
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"分数 {score}，等级 {grade}")     # 分数 85，等级 B

# 演示"只执行一个分支"
print("---")
for s in [95, 85, 75, 65, 45]:
    if s >= 90:
        g = "A"
    elif s >= 80:
        g = "B"
    elif s >= 70:
        g = "C"
    elif s >= 60:
        g = "D"
    else:
        g = "F"
    print(f"{s} -> {g}")
# 95->A, 85->B, 75->C, 65->D, 45->F

# 注意 else 块里不能再写 if；如果需要，必须用 elif 串成一条链
# 下面这种写法是错的（else 后面不能跟 elif）：
# else:
#     if s >= 0:

示例 3：顺序的重要性

Python# order_matters.py —— elif 链的顺序为什么关键

age = 20

# ===== 错误顺序：条件从宽到窄 =====
print("--- 错误顺序 ---")
if age > 6:
    print("青少年")         # 20 > 6 成立，立刻执行，后面全部跳过
elif age > 18:
    print("成年")           # 永远执行不到
else:
    print("儿童")           # 也永远执行不到

# ===== 正确顺序：条件从窄到宽 =====
print("--- 正确顺序 ---")
if age > 18:
    print("成年")
elif age > 6:
    print("青少年")
else:
    print("儿童")

# 结论：if 链是"从上往下、命中即停"，所以最特殊的放最前面

示例 4：逻辑运算符与短路求值

Python# logic_ops.py —— and / or / not 与短路求值

age = 20
income = 8000
is_student = False

# and：全部为真才为真
print(age >= 18 and income >= 3000)         # True
print(age >= 18 and income >= 10000)        # False
# or：有一个为真就为真
print(age < 18 or income >= 3000)           # True
# not：取反
print(not is_student)                       # True

# ===== 短路求值：真实的安全价值 =====
numbers = [5, 8, 13]

# 安全写法：先问"长度够不够"，再问"内容是什么"
if len(numbers) > 0 and numbers[0] == 5:
    print("第一个数是 5")

# 危险写法：先访问元素，空列表直接崩溃
empty = []
# if empty[0] == 5 and len(empty) > 0:
#     print("这行永远不会安全执行")

# 正确演示：对比两个空列表
print("--- 短路求值演示 ---")
if empty and empty[0] == 5:
    print("第一个数是 5")
else:
    print("列表为空，跳过检查（短路了，没有访问 empty[0]）")

# and / or 可以直接返回操作数本身，不只返回布尔值
print("--- or 的一个实用技巧 ---")
name = ""
display_name = name or "匿名用户"# 空字符串为假，所以取了右边
print("显示名：", display_name)

real_name = "小明"
print("显示名：", real_name or "匿名用户")   # 小明

# 这就是单元 9 里写文件时的常见写法：
# content = text or "默认内容"

示例 5：链式比较与字符串比较

Python# comparisons.py —— 各种比较的细节

# 数字链式比较
age = 25
if 18 <= age <= 60:
    print("适龄")
if 10 <= age < 20:
    print("少年")
else:
    print("不是少年")

# 字符串按编码逐个比较，等价于字典序
print("apple" < "banana")        # True
print("apple" > "Apple")         # True（小写 a 的编码比大写 A 大）
print("abc" < "abd")             # True（逐位比，c < d）

# 链式比较字符串：判断是否是小写字母
letter = "k"
if "a" <= letter <= "z":
    print(f"{letter} 是小写英文字母")

# 判断是否全是大写
upper_word = "HELLO"
if upper_word.isupper():
    print(f"{upper_word} 全是大写")

# 注意：列表不能做大小比较
# if [1, 2] > [1, 3]:     # TypeError: '>' not supported between 'list' and 'list'
# 但可以判断相等
print([1, 2] == [1, 2])          # True
print([1, 2] is [1, 2])          # False，不同对象

# 元组可以比较（逐元素比）
print((1, 2) < (1, 3))           # True

示例 6：== 与 is 的区别

Python# eq_vs_is.py —— 什么时候用 ==，什么时候用 is

# == 比较内容
print("hello" == "hello")        # True
print(1000 == 1000)              # True

# is 比较对象身份
first = "hello"
second = "he" + "llo"
print(first == second)           # True  内容一样
print(first is second)           # False 可能是不同的两个对象

# 小整数是"缓存"的，恰好会命中同一个对象
a = 1000
b = 1000
print(a is b)                    # False 大整数不共享
c = 100
d = 100 + 0
print(c is d)                    # True  小整数被 Python 缓存了

# 唯一必须用 is 的场景：判断 None
value = None
if value is None:
    print("value 是 None")
if value is not None:
    print("这句不会执行")

# 结论：
# 比较内容   -> 用 ==
# 判断空值   -> 用 is None / is not None

示例 7：条件表达式与嵌套

Python# conditional_expression.py —— 一行写完 if/else

age = 20
score = 85

# 传统写法：4 行
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 条件表达式：1 行
status = "成年" if age >= 18 else "未成年"
print("状态：", status)

# 更有用的例子：给变量找默认值
input_name = ""# 用户没填
display = input_name if input_name else "游客"# 空就用默认值
print("显示名：", display)

# 嵌套一层还能读（不推荐，但要能看懂）
level = "高" if score >= 90 else "中" if score >= 60 else "低"

示例 8：用 if 处理列表——判断"空"、判断"在不在"、按条件筛选

教材 5.4 讲的是「if 语句和列表一起用」。三个最常见的场景，都是初学者容易写复杂的地方：

    if topping in available:
        print(f"加 {topping}")
    else:
        print(f"没有 {topping}，这道跳过")

    print("有订单要处理")

def classify_triangle(a, b, c):
    """根据三条边判断三角形类型。"""
    # 第一道关：是不是三角形。必须放在最前面，
    # 否则 1, 2, 100 这种数据会被误判成"普通三角形"
    if a + b <= c or a + c <= b or b + c <= a:

    elif a == b == c:
        # 三个都相等才是等边。等腰要放在等边后面判断，
        # 否则等边三角形也会被"任意两边相等"命中
        return "等边三角形"
    elif a == b or b == c or a == c:
        return "等腰三角形"
    else:
        return "普通三角形"

1. 简答题：下面代码输出什么？

Pythonage = 20

要点：输出两行——成年 和 结束。if 为真时只执行 if 块内的代码，else 块被完全跳过；print("结束") 缩进在外层，两个分支都会走到之后执行它。

2. 判断题：if 5 &gt; 3 &amp;&amp; 2 &gt; 4: print("A") else: print("B") 这段写法（用 &amp;&amp;）在 Python 里能正常运行。

要点：错误。Python 用 and 不用 &&。正确写法：if 5 > 3 and 2 > 4:。而 2 > 4 为假，所以实际输出 B。

3. 简答题：为什么下面这段代码在 score = 85 时输出"D"，而作者期望的是"B"？

Pythonscore = 85
if score >= 60:
    level = "D"
elif score >= 80:
    level = "B"
else:
    level = "F"

要点：因为 if 链是"从上往下、命中即停"。score >= 60 为真（85 ≥ 60），立刻执行 level = "D"，后面的 elif 和 else 全部跳过。修复方法：把条件最严格的放最前面——if score >= 80: B / elif score >= 60: D / else: F。

4. 简答题：为什么下面这段代码在 items 为空列表时会崩溃？写出两种修复方式。

Pythonif items[0] == "apple" and len(items) > 0:
    print("第一个是苹果")

要点：and 从左往右求值，Python 必须先算出 items[0] == "apple"，而空列表取第 0 个元素立刻抛 IndexError，右边的长度检查根本没机会执行。修复一：交换顺序写成 if len(items) > 0 and items[0] == "apple"，让便宜的安全检查在前。修复二：利用空列表为假，直接写 if items and items[0] == "apple"。

5. 判断题：if value == None: 和 if value is None: 两种写法应该优先用哪个？为什么？

要点：优先用 is None。None 是表示"没有值"的唯一对象，用 is 表达的是"身份/状态"判断，语义准确且速度快。如果某个自定义类重写了 __eq__ 允许自己等于 None，== None 就会意外成立；而 is None 永远只在真的是 None 时成立。

七、常见错误清单（务必逐条自查）

错误 1：IndentationError: expected an indented block

症状：if 后面那行没缩进。 原因：Python 用缩进表示代码块，if/for/def 后面必须缩进一层。 改法：统一 4 个空格（不要混 Tab）；VS Code 里开 Render Whitespace 能看见空格与 Tab 的区别。

错误 2：if x = 1: 或 elif 写成 else if

症状：SyntaxError。 原因：条件用 ==；Python 没有 else if，是 elif。 改法：if x == 1:；多分支写 if / elif / else。

错误 3：if answer == "Yes" 对 "yes" 不成立

症状：用户输入 yes 却走了 else。 原因：字符串比较区分大小写。 改法：比较前统一 answer.strip().lower()；需要更宽松就用 answer.lower() in ("y", "yes")。

错误 4：elif 顺序写反，永远进第一个分支

症状：分数 95 只拿到「及格」。 原因：if score > 60: ... elif score > 90: ...——90 分也满足 > 60，第一个分支就截住了。 改法：从窄到宽排：先 >= 90，再 >= 60，最后 else。

错误 5：if items: 判空却把 0 当成空

症状：数量是 0 时走了「没有数据」分支，但 0 是合法值。 原因：0、""、[]、None 在条件里都为假。 改法：要区分「没有」和「是 0」就显式判：if items is None:、if len(items) == 0:。
