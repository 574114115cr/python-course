关卡 2 · 阶段 2 · 五条硬指标

五条全部达标 = 从「会写代码」到「能交付软件」。验收靠可验证的证据，不靠自我感觉。

已达标 0 / 5 条
1

三个项目全部跑通，且已推到公开仓库，每个都有 README + requirements.txt

怎么算达标

三个仓库链接都拿到了；每个仓库首页能看到 README；每个仓库里有 requirements.txt 且依赖都带 ==；把任意一个仓库 clone 到另一台机器，照 README 能跑起来。

怎么验证

跑一遍示例 1 的 project_doctor.py，问题数为 0。

没过怎么办

README 照参考答案 21-1 的三段结构写；requirements.txt 在虚拟环境里重新 pip freeze > requirements.txt；仓库还没有就 git init → git add . → git commit → 建远程仓库 → git push。

自查命令（跑通再勾）
git remote -v有 origin 地址（说明真推上去了）
git status --short空 = 全部已提交
ls README.md requirements.txt两个文件都存在
2

「学习笔记」已部署上线，公网可访问，错误页已定制

怎么算达标

platform url 给出的网址在手机流量（不是同一个 WiFi）下能打开；访问不存在的网址返回你定制的 404 页；服务器出错时 500 页也是定制的，不是 Django 调试页。

怎么验证

重点测首页、/不存在/、/accounts/login/ 三个 URL。

没过怎么办

回单元 20，按 2.7 节三大坑（ALLOWED_HOSTS、collectstatic、DEBUG）逐项排查，改完 git commit + platform push。

注意

定制错误页只在 DEBUG = False 时生效，本地默认看不到。

自查命令（跑通再勾）
curl -I https://你的域名/HTTP/2 200 或 301
curl -s https://你的域名/no-such-page | head -5返回自定义 404 页面，不是 Django 调试页
3

能用自己的函数写出 pytest 测试并跑过（不是抄教材的）

怎么算达标

≥ 3 条测试针对你自己项目里的纯逻辑函数；每条断言具体数值；至少一条覆盖边界（0 / 空 / 非法输入）；pytest -v 全绿。

怎么验证

关掉讲义和教材，只留项目代码和 pytest，问自己：这三条测试的断言值我能自己算出来吗？ 算不出来就是抄的。

没过怎么办

先按 2.3 标准一把纯逻辑从「界面/数据库代码」里拆出来（这是前提），再照参考答案 21-2 写。记住：文件名和函数名都要 test_ 前缀，命名不对 pytest 显示 collected 0 items 而不报错。

自查命令（跑通再勾）
python -m pytest -q --collect-only | tail -5用例名是你自己起的函数名
python -m pytest -q全部 passed；删掉一个断言应该变红（证明测的是自己的代码）
4

接手一个没写过的 500 行 Python 项目，能读懂结构并定位一个 bug

怎么算达标

能在 30 分钟内画出结构图、指出入口、找到至少一处 bug（或明确的改进点）并说明理由；能判断项目属于哪一类（脚本 / 事件驱动 / 数据处理 / Web）。

怎么验证

按 2.4 的五步走一遍，用 grep -rn 搜关键字。

没过怎么办

找不到入口就搜 if __name__；读不懂逻辑就画调用图（grep 搜函数名看谁调用谁）；不敢确定是 bug就看上游有没有 open 的 issue。

自查命令（跑通再勾）
python -m cProfile -s cumtime main.py 2>&1 | head -15能说出耗时最多的三个函数
python -m trace --count -m main 2>&1 | tail -5能看到哪些行被执行过
5

能说清每个项目「解决了什么问题、还能怎么扩展」

怎么算达标

对三个项目各能回答两问——① 它解决什么真实问题（不是「练了 xxx API」）；② 至少说得出三条扩展方向，并能说明每条要动哪几个文件。

怎么验证

录一段 3 分钟口述，或写进每个项目 README 的「未来想法」一节。

没过怎么办

这题问的是判断力，只能自己想。万能模板（以数据看板为例）：① 数据源换更细的粒度；② 加一个导出报告的功能；③ 每天定时跑并把结果推给你。能说出「要动哪几个文件」，就说明你真懂它的结构。

自查命令（跑通再勾）
grep -c '^##' README.md≥3：说明写了「做什么 / 怎么跑 / 还能怎么扩展」
python -c "import json;print(len(json.load(open('data.json'))))"能报出项目真实数据规模，而不是「大概几十条」

全部达标后

五条全绿后按路线图继续，或直接拿三个项目去投简历。
