卡住了怎么办

这一页解决的是「报错看不懂、搜也搜不到、身边没人可问」。 自己能解决 80% 的问题、剩下 20% 知道怎么问，才算真能脱离课本自学。 下面的报错提取器和提问模板都可以直接用。

1 · 从报错里取出该搜的那一句

把完整报错粘进来，自动抽出最后一行——搜索只该用这一行， 前面几行是调用栈，带着你的文件名和行号，搜了也搜不到。

去搜索 
（提取结果会显示在这里）

2 · 求助前先做完这三件事

  1. 把报错的最后一行原样复制——不是凭记忆复述。
  2. 把问题压到最小：删代码删到「再删就不报错了」为止。
  3. 自己先试过至少两种改法，并把试过什么写进问题里。

做完这三步，大概有三分之一的问题不用问就已经解决了—— 因为在压最小的过程中你自己就看见了原因。

3 · 怎么把问题压到最小（MRE）

  1. 去掉无关的读写和网络请求：文件里读出来的数据，直接用字面量写在代码里。
  2. 去掉无关的函数包装：能直接跑的循环就别套函数。
  3. 把大列表缩到两三个元素：只要还能复现报错就行。
users = [{"name": "a", "active": True}, {"name": "b"}]
for u in users:
    print(u["active"])   # 第二项没有 active 键 → KeyError

压到这一步，答案往往自己浮出来：有数据缺字段，改 u.get("active", False) 就行。

4 · 提问模板（点下面的按钮直接复制）

【环境】
【想做什么】
【我写的代码】（贴能跑的最小版本）
【期望结果】
【实际结果】
【完整报错】（Traceback 全部复制）
【我试过的】

四个最容易犯的错：不贴完整报错、贴截图而不是文字、 贴 300 行原始代码、把报错翻译成中文再问（别人要搜原文）。

5 · 去哪问

渠道适合什么注意
搜索引擎所有报错，尤其是常见错误用上面提取出来的那一行原文
Python 官方文档 docs.python.org某个函数/模块到底怎么用有中文版，英文版更新更全
Stack Overflow搜不到、又确实卡住的先搜是否已有答案；按模板写
库的 GitHub Issues第三方库本身的 bug先搜 closed issues，多半有人问过
学习群 / 社区概念理解、方向选择同样要贴报错和代码

6 · 问 AI 的四条纪律

  1. 给完整上下文：报错原文 + 相关代码 + 你想达成的目标。
  2. 要求解释，而不是只给代码：问「为什么」，比问「帮我改」学到的多。
  3. 它给的代码一定要自己跑一遍——它会编造不存在的 API，一跑就现形。
  4. 它给的解释要能用自己的话复述：复述不出来就是你没懂。

AI 是加速器，不是裁判。代码跑得通才是唯一的裁判。
