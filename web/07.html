二、核心知识点讲解

2.1 函数：给一段代码起个名字

没有函数时，计算 BMI 的代码要在不同地方重复写三遍：

Pythonbmi1 = 70 / 1.75 ** 2
bmi2 = 80 / 1.80 ** 2
bmi3 = 60 / 1.65 ** 2

函数把它打包成一个"有名字的积木"：

Pythondef calculate_bmi(weight, height):
    """根据体重和身高计算 BMI。"""
    return weight / height ** 2


print(calculate_bmi(70, 1.75))   # 22.86
print(calculate_bmi(80, 1.80))   # 24.69

生活化类比：函数就像**「饺子机」**——你把原料（参数）放进去，按下按钮（调用），机器产出饺子（返回值）。同一台机器可以反复使用，产出多少饺子取决于你这次放了多少原料。你不需要知道机器内部怎么运作，只需要会用。

三条语法铁律：

Pythondef 函数名(参数):
    """文档字符串"""
    函数体
    return 结果
  1. def 和函数名之间有空格（def 函数名，不是 def函数名）
  2. 括号后面必须有冒号
  3. 函数体必须缩进

2.2 return：把结果"递出窗口"

return 做两件事： 1. 立刻结束函数（后面的代码不再执行） 2. 把一个值交回给调用者

有 return 和没 return 的本质区别：

Pythondef with_return():
    return 42

def without_return():
    pass              # 什么都不返回


print(with_return())       # 42
print(without_return())    # None  ← 默认就是 None

生活化类比：return 相当于柜台的取货窗口。函数内部的员工在窗口后面干活，做好的东西从窗口递给你。没有窗口（没有 return），你伸手只能拿到一个空的窗口（None）。

两条极重要的规则：

① return 之后的代码永远不执行：

Pythondef check():
    return "早退了"
    print("这句话永远不会打印")      # 死代码
    return "第二个 return 也不可达"

② 一个函数可以有多个 return，但只会走一个：

Pythondef classify(n):
    if n > 0:
        return "正数"      # 命中就返回，函数结束
    elif n < 0:
        return "负数"
    return "零"            # 兜底分支

注意最后那个 return "零" 要缩进在函数体层级（和 if 平齐），而不是缩进在 elif 里面。

2.3 三种参数写法

Pythondef describe(name, age=18, *hobbies, **extras):
    """三种参数写法的演示。"""
    print(f"姓名：{name}")
    print(f"年龄：{age}")
    print(f"爱好：{hobbies}")
    print(f"其他：{extras}")


describe("小明")                        # 年龄用默认值 18，hobbies 为空
describe("小红", 25)                    # 位置传参：第二个参数是年龄
describe("小刚", age=30)                # 关键字传参：明确指定年龄
describe("小丽", 22, "读书", "游泳")       # 多余的位置参数进 *hobbies
describe("小强", 20, "篮球", city="杭州")   # 多余关键字参数进 **extras

Python 的强制规则：有默认值的参数必须放在没有默认值的参数后面。

2.4 ★ 参数传递的副本语义（本单元最重要的概念）

这是零基础学习者最容易掉坑的地方，必须彻底搞懂。

Python 传递参数时，传递的永远是"指向数据的地址"。 而函数内部对参数做的操作，分为两类：

参数类型 函数内部做什么 影响到原变量吗
整数、字符串、布尔、浮点数（不可变类型） 修改参数 = 造一份新的给参数 不影响
列表、字典（可变类型） 修改参数 = 改同一份数据 会影响！

看代码：

Python# ===== 情况1：传整数，不影响原变量 =====
def add_one(n):
    n = n + 1        # 只是让参数 n 指向了一个新的整数
    print(f"函数内 n = {n}")      # 11


age = 10
add_one(age)
print(f"函数外 age = {age}")      # 10  ← 没变

# ===== 情况2：传列表，会影响原列表 =====
def add_item(items):
    items.append("新元素")    # 直接改的是同一份列表
    print(f"函数内 items = {items}")


fruits = ["苹果", "香蕉"]
add_item(fruits)
print(f"函数外 fruits = {fruits}")  # ['苹果', '香蕉', '新元素']  ← 变了！

生活化类比（务必记住这个）：

函数就像一个公共厨房。你把食材递进去： - 递进去一瓶牛奶（整数、字符串这类不可变数据）——厨房里的人往瓶子上贴了新标签自己用，你的那瓶没动。 - 递进去一整盘菜（列表、字典这类可变数据）——厨房里的人直接吃了你的菜，还往盘子里加了料，你的盘子内容就变了。

三种正确的应对方式（按推荐程度排序）：

Python# 方案 1：函数内自己造副本（推荐，最简单）
def safe_append_1(items):
    items = items[:]    # 先复制一份，只改副本
    items.append("新元素")
    return items

# 方案 2：调用时传副本
result = safe_append_1(fruits[:])     # 调用方负责给副本

# 方案 3：用不可变类型替代可变类型
def safe_append_3(items):
    return items + ["新元素"]          # + 号产生新列表，原列表不动

判断原则：如果一个函数接收列表或字典，并且它可能修改这个参数，那么这个函数有一个"副作用"——调用者需要知道这件事。所以有两种设计取向：

  • 有意修改：用 modify() 这样的名字明确表达"我会改它"，比如单元 9 里写文件。
  • 无意修改：函数内部造副本，或者干脆不要这个参数。

2.5 作用域：谁能看见谁

Pythonname = "全局变量"


def show():
    local_name = "局部变量"
    print(name)                # 能看全局的
    print(local_name)          # 能看自己的


show()
print(local_name)      # NameError: name 'local_name' is not defined

规则很简单： - 函数内定义的变量是局部变量，只在函数内可见，函数结束就消失。 - 函数可以读取全局变量，但不推荐修改全局变量。 - 函数内如果要给一个名字赋值，Python 就认为它是局部的（不会去改全局的那个）。

Pythoncount = 0

def broken():
    count = 100        # 这是新建了一个局部 count，全局的那个不受影响
    print(count)       # 100

def works():
    global count       # 声明"我要用全局的那个"
    count = 100


broken()
print(count)       # 0  ← 全局没被改
works()
print(count)       # 100 ← 这次真改了

最佳实践：不要用 global。 需要修改全局状态时，把数据传进去、把结果返回出来：

Pythondef add_to_total(amount, current_total):
    """返回新的总额，而不是修改外部变量。"""
    return current_total + amount


total = 100
total = add_to_total(50, total)     # 显式地接住返回值
print(total)       # 150

2.6 函数是"一等公民"

Python 的函数可以： - 赋给变量：double = lambda x: x * 2（lambda 就是"一次性小函数"） - 当参数传给别的函数：sorted(scores, key=scores.get) - 放进列表：operations = [加, 减, 乘] - 当返回值返回：def get_adder(): return 加

Pythondef add(a, b):
    return a + b


# 函数赋给变量
operation = add
print(operation(3, 4))    # 7

# lambda：一个参数的小函数，写法极简
square = lambda x: x ** 2
print(square(5))         # 25

# 函数放进列表，根据需要选
operations = [lambda a, b: a + b, lambda a, b: a - b, lambda a, b: a * b]
print([op(10, 3) for op in operations])    # [13, 7, 30]

这个特性的价值在单元 11 的投票分析器里会充分体现——你可以把"加票"和"投票"两个函数分别交给两个不同的类。

2.7 把函数存进模块（教材 8.6）

函数越写越多，一个 .py 文件迟早会到几百行：定义、调用、测试混在一起，改一处要滚半天。教材 8.6 的解法是按用途拆文件——一个 .py 文件就是一个模块，模块名就是文件名去掉 .py。

最小的模块就是两个文件。

Python# （片段）pizza.py —— 函数放在这里，文件名就是模块名
def make_pizza(size, *toppings):
    """概述要制作的披萨。"""
    print(f"\n制作 {size} 寸披萨，配料：")
    for t in toppings:
        print(f"  - {t}")


if __name__ == "__main__":
    make_pizza(12, "蘑菇", "青椒")     # 只有直接运行 pizza.py 才执行

Python# （片段）main.py —— 与 pizza.py 放在同一目录
import pizza                        # ① 导入整个模块
from pizza import make_pizza        # ② 只导入函数
from pizza import make_pizza as mp  # ③ 导入并起别名
import pizza as p                   # ④ 给模块起别名

pizza.make_pizza(16, "芝士")          # ① 用「模块名.函数名」调用
make_pizza(12, "蘑菇")               # ② 直接调用
mp(9, "榴莲")                        # ③ 用别名调用
p.make_pizza(6, "玉米")               # ④ 别名也能点出函数

四种写法没有优劣，区别只在调用时写多长和名字冲突的风险：

写法 调用时要写 适合场景
import pizza pizza.make_pizza() 模块名短、函数多，一眼看出函数来自哪
from pizza import make_pizza make_pizza() 只用一两个函数，代码更短
from pizza import make_pizza as mp mp() 函数名太长，或与本地函数重名
from pizza import * make_pizza() 不推荐：导入了什么看不出来，容易覆盖同名变量

if __name__ == "__main__": 到底在防什么？ 每个模块都有一个内置变量 __name__：

  • 直接运行这个文件时，__name__ 的值是 "__main__"；
  • 被别的文件 import 时，__name__ 的值是模块名 "pizza"。

所以把「只有自己运行时才该做的事」（打印演示、跑一遍自测）放进这个判断里，别人 import 你的函数时就不会被那些 print 打扰。模块顶层不要写会造成副作用的代码（打印、input()、删文件），这是 Python 模块的基本礼貌。

Python# （片段）两种结果对照
# 直接运行：      python pizza.py   → __name__ == "__main__" → 打印演示
# 被别人导入：    import pizza      → __name__ == "pizza"    → 只拿到函数，不打印

要点 - 模块名不能和标准库重名：自己写一个 random.py，import random 就会导入你自己那个，标准库彻底用不了。 - 同目录才能直接 import；跨目录要靠包（带 __init__.py 的文件夹）或 sys.path，本课程不展开。 - 导入是执行一次模块顶层代码，之后再用不会重复执行——这也是为什么顶层别写副作用。 - 模块里的函数照样要遵守 2.1～2.6 的规则：参数、返回值、作用域都不变。

def longest_word_loop(words):
    """用普通循环找最长单词，长度相同返回第一个。"""
    if not words:               # 空列表要提前处理
        return ""

    longest = words[0]          # 假设第 0 个最长
    for word in words:
        if len(word) > len(longest):     # 严格大于，所以同长度保留先来的
            longest = word
    return longest


def longest_word_max(words):
    """用内置 max 找最长单词。"""
    if not words:
        return ""
    return max(words, key=len)

def analyze_text(text):
    """分析一段文本，返回包含各项统计信息的字典。

    返回的字典包含：
        字符数     不含空格的字符总数
        单词数     按空格切分后的单词数量
        最长单词   长度最大的单词
        各单词次数 {单词: 出现次数}
    """
    # 切分成单词列表
    words = text.split()

    # 统计各单词出现次数（单元 5 的计数方法）
    counts = {}
    for word in words:

    # 找最长单词

        if len(word) > len(longest):
            longest = word

    return {
        "字符数": len(text.replace(" ", "")),
        "单词数": len(words),
        "最长单词": longest,
        "各单词次数": counts,
    }

def analyze_numbers(numbers):
    """返回 (总和, 平均值, 最大值, 最小值, 偶数个数) 组成的元组。"""
    total = sum(numbers)
    average = total / len(numbers)
    largest = max(numbers)
    smallest = min(numbers)
    even_count = 0
    for n in numbers:
        if n % 2 == 0:
            even_count += 1
    # 逗号分隔多个值，Python 会自动打包成元组返回
    return total, average, largest, smallest, even_count


def count_vowels(text):

Python# timer_decorator.py —— 用"函数返回函数"实现计时器

import time


def make_timer(func):
    """把一个函数包成"会自动打印耗时"的版本。"""
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)      # 真正干活
        end = time.time()
        print(f"  [{func.__name__}] 耗时 {end - start:.6f} 秒")
        return result                      # 别忘了把结果传出去
    return wrapper


# 被包装的函数：故意做点耗时的活
def slow_sum(n):
    """累加 1 到 n 的和，n 大一点才有感。"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total


def quick_answer():
    """一个几乎不耗时的函数。"""
    return 42


# ===== 使用 =====
timed_slow_sum = make_timer(slow_sum)
timed_answer = make_timer(quick_answer)

print("调用被包装的慢函数：")

print("  返回值：", result1)

print("\n调用被包装的快函数：")

print("  返回值：", result2)

        return result
    return wrapper

七、本单元验收自测

1. 简答题：

Pythondef modify(n):
    n = 10
    return n


x = 5
result = modify(x)
print(x, result)

输出什么？为什么？

要点：输出 5 10。整数是不可变类型，函数内的 n = 10 只是让参数 n 指向了一个新的整数 10，原始数据 5 毫发无损。return 返回的 10 和外部的 x = 5 是两个完全无关的值。

2. 简答题：

Pythondef add_item(items):
    items.append("新")


data = []
add_item(data)
print(data)

输出什么？如果希望 data 保持为空，应该怎么改？

要点：输出 ['新']。列表是可变对象，Python 传递的是指向列表的地址，函数内的 append 修改的就是 data 指向的那一份数据。要让 data 保持为空，两种改法：① 函数内先造副本 items = items[:] 再 append；② 或者干脆改用 return items + ["新"] 的纯函数写法。

3. 判断题：def f(a, b=2): return a + b 这行代码可以写成 def f(b=2, a) 吗？

要点：不可以，会报 SyntaxError: non-default argument 'a' follows default argument。Python 要求有默认值的参数必须排在没有默认值的参数之后，否则调用时无法判断 f(5) 里的 5 是给 a 还是 b。

4. 简答题：return 语句有哪些作用？如果函数里没有写 return，调用它会得到什么？

要点：return 有两个作用——① 立刻结束函数，后面的代码不再执行；② 把一个值交回调用者。没有写 return 的函数，调用结果是 None（Python 默认隐式返回 None）。这个坑很隐蔽：函数里明明修改了列表，但 result = func(lst) 拿到的却是 None。

5. 简答题：下面这个函数为什么第二次调用时结果里会多出第一次的"买菜"？

Pythondef add_task(task, todo=[]):
    todo.append(task)
    return todo

要点：因为默认参数 [] 是在函数定义时只求值一次，那个列表对象被后续所有调用共享。所以第二次调用时，todo 里已经有了第一次放进去的"买菜"。正确写法是 def add_task(task, todo=None):，然后在函数体里写 if todo is None: todo = []，让每次调用都创建一个新列表。
