一、学习目标

完成本单元后，你应该能够：

  1. 用 input() 读取用户输入，并熟练完成「输入字符串 → 转换类型 → 参与运算」这三步。

  3. 写出带条件的 while 循环，并说清条件为假时循环体一次都不执行。
  4. 熟练使用 break（跳出）和 continue（跳过本轮），并用 while ... else 组织「循环正常结束」的逻辑。

二、核心知识点讲解

2.1 input() 的铁律：拿回来的永远是字符串

Pythonage = input("请输入年龄：")
print(type(age))     # <class 'str'>   哪怕你输入 18，它也是字符串 "18"

这带来一个必须处理的经典问题：

Pythonage = input("年龄：")       # 用户输入 18
print(age + 1)
# TypeError: can only concatenate str (not "int") to str

生活化类比：input() 相当于一个只认字不认数的管理员。你把数字 "18" 递过去，他不管你写的是数字还是文字，一律登记成"文字"。想让它按数字处理，你必须再翻译一次：

Pythonage = int(input("年龄："))       # 用户输入 18 -> 字符串 "18" -> 整数 18
print(age + 1)                   # 19

标准三步模板：

Python# 第1 步：用 input() 拿字符串
# 第 2 步：转成需要的类型（int / float）
# 第 3 步：参与运算或输出

还有个实用技巧——给 input 加提示信息：

Pythonname = input("请输入你的名字：")          # 带提示
name = input()                          # 不带提示

默认没有提示，用户会一脸茫然。

2.2 for 还是 while：怎么选

for while
控制方式 遍历一个确定的数据序列 判断一个条件
循环次数 序列有多长就转多少圈 条件为真就转
适合场景 遍历列表、字符串、range 次数未知、直到满足条件才停

选择规则一句话：你知不知道要循环几次？知道就用 for，不知道就用 while。

Python# 知道次数：遍历 10 个学生 -> for
for i in range(10):
    process(i)

# 不知道次数：一直问，直到用户输对了 -> while
while True:
    answer = input("请输入正确答案：")
    if answer == "python":
        break

生活化类比： - for 像按清单点名——名单上有 10 个人，念完 10 个就结束。 - while 像守门等人——你说"他来了我就开门"，所以得一直站着等，来几个人都不确定。

2.3 while 的核心：条件先行

Pythoncount = 0
while count < 3:
    print(count)
    count += 1
# 输出 0 1 2

三个必须记住的点：

  1. 条件为假时，循环体一次都不执行。
Pythoncount = 10
while count < 3:
    print("永远不会打印")
    count += 1
  1. 必须有让条件变假的那一行，否则进入死循环。
故意写错 · 先跑一遍看报错# 死循环：count 永远是 0，永远小于 3
count = 0
while count < 3:
    print(count)     # 停不下来，只能按 Ctrl+C 强制中断
这是故意写错的示例——先自己跑一遍看报错，再对照下面的解析弄清错在哪

调试死循环时最直接的救命办法：在循环里加一行 print(count)，看它到底变没变。

  1. Python 允许 while count: 这种写法——条件本身是整数时，0 为假、非 0 为真。
Pythonn = 3
while n:
    print(n)
    n -= 1

这个写法很地道，但初学阶段建议写完整的 while n > 0:，更明确。

2.4 break 与 continue

Python# break：立刻跳出整个循环
for i in range(10):
    if i == 3:
        break        # 直接跳出，后面的不再执行
    print(i)
# 输出 0 1 2

# continue：跳过本轮，直接进入下一轮
for i in range(10):
    if i % 2 == 0:
        continue     # 偶数跳过，只打印奇数
    print(i)
# 输出 1 3 5 7 9

生活化类比： - break 是"提前下课"——举手表说"这节课剩下的不上了"，直接走人。 - continue 是"这题跳过，下一题"——留在教室里，只是跳过当前这一题。

一个常见混用错误：

Python# 错误：continue 之后多余的代码永远执行不到
for i in range(5):
    if i == 2:
        continue
        print("这里永远不执行")   # 缩进在 if 块内，且在 continue 之后

    print(i)

2.5 while ... else：循环"没被打断"时执行

这是一个非常优雅但很少人用、却极其好用的结构：

Pythonwhile 次数 < 3:
    ...
else:
    print("三次机会都用完了，仍然没猜对")

else 块只在循环正常走完（没有被 break 打断）时执行。一旦 break，else 就被跳过。

生活化类比："如果这节课没被老师叫停，就说明大家表现好，下课"。一旦被叫停（有 break），这个"表扬"就不会发生。

Python# 猜谜游戏的标准写法
guess = 0
while guess < 3:
    answer = int(input("1-10 猜个数："))
    if answer == 7:
        print("猜对了！")
        break
    guess += 1
else:
    print("机会用完了")

这段代码读起来非常自然：猜对了就 break 走人，猜满 3 次还没对就落进 else。这是单元 11 猜数字游戏的核心结构。

2.6 交互程序的骨架

任何需要"反复问用户"的程序，都是这个模式：

Pythonwhile True:                # 无限循环
    用户输入 = input(...)
    if 输入 == "退出":       # 用户主动要求结束
        break                # 用 break 跳出无限循环
    if 输入无效:
        print("请重新输入")   # 用 continue 回到循环开头
        continue
    处理有效的输入
print("程序结束")             # 只有 break 出来才会走到这里

注意这个模式的关键点： - while True 本身没有出口，唯一的出口是 break。 - 所以每一条通向"用户想退出"的路径，都必须有 break。 - 这也是为什么必须有"退出"这个选项——否则用户被永远困在里面。

这个骨架在单元 11 的猜数字游戏、投票分析器里会反复出现，请务必掌握到能默写。

2.7 用 while 处理列表和字典（教材 7.3）

for 适合「每个元素都做一次」，while 适合「一直做，直到某个条件不成立」。教材 7.3 用三个场景说明后者，这三个场景在真实代码里出现频率极高。

① 在列表之间搬元素。 一个列表放待处理项，另一个放已完成项，处理完就从原列表里「取走」：

Pythonunconfirmed = ["alice", "bob", "carol"]
confirmed = []

while unconfirmed:              # 空列表为假 → 循环自然结束，不需要计数器
    user = unconfirmed.pop()    # 从末尾取走一个
    print(f"正在验证 {user}…")
    confirmed.append(user)

print("已验证", confirmed)      # ['carol', 'bob', 'alice']  ← 顺序反了
print("待验证", unconfirmed)    # []

注意输出顺序是反的：pop() 取末尾。要保序用 pop(0)（从头取，元素多时更慢），或者先把原列表反转。

② 删除所有等于某值的元素。 list.remove(x) 只删第一个匹配项，删干净必须靠循环：

Pythonpets = ["cat", "dog", "cat", "rabbit", "cat"]

while "cat" in pets:            # 条件：列表里还有 cat
    pets.remove("cat")

print(pets)                     # ['dog', 'rabbit']

这里最容易踩的坑是边 for 边 remove：

Pythonnums = [1, 2, 2, 3]
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)                     # [1, 2, 3]  ← 还剩一个 2！

原因是 for 内部维护着下标，删掉一个元素后后面的元素整体前移，下标正好跳过了一个。规则很简单：要删元素就别用 for 遍历同一个列表，改用 while、列表推导式，或者遍历副本 for n in nums[:]。

③ 用用户输入来填充字典。 收集问卷、登记报名都是这个结构：

Pythonresponses = {}
active = True

while active:
    name = input("姓名（输入 q 结束）：")
    if name == "q":
        active = False
    else:
        responses[name] = input("你想学什么：")

print(responses)

active = False 和 break 都能退出，区别是 break 立刻跳出、active = False 要等本轮循环体执行完。上面这种写法里两者等价，但退出后不能再使用 name——如果用户输入 q，name 就是 "q"，把它写进字典就错了，所以要用 else 把写入包起来。

要点 - 判断「列表空没空」直接写 while items:，不要写 while len(items) > 0:。 - while "x" in items: items.remove("x") 是「删干净」的标准写法；remove() 一次只删一个。 - 边遍历边改列表是 bug 温床，遍历副本写 for x in items[:]。 - pop() 取末尾、pop(0) 取开头，后者在长列表上是 O(n)。

示例 3：break 与 continue

Python# break_continue.py —— 两个跳出关键字

# break：跳出整个循环
print("--- break 演示 ---")
for i in range(10):

print("\n--- 输入校验（关键模式）---")
while True:
    age = input("请输入你的年龄：")
    # 如果不是纯数字，int() 会报 ValueError
    try:
        age = int(age)

示例 5：标志位 flag

当一个循环里需要触发多个 break 时，用一个变量"记账"更清晰：

Python# flag_demo.py —— 用标志位组织复杂退出条件

# 问题：如果密码错误 和 用户名不存在 都要跳出，怎么写？
username = "admin"
password = "wrong"

#===== 做法一：标志位（推荐，可读性最好）=====
username_ok = False
password_ok = False

if username == "admin":
    username_ok = True
if password == "123456":
    password_ok = True

if username_ok and password_ok:
    print("登录成功")
else:
    print("用户名或密码错误")

# ===== 做法二：逻辑运算符（更简洁）=====
if username == "admin" and password == "123456":
    print("登录成功")
else:
    print("用户名或密码错误")

# ===== 标志位的真正用武之地：在循环里 =====
numbers = [10, 25, 3, 47, 8, 91]
target = 47

# 找出目标值的下标，找不到返回 -1
found_index = -1

# 标志位：记录"找到了没有"
found = False

for i, n in enumerate(numbers):
    if n == target:
        found_index = i
        found = True
        break            # 找到了就停，不必再往下看

# 用标志位决定后续走哪条路
if found:
    print(f"在索引 {found_index} 处找到了 {target}")
else:
    print(f"列表中没有 {target}")

# 也可以不用标志位，直接判断 found_index != -1
print(f"（等价判断）索引是 {found_index}")

示例 6：交互式程序骨架

Python# interactive_skeleton.py —— 所有交互程序的通用骨架

# ===== 骨架 1：菜单循环 =====
# while True + break + continue 的完整组合
while True:
    print("\n===== 简易计算器 =====")
    print("1. 加法")
    print("2. 减法")
    print("3. 退出")

    choice = input("请选择操作：")

    if choice == "3":
        print("再见！")
        break# 唯一的出口：用户要求退出

    if choice not in ["1", "2"]:
        print("无效的选项，请重新输入")
        continue             # 回到循环开头，菜单重新打印

    a = float(input("请输入第一个数："))
    b = float(input("请输入第二个数："))

    if choice == "1":
        print(f"结果：{a + b}")
    else:
        print(f"结果：{a - b}")

print("循环外的代码，只有 break 出来才会执行")

# ===== 骨架 2：多条退出路径 =====
# 三个不同的条件都要能退出循环，用标志位最清晰
attempts_left = 3
locked = False

for i in range(attempts_left):
    print(f"你还有 {attempts_left - i} 次机会")
    answer = input("输入 'quit' 可以放弃：")

    if answer == "quit":
        print("你选择了放弃")
        break
    if answer != "yes":
        print("答案错误")
        continue

    print("回答正确！")
    locked = True
    break
else:
    print("机会用完，锁定账户")

if locked:
    print("=== 已解锁 ===")

示例 7：倒计时与死循环的自救

Python# countdown.py —— while 的经典应用：倒计时

# 1）从 5 数到 1
count = 5
while count > 0:
    print(count)
    count -= 1

pending = ["写周报", "", "回邮件", "订机票", ""]
done = []

while pending:                     # 列表非空就继续
    task = pending.pop(0)          # 从头取，保持原始顺序
    if not task:                   # 空字符串为假 → 这一项不算任务
        continue
    done.append(task)
    print(f"完成：{task}（还剩 {len(pending)} 项）")

print("已完成", done)
print("待办  ", pending)

三个细节：

  1. pop(0) 与 pop() 的差别就是顺序。这里要按用户输入顺序完成，所以从头取；如果不在乎顺序，pop() 更快（不用移动后面的元素）。

  3. 循环结束时 pending 一定是空列表，这不是巧合：while pending 的条件就是「非空」，所以退出时必然为空。写这种循环时，条件本身就能当断言用。

    """返回第一个大于 limit 的元素及其下标，都找不到时返回 (None, -1)。"""
    for index, item in enumerate(items):
        if item > limit:
            return item, index
    return None, -1

    print("你好")
    count += 1

要点：什么都不输出。while 是先判断条件再执行，第一次判断 10 < 5 就是假，所以循环体一次都不执行。这是 while 和 for 的重要差别之一（for 在序列为空时同样不执行，但 while 的"不执行"发生在任何一行代码之前）。

3. 判断题：break 和 continue 的区别在于：break 结束整个循环，continue 只跳过本次循环。

要点：正确。break 一旦执行，整个最内层循环立即结束，控制流跳到循环之后；continue 立刻开始下一轮循环，本次循环体中 continue 之后的所有代码都不会执行。两者都只作用于最内层循环——嵌套循环里的 break 只能跳出内层。

4. 简答题：while ... else 中的 else 在什么情况下会被执行？什么情况下会被跳过？

要点：else 块只在循环自然结束（条件变假而退出）时执行。一旦循环被 break 打断，else 就被跳过。典型用途：游戏重试机制——猜对了 break 走人，猜满次数没 break 就落进 else 执行"机会用完"的逻辑。

5. 简答题：为什么 while True 循环必须设计"退出"选项？写出这个骨架的关键组成部分。

要点：因为 while True 的条件永远是真，循环没有任何自动出口，唯一的出口是 break。如果不提供退出方式，用户会被永久困在循环里，程序也无法结束。骨架四个部分：① while True: 开始无限循环；② 用 input() 读取用户输入；③ if 输入 == "退出" 则 break；④ if 输入无效 则 continue（或 continue 让流程回到循环开头），末尾放一句"程序结束"作为 break 之后的出口标记。

七、常见错误清单（务必逐条自查）

错误 1：input() 拿到的数字当数字用

症状：if age > 18: 报 TypeError: '>' not supported between 'str' and 'int'。 原因：input() 永远返回字符串，"18" > 18 不成立。 改法：age = int(input("年龄："))；不确定输入合法就先 try: age = int(s) except ValueError: 提示重输。

错误 2：while 忘了改条件，死循环

症状：程序卡住不动，CPU 占满。 原因：while i < 5: 里没写 i += 1，条件永远成立。 改法：循环体里必须有能让条件变假的语句；临时排查在循环里加 print(i)（Ctrl+C 停）。

错误 3：while "x" in items: items.remove("x") 写成 if

症状：删了一个还剩俩。 原因：if 只判断一次；要删干净得反复判断。 改法：用 while ... in ...；或 items = [i for i in items if i != "x"]。

错误 4：break 只跳出最内层

症状：两层循环里 break 之后外层还在跑。 原因：break 只结束它所在的那一层。 改法：用标志位 done = True 让外层也退出，或把内层抽成函数 return。

错误 5：while True: 里没留退出路径

症状：必须强制关窗口。 原因：只写了 break 的条件永远不会满足（比如没处理「退出」关键字）。 改法：明确列出所有结束条件；while True 里至少有一条 break 与用户输入相关。
