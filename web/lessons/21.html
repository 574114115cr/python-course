2.5 链式比较：Python 的贴心语法

Python 支持把比较串起来写，像数学一样：

Pythonif 18 <= age <= 60:
    print("适龄")

# 等价于（但更慢，因为 age 被求值两次）
if age >= 18 and age <= 60:
    print("适龄")

数字能链式比较，字符串也能：

Pythonif "a" <= letter <= "z":
    print("是小写字母")

注意：链式比较不能用于列表，列表不支持大小比较（> 报错）。

2.6 == 还是 is？

新手必问的问题。答案是：99% 的场景用 ==，唯一该用 is 的场景是 is None。

Python# == 比较"内容是否相同"
print("hello" == "hello")          # True，内容一样

# is 比较"是不是同一个对象"（内存地址）
# 这种情况 is 会是 False，但我们要的其实是内容相等
first = "hello"
second = "he" + "llo"
print(first == second)             # True
print(first is second)             # False（可能是两个不同的对象）

# 但判断"是否为空"必须用 is，因为 None 是唯一的单例
result = None
if result is None:                 # 正确：表达"这个变量还没有值"
    print("还没有结果")

为什么不用 if result == None？ 因为 None 只可能是那一个对象，is None 语义明确、速度快；而如果哪天你写了个自定义类，它的 __eq__ 允许自己"等于 None"，那 == None 就真的会成立。

所以：判断"有没有值" → is None / is not None；判断"内容是否一样" → ==。

2.7 条件表达式：把 5 行压成 1 行

Python# 传统写法
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 条件表达式（也叫三元表达式）
status = "成年" if age >= 18 else "未成年"

结构是 真值时的结果 if 条件 else 假值时的结果。

这在单元 3 的列表推导式和单元 9 的写入文件时会大量用到。但有一条使用原则：

超过一层嵌套的条件表达式就该拆开用普通 if。 写成 a if x else b if y else c 虽然合法，但没人能一眼读懂——为了少打两行而牺牲可读性，是很不划算的交换。

三、可运行代码示例

示例 1：if 单分支

Python# if_single.py —— 最简单的条件判断

age = 20

# 缩进的行才是条件成立时执行的
if age >= 18:
    print("你已成年，可以进入")

# 条件不成立时，这段代码被完全跳过（不是报错，是安静地跳过）
if age < 18:
    print("你未成年，禁止进入")
print("这句无论条件如何都会执行")     # 缩进退回一级 = 在 if 外面

# 注意：= 是赋值，== 才是比较。下面这行会报 SyntaxError
# if age = 18:
#     print("错误写法")

# 多个条件用 and 连接
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("可以入场")

# 也可以写成链式比较（数字专用）
if 18 <= age < 60:
    print("处于 18 到 60 之间")

示例 2：if / elif / else 三分支

Python# grade_if.py —— 多分支：成绩等级评定

score = 85

# 从最严格的条件开始，逐步放宽
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"分数 {score}，等级 {grade}")     # 分数 85，等级 B

# 演示"只执行一个分支"
print("---")
for s in [95, 85, 75, 65, 45]:
    if s >= 90:
        g = "A"
    elif s >= 80:
        g = "B"
    elif s >= 70:
        g = "C"
    elif s >= 60:
        g = "D"
    else:
        g = "F"
    print(f"{s} -> {g}")
# 95->A, 85->B, 75->C, 65->D, 45->F

# 注意 else 块里不能再写 if；如果需要，必须用 elif 串成一条链
# 下面这种写法是错的（else 后面不能跟 elif）：
# else:
#     if s >= 0:
#         g = "零分"

示例 3：顺序的重要性

Python# order_matters.py —— elif 链的顺序为什么关键

age = 20

# ===== 错误顺序：条件从宽到窄 =====
print("--- 错误顺序 ---")
if age > 6:
    print("青少年")         # 20 > 6 成立，立刻执行，后面全部跳过
elif age > 18:
    print("成年")           # 永远执行不到
else:
    print("儿童")           # 也永远执行不到

# ===== 正确顺序：条件从窄到宽 =====
print("--- 正确顺序 ---")
if age > 18:
    print("成年")
elif age > 6:
    print("青少年")
else:
    print("儿童")

# 结论：if 链是"从上往下、命中即停"，所以最特殊的放最前面

示例 4：逻辑运算符与短路求值

Python# logic_ops.py —— and / or / not 与短路求值

age = 20
income = 8000
is_student = False

# and：全部为真才为真
print(age >= 18 and income >= 3000)         # True
print(age >= 18 and income >= 10000)        # False
# or：有一个为真就为真
print(age < 18 or income >= 3000)           # True
# not：取反
print(not is_student)                       # True

# ===== 短路求值：真实的安全价值 =====
numbers = [5, 8, 13]

# 安全写法：先问"长度够不够"，再问"内容是什么"
if len(numbers) > 0 and numbers[0] == 5:
    print("第一个数是 5")

# 危险写法：先访问元素，空列表直接崩溃
empty = []
# if empty[0] == 5 and len(empty) > 0:
#     print("这行永远不会安全执行")

# 正确演示：对比两个空列表
print("--- 短路求值演示 ---")
if empty and empty[0] == 5:
    print("第一个数是 5")
else:
    print("列表为空，跳过检查（短路了，没有访问 empty[0]）")

# and / or 可以直接返回操作数本身，不只返回布尔值
print("--- or 的一个实用技巧 ---")
name = ""
display_name = name or "匿名用户"# 空字符串为假，所以取了右边
print("显示名：", display_name)

real_name = "小明"
print("显示名：", real_name or "匿名用户")   # 小明

# 这就是单元 9 里写文件时的常见写法：
# content = text or "默认内容"

示例 5：链式比较与字符串比较

Python# comparisons.py —— 各种比较的细节

# 数字链式比较
age = 25
if 18 <= age <= 60:
    print("适龄")
if 10 <= age < 20:
    print("少年")
else:
    print("不是少年")

# 字符串按编码逐个比较，等价于字典序
print("apple" < "banana")        # True
print("apple" > "Apple")         # True（小写 a 的编码比大写 A 大）
print("abc" < "abd")             # True（逐位比，c < d）

# 链式比较字符串：判断是否是小写字母
letter = "k"
if "a" <= letter <= "z":
    print(f"{letter} 是小写英文字母")

# 判断是否全是大写
upper_word = "HELLO"
if upper_word.isupper():
    print(f"{upper_word} 全是大写")

# 注意：列表不能做大小比较
# if [1, 2] > [1, 3]:     # TypeError: '>' not supported between 'list' and 'list'
# 但可以判断相等
print([1, 2] == [1, 2])          # True
print([1, 2] is [1, 2])          # False，不同对象

# 元组可以比较（逐元素比）
print((1, 2) < (1, 3))           # True

示例 6：== 与 is 的区别

Python# eq_vs_is.py —— 什么时候用 ==，什么时候用 is

# == 比较内容
print("hello" == "hello")        # True
print(1000 == 1000)              # True

# is 比较对象身份
first = "hello"
second = "he" + "llo"
print(first == second)           # True  内容一样
print(first is second)           # False 可能是不同的两个对象

# 小整数是"缓存"的，恰好会命中同一个对象
a = 1000
b = 1000
print(a is b)                    # False 大整数不共享
c = 100
d = 100 + 0
print(c is d)                    # True  小整数被 Python 缓存了

# 唯一必须用 is 的场景：判断 None
value = None
if value is None:
    print("value 是 None")
if value is not None:
    print("这句不会执行")

# 结论：
# 比较内容   -> 用 ==
# 判断空值   -> 用 is None / is not None

示例 7：条件表达式与嵌套

Python# conditional_expression.py —— 一行写完 if/else

age = 20
score = 85

# 传统写法：4 行
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 条件表达式：1 行
status = "成年" if age >= 18 else "未成年"
print("状态：", status)

# 更有用的例子：给变量找默认值
input_name = ""# 用户没填
display = input_name if input_name else "游客"# 空就用默认值
print("显示名：", display)

# 嵌套一层还能读（不推荐，但要能看懂）
level = "高" if score >= 90 else "中" if score >= 60 else "低"
print(f"{score} 分，水平：{level}")     # 85 分，水平：中

# 嵌套两层就别再压缩了，拆开写
if score >= 90:
    level = "优秀"
elif score >= 80:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"
print(f"{score} 分，等级：{level}")     # 85 分，等级：良好
# 原则：可读性优先于行数，超过一层嵌套就该用 elif 链

示例 8：用 if 处理列表——判断"空"、判断"在不在"、按条件筛选

教材 5.4 讲的是「if 语句和列表一起用」。三个最常见的场景，都是初学者容易写复杂的地方：

Python# list_if.py —— if 与列表的三个组合
requested = ["蘑菇", "芝士", "榴莲"]
available = ["蘑菇", "芝士", "青椒"]

# ① 在不在名单里
for topping in requested:
    if topping in available:
        print(f"加 {topping}")
    else:
        print(f"没有 {topping}，这道跳过")

# ② 列表是不是空的：空列表直接当条件用
orders = []
if orders:
    print("有订单要处理")
else:
    print("购物车是空的")

# ③ 按多个条件筛选
nums = [12, 5, 30, 7, 18, 42]
big_even = [n for n in nums if n >= 10 and n % 2 == 0]
print("大于等于 10 的偶数", big_even)

运行结果：

示例加 蘑菇
加 芝士
没有 榴莲，这道跳过
购物车是空的
大于等于 10 的偶数 [12, 30, 18, 42]

三点解释：

  1. if orders: 就是「列表非空」，等价于 if len(orders) > 0:，但更短更快。空列表、空字符串、空字典、0、None 都是「假」，这是 Python 的统一约定。
  2. in 判断的是"值"不是"下标"，字符串比较区分大小写："蘑菇" in available 为真，"蘑菇 "（多一个空格）为假。用户输入要先 strip()。
  3. 筛选优先用推导式，for + if + append 三行能压成一行。但条件超过两个、或者里面还要做计算时，写回 for 循环反而更好读——可读性优先于短。
