七、本单元验收自测（综合 10 题）

1. lst = [1,2,3,4,5]，lst[1:4] 和 lst[1:4:2] 分别是什么？

要点：lst[1:4] = [2, 3, 4]（含索引 1 不含 4）；lst[1:4:2] = [2, 4]（每 2 个取一个）。

2. def f(a, b=[]): b.append(a); return b，连续调 f(1)、f(2)、f(3) 分别返回什么？

要点：[1]、[1, 2]、[1, 2, 3]。因为默认参数 [] 在函数定义时只求值一次，被所有调用共享。这是最隐蔽的 bug 之一。

3. 下面代码输出什么？

Pythondef modify(lst):
    lst = lst[:]
    lst.append(4)

data = [1, 2, 3]
modify(data)
print(data)

要点：[1, 2, 3]。函数内先造了副本（lst = lst[:]），后面的 append 只改了副本，外部的 data 不受影响。这是防止"函数修改原列表"的标准手法。

4. class A: def __init__(self): self.x = 1 换成多行写法时，最容易漏掉什么？

要点：漏掉冒号 : 和缩进。正确写法是：

Pythonclass A:
    def __init__(self):
        self.x = 1

class 体是 4 空格缩进，方法 def 同为 4 空格，方法体为 8 空格。

5. 子类的 __init__ 里不写 super().__init__()，父类设置的属性会怎样？

要点：父类的 __init__ 根本不会执行，它设置的属性（如 self.name）在对象上根本不存在，访问时抛 AttributeError: 'Child' object has no attribute 'name'。

6. 用 open("f.txt", "w") 打开一个已有文件然后写一行，会发生什么？

要点：文件被清空，原内容全部丢失。"w" 是"清空后重写"。想追加必须用 "a"。这是最容易造成数据丢失的操作。

7. 为什么不能写 except: ？

要点：它会捕获一切，包括 KeyboardInterrupt（导致 Ctrl+C 失效）和 SystemExit，还会静默吞掉真正的代码 bug。应明确写出异常类型，如 except ValueError:。

8. 下面这个 pytest 测试为什么不会被执行？

Pythondef check_add():
    assert 1 + 1 == 2

要点：函数名不以 test_ 开头。pytest 靠命名约定发现测试，命名不对会显示 collected 0 items——不报错，但什么都不跑。

9. 判断下面每个 self.count = self.count + 1 的执行结果，如果原代码是 count = self.count + 1 会怎样？

要点：原写法（漏 self.）只创建了一个局部变量，函数结束就消失，self.count 永远是 0。这是最常见的类编写错误之一。

10. 下面哪一句最能解释「函数传列表会改到原列表、传整数不会」？

A. 因为 Python 不复制参数 B. 因为列表是引用类型，修改它就是修改原对象；整数赋值只是让局部名字指向了新对象 要点：B 更准确。A 是对的但不完整——真正的原因是：Python 传递的是"指向对象的引用"。列表这个对象可变，改它的内容 = 改原件；整数不可变，n = n + 1 只是让局部变量 n 指向了一个新的整数对象，原来的整数完全没动。
