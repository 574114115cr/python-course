功能需求： 1. 添加任务（标题 + 优先级：高/中/低） 2. 标记完成 / 取消完成 3. 删除任务 4. 按优先级列出任务（高在前） 5. 统计（总数/已完成/待办/各优先级数量） 6. 数据保存到 todos.json，程序重启后数据仍在

技术要求： - 用 Task 类 + TodoManager 类 - 用 try/except 处理用户输入错误 - 文件读写全部用 with + try/except - 提供菜单式交互循环

加分项： - 支持按关键字搜索任务 - 支持导出为 CSV - 用 pytest 写 5 个以上测试

练习 11-3【综合项目 2：成绩管理分析器】 实现一个分析考试成绩数据的命令行工具。

功能需求： 1. 从 scores.json 读取数据（文件格式：[{"name": "小明", "math": 92, "english": 88}, ...]） 2. 显示全班各科平均分、最高分、最低分 3. 显示总分排名榜 4. 显示单科第一名 5. 找出需要补考的学生（某科 < 60） 6. 把分析结果导出为 report.csv 7. 文件不存在或数据损坏时给出友好提示，而不是崩溃

技术要求： - 分析逻辑写成纯函数（接收数据返回结果，不做 I/O），这样最容易写测试 - 用 try/except 处理文件错误和数字转换错误 - 用 pytest 写至少 6 个测试，覆盖正常、边界、空数据

练习 11-4【综合项目 3：文本统计工具】 实现一个分析文本文件的工具。

功能需求： 1. 读取 .txt 文件（指定路径或命令行参数） 2. 统计：总字符数、单词数、行数、句子数 3. 词频统计，输出 Top 10 高频词 4. 过滤停用词（的、了、是、在、和...） 5. 把统计结果保存为 JSON 6. 支持一次分析多个文件

五、参考答案

参考答案 11-1（知识自查答案）

考点 答案
索引 lst[-1] 是最后一个元素。因为负索引从末尾往回数，lst[len(lst)] 会越界（合法下标只到 len(lst)-1）
切片 [1:4] 长度是 3。因为左闭右开，长度 = stop - start = 4 - 1 = 3
短路求值 and 从左往右求值。if x and x[0]==1 先判断 x 是否为空列表（空列表为假直接短路），安全；反过来的写法会先访问 x[0]，空列表立刻 IndexError
副本语义 会改到。列表是可变对象，Python 传参传的是地址，函数内的 append 修改的就是原列表。整数/字符串这类不可变类型则不会
默认参数 因为默认参数在函数定义时只求值一次，那个列表被所有调用共享，会导致第二次调用出现第一次的数据。要用 todo=None 再在函数内 if todo is None: todo = []
self 因为调用对象方法时（如 obj.method()），Python 会自动把 obj 作为第一个参数传入。不写 self 就会参数数量不匹配，或函数内访问 self.xxx 时报 NameError
继承 父类的 __init__ 不会自动执行。不调用的话父类设置的属性（如 self.name）永远不存在，访问时会报 AttributeError
is None 因为 None 是唯一的单例对象，is 判断的是身份，语义准确且快。而 == 比较内容，如果某个类重写了 __eq__ 允许自己等于 None，那 == None 就会意外成立
w 模式 会清空原文件的所有内容，然后从零开始写。如果本意是"追加"，就会无声地丢失所有旧数据。要追加必须用 a
with ① 自动关闭文件，且即使块内抛异常也保证关闭（防文件句柄泄漏）；② 出块后 f 变量本身失效，强制你把内容存到别的变量，养成好习惯
except 裸 except: 会捕获一切，包括 KeyboardInterrupt（导致 Ctrl+C 失效）和 SystemExit，还会静默吞掉真正的代码 bug（NameError、TypeError），让问题在别处才暴露，排查成本极高
pytest 文件必须是 test_*.py，函数必须是 test_*，测试类是 Test* 且不能有 __init__。命名错了 pytest 显示 collected 0 items，不报错但完全不执行
PEP 8 一行不超过 79 字符（现代代码库放宽到 99）；缩进统一 4 个空格，绝不混用 Tab；运算符两侧加空格，逗号后加一个空格

参考答案 11-2（综合项目 1：待办管理器完整实现）

Python# todo_manager.py —— 综合项目 1：命令行待办事项管理器

import json
import os
import csv

TODO_FILE = "todos.json"
PRIORITY_ORDER = {"高": 0, "中": 1, "低": 2}
STOP_WORDS = set()


class Task:
    """一个待办任务。"""
    def __init__(self, title, priority="中", done=False, created_at=None):
        if priority not in PRIORITY_ORDER:
            raise ValueError("优先级必须是高、中、低之一")
        self.title = title
        self.priority = priority
        self.done = done
        self.created_at = created_at or self._now()

    @staticmethod
    def _now():
        from datetime import datetime
        return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    def complete(self):
        """标记完成，返回自身支持链式调用。"""
        self.done = True
        return self

    def undo(self):
        """取消完成。"""
        self.done = False
        return self

    def toggle(self):
        """切换完成状态。"""
        self.done = not self.done
        return self

    def matches(self, keyword):
        """是否包含关键字（不区分大小写）。"""
        return keyword.lower() in self.title.lower()

    def to_dict(self):
        return {
            "title": self.title,
            "priority": self.priority,
            "done": self.done,
            "created_at": self.created_at,
        }

    @classmethod
    def from_dict(cls, data):
        return cls(
            title=data["title"],
            priority=data.get("priority", "中"),
            done=data.get("done", False),
            created_at=data.get("created_at"),
        )

    def __str__(self):
        mark = "✓" if self.done else "○"
        return f"{mark} [{self.priority}] {self.title}"


class TodoManager:
    """待办管理器：负责所有业务逻辑与数据持久化。"""

    def __init__(self, filename=TODO_FILE):
        self.filename = filename
        self.tasks = []
        self.load()

    # ===== 持久化 =====
    def load(self):
        """从文件加载，失败时降级为空列表。"""
        try:
            with open(self.filename, "r", encoding="utf-8") as f:
                data = json.load(f)
            self.tasks = [Task.from_dict(item) for item in data]
            print(f"已从 {self.filename} 加载 {len(self.tasks)} 个任务")
        except FileNotFoundError:
            self.tasks = []
            print(f"{self.filename} 不存在，从空列表开始")
        except json.JSONDecodeError:
            self.tasks = []
            print(f"{self.filename} 内容损坏，已重置为空列表")
        except Exception as error:
            self.tasks = []
            print(f"加载失败：{error}")

    def save(self):
        """保存到文件。"""
        try:
            data = [task.to_dict() for task in self.tasks]
            with open(self.filename, "w", encoding="utf-8") as f:
                json.dump(data, f, ensure_ascii=False, indent=2)
            print(f"已保存到 {self.filename}")
        except Exception as error:
            print(f"保存失败：{error}")

    # ===== 增删改查 =====
    def add(self, title, priority="中"):
        """添加任务，标题重复时返回 False。"""
        title = title.strip()
        if not title:
            print("标题不能为空")
            return False
        if any(task.title == title for task in self.tasks):
            print(f"任务 '{title}' 已存在")
            return False
        try:
            self.tasks.append(Task(title, priority))
            print(f"已添加：{self.tasks[-1]}")
            return True
        except ValueError as error:
            print(f"添加失败：{error}")
            return False

    def find(self, title):
        """按标题找任务，找不到返回 None。"""
        for task in self.tasks:
            if task.title == title:
                return task
        return None

    def toggle(self, title):
        task = self.find(title)
        if task is None:
            print(f"未找到任务：{title}")
            return False
        task.toggle()
        status = "已完成" if task.done else "已取消完成"
        print(f"'{title}' 已标记为{status}")
        return True

    def delete(self, title):
        original = len(self.tasks)
        self.tasks = [t for t in self.tasks if t.title != title]
        if len(self.tasks) < original:
            print(f"已删除：{title}")
            return True
        print(f"未找到任务：{title}")
        return False

    # ===== 查询与统计（纯函数，不做 I/O）=====
    def list_all(self, show_done=True):
        """按优先级列出任务。"""
        visible = [t for t in self.tasks if show_done or not t.done]
        visible.sort(key=lambda t: (PRIORITY_ORDER[t.priority], t.created_at))
        if not visible:
            print("  （没有任务）")
            return []
        print(f"  共 {len(visible)} 个任务：")
        for task in visible:
            print(f"    {task}")
        return visible

    def search(self, keyword):
        """按关键字搜索。"""
        found = [t for t in self.tasks if t.matches(keyword)]
        if not found:
            print(f"  没有包含 '{keyword}' 的任务")
            return []
        print(f"  找到 {len(found)} 个任务：")
        for task in found:
            print(f"    {task}")
        return found

    def statistics(self):
        """统计信息。"""
        total = len(self.tasks)
        done = len([t for t in self.tasks if t.done])
        by_priority = {}
        for priority in PRIORITY_ORDER:
            count = len([t for t in self.tasks if t.priority == priority])
            by_priority[priority] = count
        return {
            "总数": total,
            "已完成": done,
            "待办": total - done,
            "高优先级": by_priority["高"],
            "中优先级": by_priority["中"],
            "低优先级": by_priority["低"],
            "完成率": f"{done / total * 100:.1f}%" if total else "0.0%",
        }

    def export_csv(self, filename="todos.csv"):
        """导出为 CSV。"""
        try:
            with open(filename, "w", newline="", encoding="utf-8-sig") as f:
                writer = csv.writer(f)
                writer.writerow(["标题", "优先级", "状态", "创建时间"])
                for task in self.tasks:
                    writer.writerow([
                        task.title,
                        task.priority,
                        "已完成" if task.done else "待办",
                        task.created_at,
                    ])
            print(f"已导出到 {filename}")
            return True
        except Exception as error:
            print(f"导出失败：{error}")
            return False


# ===== 用户交互 =====
MENU = """
========== 待办事项管理器 ==========
1. 添加任务
2. 列出任务
3. 标记完成/取消
4. 删除任务
5. 搜索任务
6. 统计信息
7. 导出 CSV
0. 保存并退出
===================================
"""


def main():
    manager = TodoManager()

    while True:
        print(MENU)
        choice = input("请选择操作：").strip()

        try:
            if choice == "1":
                title = input("任务标题：")
                priority = input("优先级（高/中/低，直接回车为中）：").strip() or "中"
                manager.add(title, priority)
            elif choice == "2":
                show_done = input("显示已完成任务吗？(y/n)：").lower() != "n"
                manager.list_all(show_done)
            elif choice == "3":
                title = input("要切换的任务标题：")
                manager.toggle(title)
            elif choice == "4":
                title = input("要删除的任务标题：")
                confirm = input(f"确定删除 '{title}' 吗？(y/n)：").lower()
                if confirm == "y":
                    manager.delete(title)
            elif choice == "5":
                keyword = input("搜索关键字：")
                manager.search(keyword)
            elif choice == "6":
                print("\n--- 统计信息 ---")
                for key, value in manager.statistics().items():
                    print(f"  {key}: {value}")
            elif choice == "7":
                manager.export_csv()
            elif choice == "0":
                manager.save()
                print("再见！")
                break
            else:
                print("无效选项，请重新输入")

        except KeyboardInterrupt:
            # 不该被裸 except 吞掉
            print("\n检测到 Ctrl+C，正在保存并退出...")
            manager.save()
            break
        except Exception as error:
            # 兜底：保证任何意外都不会让程序崩溃
            print(f"发生未预期的错误：{error}")

    # 清理
    if os.path.exists(TODO_FILE):
        os.remove(TODO_FILE)


if __name__ == "__main__":
    main()
