四、动手练习

全部题目都可以保存成 .py 文件直接运行。标注 🌐 的题目需要你手动在终端输入内容（input()）。

基础档

在终端里执行 python --version，把输出的一整行文字原样抄下来。然后执行 python -c "print('命令行直接执行')"，把输出抄下来。

练习 0-4【类型辨认】
写 types.py，创建 5 个变量，让它们分别是 int、float、str、str、bool 类型，然后用 for 之前还不存在的知识——直接写 5 行 print(type(变量名), 变量名) 把类型和值都打出来。不允许使用 for 循环（那是单元 3 的内容）。

五、参考答案

参考答案 0-1

终端里的输出随安装版本不同而不同，关键是确认版本号 ≥ 3.12，形如：

示例$ python --version
Python 3.12.4

$ python -c "print('命令行直接执行')"
命令行直接执行

-c 的意思是 command：把后面引号里的那一段直接当作程序执行，不写文件、不留 .py。 它最适合「只验证一句话」的场景——比如确认装对了、确认某个库能导入：

示例$ python -c "import sys; print(sys.version_info[:2])"
(3, 12)

三条自查： - 如果是 Python 3.11.x 或更低 → 本课程要求 3.12+（removeprefix、更好的错误信息都用得上），先升级。 - 如果报 'python' 不是内部或外部命令 → 装的时候没勾「Add Python to PATH」，重装或手动加环境变量。 - 如果输出的是 Python 2.7 → 你机器上有两套 Python，用 python3 --version 确认，后面统一用 python3。

参考答案 0-3（两种写法）

Python# intro.py —— 用 f-string 输出自我介绍

name = "小明"
age = 18
height = 1.75
hobby = "篮球"

# 写法一：f-string（推荐，格式最自由）
print(f"我叫{name}，今年 {age} 岁，身高 {height} 米，我喜欢{hobby}。")

Python# 写法二：不用 f-string，用逗号分隔（数字前后会自动加空格）
print("我叫", name, "，今年", age, "岁，身高", height, "米，我喜欢", hobby, "。")

参考答案 0-5

Python# ask_name.py —— 第一个交互程序

# input() 会暂停等待用户键盘输入，拿回来的结果永远是 str
name = input("请输入你的名字：")
age = int(input("请输入你的年龄："))   # 用 int() 把字符串转成整数

# 加 1 得到明年的年龄
next_age = age + 1

# 用 f-string 把变量嵌进句子里
print(f"你叫 {name}，你今年 {age} 岁，明年就 {next_age} 岁了。")

如果用户输入的是 abc，int("abc") 会报 ValueError，这是正常的，单元 9 会教你怎么处理它。

Python# fix_me.py —— 修复后的正确版本

参考答案 0-8（命令序列说明）

终端命令# === Git 首次提交完整流程（Windows PowerShell / Git Bash 通用）===

# 1. 创建并进入项目目录
mkdir my_first_project
cd my_first_project

# 2. 把练习代码存进来（这里假设你已经保存了 hello.py）

# 3. 初始化仓库 —— 这一步让 Git 开始记录这个文件夹
git init

# 4. 查看状态 —— 确认哪些文件被识别到了
git status

# 5. 把文件放进暂存区 —— "挑出来准备存档"
git add hello.py

# 6. 提交 —— 盖章存档，-m 后面是这次改动的说明
git commit -m "第一个提交：hello 世界"

# 7. 查看历史 —— 确认存档成功
git log

如果第 6 步报 Please tell me who you are，说明 Git 不知道你是谁，需要先设置一次身份（这只会做一次）：

终端命令git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
