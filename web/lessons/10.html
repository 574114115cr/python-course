  1. 画一个列表并标出每个元素的下标
  2. 用负索引取最后三个元素

一、学习目标

完成本单元后，你应该能够：

  1. 用方括号创建一个列表，并说清列表与"变量"在本质上的区别（一个名字装多个值）。
  2. 解释「索引从 0 开始」，能正确写出任意位置的正索引与负索引，并说明越界报什么错。
  3. 用 len() 求长度，用索引做读取和赋值两种操作。
  4. 熟练使用 .append()、.insert()、.remove()、.pop()、del 五种增删改方法，并说清 .pop() 的返回值可以被使用。
  5. 理解列表是可变对象，理解"引用共享"现象——两个变量指向同一个列表时，改一个另一个也会变。
  6. 分清 b = a、a[:]、a.copy() 三种写法，能解释浅复制为什么改不动数字却改得动子列表。

二、核心知识点讲解

2.1 列表：一个名字，一排抽屉

到目前为止，变量只能装一个值。但现实中数据总是成组的：一串商品名、一堆分数、一串待办事项。

如果用变量硬撑，需要这样：

Pythoncar1 = "小红帽"
car2 = "二手柯尼塞格"
car3 = "凯迪拉克"

三个变量名，且加新的一辆车要改所有相关代码。列表的解法是：

Pythoncars = ["小红帽", "二手柯尼塞格", "凯迪拉克"]

生活化类比：变量像单个盒子，列表像一整排带编号的抽屉柜。cars 是柜子的名字，抽屉编号就是索引，你按编号取放东西。

2.2 索引从 0 开始：为什么不是从 1 开始

这是一个"计算机思维 vs 日常思维"的经典冲突。你在数抽屉时会说"第一个、第二个"，但 Python 从 0 开始数。

目录结构索引:      0        1                2
      ┌────────┬─────────────────┬──────────────┐
      │ 小红帽 │ 二手柯尼塞格│ 凯迪拉克      │
      └────────┴─────────────────┴──────────────┘
正索引:     第1个     第2 个             第3 个

生活化类比更准确的说法是：索引表示"从门口数起走几步"。站在门口（第 0 步）一步不用走就是第一个抽屉，往左走一步（1 步）是第二个。数组在内存里就是这样寻址的——第一个元素的地址就是起始地址，不需要"再加 1"。

负索引是 Python 的贴心设计：cars[-1] 表示最后一个，cars[-2] 表示倒数第二个。这样你不必先算长度就能从末尾取数据。

Pythoncars = ["小红帽", "二手柯尼塞格", "凯迪拉克"]
print(cars[0])     # 小红帽   （第一个）
print(cars[1])     # 二手柯尼塞格（第二个）
print(cars[-1])    # 凯迪拉克   （最后一个）
print(cars[-3])    # 小红帽     （第一个）

越界会报 IndexError：cars[3] 或 cars[-4] 都会崩。

2.3 列表是可变的：能直接改

字符串是"打印好的纸条"（不可变），而列表是"活页笔记本"（可变）——你可以撕下第 2 页换一张新的，顺序和数量都不变。

Pythoncars[0] = "特斯拉"
print(cars)   # ['特斯拉', '二手柯尼塞格', '凯迪拉克']

注意这个和字符串方法的区别：

Pythonname = "tom"
name.upper()   # 只是复印了一份大写，name 不变

cars = ["a", "b"]
cars[0] = "z"  # 直接改了原列表本身

列表元素可以是任意类型，包括另一个列表（叫嵌套列表）：

Pythonmatrix = [[1, 2], [3, 4]]   # 两个列表组成的列表
