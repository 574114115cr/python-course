2.3 datetime：把字符串变成日期 ★

这是本章最实用的新技能。CSV 里读出来的 "2021-07-01" 是字符串：没法做日期运算，matplotlib 也会把它当成普通文字，x 轴上 365 个标签挤成一团黑条。

datetime.strptime() 负责「解析」——把符合某个格式的字符串转成日期对象：

Pythonfrom datetime import datetime

first_date = datetime.strptime("2021-07-01", "%Y-%m-%d")
print(first_date)               # 2021-07-01 00:00:00

第二个参数是格式说明书。最常用的格式码：

格式码 含义 例子
%Y 四位年份 2021
%m 两位月份 07
%d 两位日期 01
%H 小时（24 小时制） 14
%M 分钟 30
%S 秒 05
%B 月份全称 July
%A 星期全称 Thursday

记忆口诀：p 是 parse（解析），字符串 → 日期对象；反过来 f 是 format（格式），日期对象 → 字符串：

Pythonfrom datetime import datetime

moment = datetime.strptime("2021-07-01 14:30", "%Y-%m-%d %H:%M")
print(moment.strftime("%Y年%m月%d日 %H:%M"))    # 2021年07月01日 14:30

这里难在哪？格式码必须和字符串严格对应。字符串里是连字符，格式码里也要有；字符串是 2021/07/01 而格式码写 %Y-%m-%d，就会抛 ValueError。卡住很正常——把字符串和格式码并排盯着看，一个字符一个字符对。

好消息是：matplotlib 认识日期对象。x 轴传日期对象进去，它会自动按月份、季度分布刻度，横轴立刻清爽——这就是「在图中添加日期」一节的全部秘密。

2.4 缺失值：真实数据的第一课

死亡谷的数据里有几天没测最高温，CSV 里对应字段是空的。int("") 会抛 ValueError，不处理程序直接崩。教材的处理模式值得逐行读懂（下面用 rows 模拟从 CSV 读出来的数据行）：

Pythonfrom datetime import datetime

rows = [
    ["USC00042319", "DEATH VALLEY, CA US", "2021-01-01", "71", "51"],
    ["USC00042319", "DEATH VALLEY, CA US", "2021-03-05", "", ""],   # 这天缺数据
]

dates, highs, lows = [], [], []
for row in rows:
    current_date = datetime.strptime(row[2], "%Y-%m-%d")
    try:
        high = int(row[3])
        low = int(row[4])
    except ValueError:
        print(f"Missing data for {current_date}")
    else:
        dates.append(current_date)
        highs.append(high)
        lows.append(low)

print(dates, highs, lows)

三个要点：

  1. try 只包住可能出错的两行转换——strptime 放在外面，日期格式是稳定的，真正的风险是空值。
  2. else 是灵魂：转换成功才把三个值分别 append。如果写在 try 里面，某天只有 TMAX 缺失时三个列表就可能错位——不等长，画图时直接报错。
  3. 警告要打印出来：print(f"Missing data for {current_date}") 让你知道「图上的缺口是数据缺失，不是代码 bug」。静默跳过的数据是不可信的。

类比：try/except 在这里是筛子——烂叶子（空值）漏出去，好菜进篮子。但筛子要留记录，否则你不知道漏掉了多少。

2.5 画温度图：plot + fill_between

数据洗干净了，画图只要几行（下面用内联小数据演示，真实项目里三个列表从 CSV 读出来）：

Pythonimport matplotlib.pyplot as plt
from datetime import datetime, timedelta

dates = [datetime(2021, 7, 1) + timedelta(days=i) for i in range(10)]
highs = [20, 21, 19, 22, 23, 21, 20, 19, 18, 20]
lows = [h - 7 for h in highs]

plt.style.use("seaborn-v0_8")       # 好看的内置样式（版本说明见下）
fig, ax = plt.subplots()
ax.plot(dates, highs, c="red", alpha=0.5)
ax.plot(dates, lows, c="blue", alpha=0.5)
ax.fill_between(dates, highs, lows, facecolor="blue", alpha=0.1)
fig.autofmt_xdate()                 # 日期标签自动倾斜，防止重叠
plt.savefig("演示温度图.png", dpi=120, bbox_inches="tight")
  • alpha 是透明度（0 全透明 ~ 1 全不透明）。两条线都半透明，重叠处颜色更深，信息不互相遮挡。
  • fill_between 把两条线之间的区域涂上颜色——温度区间带。一眼看出「这天的温差大不大」，比两根孤零零的线信息量大得多。
  • fig.autofmt_xdate() 让日期标签斜着排，365 天也不糊成一团。

绘图库的安装（本单元和下一单元都要用）：

终端命令# 安装绘图库（只需装一次）
pip install matplotlib plotly

版本说明（教材未涉及，补充）：plt.style.use("seaborn-v0_8") 的样式名带 -v0_8 后缀，是 matplotlib 0.13 之后的写法；老教程写 "seaborn"，新版会报 ValueError。样式只是皮肤，删掉这行完全不影响绘图。

教材里用 plt.show() 弹窗显示图形。本讲义的示例统一用 plt.savefig("文件名.png") 把图存成文件——服务器、远程环境、没有图形界面的地方也能跑，而且图能反复看、能贴进笔记。两者画出来的图完全一样。
