一、学习目标

完成本单元后，你应该能够：

  1. 用 if 写单分支条件，并说清「条件为真时执行、为假时跳过」的运行逻辑。
  2. 熟练使用 if / elif / else 三分支结构，并解释为什么 elif 链中顺序很重要。
  3. 掌握 6 个比较运算符和 3 个逻辑运算符，能正确写出包含多个条件的判断。
  4. 解释「短路求值」现象，能举出一个靠它避免崩溃的真实例子。
  5. 用条件表达式把 5 行 if/else 压缩成 1 行，并知道什么场景下不该压缩。
  6. 把 if 和列表一起用：用 if 列表: 判空、用 in 判成员、用推导式按条件筛选。

二、核心知识点讲解

2.1 条件测试：一个只能回答是/否的问题

条件测试就是一个布尔表达式：求值结果不是 True 就是 False。

Pythonage = 18
print(age == 18)     # True
print(age >= 18)      # True
print(age < 18)       # False

生活化类比：条件测试像门禁核验——刷卡机不问你是谁、你想干什么，只问"你是否有权限"，答案只有"放行"或"拒绝"两个。

最常见的语法错误：把 == 写成 =。

Pythonage = 18
# if age = 18:      # SyntaxError：= 是赋值，条件必须用 ==
if age == 18:      # 正确
    print("成年了")

记忆方法：= 是"把右边交给左边"，== 是"左右两边一样吗"。

2.2 六个比较运算符

运算符 含义 记忆口诀
== 等于 一一对应
!= 不等于 ! 就是"否定"
> / < 大于 / 小于
>= / <= 大于等于 / 小于等于 = 是"可以等于"

初学者最容易在数学思维里写出 = 表示"等于"、<= 表示"小于等于"，但 Python 里 <= 只能是"小于等于"，"不等于"必须写 !=。

字符串也能比较：Python 按字符编码逐个比较，所以可以按字母排序：

Pythonprint("apple" < "banana")    # True
print("Zoo" < "apple")       # True，因为大写 Z 的编码比小写 a 小
