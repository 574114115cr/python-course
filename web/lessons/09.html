六、本单元验收自测

1. 判断题：name = "Alice" 然后 print(name.upper()) 之后，name 的值变成了 "ALICE"。

要点：错误。name 仍是 "Alice"。字符串不可变，.upper() 返回一个新字符串，必须写 name = name.upper() 才能把新值存回变量。

2. 简答题：int("3.9") 会返回什么？为什么不能直接转？

要点：会报 ValueError。因为把字符串转成 int 要求这个字符串整体是一个合法整数，而 "3.9" 带小数点，不满足要求。正确做法是分两步：int(float("3.9")) 得 3。

3. 判断题：bool("False") 的结果是 False。

要点：错误，结果是 True。Python 只看"是否为空"，"False" 是一个非空字符串（里面恰好有 5 个字母），所以为真。Python 不解析字符串内容。

4. 简答题：下面代码输出什么？

Pythonx = 5
x = str(x)
x = x + "5"
print(x * 2)

要点：输出 5555。逐步跟踪：第 2 行 x 变成字符串 "5"；第 3 行 x + "5" 是字符串拼接，得 "55"；第 4 行 "55" * 2 是字符串重复，得 "5555"。同一个运算符 + 和 *，对字符串和对数字的含义完全不同——这正是"Python 根据类型决定行为"的体现。

5. 简答题：说出下面三种变量名为什么非法（各写一句理由）。 2nd_place、my name、class

要点：2nd_place 以数字开头（语法层面名称必须以字母或下划线开头）；my name 中间有空格（名称是一个整体，不能拆开）；class 是 Python 关键字，已被语言本身占用（正确写法 class_name = "三班"）。

七、常见错误清单（务必逐条自查）

错误 1：SyntaxError: unterminated string literal

症状：字符串那行报「未闭合」。 原因：引号不成对——常见是中文引号 “”，或字符串里本身有引号没转义。 改法：统一用英文 " '；字符串里要引号就用另一种，或 \"。

错误 2：int("3.9") 报 ValueError

症状：把用户输入转整数崩了。 原因：int() 只认整数字面量，"3.9" 是浮点写法。 改法：先 float("3.9") 再 int(...)（会截断成 3）；要四舍五入用 round()，别指望 int()。

错误 3：bool("0") 竟然是 True

症状：以为 "0" 是假值。 原因：bool() 对字符串只看「空不空」，非空字符串一律为真。 改法：要判断「是不是数字 0」得先转换：int(s) == 0；或用 s in ("0", "") 这类显式判断。

错误 4：if x = 1: 语法错误

症状：SyntaxError: invalid syntax 指向等号。 原因：= 是赋值，== 才是比较。 改法：条件里一律 ==；想同时赋值用海象运算符 if (n := len(s)) > 3:（3.8+）。

错误 5：变量名 class / 2myvar 报错

症状：SyntaxError 或变量莫名其妙是别的东西。 原因：class 是关键字；标识符不能以数字开头。 改法：避开 Python 关键字（import keyword; print(keyword.kwlist) 可查），名字用 my_var 这种下划线风格。
