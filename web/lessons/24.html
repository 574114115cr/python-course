◆ 复盘（10 分钟）｜上一节：第 23 节 · 字典：按名字找数据

  • 字典 = 键值对 {key: value}；列表按位置找，字典按名字找。
  • 取值用 d["键"]，键不存在会报 KeyError（这是和列表越界并列的常见崩法）。
  • 同一句赋值两种含义：键已存在是改，键不存在是加。
  • 键必须不可变——列表不能当键，元组和字符串可以。

  2. 故意用 [] 取不存在的键看 KeyError

2.4 三种遍历方式

Pythonuser = {"name": "小明", "age": 18, "city": "杭州"}

# 只看键
for key in user:              # 等价于 for key in user.keys():
    print(key)

# 只看值
for value in user.values():
    print(value)

# 键和值都要 —— 最常用
for key, value in user.items():
    print(f"{key}: {value}")

# 遍历字典默认只给键，这是最容易踩的坑
for item in user:
    print(item)      # 输出 "name"，不是 "name: 小明"

for key in dict 实际等于 for key in dict.keys()，因为 dict.keys() 返回的对象在遍历行为上等同于键本身（它是一个"视图对象"，会随字典变化而变化，这点比列表拷贝更安全）。

2.5 .get()：不 crash 的取值方式

故意写错 · 先跑一遍看报错scores = {"语文": 90, "数学": 85}

print(scores["语文"])# 90   安全
print(scores["英语"])          # KeyError: '英语'   崩了

# .get() 提供默认值，键不存在也不崩
print(scores.get("语文"))       # 90
print(scores.get("英语"))       # None（键不存在时返回 None）
print(scores.get("英语", 0))    # 0    第二个参数是默认值
这是故意写错的示例——先自己跑一遍看报错，再对照下面的解析弄清错在哪

生活化类比：scores["英语"] 像直接拉开一个可能不存在的抽屉（柜子会"咔哒"响一声表示没有）；.get("英语", 0) 像先问柜管理员"有没有英语这格？没有的话给我 0"。

.get() 还有一个更妙的地方：链式访问

Pythonusers = {"u1": {"name": "小明", "age": 18}}

# 传统写法：每一层都要判断是否存在，非常啰嗦
if "u1" in users:
    if "name" in users["u1"]:
        name = users["u1"]["name"]

# .get() 链式写法：简洁且永不崩溃
name = users.get("u1", {}).get("name", "未知")
#                        ↑键不存在时给一个空字典，后面的 .get() 就有东西可操作了

最后那个空字典 {} 是这个技巧的灵魂——它保证链条不会因为某层缺失而断掉。
