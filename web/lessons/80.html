◆ 复盘（10 分钟）｜上一节：第 79 节 · Matplotlib 入门与折线图

  • ax.scatter(x, y, s=, c=, alpha=) 画散点图：s 是点大小、c 是颜色、alpha 是透明度。
  • 不设 s 时所有点看起来一样大——因为默认是一个固定值，数据越大差异越看不出来。
  • range(num_points) 控制点数，random.choice() 造随机数；random.seed() 能让结果可复现。

2.3 折线图细节：线宽、标签、样式

参数 作用 例子
linewidth / lw 线条粗细（单位是「点」不是像素） lw=3
linestyle / ls 线型 "--" 虚线、":" 点线
color / c 颜色 c="red"、c="#1f77b4"
marker 数据点形状 marker="o"
alpha 透明度 0~1 alpha=0.5
label 图例用的名字 label="实际值"

内置样式一行换肤：先 print(plt.style.available) 看有哪些，再 plt.style.use("seaborn-v0_8")。

版本坑（教材未涉及，补充）：matplotlib 0.13 之后 seaborn 系列样式名都带版本后缀，要写 "seaborn-v0_8" 而不是 "seaborn"，否则抛 ValueError: style 'seaborn' is not in the list of available styles。而 "ggplot"、"bmh" 这些老名字仍然有效。样式只是皮肤，删掉不影响结果。

★ figsize 与 dpi：清晰度靠 dpi，物理尺寸靠 figsize（英寸）。想插一张不糊的图，两个一起加：subplots(figsize=(12, 8)) 配 savefig(..., dpi=200)。

2.4 散点图三件套：s=、c=、cmap=

折线图适合有先后顺序的数据，散点图适合两个量的关系。★ 三件套是三个独立通道：

示例散点图 = 点在哪（x, y）
       + 点多大（s=）      ← 第三个维度：数量级
       + 点什么色（c=）    ← 第四个维度：类别或数值
  • s=（size）控制面积，单位是「点」。教材里 s=x_values * 2 就是为了看得清。
  • c=（color）可以传颜色名字（分类），也可以传数值（必须配 cmap=）。
  • cmap=（color map）规定「数值怎么翻译成颜色」，最常用 plt.cm.Blues——值小则浅，值大则深。

「绘制一系列点」就是把两组数据画在同一张 ax 上（见示例 2），两种颜色叠着，一眼看出「谁增长得快」。

传颜色名字和传数值是两套机制：前者是「每点自己指定颜色」，后者是「让 matplotlib 按数值自动上色，并自动多一条颜色条」。初学最容易混的就是这个——c 里传数字却不给 cmap，所有点会变成同一种默认颜色，不报错，但你以为的渐变根本没出现。
