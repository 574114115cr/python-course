一、学习目标

完成本单元后，你应该能够：

  1. 说出并正确使用四种基本数据类型 str / int / float / bool，能判断一个变量的类型。
  2. 独立写出符合 PEP 8 命名规范的变量名，能说出为什么不能用 2myvar、my var、class 这类名字。
  3. 熟练使用 str() int() float() bool() 完成类型转换，能解释 int("3.9") 报错的原因。
  4. 掌握字符串常用方法：.upper() .lower() .title() .strip() .len()，并说明它们不改变原字符串。
  5. 会用 split() / join() 在「一行文本」和「列表」之间来回转换，会用 removeprefix() 安全地去前缀。
  6. 用 f-string 拼接输出任意格式的句子，并用 # 写规范的注释。

二、核心知识点讲解

2.1 变量：一个贴了标签的盒子

变量不是"存储数据的空间"，更准确的说法是：一个指向某个数据的名字。

生活化类比：你有一支笔，笔身上贴了一张标签写着"会议记录"。变量 pen 就是那张标签，而笔（数据）是真实存在的东西。你可以换一支笔，只要把标签重新贴一下——这就是"重新赋值"：

Pythoncolor = "红"
color = "蓝"   # 换了一支笔，标签上现在写"蓝"

Python 的重要特点：先赋值，后使用。如果变量还没有被赋值就被使用，会报 NameError。这就像你还没买笔就想用"会议记录"这个标签去柜子里拿东西——柜子里空无一物。

2.2 命名规则：为什么 my-var 和 2var 不行

变量名只能包含三类字符：字母、数字、下划线，且不能以数字开头。除此之外还有一批 Python 关键字被系统保留了，不能用作变量名（if、for、while、class、def、import、True、False、None 等）。

PEP 8 是 Python 官方风格指南，对变量命名的核心建议是：全小写 + 多词用下划线分隔。 - 好：user_name、total_price、item2 - 差：UserName、userName、用户名

另外一条来自本书的实践建议：名字要够长、够具体。a、x、data、temp 这类短名字在一周后你自己都看不懂，而 current_user_score 一眼就懂。这项习惯对零基础学习者尤其重要。

2.3 字符串 str：带引号的文字

字符串必须被引号包起来，可以是单引号 'abc' 或双引号 "abc"。两者的区别在于当字符串本身含引号时：

Pythonmsg1 = "I'm happy"    # 双引号包住里面的单引号 → 合法
msg2 = 'He said "hi"' # 单引号包住里面的双引号 → 合法

不可变性是字符串最重要的性质：字符串一旦创建就不能原地修改。所有"看起来在改"的方法，实际上都是返回了一个新的字符串。

生活化类比：一张打印好的纸条。你不能把纸条上的字擦掉重写；但你可以复印一份，在复印件上改。.upper() 就是"复印一份并把字改成大写"。

Pythonname = "tom"
print(name.upper())   # 输出 TOM
print(name)           # 输出 tom —— 原纸条没变！

所以正确用法是接住返回值：

Pythonname = name.upper()   # 现在 name 才是 "TOM"
