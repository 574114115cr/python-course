2.6 建议的目录结构

从第一天起就养成"一个项目一个文件夹"的习惯，单元 10 开始你会立刻感谢自己：

目录结构my_project/
├── .gitignore
├── README.md
├── venv/              ← 虚拟环境（可随时删掉重建，不要手动改）
├── main.py            ← 主程序入口
├── data/
│   └── sample.txt     ← 数据文件放这里
└── tests/
    └── test_main.py   ← 测试代码放这里（单元 10 会用）

三、可运行代码示例

示例 1：第一个脚本

Python# hello.py —— 这是你的第一个 Python 程序
# 井号 # 开头的内容叫"注释"，Python 会忽略它，用给人看

print("Hello, Python!")   # print() 把括号里的内容显示到屏幕上
print("我是零基础学习者")   # 中文一样可以直接写
print(2 + 3)              # 表达式也可以直接交给 print，Python 会先算出 5

示例 2：先写后跑的顺序演示（体会"从上到下"）

Python# order_demo.py —— Python 严格从上往下逐行执行

print("第一步：准备开始")     # 第 1 行最先打印

name = "小明"                # 第 3 行：把"小明"这个名字存进变量 name
print("第二步：变量已赋值，name =", name)   # 第 4 行：这里才能用 name

print("第三步：程序结束")     # 最后一行

注意：如果把 print("第二步...", name) 挪到 name = "小明" 之前，程序就会报 NameError: name 'name' is not defined。

示例 3：用变量做一次简单计算

Python# calc_demo.py —— 认识变量赋值和基本运算

# 变量名 = 值，等号叫"赋值号"，把右边的东西交给左边的名字
price = 35.5        # 一个小数：单价 35.5 元
count = 3           # 一个整数：买了 3 个
total = price * count   # * 是乘法

print("单价：", price, "元")
print("数量：", count, "个")
print("总价：", total, "元")

# 变量可以被重新赋值，像一个可以反复贴标签的盒子
total = total - 5   # 抹掉零头，给 5 元优惠
print("优惠后总价：", total, "元")

示例 4：认识 print 的分隔符与注释

Python# print_demo.py —— print 的三个实用参数

# sep 指定"用什么把多个值隔开"
print("苹果", "香蕉", "橘子", sep="、")
# 输出：苹果、香蕉、橘子

# end 指定"这一行结束之后接什么"
print("正在加载", end="...")
print("完成")
# 输出：正在加载...完成（中间没有换行）

# 注释的三种写法
# 1）井号写在代码后面，前面要有两个空格才符合 PEP8
x = 1  # 这是行尾注释

# 2）单独成行的注释
# 这一整行都是说明文字

# 3）用三引号写"文档字符串"，常放在文件或函数开头
"""
这是模块级文档字符串。
说明这个文件是干什么的。
"""

示例 5：用 f-string 把变量嵌进文字里

Python# fstring_demo.py —— 格式化字符串，最常用的"拼句子"方式

name = "小红"
score = 92.567

# 普通做法：靠逗号隔开，输出会有多余空格
print("同学", name, "成绩", score)

# f-string 做法：大写 f 前缀，花括号里直接写变量名
print(f"同学{name}成绩{score}")

# 想控制小数位数，就在花括号里写 :.2f（保留两位小数）
print(f"同学{name}成绩{score:.2f}")

# 字符串里的对齐和补零也能做
num = 7
print(f"编号：{num:03d}")      # 03d 表示至少 3 位，不够前面补零 → 007
print(f"右对齐：{'hi':>8}|")     # >8 表示靠右，占 8 个字符宽度
print(f"左对齐：{'hi':<8}|")     # <8 表示靠左
print(f"居中对齐：{'hi':^8}|")  # ^8 表示居中

示例 6：初识类型与打印类型

Python# type_demo.py —— 认识 Python 的基本数据类型

age = 18# 整数 int
height = 1.75        # 小数 float
name = "小明"# 字符串 str
is_student = True    # 布尔值 bool（只有 True 和 False，首字母必须大写）

print(type(age), age)         # <class 'int'> 18
print(type(height), height)   # <class 'float'> 1.75
print(type(name), name)       # <class 'str'> 小明
print(type(is_student))       # <class 'bool'>

# type() 返回的是"类型"，数据才是真正存的东西
# 类比：type() 告诉你容器是什么，变量里装的是内容

# 下面这行少了一个右括号，是最常见的错误
print("这一行少括号"
# 正确写法应该是：print("这一行少括号")
这是故意写错的示例——先自己跑一遍看报错，再对照下面的解析弄清错在哪

运行结果：

报错信息  File "error_demo.py", line 6
    print("这一行少括号"
SyntaxError: '(' was never closed

对照看三行：line 6 告诉你第几行；^ 指向缺右括号的位置；SyntaxError 告诉你"语法不对，Python 连读都读不下去"。

◆ 讲评（20 分钟）｜对照检查你刚写的代码

  • 项目目录建对了吗？代码、数据、说明分开放了没有？
  • sep 和 end 各改一次，输出变化和你预测的一样吗？
  • f-string 里忘了写 f 会怎样？试一次，看它把 {} 当什么。
  • 注释是在解释「为什么」还是在重复代码在做什么？
