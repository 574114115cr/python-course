◆ 复盘（10 分钟）｜上一节：第 72 节 · 外星舰队与整体移动

  • _create_fleet() 把「造一行 → 造多行」封装起来，是第一次真正的函数化重构。
  • 整队移动靠 fleet_direction 标志位（1 向右、-1 向左），任何一只外星人触边就整队下移并取反方向。
  • 边缘检测用 >= / <= 而不是 ==：速度大于 1 时可能一步跨过精确坐标，== 会漏判，表现为「舰队飞出屏幕再也没回来」。

◆ 课堂实操（40 分钟，全程不许看答案）

  1. 实现击落与加分
  2. 把两个 True 改成 False，复现「外星人不消失」bug
  3. 故意撞自己一次，看游戏是否正确结束

2.7 碰撞检测与游戏结束（13.5–13.7）

（1）子弹打中外星人。 Pygame 把「两个编组互相检测碰撞」做成了一个函数：

Pythoncollisions = pygame.sprite.groupcollide(self.bullets, self.aliens, True, True)

四个参数的含义：

参数 值 含义
第 1 个 self.bullets 编组 A（子弹）
第 2 个 self.aliens 编组 B（外星人）
第 3 个 True 碰撞后删除子弹
第 4 个 True 碰撞后删除外星人

返回值是个字典：键是「撞到人的子弹」，值是「被这颗子弹撞到的外星人列表」。所以「这一帧击落几个」可以直接 len(collisions) 算出来。

击落全部外星人后要生成新舰队，顺便把残留子弹清掉：

Pythondef _check_bullet_alien_collisions(self):
    """响应子弹和外星人的碰撞。"""
    collisions = pygame.sprite.groupcollide(
        self.bullets, self.aliens, True, True)
    if not self.aliens:
        # 外星人死光了：清空子弹，再来一队
        self.bullets.empty()
        self._create_fleet()

（2）「为测试创建大子弹」的调试思维。 教材在这里专门讲了一个调试技巧：怀疑碰撞检测有 bug 时，临时把 bullet_width 从 3 改成 300——子弹粗到不可能打不中。如果这样能击落了，说明碰撞逻辑没问题，只是正常尺寸下命中率低；如果还不能击落，才说明真有 bug。把偶发问题变成必现问题，是调试的第一生产力。 验证完记得改回 3。

（3）外星人撞到飞船。 检测「一个精灵 vs 整个编组」用另一个函数：

Pythonif pygame.sprite.spritecollideany(self.ship, self.aliens):
    self._ship_hit()

spritecollideany() 只要有任意一个外星人碰到飞船就返回那个外星人（否则返回 None），用作条件判断正合适。注意它要求飞船也是精灵，所以 13.6 节要把 Ship 改成继承 Sprite 并调用 super().__init__()。

被撞之后不是「游戏结束」，而是「少一条命、重置局面」：

Pythondef _ship_hit(self):
    """响应飞船被外星人撞到。"""
    if self.stats.ships_left > 0:
        self.stats.ships_left -= 1        # 少一条命
        self.aliens.empty()               # 清空现存外星人
        self.bullets.empty()              # 清空现存子弹
        self._create_fleet()              # 重新放一队
        self.ship.center_ship()           # 飞船回底部中央
        sleep(0.5)                        # 暂停半秒，让玩家看清发生了什么
    else:
        self.stats.game_active = False    # 没命了，游戏结束

外星人碰到屏幕下边缘也算「被撞」，处理完全相同（_check_aliens_bottom()）——敌人突破防线，和你主动撞上去，后果一样。

（4）游戏状态。 到这里出现了第一个「不是屏幕上可见对象、却决定游戏怎么跑」的类：GameStats。它只存两样东西——还剩几条命（ships_left），以及游戏是否正在进行（game_active）。

Pythonclass GameStats:
    """跟踪游戏统计信息的类。"""

    def __init__(self, ai_game):
        self.settings = ai_game.settings
        self.reset_stats()
        self.game_active = True           # 游戏一开始是活动状态

    def reset_stats(self):
        """初始化在游戏运行期间可能变化的信息。"""
        self.ships_left = self.settings.ship_limit

（5）13.7 节：确定应运行游戏的哪些部分。 最后给主循环加一道闸门——游戏结束后，只画屏幕、收事件，不再更新任何游戏对象：

Pythondef run_game(self):
    """开始游戏的主循环。"""
    while True:
        self._check_events()
        if self.stats.game_active:
            self.ship.update()
            self._update_bullets()
            self._update_aliens()
        self._update_screen()
        self.clock.tick(60)

为什么_update_screen() 在闸门外面？因为游戏结束后画面要停在最后那一帧（残局），而不是黑屏或继续动。这种「用状态位控制每帧跑多少逻辑」的写法，是后面做「开始按钮」「暂停」的地基。

示例 2：group_demo.py——不打开窗口，把编组的核心行为演示一遍

这个示例把 Group 的添加、批量更新、批量绘制、两种碰撞检测、清空全部跑一遍，而且不需要显示器。

Python# group_demo.py —— 用 dummy 驱动演示 Group 的核心行为（无需真实显示器）
import os

os.environ["SDL_VIDEODRIVER"] = "dummy"

import pygame
from pygame.sprite import Group, Sprite, groupcollide, spritecollideany

pygame.init()
screen = pygame.display.set_mode((800, 600))


class Block(Sprite):
    """一个彩色小方块精灵：有 image（长相）和 rect（站位）。"""

    def __init__(self, color, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill(color)
        self.rect = self.image.get_rect(topleft=(x, y))
        self.vx = 0

    def update(self):
        """Group.update() 会自动调用每个成员的 update()。"""
        self.rect.x += self.vx

    def __repr__(self):
        return f"Block(x={self.rect.x}, y={self.rect.y})"


# 1）创建编组，放入 5 个精灵
blocks = Group()
for i in range(5):
    blocks.add(Block((200, 60, 60), 100 + i * 90, 100))
print("① 编组建好，成员数：", len(blocks))

# 2）批量更新：改一次速度，一次 update 全员生效
for block in blocks:
    block.vx = 10
blocks.update()
print("② update 后第一个方块的 x：", blocks.sprites()[0].rect.x)

# 3）批量绘制：把每个精灵的 image 画到屏幕上（dummy 下不可见但不报错）
blocks.draw(screen)
print("③ draw() 调用成功")

# 4）spritecollideany：单个精灵 vs 整个编组
runner = Block((60, 60, 200), 150, 100)
runner.vx = 20
for _ in range(10):
    runner.update()
    if spritecollideany(runner, blocks):
        break
print("④ spritecollideany 撞到了吗：", spritecollideany(runner, blocks) is not None)

# 5）groupcollide：两个编组互撞，两个 True 表示"碰撞后双方都消失"
enemies = Group()
for i in range(3):
    enemies.add(Block((60, 200, 60), 140 + i * 90, 100))
collisions = groupcollide(blocks, enemies, True, True)
print("⑤ groupcollide 撞掉了", len(collisions), "个；",
      "blocks 剩", len(blocks), "个，enemies 剩", len(enemies), "个")

# 6）empty()：一键清空
blocks.empty()
enemies.empty()
print("⑥ empty() 之后剩：", len(blocks), len(enemies))

运行结果：

示例① 编组建好，成员数： 5
② update 后第一个方块的 x： 110
③ draw() 调用成功
④ spritecollideany 撞到了吗： True

示例 3：bullet.py——子弹类（可直接运行自测）

Python# bullet.py —— 管理飞船发射的子弹的类
import os

os.environ["SDL_VIDEODRIVER"] = "dummy"   # 自测不需要真实显示器

import pygame
from pygame.sprite import Sprite


class Bullet(Sprite):
    """管理飞船发射的子弹的类。"""

    def __init__(self, ai_game):
        """在飞船的当前位置创建一颗子弹。"""
        super().__init__()
        self.screen = ai_game.screen
        self.settings = ai_game.settings
        self.color = self.settings.bullet_color

        # 先在 (0, 0) 处创建子弹矩形，再移动到飞船顶部
        self.rect = pygame.Rect(0, 0, self.settings.bullet_width,
                                self.settings.bullet_height)
        self.rect.midtop = ai_game.ship.rect.midtop

        # 用浮点数记录纵坐标（Rect 的 y 只能是整数）
        self.y = float(self.rect.y)

    def update(self):
        """向上移动子弹。"""
        self.y -= self.settings.bullet_speed
        self.rect.y = self.y

    def draw_bullet(self):
        """在屏幕上绘制子弹。"""
        pygame.draw.rect(self.screen, self.color, self.rect)


if __name__ == "__main__":

Python# alien.py —— 表示单个外星人的类
import os

os.environ["SDL_VIDEODRIVER"] = "dummy"   # 自测不需要真实显示器

import pygame
from pygame.sprite import Sprite


class Alien(Sprite):
    """表示单个外星人的类。"""

    def __init__(self, ai_game):
        """初始化外星人并设置其起始位置。"""
        super().__init__()
        self.screen = ai_game.screen
        self.settings = ai_game.settings

        # 加载外星人图像；没有图片文件时生成一张占位图
        if not os.path.exists("images/alien.bmp"):
            os.makedirs("images", exist_ok=True)
            placeholder = pygame.Surface((60, 58))
            placeholder.fill((80, 200, 120))
            pygame.image.save(placeholder, "images/alien.bmp")
        self.image = pygame.image.load("images/alien.bmp")
        self.rect = self.image.get_rect()

        # 初始位置在屏幕左上角附近，留出一个身位
        self.rect.x = self.rect.width
        self.rect.y = self.rect.height

        # 用浮点数记录水平位置
        self.x = float(self.rect.x)

    def check_edges(self):
        """如果外星人位于屏幕边缘，就返回 True。"""
        screen_rect = self.screen.get_rect()
        return (self.rect.right >= screen_rect.right) or (self.rect.left <= 0)

    def update(self):
        """向左或向右移动外星人。"""
        self.x += self.settings.alien_speed * self.settings.fleet_direction
        self.rect.x = self.x


if __name__ == "__main__":

import pygame
from pygame.sprite import Sprite


class Ship(Sprite):                      # 改动一：继承 Sprite
    """管理飞船的类。"""

    def __init__(self, ai_game):
        super().__init__()               # 改动一（续）：必须调用
        self.screen = ai_game.screen
        self.screen_rect = ai_game.screen.get_rect()
        self.settings = ai_game.settings

        try:
            self.image = pygame.image.load("images/ship.bmp")
        except (FileNotFoundError, pygame.error):
            self.image = pygame.Surface((60, 48))
            self.image.fill((70, 130, 180))
        self.rect = self.image.get_rect()
        self.rect.midbottom = self.screen_rect.midbottom

        self.x = float(self.rect.x)
        self.moving_right = False
        self.moving_left = False

    def update(self):
        """根据移动标志调整飞船的位置，并限制在屏幕内。"""
        if self.moving_right and self.rect.right < self.screen_rect.right:
            self.x += self.settings.ship_speed
        if self.moving_left and self.rect.left > 0:
            self.x -= self.settings.ship_speed
        self.rect.x = self.x

    def blitme(self):
        """在指定位置绘制飞船。"""
        self.screen.blit(self.image, self.rect)

    def center_ship(self):               # 改动二：新增
        """让飞船回到屏幕底部中央。"""
        self.rect.midbottom = self.screen_rect.midbottom
        self.x = float(self.rect.x)

示例 6：alien_invasion.py——完整版（13 章终态）

把示例 1、3、4、5 的五个文件放在同一目录，运行 SDL_VIDEODRIVER=dummy python alien_invasion.py，就得到一个完整可玩的外星人入侵：左右移动、空格射击、击落外星人、撞三次游戏结束。

Python# alien_invasion.py —— 《外星人入侵》主文件（第 13 章完成时）
import sys
from time import sleep

import pygame
from pygame.sprite import Group

from alien import Alien
from bullet import Bullet
from game_stats import GameStats
from settings import Settings
from ship import Ship


class AlienInvasion:
    """管理游戏资源和行为的类。"""

    def __init__(self):
        """初始化游戏并创建资源。"""
        pygame.init()
        self.settings = Settings()
        self.clock = pygame.time.Clock()
        self.screen = pygame.display.set_mode(
            (self.settings.screen_width, self.settings.screen_height))
        pygame.display.set_caption("Alien Invasion")

        self.stats = GameStats(self)     # 游戏统计信息
        self.ship = Ship(self)
        self.bullets = Group()           # 装子弹的编组
        self.aliens = Group()            # 装外星人的编组
        self._create_fleet()

    def run_game(self):
        """开始游戏的主循环。"""
        while True:
            self._check_events()
            if self.stats.game_active:
                self.ship.update()
                self._update_bullets()
                self._update_aliens()
            self._update_screen()
            self.clock.tick(60)

    # —— 事件处理 ——

    def _check_events(self):
        """响应按键和鼠标事件。"""
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                sys.exit()
            elif event.type == pygame.KEYDOWN:
                self._check_keydown_events(event)
            elif event.type == pygame.KEYUP:
                self._check_keyup_events(event)

    def _check_keydown_events(self, event):
        """响应按键。"""
        if event.key == pygame.K_RIGHT:
            self.ship.moving_right = True
        elif event.key == pygame.K_LEFT:
            self.ship.moving_left = True
        elif event.key == pygame.K_q:
            sys.exit()
        elif event.key == pygame.K_SPACE:
            self._fire_bullet()

    def _check_keyup_events(self, event):
        """响应松键。"""
        if event.key == pygame.K_RIGHT:
            self.ship.moving_right = False
        elif event.key == pygame.K_LEFT:
            self.ship.moving_left = False

    def _fire_bullet(self):
        """创建一颗新子弹，并加入编组（受数量限制）。"""
        if len(self.bullets) < self.settings.bullets_allowed:
            new_bullet = Bullet(self)
            self.bullets.add(new_bullet)

    # —— 子弹 ——

    def _update_bullets(self):
        """更新子弹位置，并删除消失的子弹。"""
        self.bullets.update()
        for bullet in self.bullets.copy():      # 遍历副本，安全删除
            if bullet.rect.bottom <= 0:
                self.bullets.remove(bullet)
        self._check_bullet_alien_collisions()

    def _check_bullet_alien_collisions(self):
        """响应子弹和外星人的碰撞。"""
        collisions = pygame.sprite.groupcollide(
            self.bullets, self.aliens, True, True)
        if not self.aliens:
            # 外星人全部被击落：清空子弹，再来一队
            self.bullets.empty()
            self._create_fleet()

    # —— 外星人 ——

    def _create_fleet(self):
        """创建外星舰队。"""
        alien = Alien(self)                     # 先造一个当"尺子"
        alien_width, alien_height = alien.rect.size

        available_space_x = self.settings.screen_width - (2 * alien_width)
        number_aliens_x = available_space_x // (2 * alien_width)

        ship_height = self.ship.rect.height
        available_space_y = (self.settings.screen_height
                             - (3 * alien_height) - ship_height)
        number_rows = available_space_y // (2 * alien_height)

        for row_number in range(number_rows):
            for alien_number in range(number_aliens_x):
                self._create_alien(alien_number, row_number)

    def _create_alien(self, alien_number, row_number):
        """创建一个外星人，并把它放进舰队。"""
        alien = Alien(self)
        alien_width = alien.rect.width
        alien.x = alien_width + 2 * alien_width * alien_number
        alien.rect.x = alien.x
        alien.rect.y = alien.rect.height + 2 * alien.rect.height * row_number
        self.aliens.add(alien)

    def _update_aliens(self):
        """更新舰队位置，并处理与飞船的碰撞。"""
        self._check_fleet_edges()
        self.aliens.update()
        if pygame.sprite.spritecollideany(self.ship, self.aliens):
            self._ship_hit()
        self._check_aliens_bottom()

    def _check_fleet_edges(self):
        """有外星人到达边缘时，改变整个舰队的方向。"""
        for alien in self.aliens.sprites():
            if alien.check_edges():
                self._change_fleet_direction()
                break

    def _change_fleet_direction(self):
        """将整队外星人下移，并改变移动方向。"""
        for alien in self.aliens.sprites():
            alien.rect.y += self.settings.fleet_drop_speed
        self.settings.fleet_direction *= -1

    def _ship_hit(self):
        """响应飞船被外星人撞到。"""
        if self.stats.ships_left > 0:
            self.stats.ships_left -= 1
            self.aliens.empty()
            self.bullets.empty()
            self._create_fleet()
            self.ship.center_ship()
            sleep(0.5)
        else:
            self.stats.game_active = False

    def _check_aliens_bottom(self):
        """检查是否有外星人到达屏幕下边缘。"""
        screen_rect = self.screen.get_rect()
        for alien in self.aliens.sprites():
            if alien.rect.bottom >= screen_rect.bottom:
                self._ship_hit()      # 像飞船被撞一样处理
                break

    # —— 画面 ——

    def _update_screen(self):
        """更新屏幕上的图像，并切换到新屏幕。"""
        self.screen.fill(self.settings.bg_color)
        for bullet in self.bullets.sprites():
            bullet.draw_bullet()      # 子弹没有 image，手动绘制
        self.aliens.draw(self.screen)  # 外星人有 image，整编组一次画完
        self.ship.blitme()
        pygame.display.flip()


if __name__ == "__main__":
    ai = AlienInvasion()
    ai.run_game()

_update_screen() 里两种画法放在一起正好对比：外星人走 Group.draw()（因为它们有 image），子弹只能手动循环 draw_bullet()（因为它是色块，没有 image）——这就是 2.2 节说的「装备不齐，编组帮不了你」。
