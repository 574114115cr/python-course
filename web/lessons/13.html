六、本单元验收自测

1. 简答题：fruits = ["苹果", "香蕉", "橙子"]，fruits[1] 和 fruits[-2] 分别是什么？为什么它们相同？

要点：都是 "香蕉"。索引从 0 开始时，[1] 是正向走 1 步（第二个）；负索引 [-2] 是从末尾倒着数第 2 个。列表长度是 3，从末尾数第 2 个正好也是第二个，所以两者指向同一个元素。

2. 判断题：a = [1, 2, 3] 和 b = [1, 2, 3] 这两行代码执行后，a == b 的结果是什么？a is b 呢？

要点：a == b 是 True（内容相同）；a is b 是 False（is 比较"是不是同一个对象"，方括号各自创建了两个独立列表）。这说明 == 比内容，is 比身份。

3. 简答题：下面代码输出什么？

Pythoncars = ["a", "b", "c"]
last = cars.remove("b")
print(last)
print(cars)

要点：第一行报错 TypeError: 'NoneType' object is not iterable——不对，更准确的是：last 是 None，然后 print(last) 输出 None，print(cars) 输出 ['a', 'c']。关键点是 .remove() 没有返回值，它只负责删除。而 .pop() 有返回值。

4. 判断题：lst = [1, 2, 3] 然后 lst2 = lst[:] 然后 lst2.append(4)，此时 lst 的内容是 [1, 2, 3, 4]。

要点：错误。lst 仍然是 [1, 2, 3]。lst[:] 是切片，会产生一个新列表（外层浅拷贝），所以 lst2 是独立的对象。若写成 lst2 = lst，才会互相影响。

5. 简答题：append() 和 insert() 都可以添加元素，两者区别是什么？各写一行代码实现"在列表 nums = [1, 4] 的索引 1 处插入 2"。

要点：append() 只能加到末尾（不传位置）；insert(位置, 值) 可以加到任意位置，该位置及其后的元素会自动后移。实现：nums.insert(1, 2) → [1, 2, 4]。若用 append 则只能是 nums.append(2) → [1, 4, 2]。

七、常见错误清单（务必逐条自查）

错误 1：IndexError: list index out of range

症状：cars[3] 崩了，列表明明有 3 个元素。 原因：下标从 0 开始，3 个元素的下标是 0/1/2。 改法：最后一项用 cars[-1]；要按下标循环就 range(len(cars))，别手写上限。

错误 2：空列表上 x[-1] 也崩

症状：IndexError 出现在取最后一项时。 原因：空列表没有任何元素，-1 一样越界。 改法：先判 if cars:（空列表为假），或用 cars[-1] if cars else None。

错误 3：cars = cars.sort() 之后列表变成 None

症状：排序后再用就 TypeError: 'NoneType' object is not subscriptable。 原因：sort() 原地排序、返回 None；sorted() 才返回新列表。 改法：cars.sort() 单独一行；要保留原列表就 new = sorted(cars)。

错误 4：b = a 之后改 b，a 也变了

症状：明明只改了副本。 原因：b = a 只是给同一个列表起了个别名，不是复制。 改法：b = a.copy() 或 b = a[:]（浅复制）；列表里还套列表时要用 copy.deepcopy(a)。

错误 5：cars.remove("bmw") 只删掉一个

症状：列表里有两个 "bmw"，只少了一个。 原因：remove() 只删第一个匹配项，且没有返回值。 改法：要删干净用循环 while "bmw" in cars: cars.remove("bmw")，或列表推导 cars = [c for c in cars if c != "bmw"]。
