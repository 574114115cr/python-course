2.4 整数 int 与浮点数 float

int 是整数（-3、0、42），float 是小数（3.14、-0.5）。

一个必须知道的细节：Python 的小数是二进制浮点数，会存在精度误差。所以你会看到：

Pythonprint(0.1 + 0.2)   # 0.30000000000000004  ← 不是 bug，是浮点表示的本质

若必须得到精确结果，教材和工程界的做法是先用 round() 保留有效位数：

Pythonprint(round(0.1 + 0.2, 2))   # 0.3

round(数字, 位数) 的第二个参数表示保留几位小数。

2.5 布尔值 bool：只有两个取值

布尔值只有 True 和 False，首字母必须大写，这是初学者的高频语法错误（写 true 会报 NameError）。

Python 里有一批"真值判断"规则，在单元 4、6 会大量用到：

值为以下情况 布尔意义
0、0.0、空字符串 ""、空列表 []、空字典 {}、None False（假）
其他任何值（含非零数字、非空文本） True（真）

生活化类比：问"这个盒子里有东西吗？"——空盒子回答 False，非空盒子回答 True。Python 判断的就是"有没有内容"，不关心内容是什么。

2.6 类型转换：把一种类型的标签换成另一种

input() 拿回来的永远是字符串，即使你输入 18，它也是 "18" 这个字符串，直接做加法会出错：

Pythonage = input("年龄：")   # 用户输入 18，age 是 str "18"
print(age + 1)          # TypeError：can only concatenate str to str

解决办法是用转换函数重新贴标签：

Pythonage = int(input("年龄："))    # "18" → 18（整数）
print(age + 1)                # 19

四个转换函数：str() 转字符串、int() 转整数、float() 转小数、bool() 转布尔。

转换可能失败，失败会报 ValueError： - int("abc") → ValueError: invalid literal for int()（abc 不是合法整数） - int("3.9") → ValueError（带小数点的字符串不能直接转整数，必须先 float 或 int(float(...))） - float("abc") → ValueError

记住这条链："3.9" → float() 得 3.9 → int() 得 3。字符串到整数没有"一步到位"的捷径，因为 3.9 转整数会丢失小数部分，Python 拒绝替你做这个决定。

2.7 字符串方法全家桶：拆分、拼接与去掉前后缀

教材 2.3 讲了 title() / upper() / lower() / strip()。还有三组在真实代码里出现频率更高的方法，书里分散在示例中没集中讲：split() 把一句话拆成列表、join() 把列表拼回字符串、removeprefix() 去掉开头固定的一段。

Pythonline = "张三,18,北京"
print(line.split(","))        # ['张三', '18', '北京']
print(line.split(",", 1))     # ['张三', '18,北京']  ← 最多拆 1 次

words = ["python", "is", "fun"]
print(" ".join(words))        # python is fun
print("-".join(words))        # python-is-fun

split() 与 join() 是一对反操作：一个把字符串变列表，一个把列表变字符串。注意 join() 的调用方向——分隔符在前、列表是参数。写反成 words.join(" ") 会报 AttributeError: 'list' object has no attribute 'join'。

Pythonfilename = "report_2026_final.csv"
print(filename.removeprefix("report_"))   # 2026_final.csv
print(filename.removesuffix(".csv"))      # report_2026_final

removeprefix() / removesuffix()（Python 3.9+）解决的是「前缀固定、后面长度不定」的问题。以前只能写切片 filename[len("report_"):]，或者图省事用 lstrip("report_")——而 lstrip 是按字符集合删的，会把 report.pdf 删成 .pdf，属于高频 bug：

Pythonprint("report.pdf".lstrip("report_"))         # .pdf        ← r/e/p/o/t/_ 都被当字符删掉
print("report.pdf".removeprefix("report_"))   # report.pdf  ← 前缀不匹配就原样返回

查找与替换这一组也常一起出现：

Pythons = "to be or not to be"
print(s.find("be"))            # 3    ← 返回下标
print(s.find("xyz"))           # -1   ← 找不到返回 -1，不报错
print(s.count("be"))           # 2
print(s.replace("be", "BE"))   # to BE or not to BE
print(s.replace("be", "BE", 1))  # to BE or not to be  ← 第三个参数限制次数

要点 - split() 不传参数时按「任意连续空白」拆并丢掉空串；传 "," 时连续逗号会拆出空字符串。 - join() 只能拼字符串列表：",".join([1, 2]) 报 TypeError，要先 ",".join(map(str, nums))。 - 这几个方法都返回新字符串，原字符串不变（同 2.3 的「复印纸条」模型）。 - find() 找不到返回 -1，index() 找不到才抛 ValueError——判断「有没有」优先用 in。

2.8 三个容易漏掉的运算符：//、%、**

只有 + - * / 是不够用的，下面这三个在真实代码里出现频率极高：

Python# 四种运算放一起看差别
print("7 / 2  =", 7 / 2)     # 3.5   ← / 永远是浮点，哪怕能整除
print("7 // 2 =", 7 // 2)    # 3     ← 地板除：只要整数部分，向下取整
print("7 % 2  =", 7 % 2)     # 1     ← 取余：7 除以 2 余 1
print("2 ** 10 =", 2 ** 10)  # 1024  ← 幂（不是异或！很多语言的 ^ 才是幂）

# 地板除对负数是「向下」而不是「向零」——这是最容易踩的一处
print("-7 // 2 =", -7 // 2)  # -4（不是 -3：-3.5 向下取整是 -4）
print("7 // -2 =", 7 // -2)  # -4

% 取余有什么用？ 三件高频的事：

Python# ① 判断奇偶：能被 2 整除就是偶数
for n in range(1, 6):
    kind = "偶" if n % 2 == 0 else "奇"
    print(n, kind)

# ② 判断"每隔 N 个做一次"（分页、进度打印都靠它）
for i in range(1, 11):
    if i % 3 == 0:
        print(f"第 {i} 次：每 3 次执行一次")

# ③ 把总秒数拆成时分秒（单位换算的经典写法）
total = 3725
h = total // 3600
m = (total % 3600) // 60
s = total % 60
print(f"{total} 秒 = {h} 小时 {m} 分 {s} 秒")

顺带记住两条规则：/ 的结果永远是浮点数（4 / 2 是 2.0 不是 2）； ** 的优先级高于 * 和 -，所以 -2 ** 2 是 -4 而不是 4（它等于 -(2**2)）。

2.9 浮点数的精度陷阱：为什么 0.1 + 0.2 != 0.3

这是每个 Python 初学者都会被吓一跳的地方：

Pythonprint(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False  ← 不是 Python 的 bug，所有语言都这样
print(1.1 * 3)                # 3.3000000000000003

为什么：计算机用二进制存小数，而 0.1 在二进制里是无限循环小数（就像十进制里的 1/3 = 0.333...）。 存不下就必然有误差，误差在计算中会累积。

因此：永远不要用 == 比较两个浮点数的计算结果。 三种正确写法：

Pythona = 0.1 + 0.2

# 写法 1：看差值是不是足够小（最常用）
print(abs(a - 0.3) < 1e-9)          # True

# 写法 2：用标准库的 isclose（语义最清楚）
import math
print(math.isclose(a, 0.3))          # True

# 写法 3：先四舍五入到需要的位数再比
print(round(a, 2) == 0.3)            # True

涉及钱的时候不要 float，用 Decimal：

Pythonfrom decimal import Decimal
price = Decimal("19.99") * 3
print(price)                         # 59.97（精确，不是 59.97000000000001）

经验法则：计数、数量用 int；科学计算、比例、平均值用 float； 金额、需要精确对账的数字用 Decimal。

2.10 f-string 格式化进阶：小数位、千分位、对齐

f"{变量}" 只是基础用法。在冒号后面加格式说明符，能让输出直接可用：

Pythonpi = 3.14159265
n = 1234567
ratio = 0.256

print(f"{pi:.2f}")        # 3.14        保留 2 位小数
print(f"{pi:.4f}")        # 3.1416      保留 4 位（会四舍五入）
print(f"{n:,}")           # 1,234,567   千分位分隔符
print(f"{ratio:.1%}")     # 25.6%       转成百分比
print(f"{n:>12,}")        # '   1,234,567'  右对齐，总宽 12
print(f"{'OK':^10}")      # '    OK    '    居中，总宽 10
print(f"{7:03d}")         # 007         左边补 0 到 3 位

# 组合起来：一行做一个像样的报表行
name, price, qty = "笔记本", 12.5, 3
print(f"{name:<6} 单价 {price:>6.2f} × {qty} = {price * qty:>7.2f}")

调试时还有个省事的写法（3.8+）：

Pythonx, y = 10, 20
print(f"{x=} {y=}")           # x=10 y=20  ← 连名字一起打印，比 print(x, y) 清楚

2.11 一次给多个变量赋值，以及「常量」的约定

Python# ① 多重赋值：一行给多个变量（元组的自动拆包）
name, age, city = "小明", 18, "成都"

# ② 交换两个变量——Python 里不需要临时变量
a, b = 1, 2
a, b = b, a
print(a, b)                   # 2 1

# ③ 链式赋值：多个名字指向同一个值
x = y = 0

第 ③ 条有个坑：对数字没事，对列表有事。

Pythonp = q = [1, 2, 3]
p.append(4)
print(q)                      # [1, 2, 3, 4]  ← q 也跟着变了！

因为 p = q = [1, 2, 3] 是"两个名字指向同一个列表"，不是"两个列表"。 想要两份独立的就分开写：p = [1, 2, 3] 与 q = [1, 2, 3]（或用 q = p.copy()，单元 2 会细讲）。

常量：Python 没有真正的常量（谁都能改），约定是用全大写表示"不要改我"：

PythonMAX_RETRY = 3          # 全大写 = 约定上的常量，看到就别赋值
TAX_RATE = 0.13

这只是君子协定——Python 不会拦你，但所有 Python 程序员都遵守它。

示例 3：字符串常用方法

Python# string_methods.py —— 字符串的"复印与改写"

name = "  ada lovelace  "

# .upper() / .lower() 大小写转换
print(name.upper())       # '  ADA LOVELACE  '
print(name.lower())       # '  ada lovelace  '

# .strip() 去掉两端空白（不会去掉中间的空格）
print(repr(name.strip()))# 'ada lovelace'  用 repr() 才能看清首尾有没有空格

# .title() 每个单词首字母大写
print(name.strip().title())   # 'Ada Lovelace'

# .len() 计算长度（算的是字符个数）
print(len(name.strip()))      # 12

# .count() 数某个字符出现几次
print("banana".count("a"))        # 3

# .replace() 替换
print("hello world".replace("world", "python"))   # 'hello python'

# 关键：上面所有方法都"没有改动" name
print(name)                    #  '  ada lovelace  '  ← 原字符串原封不动
print(type(name.strip()))      # <class 'str'>  返回的是一个新字符串

# 想真正保存结果，必须接住返回值
name = name.strip().title()
print(name)                    # 'Ada Lovelace'  ← 现在才是新值

示例 4：类型转换

Python# convert.py —— 四种类型之间的转换

# str 转 int：常见且安全（前提是字符串确实是整数）

print(int(s) + 1)              # 19

# str 转 float

示例 5：f-string 格式化输出

Python# fstring.py —— f-string：把变量嵌进文字里的最佳方式

product = "机械键盘"
price = 499.5
quantity = 3
discount = 0.85
is_in_stock = True

total = price * quantity * discount

# 基础用法
print(f"商品：{product}")
print(f"单价：{price} 元")

# 花括号里可以放完整的表达式
print(f"总价：{price * quantity * discount:.2f} 元")

# 格式说明符：:.<宽度>.<小数位>f
print(f"|{product:<10}|")# 左对齐，占 10 字符宽
print(f"|{price:>10.2f}|")           # 右对齐，保留两位小数
print(f"|{product:^12}|")            # 居中

# 补零，常用于编号
code = 42
print(f"订单号：{code:05d}")          # 订单号：00042

# 千位分隔符
big = 1234567.891
print(f"金额：{big:,.2f} 元")         # 金额：1,234,567.89 元

# 让布尔值更易读
print(f"是否有货：{is_in_stock}")     # 是否有货：True
print(f"是否有货：{'有' if is_in_stock else '无'}")  # 是否有货：有

# 多行 f-string：括号里可以换行，不用反复 print
print(f"商品：{product}\n"
      f"单价：{price} 元\n"
      f"总价：{total:.2f} 元")

示例 7：注释的正确写法

Python# comments.py —— 注释的三种写法

# 这是"整行注释"，写在单独一行，用来解释下面这段代码在干什么

age = 18  # 这是"行尾注释"，跟在代码后面，前面要有两个空格

# 注释可以很详细，也可以很简短。判断标准是：

示例 8：拆一行日志，再拼回去

split() / join() 最典型的用法是处理「一行一条记录」的文本。下面这行是服务器访问日志，六段用空格隔开：

Python# log_line.py —— 拆开、取字段、换格式、再拼回去
line = "2026-10-26 09:15:33 GET /lessons/29.html 200 4213"

parts = line.split(" ")                 # 空格分隔，正好 6 段
print("段数  ", len(parts))
print("原始  ", parts)

date, clock, method, path, status, size = parts       # 解包，顺序必须对上
print(f"日期  {date} {clock}")
print(f"请求  {method} {path}")

pure = path.split("?")[0]               # 去掉查询串；没有 ? 时只有一段
print("纯路径", pure)
print("文件名", pure.removeprefix("/lessons/"))

print("CSV   ", ",".join([date, method, pure, status]))

kb = int(size) / 1024                   # size 现在是字符串，必须先转 int
print(f"大小  {kb:.1f} KB")
print("成功？", status.startswith("2"))

运行结果（print 会按逗号自动加空格，所以对齐看起来是参差的，这是 print 的行为不是 bug）：

示例段数   6
原始   ['2026-10-26', '09:15:33', 'GET', '/lessons/29.html', '200', '4213']
日期   2026-10-26 09:15:33
请求   GET /lessons/29.html
纯路径 /lessons/29.html
文件名 29.html
CSV    2026-10-26,GET,/lessons/29.html,200
大小   4.1 KB
成功？ True

三个值得记住的点：

  1. split() 的段数必须和解包变量个数一致，多一个少一个都会 ValueError: too many values to unpack。不确定段数时先 print(len(parts))。
  2. split("?")[0] 是「取问号前那段」的惯用法——没有问号时返回整串，不会报错，所以比 index("?") 安全。
  3. join() 只吃字符串：size 是从 split() 出来的字符串，要算数必须先 int(size)；反过来，数字要拼回 CSV 必须先 str()。
