六、本单元验收自测

1. 简答题：

Pythond = {"a": 1}
d["b"] = 2
d["a"] = 3
print(len(d), d)

输出什么？为什么？

要点：输出 2 {'a': 3, 'b': 2}。第二行新增了一对（长度 1→2），第三行只是把已存在的 a 的值从 1 改成 3（长度不变）。字典赋值语句不区分新增和修改，只看键在不在。

2. 判断题：d = {} 之后直接执行 print(d["name"]) 会打印 None。

要点：错误。会报 KeyError: 'name'。要拿到 None 必须用 d.get("name")。

3. 简答题：下面代码输出什么？为什么会报错？

Pythonscores = {"语文": 90}
for key in scores:
    if scores[key] < 60:
        del scores[key]
print(scores)

要点：会报 RuntimeError: dictionary changed size during iteration。因为循环正按顺序遍历键，一旦 del 删掉一个键，字典内部结构发生改变，迭代器的位置就和实际内容错位了。修复方法：for key in list(scores.keys()):，先复制一份键列表再遍历副本。

4. 简答题：.get() 相比 dict[键] 的两个核心优势是什么？各举一例。

要点：① 不会崩溃：键不存在时 .get() 返回默认值，而 dict[键] 抛 KeyError。例：d.get("年龄", 0) 安全返回 0。② 支持链式访问嵌套数据：因为缺键时可以返回一个空字典，链条不会断。例：users.get("u9", {}).get("name", "查无此人")，即使 u9 不存在也能安全返回兜底值。

5. 判断题：下面两行代码的作用完全一样。

Pythonfor key in d:
    print(key)

for key in d.keys():
    print(key)

要点：作用完全一样。for key in d 是 for key in d.keys() 的简写形式，Python 允许直接遍历字典的键。这不是巧合——dict.keys() 返回的视图对象本身就代表键。

七、常见错误清单（务必逐条自查）

错误 1：KeyError: 'name'

症状：取一个不存在的键就崩。 原因：d["name"] 在键缺失时抛异常（这是设计，不是 bug）。 改法：可能缺的键用 d.get("name", "默认值")；确实必须有就让它崩，但要在上层 try/except KeyError 给出可读提示。

错误 2：遍历字典时增删键 → RuntimeError

症状：dictionary changed size during iteration。 原因：迭代器依赖内部结构，边遍历边改会让它失效。 改法：先取快照 for k in list(d):，再改 d；或先用推导式算出要删的键，循环外统一删。

错误 3：拿列表当键 → TypeError: unhashable type

症状：d[[1, 2]] = "x" 报不可哈希。 原因：字典靠 hash 定位，键必须不可变。 改法：用元组 d[(1, 2)]，或把列表 tuple(lst) 转一下。

错误 4：以为 d.keys() 是列表，能下标

症状：d.keys()[0] 报 'dict_keys' object is not subscriptable。 原因：keys()/values()/items() 返回的是视图，不是列表。 改法：要下标就 list(d.keys())[0]；只是遍历直接用 for k in d:。

错误 5：嵌套字典层层 []，中间缺一层就崩

症状：d["a"]["b"]["c"] 里 d["a"] 不存在时 KeyError。 改法：逐层 get：d.get("a", {}).get("b", {}).get("c")；层次深就写个小函数或用 defaultdict。
