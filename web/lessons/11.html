◆ 复盘（10 分钟）｜上一节：第 10 节 · 列表是什么、索引为什么从 0 开始

  • 列表 = 一排抽屉，用下标取；下标从 0 开始，不是 1。
  • 负索引从右边数：-1 是最后一个，-2 是倒数第二个。
  • len() 给长度；下标越界会报 IndexError。

2.4 增删改方法：五个主力

Pythoncars = ["小红帽", "凯迪拉克"]

cars.append("雷克萨斯")       # 末尾追加一个 -> ['小红帽', '凯迪拉克', '雷克萨斯']
cars.insert(1, "宝马")        # 在索引 1 处插入 -> ['小红帽', '宝马', '凯迪拉克', '雷克萨斯']
cars.remove("宝马")           # 删除指定值（只能删值，不能删位置）
popped = cars.pop()           # 弹出最后一个，**并把它返回出来**
print(popped)                 # 雷克萨斯
del cars[0]                   # 按位置删除，不返回值

2.5 .remove() 与 .pop()：一个删"值"，一个删"位置"

这是本单元最容易混淆的一对：

方法 参数含义 有没有返回值 找不到会怎样
.remove(值) 要删掉的是哪个值 没有（返回 None） 报 ValueError
.pop(位置) 要删掉的是第几个 有（被删掉的元素） 报 IndexError

.pop() 的"顺带把元素交给你"这个特性极其有用：

Pythonlast = stack.pop()      # 弹出来之后可以直接用，这正是"栈"这种数据结构的基础

del 和 .pop() 效果类似，但 del 不返回被删的元素，所以要保留就得改用 .pop()。

2.6 引用共享：最反直觉的一课

这是初学者最容易踩的坑，也是"浅拷贝"概念的入门。

Pythoncars = ["小红帽", "凯迪拉克"]
other = cars          # 这不是复制！是给同一个列表贴了第二张标签
other.append("雷克萨斯")

print(cars)           # ['小红帽', '凯迪拉克', '雷克萨斯']  ← cars 也变了！
print(cars is other)  # True —— 它们本来就是同一个东西

生活化类比：你把同一本笔记本的封面同时写上了"cars"和"other"两个名字。用胶带贴新标签不会得到第二本笔记本，往本子上写字，另一个名字看到的也是改后的内容。

真正复制一份要用 copy()（浅拷贝，只是外层复制）：

Pythonimport copy
other = copy.deepcopy(cars)   # 完全独立的副本

这是因为 Python 传的是"指向数据的地址"，而不是数据本身。单元 7（函数）讲参数传递的副本语义时会彻底展开这个话题，现在只要记住这一句：

给变量重新起个名字 ≠ 复制数据。

三、可运行代码示例

示例 1：创建列表与基本访问

Python# list_basics.py —— 列表的创建与元素访问

# 用方括号创建列表，元素之间用逗号分隔
cars = ["小红帽", "二手柯尼塞格", "凯迪拉克"]
numbers = [1, 10, 100, 1000]
mixed = ["hello", 3.14, True, None]   # 元素类型可以混合
empty = []                            # 空列表

# 按索引读取元素：索引从 0 开始
print(cars[0])       # 小红帽（第一个）
print(cars[1])       # 二手柯尼塞格（第二个）
print(cars[2])       # 凯迪拉克（第三个）

# 负索引：从末尾往回数，-1 是最后一个
print(cars[-1])      # 凯迪拉克
print(cars[-2])      # 二手柯尼塞格
print(cars[-3])      # 小红帽

# len() 求长度：元素个数
print("cars 的长度：", len(cars))     # 3
print("empty 的长度：", len(empty))   # 0

# 常见错误：索引越界
# print(cars[3])     # IndexError: list index out of range
# print(cars[-4])    # IndexError: list index out of range

# 用 len() 配合负索引，可以取到"倒数第几个"
print("倒数第二个：", cars[len(cars) - 2])   # 二手柯尼塞格

示例 2：修改元素（列表可变的体现）

Python# list_modify.py —— 列表元素可以直接赋值修改

cars = ["小红帽", "二手柯尼塞格", "凯迪拉克"]
print("修改前：", cars)

# 直接给某个索引赋值 —— 这是列表"可变"的标志
cars[0] = "特斯拉"
print("修改第 0 个：", cars)      # ['特斯拉', '二手柯尼塞格', '凯迪拉克']

cars[-1] = "保时捷"
print("修改最后一个：", cars)      # ['特斯拉', '二手柯尼塞格', '保时捷']

# 对比字符串：字符串不能这样改
name = "tom"
# name[0] = "T"  # TypeError: 'str' object does not support item assignment
# 字符串必须"生成新的再赋回"
name = "T" + name[1:]
print("字符串的替代做法：", name)   # Tom

# 注意：直接把一个字符串塞进列表是可以的
mixed = ["hello", 18, 1.75, True]
print(mixed)
print(type(mixed[1]))    # <class 'int'> 列表可以装不同类型

示例 3：添加元素

Python# list_add.py —— 三种添加方式

cars = ["小红帽", "凯迪拉克"]
print("初始：", cars)

# 1）append()：在列表末尾追加一个元素（最常用）
cars.append("雷克萨斯")
print("append 后：", cars)          # ['小红帽', '凯迪拉克', '雷克萨斯']

# 2）insert()：在指定索引位置插入，后面的元素自动后移
cars.insert(1, "宝马")             # 在索引 1（即"小红帽"和"凯迪拉克"之间）插入
print("insert 后：", cars)          # ['小红帽', '宝马', '凯迪拉克', '雷克萨斯']

# 3）用 + 拼接两个列表（会产生一个新列表）
more = ["本田", "福特"]
combined = cars + more
print("拼接后：", combined)
print("原列表没变：", cars)          # + 不修改原列表

# append 和 insert 的返回值都是 None，所以不能写 x = cars.append(...) 后期待 x 有值
result = cars.append("沃尔沃")
print("append 的返回值：", result)   # None
print("但列表确实变了：", len(cars)) # 5

# 常见错误：append 只能一次加一个
# cars.append("A", "B")   # TypeError: append() takes exactly one argument
# 想一次加多个，用 extend
cars.extend(["奥迪", "英菲尼迪"])
print("extend 后：", cars)

示例 4：删除元素

Python# list_remove.py —— remove / pop / del / clear

cars = ["小红帽", "宝马", "凯迪拉克", "雷克萨斯", "保时捷"]
print("初始：", cars)

# 1）remove()：按"值"删除，只能删掉第一个匹配的
cars.remove("宝马")
print("remove 后：", cars)         # ['小红帽', '凯迪拉克', '雷克萨斯', '保时捷']

# 删不存在的值会报 ValueError
# cars.remove("菲亚特")           # ValueError: list.remove(x): x not in list

# 2）pop()：按"位置"弹出，并返回被弹出的元素
last = cars.pop()# 弹出最后一个
print("pop 出来的：", last)         # 保时捷
print("pop 后：", cars)             # ['小红帽', '凯迪拉克', '雷克萨斯']

# pop 也可以指定位置
first_car = cars.pop(0)            # 弹出第0 个
print("pop(0) 出来的：", first_car)  # 小红帽
print("现在：", cars)               # ['凯迪拉克', '雷克萨斯']

# 3）del：按位置删除，但不返回值
del cars[1]
print("del 后：", cars)             # ['凯迪拉克']

# 4）remove 和 pop 的本质区别
numbers = [10, 20, 30]
# numbers.remove(20)   # 删掉"值为 20 的元素"
# numbers.pop(1)       # 删掉"第 1 个位置的元素"（这里恰好也是 20）

# 5）清空列表
nums = [1, 2, 3]
nums.clear()
print("clear 后：", nums, "长度", len(nums))   # [] 长度 0

示例 5：引用共享与浅拷贝

Python# copy_semantics.py —— Python 列表的"引用"语义（重要）

import copy

# 1）直接赋值 = 给同一个列表贴第二张标签，不是复制
original = ["苹果", "香蕉"]
alias = original
alias.append("橙子")

print("original：", original)     # ['苹果', '香蕉', '橙子']  ← 也变了！
print("alias：", alias)           # ['苹果', '香蕉', '橙子']
print("是不是同一个对象：", original is alias)   # True

# 2）正确的浅拷贝：copy.copy() 或 original[:]
shallow = original[:]# 外层列表是新对象
shallow.append("葡萄")
print("original：", original)     # ['苹果', '香蕉', '橙子']  ← 没变，好
print("shallow：", shallow)       # ['苹果', '香蕉', '橙子', '葡萄']

# 3）嵌套列表时，浅拷贝只保护外层！
nested = [["a", "b"], ["c", "d"]]
outer = nested[:]# 浅拷贝
outer[0].append("X")             # 修改的是内层那个列表
print("nested：", nested)         # [['a', 'b', 'X'], ['c', 'd']]  ← 内层被改了！

# 4）完全独立的副本需要 deepcopy
deep = copy.deepcopy(nested)
deep[0].append("Y")
print("nested：", nested)         # [['a', 'b', 'X'], ['c', 'd']]  ← 完全没变
print("deep：", deep)             # [['a', 'b', 'X', 'Y'], ['c', 'd']]

示例 6：排序与反转（列表自带的小工具）

Python# list_order.py —— 顺序相关的实用方法

ages = [30, 25, 35, 20, 28]
print("原始：", ages)

# sort()：原地排序（修改原列表），返回 None
ages.sort()
print("升序 sort 后：", ages)      # [20, 25, 28, 30, 35]

# sort(reverse=True)：降序
ages.sort(reverse=True)
print("降序后：", ages)            # [35, 30, 28, 25, 20]

# sorted()：返回排好序的**新列表**，原列表不动
scores = [88, 95, 72, 100, 61]
top3 = sorted(scores, reverse=True)[:3]   # 前三名
print("原列表没变：", scores)     # [88, 95, 72, 100, 61]
print("前三名：", top3)           # [100, 95, 88]

# 按字母排序
names = ["dave", "alice", "Bob", "charlie"]
print("原样：", names)
print("按字母（区分大小写）：", sorted(names))          # Bob, alice, charlie, dave
print("忽略大小写：", sorted(names, key=str.lower))     # Alice, bob, charlie, dave

# reverse()：原地反转
nums = [1, 2, 3, 4, 5]
nums.reverse()
print("反转后：", nums)            # [5, 4, 3, 2, 1]

# count() 和 index()：计数与查找位置
fruits = ["苹果", "香蕉", "苹果", "橙子"]
print("苹果有几个：", fruits.count("苹果"))    # 2
print("橙子在第几个：", fruits.index("橙子"))  # 3（索引从 0 开始）
# print(fruits.index("葡萄"))     # ValueError: '葡萄' is not in list
