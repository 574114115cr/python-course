七、本单元验收自测

1. 简答题：下面代码的 count 属性最后是多少？为什么？

Pythonclass Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        count = self.count + 1


c = Counter()
c.increment()
print(c.count)

要点：输出 0。count = self.count + 1 这一行左边漏了 self.，所以它只是创建了一个局部变量 count，函数一结束就消失了。对象上的 self.count 从未被修改过，仍然是 0。正确写法是 self.count = self.count + 1。

2. 判断题：定义方法时，self 是 Python 的关键字，不写会报语法错误。

要点：错误。self 不是关键字，它只是函数的第一个普通参数，Python 完全允许你叫它别的名字（比如 this，能正常运行）。但它也不写会报 TypeError: area() takes 0 positional arguments but 1 was given（因为调用对象时 Python 会自动传入对象，参数数量对不上）。约定俗成必须写 self，是为了让所有 Python 代码保持一致、别人能读懂。

3. 简答题：

故意写错 · 先跑一遍看报错class Car:
    def __init__(self, make):
        self.make = make

    def __str__(self):
        return f"这是一辆{self.make}"


class ElectricCar(Car):
    def __init__(self, make, battery):
        self.battery = battery


c = ElectricCar("特斯拉", 75)
print(c.make)
这是故意写错的示例——先自己跑一遍看报错，再对照下面的解析弄清错在哪

会输出什么？应该怎么修？

要点：报 AttributeError: 'ElectricCar' object has no attribute 'make'。子类的 __init__ 里没有调用 super().__init__(make)，所以父类设置 self.make 的那段代码根本没执行。修复方法：在子类 __init__ 里加上 super().__init__(make)，并且最好放在 self.battery = battery 之前。

4. 简答题：下面这段代码输出什么？为什么是这个结果？

Pythonclass Dog:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name}：汪汪")


class Puppy(Dog):
    def speak(self):
        print(f"{self.name}：呜呜")


d = Dog("旺财")
p = Puppy("豆豆")
for animal in [d, p]:
    animal.speak()

要点：输出两行——旺财：汪汪 和 豆豆：呜呜。注意 Puppy 没有定义 __init__，但 self.name 依然可用——因为它继承了 Dog.__init__，创建 Puppy("豆豆") 时会自动调用父类的初始化方法。同时 Puppy 重写了 speak()，animal.speak() 会根据对象的真实类型调用对应版本，这正是多态。

5. 简答题：什么时候该用继承，什么时候该用组合？举一个各自的例子。

要点：判断标准是关系的性质。"是一个"（is-a）用继承：Dog 是一种 Animal，ElectricCar 是一种 Car，它们天然共享父类的属性和行为。"有一个"（has-a）用组合：Car 有一个 Engine，BankAccount 有一个 Owner，这些是"组成部分"关系而不是"种类"关系。经验法则是拿不准时优先用组合，因为它更灵活、耦合更低，也不容易因为继承层次太深而失控。
