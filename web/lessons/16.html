2.5 切片：一次取出一段

切片语法 list[start:stop:step]，含 start，不含 stop。

生活化类比：切片就像切面包——你要的是"从第 3 片到第 7 片之间"，第 3 片要、第 7 片不要（它属于下一段）。这个"要左边不要右边"的规则叫左闭右开，因为它让 len 天然对得上：len(a[b:c]) == c - b。

Pythonletters = ["a", "b", "c", "d", "e", "f"]
letters[:]      # 全部（浅拷贝）
letters[2:]     # ['c', 'd', 'e', 'f']      从索引2 到末尾
letters[:3]     # ['a', 'b', 'c']           前三个
letters[1:4]    # ['b', 'c', 'd']
letters[::2]    # ['a', 'c', 'e']           步长 2
letters[::-1]   # ['f', 'e', 'd', 'c', 'b', 'a']  反转
letters[-2:]    # ['e', 'f']                最后两个

切片可以用于列表、字符串、元组，这是三种序列类型的共同能力。

切片也是浅拷贝：a[:] 得到新列表，但里面的元素还是同一批对象（嵌套列表时要注意）。

2.6 元组：用括号表示"不可修改"

列表的方括号 [] 表示"可以改"，圆括号 () 表示"不能改"：

Pythonpoint = (3, 5)
# point[0] = 9    # TypeError: 'tuple' object does not support item assignment

生活化类比：列表像活页本，能撕能换；元组像一次性塑封的相片，封好就不能改了。

元组的三点区别：

列表 list 元组 tuple
写法 [1, 2, 3] (1, 2, 3)
能否改元素 能 不能
能否增删 能 不能（只有重新赋值整个变量）
是否有 append 有 没有
长度 变长 固定
用途 一组会变化的数据 一组固定的数据，如坐标、日期 
Python# 元组"看似不能改"，但可以整体重新赋值
point = (3, 5)
# point[0] = 9   # 不行
point = (9, 5)    # 可以：换了一个全新的元组

只有一个元素的元组必须写逗号——这是超级高频的坑：

Pythont = (5)     # 这不是元组！这是整数 5，括号只是分组
t = (5,)    # 这才是长度为1 的元组
type((5))   # <class 'int'>
type((5,))  # <class 'tuple'>

为什么字典的键要用元组这类不可变类型：键必须是"不会变的"，否则你把键改了，就再也找不到对应的值了。列表可以改，所以列表不能当键；元组不能改，所以可以。

2.7 PEP 8：让代码能被人读

PEP 8 是 Python 官方风格指南，与功能无关但直接影响你能不能维护自己的代码。核心三条：

  1. 一行不超过 79（现代放宽到 99）个字符，长了要换行。
  2. 运算符两侧加空格，逗号后加一个空格：
  3. 缩进统一用 4 个空格，永远不要混用 Tab。

对比示例：

Python# 推荐
total = price * quantity + 5
# 不推荐
total=price*quantity+5

还有两条新手常忘：

Python# 括号内逗号后留一个空格
colors = ["red", "green", "blue"]
# 切片冒号两边都留空格（复杂表达式可省略）
squares = [n**2 for n in range(10)]
sub = letters[1:4]

示例 1：for 循环基础

Python# for_basics.py —— for 循环的标准结构

cars = ["小红帽", "凯迪拉克", "雷克萨斯"]

# 结构：for 临时变量 in 数据集合:  然后缩进的循环体
for car in cars:
    print(car)

# 循环结束后，变量依然存在，保留最后一个值
print("循环结束后 car =", car)      # 雷克萨斯

# 循环体内的多行都属于循环
for car in cars:
    print("正在处理：", car)     # 执行 3 次
    print("处理完毕")             # 也执行 3 次
print("全部处理完毕")             # 只执行 1 次

# 缩进错误的后果：下面这段会报 IndentationError
# for car in cars:
# print(car)

示例 2：range 的四种形式

Python# range_demo.py —— range() 生成数字序列

print("range(5)：", list(range(5)))                # [0, 1, 2, 3, 4]
print("range(1, 6)：", list(range(1, 6)))          # [1, 2, 3, 4, 5]
print("range(2, 11, 2)：", list(range(2, 11, 2)))  # [2, 4, 6, 8, 10]
print("range(10, 0, -1)：", list(range(10, 0, -1)))# [10, ..., 1, 0]

# 关键：含起点不含终点
for i in range(1, 6):
    if i < 6:
        print(i, end=" ")
print()

# range(5) 等价于 range(0, 5)
print("两种写法相同：", list(range(5)) == list(range(0, 5)))

# len() 可以直接算 range 的长度，不必真的生成列表
print("range(1, 100) 有几个数：", len(range(1, 100)))      # 99

# 用 range 遍历列表下标
letters = ["a", "b", "c"]
for index in range(len(letters)):
    print(f"索引 {index} 的元素是 {letters[index]}")

# 更推荐的写法：enumerate
for index, letter in enumerate(letters):
    print(f"索引 {index} 的元素是 {letter}")

示例 3：常见循环搭档

Python# loop_helpers.py —— for 循环的三个高性价比搭档

letters = ["a", "b", "c"]

# 1）enumerate()：同时拿到下标和元素
for index, letter in enumerate(letters):
    print(f"第 {index} 位是 {letter}")

# start 参数可以指定下标起点
for index, letter in enumerate(letters, start=1):
    print(f"第 {index} 个是 {letter}")

# 2）zip()：同时遍历多个列表（长度不等时以最短的为准）
names = ["小明", "小红", "小刚"]
scores = [88, 95, 72, 100]#故意多一个
for name, score in zip(names, scores):
    print(f"{name} 得了 {score} 分")
# 小明 88 / 小红 95 / 小刚 72 —— 第 4 个分数因为没有对应名字被忽略

# 3）在循环里做条件筛选
for letter in letters:
    if letter in ["a", "c"]:
        print("找到元音：", letter)

# 累加器模式：循环最常见的用途
total = 0
for score in [88, 95, 72]:
    total += score# 等价于 total = total + score
print("总分：", total)         # 255

示例 4：列表推导式

Python# comprehension.py —— 列表推导式：传统写法 vs 一行写法

# 案例1：计算平方
# 传统写法
squares = []
for number in range(1, 6):
    squares.append(number ** 2)
print("传统写法：", squares)

# 推导式写法（完全等价）
squares = [number ** 2 for number in range(1, 6)]
print("推导式：", squares)          # [1, 4, 9, 16, 25]

# 案例2：筛选偶数
# 传统写法
evens = []
for number in range(1, 11):
    if number % 2 == 0:
        evens.append(number)
print("传统筛选：", evens)

# 推导式 + if 条件
evens = [number for number in range(1, 11) if number % 2 == 0]
print("推导式筛选：", evens)        # [2, 4, 6, 8, 10]

# 案例3：字符串统一大写
words = ["python", "is", "fun"]
print("大写：", [word.upper() for word in words])

# 案例4：三元表达式放进推导式
nums = [1, 2, 3, 4, 5, 6]
print("标记奇偶：", [("偶" if n % 2 == 0 else "奇") for n in nums])

# 什么时候不要用推导式：逻辑复杂时老老实实写循环
# 下面这种嵌套推导式虽然能跑，但没人看得懂：
# print([x * y for x in range(3) for y in range(3) if x != y])
# 可读性优先于行数。

示例 5：切片

Python# slicing.py —— 切片 list[start:stop:step]

letters = ["a", "b", "c", "d", "e", "f"]
print("原列表：", letters)

print("letters[:]      ", letters[:])       # 全部
print("letters[2:]     ", letters[2:])      # ['c','d','e','f']
print("letters[:3]     ", letters[:3])      # ['a','b','c']
print("letters[1:4]    ", letters[1:4])     # ['b','c','d']
print("letters[::2]    ", letters[::2])     # ['a','c','e']
print("letters[::-1]   ", letters[::-1])    # 反转
print("letters[-2:]    ", letters[-2:])     # ['e','f']
print("letters[-4:-1]  ", letters[-4:-1])   # ['c','d','e']

# 左闭右开：切片的秘密
# len(a[b:c]) == c - b，用这个公式快速预测结果
print("letters[2:5] 的长度：", len(letters[2:5]))    # 3 = 5 - 2

# 切片对字符串同样有效
url = "https://example.com/page"
print("协议：", url[:8])                # https://
print("主机名：", url[8:19])             # example.com
print("去掉末尾斜杠：", url.rstrip("/"))

# 切片是浅拷贝：外层是新的，内层元素还是同一批
matrix = [[1, 2], [3, 4]]
copy = matrix[:]
copy[0].append(99)
print("原matrix：", matrix)          # [[1, 2, 99], [3, 4]]  内层被影响！
print("copy：", copy)

# 深拷贝要显式 import copy
import copy
deep = copy.deepcopy(matrix)
deep[0].append(77)
print("深拷贝后原 matrix：", matrix)  # [[1, 2, 99], [3, 4]]  完全没变

示例 6：元组

Python# tuples.py —— 元组：不可修改的序列

# 创建元组：用圆括号，或者直接逗号
point = (3, 5)
colors = "red", "green", "blue"          # 不加括号也合法，但建议加括号
empty_tuple = ()
single = (5,)                             # 单元素元组必须带逗号！
not_tuple = (5)                           # 这其实是整数 5

print("point：", point, "类型：", type(point))
print("not_tuple：", not_tuple, "类型：", type(not_tuple))   # int！括号只是分组
print("single：", single, "类型：", type(single))            # tuple，正确

# 读取和切片都可以
print("point[0]：", point[0])              # 3
print("point[-1]：", point[-1])             # 5
print("切片：", point[:1])                  # (3,)

# 修改会报 TypeError
# point[0] = 9      # TypeError: 'tuple' object does not support item assignment

# 但可以"整体替换"
point = (9, 5)
print("整体替换后：", point)                # (9, 5)

# 元组没有 append/remove 方法
# point.append(1)   # AttributeError: 'tuple' object has no attribute 'append'

# 常用场景1：坐标
location = (116.40, 39.90)
print("经度：", location[0], "纬度：", location[1])

# 常用场景2：日期（年、月、日天然固定）
date = (2026, 10, 14)
year, month, day = date                    # 解包，一次取出三个值
print(f"{year}年{month}月{day}日")

# 常用场景3：字典的键必须是不可变类型，所以常用元组
locations = {(116.40, 39.90): "北京", (121.47, 31.23): "上海"}
print("北京坐标：", locations[(116.40, 39.90)])    # 北京
print("键的类型：", type((116.40, 39.90)))         # tuple

# 元组和列表可以互相转换
t = (1, 2, 3)
print("元组转列表：", list(t))               # [1, 2, 3]
print("列表转元组：", tuple([1, 2, 3]))        # (1, 2, 3)
