2.1 项目回顾：现在的代码里有什么（13.1）

单元 12 结束时，项目是三个文件：alien_invasion.py（主循环）、settings.py（设置）、ship.py（飞船）。本单元要往里加三样东西：子弹、外星人、游戏状态，于是项目长成了六个文件：

示例外星人入侵（单元 13 结束时）
├── alien_invasion.py   主循环 + 所有 _update/_check 方法（最忙的文件）
├── settings.py         所有会变的数值（新增子弹、外星人、舰队设置）
├── ship.py             飞船（新增：继承 Sprite、center_ship）
├── bullet.py           子弹（新增）
├── alien.py            外星人（新增）
└── game_stats.py       游戏统计信息（新增：ships_left、game_active）

先认清每个类的职责，后面才不容易晕：

类 一句话职责 关键属性/方法
Settings 存所有可调数值 bullet_speed、alien_speed、fleet_direction
Ship 飞船的位置和移动 moving_right、update()、center_ship()
Bullet 一颗子弹的位置和移动 rect、y、update()、draw_bullet()

注意一个规律：除了 Settings 和 GameStats，每个可见的东西都是一个类。屏幕上有几个「会自己动的东西」，就有几个类——这就是面向对象在游戏里的落地方式。

2.2 编组 Group 与精灵 Sprite：为什么不用普通列表 ★

本单元的核心工具是编组（Group）。新手的第一反应是：「子弹和外星人我用 list 装不就行了？」可以，但你会立刻遇到三堵墙：

  1. 批量更新：每颗子弹都要 update()，用列表得自己写 for bullet in self.bullets: bullet.update()；编组直接 self.bullets.update()，它替你遍历。
  2. 批量绘制：self.aliens.draw(self.screen) 一行画完整个舰队；用列表得自己写循环调 blit。
  3. 碰撞检测：groupcollide()、spritecollideany() 只认编组，列表没有这些方法。

生活化类比：编组像班长，精灵像学生。班长手里有一份名单，喊一声「所有人 update」，名单上每个人都动一下；喊一声「draw」，每个人都把自己画到黑板上。你要新增一个学生，只需 group.add(student)；要清空重来，group.empty() 一键搞定。

那什么是「精灵（Sprite）」？可以理解成参加过军训的学生：Pygame 要求被编组管理的对象必须继承 pygame.sprite.Sprite，并且有两样装备——

  • image：长相（一张表面，决定绘制时画什么）；
  • rect：站位（矩形，决定画在哪、碰撞时怎么比）。
Pythonimport pygame
from pygame.sprite import Sprite


class Bullet(Sprite):
    def __init__(self, ai_game):
        super().__init__()          # ★ 必须先调用，否则编组不认这个对象
        self.screen = ai_game.screen
        self.rect = pygame.Rect(0, 0, 3, 15)   # 装备一：站位
        # 子弹没有 image（它是个色块），所以不用 Group.draw()，改成手动画

★ 这里为什么难：super().__init__() 这行看起来「什么都没做」，但它是 Sprite 内部注册机制的一部分，漏掉它不会立刻报错，而是让你遇到「加进编组后 update() 不生效」这种诡异症状。记住：继承 Sprite 的类，__init__ 第一行永远是 super().__init__()。

编组常用方法一览：

方法 作用 本单元用在哪
group.add(obj) 加入一个精灵 开火时加入子弹、创建外星人
group.update() 全员执行 update() 每帧更新子弹和外星人
group.draw(surface) 全员把自己画到 surface 上 画外星舰队
group.sprites() 返回全员列表 遍历检查边缘、碰撞
group.copy() 返回副本 遍历时安全删除（见 2.3）
group.remove(obj) 移除一个精灵 删除消失的子弹
group.empty() 清空 重置游戏、击落全部外星人后

编组不是魔法，它替你做的那三件事用 40 行就能复现。看懂这个替身，你就再也不会问「为什么 list 不行」——尤其注意 spritecollideany() 的返回值：它返回的是那个精灵本身（直接拿去当条件判断），而不是 True：

Python# 编组替身：用 40 行看懂 Group 到底替你做了什么
class Group:
    """把一堆「有 rect 和 update() 的字典」当成一个整体管理。"""

    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def update(self):
        for item in self.items:          # ① 批量更新
            item["y"] += item["vy"]

    def draw(self):
        return [item["name"] for item in self.items]     # ② 批量绘制

    def empty(self):
        self.items.clear()

    def sprites(self):
        return list(self.items)


def spritecollideany(target, group):
    """③ 一个矩形 vs 整个编组：任意一个重叠就返回它，否则 None。"""
    for item in group.sprites():
        if (target["x"] < item["x"] + item["w"] and target["x"] + target["w"] > item["x"]
                and target["y"] < item["y"] + item["h"] and target["y"] + target["h"] > item["y"]):
            return item
    return None


bullets = Group()
for i in range(3):
    bullets.add({"name": f"bullet{i}", "x": 100 + i * 20, "y": 500, "w": 3, "h": 15, "vy": -3})

print("画一次编组：", bullets.draw())
bullets.update()
print("update 之后全员的 y：", [b["y"] for b in bullets.sprites()])
print("飞船撞上谁了：", spritecollideany(
    {"x": 120, "y": 480, "w": 48, "h": 48}, bullets))
print("躲开之后：", spritecollideany(
    {"x": 700, "y": 100, "w": 48, "h": 48}, bullets))
bullets.empty()
print("empty 之后还剩：", len(bullets.sprites()), "个")
print("普通 list 没有 update()/draw()/empty()，这就是编组存在的理由。")

跑出来是这样：draw() 返回 ['bullet0', 'bullet1', 'bullet2']，update() 后三颗子弹的 y 一起从 500 变成 497（因为 vy=-3），飞船撞上的是 bullet1（它的 x=120 正好和飞船重叠），躲开后 spritecollideany 返回 None，empty() 之后剩 0 个。一张「名单」加上三个批量方法，就是编组的全部。
