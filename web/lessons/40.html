完成本单元后，你应该能够：

  1. 用 class 定义类、在 __init__ 中初始化属性，并解释 self 到底是什么。

  3. 写出 __str__ 方法让对象能被人读懂地打印出来。
  4. 用继承创建子类，用 super().__init__() 调用父类初始化，并理解方法重写与多态。
  5. 独立设计一个包含继承的类层次结构，并修复 5 类高频类错误（见末尾错误清单）。
  6. 把类拆到独立模块，用 from car import Car / import car / as 三种方式取用。
  7. 用标准库 random 完成抽样与打乱，分清 choice / choices / sample / shuffle 的区别，并会用 seed() 复现结果。

二、核心知识点讲解

2.1 类：从"一堆变量"到"一类事物"

先看不用类的时候，一个"汽车"要占多少变量：

Pythoncar_make = "丰田"
car_model = "卡罗拉"
car_color = "红色"
car_year = 2020

car2_make = "本田"
car2_model = "雅阁"
car2_color = "蓝色"
car2_year = 2021
# 变量名越来越长，重复的劳动越来越多

而且如果你想让汽车"做点事"，还得写一堆名字别扭的函数：

Pythondef car1_describe(): ...
def car2_describe(): ...

类的本质是：给"同一类事物"造一个统一的模板。

生活化类比： - 类 = 建筑图纸（规定了所有房子有什么：几室几厅、什么材料） - 对象 = 按图纸盖出来的具体房子（小明家的房子、小红家的房子） - 属性 = 房子的固有特征（面积、楼层、朝向） - 方法 = 房子能做的事（开门、关灯）

一张图纸可以盖出无限多栋房子，而且每栋房子都自带"开门"这个能力——这就是类比函数的复用，但更强大：它复用的不只是"行为"，而是行为 + 数据打包在一起。

2.2 self：整个 Python 面向对象的核心

Pythonclass Dog:
    def __init__(self, name, age):
        self.name = name      # 把参数存到"这个对象自己身上"
        self.age = age


dog1 = Dog("旺财", 3)
dog2 = Dog("咪咪", 5)

self 到底是什么？ 它就是**"当前这个对象自己"**的引用。

生活化类比（最贴切的一个）：self 就像**"我自己"**这个词。

你在描述自己的时候会说"我今年 18 岁，我有 3 个爱好"。在类里： - self = 说话的那个人（"我"） - self.age = "我的年龄" - self.name = "我的名字"

所以：

Pythonself.name = name
# 左边：当前对象的名字属性
# 右边：传进来的参数值

为什么每个方法都必须写 self？ 因为一个类可以造出成千上万个对象，每个对象的属性值都不同。方法必须通过 self 知道"我现在操作的是哪一个对象"。

Pythondog1 = Dog("旺财", 3)
dog2 = Dog("咪咪", 5)

dog1.bark()      # 这个调用背后，Python 自动传入 dog1 作为 self
dog2.bark()      # 这里自动传入的是 dog2

实际上当你写 dog1.bark() 时，Python 自动做了 Dog.bark(dog1)。这个自动传递就是必须写 self 的唯一原因。

创建对象的完整过程：

Pythondog1 = Dog("旺财", 3)
# 背后发生：1) 创建一个空的 Dog 对象  2) 调用 __init__(这个空对象, "旺财", 3)
#           3) __init__ 里的 self 就指向那个空对象，于是属性被挂上去
