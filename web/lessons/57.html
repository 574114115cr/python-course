一、学习目标

完成本单元后，你应该能够：

  1. 一句话说出前 11 章每章的核心能力，说清它们之间的依赖关系。
  2. 遇到「用列表还是字典」「用继承还是组合」「用函数还是类」这类问题时，知道该按什么标准选。
  3. 独立完成 3 个综合项目中的任意一个，包含代码、数据持久化和测试。
  4. 通过关卡 1 的全部 4 条验收标准（见第六节）。
  5. 建立自己的「排错思路」，遇到报错时不慌、能定位到具体行。

二、核心知识点讲解

2.1 前 11 章的能力地图

把学过的内容按"能力"而不是"章节"重新组织，你会发现真正要做项目时，用的是这几条主线：

能力线 涉及章节 你已经会了什么
数据存取 第2章 str / int / float / bool、类型转换、f-string
批量处理 第3–4 章 列表、字典、for、while、切片、列表推导式
条件决策 第5 章 if/elif/else、逻辑运算、短路求值
重复抽象 第8 章 def、return、参数三种写法、作用域
数据建模 第9 章 class、__init__、self、继承、super()、多态
持久化 第10 章 with open、JSON、CSV
容错 第10 章 try/except/else/finally、raise
质量保障 第11 章 pytest、断言、参数化
工程基础 附录 A–D 环境、VS Code、Git、排错

最关键的一张依赖图（箭头表示"前者是后者的基础"）：

目录结构变量与类型
    ↓
列表 → 字典 ← for 循环 ──┐
    ↓                     │
  if 判断 ────────────────┤
    ↓                     │
  while 循环 ─────────────┤
    ↓                     ↓
  函数 ←─────────────── 类（继承）
    ↓                     ↓
  文件与异常 ←─────────────┘
    ↓
  测试（pytest）

一句话总结每个单元：环境能跑起来 → 数据能存住 → 批量能处理 → 条件能判断 → 循环能重复 → 代码能抽象 → 数据能建模 → 结果能持久 → 出错能容错 → 质量能验证。

2.2 六个"选什么"的高频决策

做项目时反复遇到的问题，答案都在这里：

场景 选择 判断依据
一组会变化的数据 列表 list 有顺序、会增删、按位置访问
按名字查找的映射 字典 dict 需要快速定位、键唯一
数量固定、值不会变 元组 tuple 如坐标、日期、配置
次数已知 for 能遍历一个序列
次数未知 / 依赖用户输入 while 条件为真就一直转
把一段逻辑命名复用 函数 行为，不需要状态
把数据 + 行为打包成"一类事物" 类 需要多个对象各持状态
"是一个"（is-a） 继承 Dog is a Animal
"有一个"（has-a） 组合 Car has an Engine
用逗号分隔的表格 CSV 能用 Excel 打开
有嵌套结构的数据 JSON 字典套列表、列表套字典
可能出错的操作 try/except 且要明确捕获异常类型
