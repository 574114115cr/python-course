完成本单元后，你应该能够：

  6. 用 plotly.express.scatter_geo() 画出全球地震散点图，说清 size、color、color_continuous_scale、hover_name 各控制什么。

二、核心知识点讲解

2.1 真实数据长什么样，去哪下载

前 15 个单元里，数据都是你自己写死的：scores = [92, 78, 65]——干净、整齐、随叫随到。从这一章开始，数据要从真实世界拿：

特点 玩具数据 真实数据
数量 三五条 几千上万行
质量 永远完整 有缺失、有异常
格式 你定的 别人定的，随时会变

类比：玩具数据像食堂里切好装盘的菜；真实数据像刚从菜地摘回来的菜——带着泥、有烂叶、大小不一。程序员的重要工作之一就是「洗菜」，本章就是教你洗菜。

本章处理两种最常见的真实数据格式：CSV（逗号分隔的表格，Excel 能直接打开）和 GeoJSON（带地理信息的 JSON，地震台网和地图服务的标准格式）。

教材数据去哪了。 第 16 章的代码会读这几个文件：

示例weather_data/sitka_weather_2021_simple.csv     # 锡特卡机场 2021 年气温
weather_data/death_valley_2021_simple.csv      # 死亡谷 2021 年气温（有缺失值）
eq_data/eq_data_1_day_m1.geojson               # USGS：一天内 M1 以上地震
eq_data/eq_data_30_day_m1.geojson              # USGS：30 天内 M1 以上地震

它们不在本仓库里（文件大，而且每年更新），要去教材配套资源站 https://ehmatthes.github.io/pcc_3e/ 打包下载，解压后把 chapter_16 里的 weather_data 和 eq_data 两个文件夹复制到你的项目目录。本讲义的所有示例都不依赖这些文件——先自己造小数据练手，拿到真数据后改个文件名就能用。

数据的真正来源。 气象数据来自美国 NOAA（国家海洋和大气管理局）的观测站网络；地震数据来自美国地质调查局（USGS），有实时 feed，可以自己下载最新数据：

示例USGS 地震数据 feed 列表页：
https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php

「过去一天、M1 以上」对应的实时数据：
https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/1.0_day.geojson

把第二个网址在浏览器里打开，看到的就是教材里 eq_data_1_day_m1.geojson 的「新鲜版」。教材数据是快照，你自己下载的永远是最新的——这就是「下载真实数据」的真正含义。

2.2 CSV：三件套读表头

教材的读取套路是「三件套」：Path.read_text() 读出全部文本 → splitlines() 切成行列表 → csv.reader() 逐行解析。真实 CSV 长这样（sitka 文件的前几行）：

示例"STATION","NAME","DATE","TAVG","TMAX","TMIN"
"USW00025333","SITKA AIRPORT, AK US","2021-01-01",,"44","40"
"USW00025333","SITKA AIRPORT, AK US","2021-01-02",,"44","35"

三个细节：每行一条记录、逗号分隔；字段带引号，但 csv.reader 会自动去掉；TAVG 那一列是空的（,,）——这就是后面要处理的缺失值。

Pythonfrom pathlib import Path
import csv

# 造一个小 CSV 代替教材数据（拿到真数据后换成 sitka_weather_2021_simple.csv）
path = Path("demo_weather.csv")
path.write_text(
    '"STATION","NAME","DATE","TAVG","TMAX","TMIN"\n'
    '"USW00025333","SITKA AIRPORT, AK US","2021-01-01",,"44","40"\n',
    encoding="utf-8")

lines = path.read_text(encoding="utf-8").splitlines()
reader = csv.reader(lines)
header_row = next(reader)      # 取出第一行（表头），reader 里剩下的就是数据

for index, column in enumerate(header_row):
    print(index, column)

# 正确姿势：先按列名找列号，再用变量取数据
column_index = {name: i for i, name in enumerate(header_row)}
print("DATE 在第", column_index["DATE"], "列")

为什么先取表头？ 表头告诉你每列是什么，但列的顺序不保证——今天 DATE 在第 2 列，明年 NOAA 调整格式可能就跑到第 3 列。所以教材反复强调：不要凭记忆写 row[2]，先用 enumerate 把列名和序号打出来，确认之后再写。 硬编码列号的程序，数据源一更新就会安静地取错列，或者干脆 IndexError。
