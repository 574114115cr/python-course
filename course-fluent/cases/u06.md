# 单元 6 综合案例 · Vector：一个类把「像内置类型」演一遍

> 打印、比较、哈希、取模、相加、格式化——先只写 `__repr__`，看它怎么处处不像话，再逐条补齐。

### 重构前（只够调试）

有 `__init__` 和 `__repr__`，能打印。但 `==` 比的是身份、`abs()` 不认识它、`+` 直接报错、进集合会重复：

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = float(x), float(y)

    def __repr__(self):
        return f"Vector({self.x:g}, {self.y:g})"


v = Vector(3, 4)
print(v)                              # Vector(3, 4)
print(v == Vector(3, 4))              # False：两个对象身份不同

try:
    abs(v)
except TypeError as e:
    print("abs 失败:", e)             # bad operand type for abs()

try:
    v + Vector(1, 1)
except TypeError as e:
    print("加法失败:", e)             # unsupported operand type(s) for +

print(len({Vector(3, 4), Vector(3, 4)}))   # 2：内容相同却算两个
print(f"{v}")                          # 走默认 __format__，等于 str(v)
```

### 重构后（把协议补全）

一次补齐表示、比较、哈希、数值、布尔与格式化。注意 `__eq__` 返回 `NotImplemented` 而不是抛异常，`__hash__` 必须和 `__eq__` 一起定义。

```python
import math


class Vector:
    __match_args__ = ("x", "y")

    def __init__(self, x, y):
        self.x, self.y = float(x), float(y)

    def __repr__(self):
        return f"Vector({self.x:g}, {self.y:g})"

    def __str__(self):
        return f"({self.x:g}, {self.y:g})"

    def __eq__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        return hash((self.x, self.y))

    def __abs__(self):
        return math.hypot(self.x, self.y)

    def __bool__(self):
        return bool(abs(self))

    def __format__(self, spec):
        if not spec:
            return str(self)
        return f"({format(self.x, spec)}, {format(self.y, spec)})"

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        return Vector(self.x * k, self.y * k)

    __rmul__ = __mul__

    def describe(self):
        match self:
            case Vector(0, 0):
                return "origin"
            case Vector(x, 0):
                return f"on x-axis at {x:g}"
            case Vector(0, y):
                return f"on y-axis at {y:g}"
            case Vector(x, y):
                return f"point ({x:g}, {y:g})"


v = Vector(3, 4)
print(repr(v), str(v), abs(v), bool(Vector(0, 0)))   # Vector(3, 4) (3, 4) 5.0 False
print(f"{v:.1f}", format(v, ""))                     # (3.0, 4.0) (3, 4)
print(v + Vector(1, 1), 2 * v, v * 2)                # Vector(4, 5) Vector(6, 8) Vector(6, 8)
print(len({v, Vector(3, 4), Vector(1, 1)}))          # 2
print(Vector(0, 2).describe())                       # on y-axis at 2
```

### 差异说明

| 问题 | 重构前 | 重构后 | 收益 | 代价 |
|---|---|---|---|---|
| 相等 | 身份比较，内容相同也不等 | `__eq__` 逐分量比较 | 可断言、可去重 | 必须同时处理 `NotImplemented` |
| 哈希 | 继承 `object.__hash__`，与 `==` 不一致 | 基于 `(x, y)` | 能进 set/dict，且与相等自洽 | 对象从此不能当可变键 |
| 取模 | `abs()` 报错 | `__abs__` 用 `hypot` | 与内置数值类型行为一致 | 多一次平方和开方 |
| 布尔 | 任何实例都为真 | 零向量为假 | `if v:` 有物理意义 | 与直觉可能相反，要写文档 |
| 加法 | 报错 | `__add__` + 类型检查 | 可组合、可链式 | 每个运算符都要写一遍 |
| 交换律 | 不存在 | `__rmul__ = __mul__` | `2 * v` 也能用 | 需要知道反射方法机制 |
| 格式化 | 只有默认 | `__format__` 支持 spec | f-string 可控 | spec 会同时作用于两个分量，`>12` 不能整体对齐 |
| 模式匹配 | 不支持 | `__match_args__` | `case Vector(x, 0)` 可直接解构 | 位置顺序一旦定下不能随便改 |
