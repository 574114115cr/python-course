# 单元 12 综合案例 · 迷你校验框架：把 if 校验收进描述符

> 两个模型、五条规则，先写成一堆 if，再看它怎么随字段增长失控，最后用描述符 + 子类注册收掉。

### 重构前（每个模型各写一遍校验）

字段校验写在 `__init__` 里，字段名重复出现三次（签名、检查、赋值）；新增一个模型就得复制一遍规则；拼错字段名不会有任何提示。

```python
class ValidationError(ValueError):
    pass


class User:
    def __init__(self, name, age, email=None):
        if not name:
            raise ValidationError("name is required")
        if not isinstance(age, int) or age < 0:
            raise ValidationError("age must be a non-negative int")
        if email is not None and "@" not in email:
            raise ValidationError("email looks invalid")
        self.name, self.age, self.email = name, age, email

    def to_dict(self):
        return {"name": self.name, "age": self.age, "email": self.email}


class Article:
    def __init__(self, title, views, email=None):
        if not title:
            raise ValidationError("title is required")
        if not isinstance(views, int) or views < 0:
            raise ValidationError("views must be a non-negative int")
        self.title, self.views, self.email = title, views, email

    def to_dict(self):
        return {"title": self.title, "views": self.views, "email": self.email}


print(User("Ann", 30).to_dict())
print(Article("Post", 3).to_dict())

for bad in [lambda: User("", 1), lambda: User("A", -1), lambda: User("A", 1, "nope")]:
    try:
        bad()
    except ValidationError as e:
        print("rejected:", e)

u = User("Ann", 30)
u.name = ""                       # 绕过校验直接改
print("改成空名也成功:", u.to_dict())
```

### 重构后（描述符声明规则 + 子类自动注册）

字段是 `Field` 的类属性，规则写在字段上；`Model.__init_subclass__` 自动把子类登记进注册表；`__init__(**data)` 遍历字段统一赋值，顺带拒绝未知字段。

```python
class ValidationError(ValueError):
    pass


class Field:
    def __init__(self, *, required=True, min_value=None, contains=None):
        self.required = required
        self.min_value = min_value
        self.contains = contains

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, owner=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        empty = value is None or (isinstance(value, str) and not value.strip())
        if empty:
            if self.required:
                raise ValidationError(f"{self.name} is required")
            obj.__dict__[self.name] = value
            return
        if self.min_value is not None and value < self.min_value:
            raise ValidationError(f"{self.name} must be >= {self.min_value}")
        if self.contains is not None and self.contains not in value:
            raise ValidationError(f"{self.name} must contain {self.contains!r}")
        obj.__dict__[self.name] = value


class Model:
    registry = {}

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        Model.registry[cls.__name__] = cls

    def __init__(self, **data):
        for name in type(self).fields():
            setattr(self, name, data.pop(name, None))
        if data:
            raise ValidationError(f"unknown fields: {sorted(data)}")

    @classmethod
    def fields(cls):
        found = {}
        for klass in reversed(cls.__mro__):
            for key, value in vars(klass).items():
                if isinstance(value, Field):
                    found[key] = value
        return found

    def to_dict(self):
        return {name: getattr(self, name) for name in type(self).fields()}


class User(Model):
    name = Field()
    age = Field(min_value=0)
    email = Field(required=False, contains="@")


class Article(Model):
    title = Field()
    views = Field(min_value=0)


print(sorted(Model.registry))                  # ['Article', 'User']
print(User(name="Ann", age=30).to_dict())
print(Article(title="Post", views=3).to_dict())

for kwargs in [{"name": "", "age": 1},
               {"name": "A", "age": -1},
               {"name": "A", "age": 1, "email": "nope"},
               {"name": "A", "age": 1, "nick": "x"}]:
    try:
        User(**kwargs)
    except ValidationError as e:
        print("rejected:", e)

u = User(name="Ann", age=30)
try:
    u.name = ""
except ValidationError as e:
    print("赋空值也被拦:", e)          # 数据描述符优先级高于实例字典
```

### 差异说明

| 问题 | 重构前 | 重构后 | 收益 | 代价 |
|---|---|---|---|---|
| 规则位置 | 写在 `__init__` 里 | 写在字段声明上 | 规则一眼可见，可复用 | 需要理解描述符协议 |
| 新增模型 | 复制一段校验 | 继承 `Model`，声明字段 | 不重复、不漏校验 | 子类只能多字段，不能改协议 |
| 绕过校验 | `u.name = ""` 直接改 | `__set__` 拦截 | 任何赋值路径都受控 | 数据描述符优先级会挡住实例字典 |
| 字段名 | 三处重复，拼错才发现 | `__set_name__` 自动取 | 不会写错名字 | 描述符实例不能跨类共享 |
| 未知字段 | 静默忽略 | 抛 `ValidationError` | 拼错立刻暴露 | 需要 `**data` 的调用约定 |
| 继承 | 不存在 | `fields()` 走 MRO 合并 | 父类字段自动带上 | MRO 里同名字段要定覆盖规则 |
| 性能 | 直接赋值 | 每次赋值过一次 `__set__` | 换来确定性 | 高频热路径有开销 |

### 再往前一步

给 `Field` 加 `default`、`converter`（如 `int`）和 `choices`，校验就从「单字段」升级到「模型级」跨字段规则（`start <= end`）；再把 `to_dict` 换成 `to_row()` / `from_row()`，这套东西就是 ORM 的雏形。注意 pydantic v2 的核心已改成 Rust 实现——纯 Python 描述符版更容易读懂，但性能差一个数量级。
