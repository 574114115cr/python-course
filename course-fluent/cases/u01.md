# 单元 1 综合案例 · 从「能跑」到「好用」的 Deck

> 同一个牌堆，先写只够演示的版本，再补成能进真实代码的版本。

### 重构前（能跑但粗糙）

只实现 `__len__` 和 `__getitem__`。`len`、索引、切片都能用，但三个操作会立刻露馅：`in` 退化成逐个比较、`reversed` 依赖 C 层回退、`random.shuffle` 直接报错。

```python
import random


class Deck:
    ranks = [str(n) for n in range(2, 11)] + list("JQKA")
    suits = "spades diamonds clubs hearts".split()

    def __init__(self):
        self._cards = [(r, s) for s in self.suits for r in self.ranks]

    def __len__(self):
        return len(self._cards)

    def __getitem__(self, i):
        return self._cards[i]


deck = Deck()
print(len(deck))                       # 52
print(deck[0])                         # ('2', 'spades')
print(("A", "hearts") in deck)         # True，但走了 52 次比较
print(list(reversed(deck))[:2])        # 靠 len + getitem 倒着取

try:
    random.shuffle(deck)
except TypeError as e:
    print("shuffle 失败:", e)          # 没有 __setitem__，改不了元素
```

### 重构后（可直接用）

补上四个协议方法，外加一个「抽 n 张返回新牌堆」的业务方法。注意 `__iter__` 返回的是**迭代器**而不是 `self`，否则牌堆会被用成一次性迭代器。

```python
import random


class Deck:
    ranks = [str(n) for n in range(2, 11)] + list("JQKA")
    suits = "spades diamonds clubs hearts".split()

    def __init__(self, cards=None):
        self._cards = list(cards) if cards is not None else [
            (r, s) for s in self.suits for r in self.ranks]

    def __len__(self):
        return len(self._cards)

    def __getitem__(self, i):
        return self._cards[i]

    def __contains__(self, card):
        return card in self._cards

    def __iter__(self):
        return iter(self._cards)

    def __reversed__(self):
        return reversed(self._cards)

    def __eq__(self, other):
        if not isinstance(other, Deck):
            return NotImplemented
        return self._cards == other._cards

    def pick(self, n=1):
        """抽走 n 张，返回新牌堆；原牌堆不变。"""
        picked = random.sample(self._cards, n)
        rest = [c for c in self._cards if c not in picked]
        return Deck(rest), Deck(picked)

    def shuffle(self):
        random.shuffle(self._cards)
        return self


deck = Deck()
print(len(deck), deck[0], ("A", "hearts") in deck)
print(list(reversed(deck))[:1])        # [('A', 'hearts')]

rest, hand = Deck().shuffle().pick(3)
print(len(rest), len(hand), len(rest) + len(hand))   # 49 3 52
print(Deck([("A", "hearts")]) == Deck([("A", "hearts")]))   # True
```

### 差异说明

| 问题 | 重构前 | 重构后 | 收益 | 代价 |
|---|---|---|---|---|
| 成员判断 | 没有 `__contains__`，`in` 逐个比较 | 显式实现 | 语义清楚，可换 O(1) 结构 | 多 4 行代码 |
| 反向遍历 | 靠 `len` + `__getitem__` 的 C 层回退 | 实现 `__reversed__` | 不依赖对象可索引 | 必须先想清楚「反向」的语义 |
| 洗牌 | 没有 `__setitem__`，`shuffle` 直接抛错 | 提供 `shuffle()` 方法改内部列表 | 不暴露可变接口就能打乱 | 调用方不能对 Deck 下标赋值 |
| 相等判断 | 默认按身份比较，两个内容相同的牌堆不相等 | `__eq__` 逐张比较 | 可进集合、可断言 | 必须同时想 `__hash__`（可变对象不该有） |
| 抽牌 | 只能自己 `deck[i]`，容易和洗牌混在一起 | `pick(n)` 返回两个新牌堆 | 不可变风格，便于测试 | 每次复制列表，牌多时有开销 |
| 迭代器 | 若 `__iter__` 返回 `self`，只能遍历一次 | 返回 `iter(self._cards)` | 可重复遍历、可嵌套 | 无 |

### 再往前一步

把 `_cards` 换成 `frozenset` 索引 + `tuple` 顺序，`__contains__` 就变成 O(1)；或者把 `pick` 改成返回生成器，让「抽牌」也能惰性消费。真要做牌类游戏，牌堆应该是**不可变的值对象**，所有操作返回新牌堆——这样撤销和回放都不用额外记录状态。
