> 原书第 1 章靠一个 `Vector` 从 20 行长到 200 行，把特殊方法讲完。这里保留它的骨架：一个类同时具备表示、比较、哈希、求模、算术、索引、切片、迭代。

## 程序

```python
import math


class Vector:
    """二维向量：一个类覆盖原书第 1 章的主要特殊方法。"""

    def __init__(self, x=0.0, y=0.0):
        self.x, self.y = float(x), float(y)

    # ① 表示：__repr__ 给开发者看，__str__ 给用户看
    def __repr__(self):
        return f"Vector({self.x:g}, {self.y:g})"

    def __str__(self):
        return f"({self.x:g}, {self.y:g})"

    # ② 比较：__eq__ 按值比较；__hash__ 必须跟着一起定义
    def __eq__(self, other):
        return tuple(self) == tuple(other) if isinstance(other, Vector) else NotImplemented

    def __hash__(self):
        return hash((self.x, self.y))

    # ③ 数值协议：__abs__ 让 abs() 直接可用
    def __abs__(self):
        return math.hypot(self.x, self.y)

    def __bool__(self):
        return bool(abs(self))

    # ④ 算术：__add__ 与 __mul__，返回新对象而不是原地改
    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        return Vector(self.x * k, self.y * k)

    __rmul__ = __mul__

    # ⑤ 序列协议：__len__ + __getitem__ 就够切片、迭代、in、reversed
    def __len__(self):
        return 2

    def __getitem__(self, i):
        if isinstance(i, slice):
            return Vector(*[self.x, self.y][i])
        return (self.x, self.y)[i]

    def __iter__(self):
        yield self.x
        yield self.y


v = Vector(3, 4)
w = Vector(1, 2)

print("repr   ", repr(v))
print("str    ", str(v))
print("abs    ", abs(v))
print("bool   ", bool(Vector()), bool(v))
print("add    ", v + w)
print("mul    ", v * 2, "| rmul", 2 * v)
print("equal  ", v == Vector(3, 4), v == w)
print("hash   ", len({v, Vector(3, 4), w}), "个不同元素")
print("index  ", v[0], v[1])
print("slice  ", v[0:2], "| 切片返回新对象：", v[0:2] is not v)
print("iter   ", [round(t, 1) for t in v], "| 可解包", end=" ")
a, b = v
print(a, b)
print("in     ", 3.0 in v, 9.0 in v)
print("len    ", len(v))
try:
    sorted([Vector(3, 4), Vector(1, 2)])
except TypeError as e:
    print("sorted ", "TypeError:", str(e)[:38])
```

## 逐段走读

1. **`__repr__` 与 `__str__` 分开写。** `repr` 的目标是「复制回终端能重建对象」，所以写成 `Vector(3, 4)`；`str` 给用户看，写成 `(3, 4)`。只写 `__repr__` 时 `print()` 也会用它，但反过来不成立——只写 `__str__` 会让交互式环境里的对象显示成 `<Vector object at 0x…>`。

2. **`__eq__` 返回 `NotImplemented` 而不是 `False`。** 当对方不是 `Vector` 时，把决定权交回给 Python，它再去试对方的 `__eq__`。写 `False` 会让 `Vector(3,4) == 某对象` 永远为假，连对方自定义的相等逻辑都跑不到。

3. **`__eq__` 与 `__hash__` 成对出现。** 一旦定义了 `__eq__`，Python 会把 `__hash__` 置为 `None`，对象立刻不可哈希。这里显式按 `(x, y)` 求哈希，于是两个值相等的向量在 `set` 里只留一个——上面的 `len({v, Vector(3,4), w})` 输出 2 就是这个原因。

4. **`abs()` 与 `bool()` 是两件事。** `__abs__` 返回模长（标量），`__bool__` 返回真假。没有 `__bool__` 时 Python 会退回去看 `__len__`，所以空向量必须让 `__len__` 或 `__bool__` 至少一个说「假」。

5. **算术返回新对象。** `__add__` 不修改 `self`，这是值类型的基本约定；`__mul__` 同时赋给 `__rmul__`，于是 `2 * v` 也能用——左操作数不认识 `Vector` 时，Python 会来找右操作数的 `__rmul__`。

6. **`__len__` + `__getitem__` ≈ 序列。** 只要这两个方法存在，`in`、迭代、`reversed`、`list()` 都能工作；`__iter__` 只是让迭代更快、语义更明确。切片走 `__getitem__` 的 `slice` 分支，这里返回**新对象**而不是视图，和 tuple 一致。

7. **`sorted` 没有 `__lt__` 就不能排。** 最后一段故意试了一次：`sorted` 比较两个 `Vector` 时找不到 `__lt__`，抛 `TypeError`。程序里用 `try` 抓住它并打印出来——这正是「只实现需要的协议」的另一面：没实现的那一半会明确报错，而不是悄悄给出错误答案。

## 跑通之后改三处

- 把 `__eq__` 里的 `tuple(self)` 换成 `id(self)`：`v == Vector(3, 4)` 会变成 `False`，同时解释为什么 `hash` 也要跟着改成 `id`。
- 删掉 `__hash__`：`{v, Vector(3,4)}` 那一行立刻抛 `TypeError: unhashable type`。
- 给 `__getitem__` 的 `slice` 分支改成 `return [self.x, self.y][i]`（返回 list）：切片仍然能用，但 `v[0:2] + w` 会因为类型不同而崩——这就是「返回同类型」为什么重要。
