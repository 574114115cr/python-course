@@u12|元编程：描述符、类钩子与动态建类
> 原书第 22–24 章讲动态属性、描述符与类元编程。这一篇写一个 40 行的迷你 ORM：字段校验靠描述符，字段收集靠 `__init_subclass__`，打印靠类装饰器，最后用 `type()` 现场造一个类。

## 程序

```python
# ① 描述符：把「校验 + 存取」从每个类里抽出来
class Field:
    def __init__(self, kind, default=None):
        self.kind, self.default, self.name = kind, default, None

    def __set_name__(self, owner, name):        # 类创建时自动调用
        self.name = name
        self.storage = f"_{name}"

    def __get__(self, obj, owner=None):
        if obj is None:                          # 通过类访问，返回描述符本身
            return self
        return getattr(obj, self.storage, self.default)

    def __set__(self, obj, value):
        if not isinstance(value, self.kind):
            raise TypeError(f"{self.name} 需要 {self.kind.__name__}，"
                            f"收到 {type(value).__name__}")
        setattr(obj, self.storage, value)


# ② __init_subclass__：子类定义好时自动收集字段
class Model:
    fields = {}

    def __init_subclass__(cls, **kw):
        super().__init_subclass__(**kw)
        cls.fields = {k: v for k, v in vars(cls).items() if isinstance(v, Field)}

    def __init__(self, **data):
        for k, f in self.fields.items():
            setattr(self, k, data.get(k, f.default))

    def to_dict(self):
        return {k: getattr(self, k) for k in self.fields}


# ③ 类装饰器：补一个 __repr__，不改子类代码
def printable(cls):
    def __repr__(self):
        body = ", ".join(f"{k}={getattr(self, k)!r}" for k in self.fields)
        return f"{type(self).__name__}({body})"
    cls.__repr__ = __repr__
    return cls


@printable
class User(Model):
    name = Field(str)
    age = Field(int, 0)


@printable
class Product(Model):
    title = Field(str)
    price = Field(float, 0.0)


u = User(name="Ada", age=36)
p = Product(title="键盘", price=299.0)
print("实例    ", u)
print("字段表  ", {c.__name__: list(c.fields) for c in (User, Product)})
print("to_dict ", u.to_dict())
print("校验    ", end="")
try:
    User(name="Bob", age="老")
except TypeError as e:
    print(e)
print("默认值  ", Product(title="鼠标").price)

# ④ 通过类访问描述符，拿到的是描述符本身
print("类访问  ", type(User.age).__name__, "| 实例访问", type(u.age).__name__)

# ⑤ type() 动态建类：等价于 class 语句
def greet(self):
    return f"你好，{self.name}"


Dynamic = printable(type("Dynamic", (Model,), {
    "name": Field(str),
    "__doc__": "运行时拼出来的类",
    "greet": greet,
}))
d = Dynamic(name="动态")
print("动态类  ", d, "|", d.greet(), "| 是 Model 子类？", issubclass(Dynamic, Model))

# ⑥ __getattr__ 兜底：只在正常查找失败后调用
class Lazy:
    def __getattr__(self, name):
        print(f"  （兜底生成 {name}）")
        return lambda *a: f"{name}{a}"


lz = Lazy()
print("兜底    ", lz.render(1, 2))
print("正常属性", lz.__class__.__name__, "（已有属性不会触发 __getattr__）")
```

## 逐段走读

1. **描述符是「把属性访问变成代码」的钩子。** `Field.__get__`/`__set__` 让 `user.age = "老"` 先经过类型校验。关键前提是**描述符必须是类属性**：写在类体里的是「数据描述符」，写在实例上则完全不起作用。

2. **`__set_name__` 解决「描述符不知道自己的名字」。** 类创建时 Python 会自动调用每个描述符的 `__set_name__(owner, name)`，于是 `Field` 能知道自己是 `age` 还是 `name`，并用 `_age` 这样的私有名存值。没有它就得在 `__init__` 里手工传名字，容易漏。

3. **`__get__(None, owner)` 是「通过类访问」。** `User.age` 返回描述符对象本身（所以能看它的配置），`u.age` 返回真正的值。这个双分支是描述符的标准写法，classmethod/staticmethod/property 内部都是这个机制。

4. **`__init_subclass__` 是「类定义完成时的回调」。** 每个继承 `Model` 的子类创建时都会执行一次，把类体里的 `Field` 收集进 `fields`。它比元类轻——不需要 `metaclass=`，也不影响 MRO，是最常用的「注册表」钩子。

5. **类装饰器与 `__init_subclass__` 的分工。** 前者在外面加工类（加 `__repr__`），后者在父类里响应子类创建。两者都不需要修改子类源码，但类装饰器的顺序更明确（定义完立刻执行），也更适合「一次性注入」。

6. **`type("Name", bases, namespace)` 与 `class` 语句完全等价。** 第五段拼出来的 `Dynamic` 是真正的 `Model` 子类，描述符、`to_dict`、`greet` 全部可用；再套上同一个 `@printable`，连 `__repr__` 都和 `class` 写出来的版本一致。所有 `class` 语句在 CPython 里最终都走这一步——元类就是在这一层介入的。

7. **`__getattr__` 只在「正常查找失败」后调用。** 它不拦截已经存在的属性，也不拦截 `__getattribute__` 能找到的东西。用它做兜底（代理、懒加载）很合适，但别在里面写递归——`self.x` 找不到会再次触发它。

## 跑通之后改三处

- 删掉 `__set_name__`：`Field.name` 为 `None`，校验报错信息变成「None 需要 str」，存取也全部失效。
- 把 `User.age` 改成 `Field(str)`：`User(name="Ada", age=36)` 立刻抛 `TypeError`。
- 把 `@printable` 去掉：`print(u)` 输出 `<User object at 0x…>`，验证装饰器确实注入了 `__repr__`。
