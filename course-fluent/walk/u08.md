@@u08|运算符重载与类型进阶：让 Money 像数字一样工作
> 原书第 16 章讲重载运算符的规则，第 15 章讲类型变量与泛型。这一篇用同一个类把两边接起来：既让 `+` `*` `-` 说得通，也用 `TypeVar` 与 `@overload` 把签名写准。

## 程序

```python
from __future__ import annotations

from decimal import Decimal
from typing import Iterable, TypeVar

T = TypeVar("T", bound="Money")


class Money:
    __slots__ = ("amount", "currency")

    def __init__(self, amount, currency="CNY"):
        self.amount = Decimal(str(amount)).quantize(Decimal("0.01"))
        self.currency = currency

    def __repr__(self):
        return f"Money({self.amount}, '{self.currency}')"

    # ① 同类相加：返回新对象
    def __add__(self: T, other: T) -> T:
        self._check(other)
        return Money(self.amount + other.amount, self.currency)

    # ② 反向加法：0 + money 时 Python 会来找这里，sum() 的起点就是 0
    def __radd__(self, other):
        if other == 0:
            return self
        return self + other

    # ③ 原地加法：可变对象才需要；值对象直接复用 __add__
    def __iadd__(self, other):
        return self + other

    # ④ 减法与取负：一元运算符不带 other
    def __sub__(self, other):
        self._check(other)
        return Money(self.amount - other.amount, self.currency)

    def __neg__(self):
        return Money(-self.amount, self.currency)

    # ⑤ 乘法：支持 Money * 数 与 数 * Money
    def __mul__(self, k):
        if not isinstance(k, (int, float, Decimal)):
            return NotImplemented
        return Money(self.amount * Decimal(str(k)), self.currency)

    __rmul__ = __mul__

    # ⑥ 比较：同类比金额，不同类返回 NotImplemented
    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return (self.amount, self.currency) == (other.amount, other.currency)

    def __lt__(self, other):
        self._check(other)
        return self.amount < other.amount

    def __hash__(self):
        return hash((self.amount, self.currency))

    def _check(self, other):
        if not isinstance(other, Money):
            raise TypeError(f"不能和 {type(other).__name__} 运算")
        if other.currency != self.currency:
            raise ValueError(f"币种不同：{self.currency} vs {other.currency}")


# ⑦ 泛型函数：TypeVar 让「返回同类型」这件事被类型检查器看见
def total(items: Iterable[T]) -> T:
    items = list(items)
    acc = items[0]
    for x in items[1:]:
        acc = acc + x
    return acc


a, b, c = Money("19.99"), Money("0.01"), Money(100)
print("加      ", a + b)
print("零加    ", 0 + a, "| 反向；sum 也能用了", sum([a, b, c]))
print("原地    ", end="")
a += b
print(a)
print("减与负  ", c - b, "|", -b)
print("乘      ", b * 3, "|", 3 * b)
print("比较    ", b < a, "| 相等", a == Money("20.00"), "| 不同类型", a == 20)
print("求和    ", total([a, b, c]))

try:
    a + Money(1, "USD")
except ValueError as e:
    print("币种    ", e)
try:
    a + 1
except TypeError as e:
    print("类型    ", e)

# ⑧ 精度：Decimal 而不是 float
print("精度    ", Money("0.1") + Money("0.2"))
print("float   ", 0.1 + 0.2)
print("哈希集合", len({b, Money("0.01")}), "个不同元素")
```

## 逐段走读

1. **重载运算符的第一条规则：语义要对得上。** `+` 应该表示「合并」，`*` 表示「缩放」，所以 `Money + Money` 合理、`Money + int` 不合理。这条不是风格问题——违反直觉的 `+` 会让调用方无法推理，最终没人敢用这个类。

2. **`__radd__` 处理「左边不认识你」的情况。** 写 `0 + a` 时，`int.__add__(0, a)` 返回 `NotImplemented`，Python 转去调 `a.__radd__(0)`。这里对 `other == 0` 特判返回 `self`——因为内置 `sum()` 的起点就是 `0`，不特判的话 `sum([a, b, c])` 会拿 `Money + int` 直接报错。减法就不能这么偷懒。

3. **`__iadd__` 对不可变值对象可以退化成「返回新对象」。** `a += b` 会先试 `__iadd__`，拿到的返回值重新绑定给 `a`。值对象不需要真的原地改，所以返回 `self + other` 就够了——但要记得写 `return`，忘了返回会得到 `None`。

4. **`__eq__` 返回 `NotImplemented` 让比较「可协商」。** `a == 20` 最终是 `False`，但路径是：`Money.__eq__` 返回 `NotImplemented` → Python 试 `int.__eq__(20, a)` → 也是 `NotImplemented` → 回退到 `is` 比较 → `False`。如果这里直接 `return False`，别人写的 `int` 子类就永远没机会参与比较。

5. **`Decimal(str(x))` 是金额的底线。** `Decimal(0.1)` 会把浮点的二进制误差一起带进来，`Decimal("0.1")` 才是十进制意义上的 0.1。输出里 `0.1 + 0.2` 的对比（`Decimal` 得 0.30、float 得 0.30000000000000004）就是为什么金额不能用 float。

6. **`TypeVar("T", bound="Money")` 让泛型函数保住返回类型。** `total([a, b, c])` 的静态类型是 `Money`，而不是 `Any` 或 `object`。`__add__` 上写 `self: T, other: T) -> T` 也是同一目的——让类型检查器知道「加完还是 Money」，链式调用才不会丢类型。

7. **`__slots__` 与 `__hash__` 让值对象能当字典键。** 两个金额与币种相同的 `Money` 哈希相同、相等为真，所以 `{b, Money("0.01")}` 只有一个元素。这也是 dataclass 那篇里 `frozen=True` 做的事情的手写版。

## 跑通之后改三处

- 把 `__eq__` 里的 `NotImplemented` 改成 `False`：`a == 20` 结果不变，但再写一个 `class MyInt(int)` 并自定义相等，你会发现它永远不生效。
- 把 `Decimal(str(amount))` 改成 `Decimal(amount)`：传入 `0.1` 时会看到 `0.1000000000000000055511151231257827`。
- 删掉 `__hash__`：定义过 `__eq__` 后它自动变成 `None`，最后一行抛 `TypeError: unhashable type`。
