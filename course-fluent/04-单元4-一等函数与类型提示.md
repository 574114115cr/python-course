# 单元 4 · 一等函数与类型提示

> 教材第 7–8 章 ｜ 4 节课 × 90 分钟 ｜ 建议 1–2 周

## 单元导入

在很多语言里，函数只是「可调用的语法结构」；在 Python 里，函数是对象：有身份、有属性、能赋值、能当参数、能当返回值、能存进容器。这一条决定了 `sorted(key=...)`、装饰器、回调、策略模式全都成立。

第二件事是类型提示。它不是运行时检查，而是给编辑器、mypy、pyright 看的「可执行的文档」。用得好，重构时能提前发现 80% 的低级错误；用不好，会写出一堆 `Any` 和 `# type: ignore`。

学完本单元，你应该能：

- 把函数当值传递，写出高阶函数和可调用对象；
- 熟练使用仅限位置、仅限关键字、`*args`、`**kwargs` 四类参数；
- 给公开 API 写全注解，并让 mypy 在 strict 模式下通过；
- 知道类型系统的边界：哪些错误它抓不到，必须靠测试。

## 第 13 课 · 函数是对象：高阶函数与可调用对象

> 本节目标：能把函数赋值、传参、返回、存容器，并说明 `sorted(key=...)` 与 `functools.reduce` 的工作原理。

### 讲解

函数对象有 `__name__`、`__doc__`、`__annotations__`，也能被赋值和传递：

```python
def shout(text):
    """把文本转成大写并加感叹号。"""
    return text.upper() + "!"

f = shout
print(f.__name__, f.__doc__)
print(list(map(f, ["hi", "ok"])))     # ['HI!', 'OK!']
```

「接收函数或返回函数」的函数叫高阶函数。`sorted` 的 `key` 就是典型：

```python
words = ["banana", "apple", "fig"]
print(sorted(words, key=len))              # 按长度
print(sorted(words, key=str.lower, reverse=True))   # 忽略大小写降序
```

内置的 `map`、`filter` 返回迭代器，`functools.reduce` 做归约：

```python
from functools import reduce
from operator import add

nums = [1, 2, 3, 4]
print(reduce(add, nums))          # 10
print(sum(nums))                  # 10，能用 sum 就别用 reduce
```

任何实现了 `__call__` 的实例也是可调用对象，适合「带状态的函数」：

```python
class Counter:
    def __init__(self):
        self.n = 0

    def __call__(self, step=1):
        self.n += step
        return self.n

c = Counter()
print(c(), c(5), c.n)             # 1 6 6
```

### 延伸：可调用对象有九类

`callable()` 为真的东西不止「函数」：

1. 普通函数　2. lambda　3. 类（调用即构造）　4. 定义了 `__call__` 的实例　5. 生成器函数　6. 协程函数　7. 内置函数 / 内置方法（`len`、`print`）　8. 绑定方法 / 类方法 / 静态方法　9. `functools.partial` 对象

```python
def f(): pass
class C:
    def __call__(self): return "called"
    def m(self): return "m"
print([callable(x) for x in (f, C, C(), C.m, C().m, len, print)])   # 全 True
```

判断「是不是函数」要用 `inspect.isfunction`；`callable` 只回答「能不能加括号」。这条区别在写参数校验时很关键：你要求的是「可回调」，不是「函数」，用 `callable` 才对，用 `isinstance(x, types.FunctionType)` 会把类实例、`partial` 全挡掉。

### 关键点

- **`key=` 接收的是函数，不是比较结果**：写 `key=len`，不要写 `key=len(x)`。
- **`operator` 模块比 lambda 更清晰**：`itemgetter("name")`、`attrgetter("score")`、`add`。
- **`map`/`filter` 是惰性的**，返回迭代器，需要 list 时显式转换。
- **可调用对象能保存状态**，但别滥用；能用闭包或 dataclass 表达时优先考虑可读性。

### 动手

1. 用 `sorted` + `operator.itemgetter` 对一份字典列表按两个字段排序。
2. 写一个 `compose(f, g)`，返回 `lambda x: f(g(x))`，并用它组合 `str.strip` 与 `str.upper`。
3. 用可调用类实现一个带计数的 `Tagger`，每调用一次返回 `tag-1`、`tag-2`……

### 验收清单

- [ ] 能解释「函数是一等对象」在 `sorted(key=...)` 中的体现
- [ ] 会用 `operator` 替代简单 lambda
- [ ] 知道可调用对象与闭包各自的适用场景

## 第 14 课 · 参数形态：位置、关键字与可变参数

> 本节目标：能写出带 `/` 和 `*` 的函数签名，正确解包 `*args`/`**kwargs`，并用 `inspect.signature` 检查契约。

### 讲解

Python 的参数分为五类，顺序固定：

```python
def func(a, b, /, c, d, *args, e, f=1, **kwargs):
    ...
```

- `a, b`：仅限位置（`/` 之前），不能用 `func(a=1)` 调用；
- `c, d`：位置或关键字；
- `*args`：多余位置参数，打包成 tuple；
- `e`：仅限关键字（`*` 之后），必须写 `e=`；
- `**kwargs`：多余关键字参数，打包成 dict。

```python
def tag(name, /, content, *, cls="", **attrs):
    attr = "".join(f' {k}="{v}"' for k, v in attrs.items())
    return f'<{name} class="{cls}"{attr}>{content}</{name}>'

print(tag("p", "hi", cls="lead", id="x1"))
```

调用时的解包：

```python
args = (1, 2)
kwargs = {"sep": "-"}
print(*args, **kwargs)      # 1-2
```

`inspect.signature` 可以读出签名，写装饰器、框架路由、参数校验时都要用：

```python
import inspect
print(inspect.signature(tag))
# (name, /, content, *, cls='', **attrs)
```

### 延伸：仅限关键字参数与 partial 的签名

`def f(a, *, b)` 里的 `b` 只能按关键字传，防止调用方把两个同类型参数传反。`functools.partial` 绑定参数后再交给 `inspect.signature`，签名会跟着变：

```python
import inspect
from functools import partial

def area(w, h, *, unit="cm"):
    return f"{w * h} {unit}²"

p = partial(area, unit="m")
print(inspect.signature(p))     # (w, h, *, unit='m')
print(p(2, 3))                  # 6 m²
print(p(2, 3, unit="km"))       # 6 km²，后传的覆盖先绑的
```

`partial` 只能追加关键字或左侧位置参数，不能跳过中间参数——要那样就用 lambda。`functools.partialmethod` 是它给描述符协议准备的版本，用于类方法场景。

### 关键点

- **`/` 与 `*` 是签名的一部分**，改动它们属于破坏性变更。
- **`*args` 是 tuple，`**kwargs` 是 dict**；不要再手动拼 list/dict。
- **默认参数只求值一次**，可变默认值用 `None` 哨兵（第 12 课）。
- **位置参数与关键字参数混用时**，位置参数必须在前；`f(1, c=2)` 合法，`f(c=2, 1)` 语法错误。

### 动手

1. 写 `def make_table(data, /, headers=None, *, align="left")`，实现仅限位置与仅限关键字混用。
2. 用 `*args` 写一个 `sum_all(*nums)`，再传一个列表进去，验证需要 `*lst` 解包。
3. 用 `inspect.signature` 打印三个标准库函数的签名，解释每个符号的含义。

### 验收清单

- [ ] 能写出同时包含 `/`、`*args`、`*`、`**kwargs` 的合法签名
- [ ] 知道 `*args` 与 `**kwargs` 在函数内部的实际类型
- [ ] 能用 `inspect.signature` 读出并解释一个函数的参数契约

## 第 15 课 · 渐进式类型：注解语法与常用类型

> 本节目标：能给变量、函数、容器写类型注解，理解 `Optional`、`Union`、`Callable`、`Any` 的含义，并知道注解在运行时不做检查。

### 讲解

Python 的类型提示是「渐进式」的：可以只给关键函数加，也可以全量加，解释器都不会因此改变行为。

```python
from typing import Callable, Iterable, Optional

def total(nums: Iterable[float]) -> float:
    return sum(nums)

def find(name: str, table: dict[str, int]) -> Optional[int]:
    return table.get(name)

def apply(f: Callable[[int], int], x: int) -> int:
    return f(x)
```

3.10 起可以写 `int | None` 代替 `Optional[int]`，3.9 起内置容器可直接下标 `list[int]`、`dict[str, int]`。注解保存在 `__annotations__` 里：

```python
print(total.__annotations__)
# {'nums': typing.Iterable[float], 'return': float}
```

但运行时不会校验：

```python
def double(x: int) -> int:
    return x * 2

print(double("a"))   # 'aa'：解释器照跑，mypy 会报错
```

`Any` 表示「放弃检查」，它会污染调用链——一个 `Any` 传进去，后面的检查全部失效。优先用 `object` 表示「任意对象但只能做 object 支持的操作」，只有在对接无类型第三方库时才用 `Any`。

### 延伸：Literal、Final、Annotated

```python
from typing import Literal, Final, Annotated

Mode = Literal["r", "w", "a"]           # 只能是这三个字符串
MAX_LEN: Final = 1024                    # 检查器禁止再赋值
UserId = Annotated[int, "primary key"]  # 把运行时元数据挂在类型上

def open_file(path: str, mode: Mode = "r") -> None: ...
```

`Annotated` 的元数据在运行时能取到：`typing.get_type_hints(fn, include_extras=True)`。FastAPI 的参数校验、文档、依赖注入都建在这上面——它先用注解，再用 `Annotated` 里的元数据，最后看默认值。`Literal` 和 `Final` 只影响静态检查，运行时传 `"x"` 不会报错，别拿它当校验器。

### 关键点

- **注解是给静态检查器的**，不是运行时断言；要运行时校验得用 `pydantic` 或手写检查。
- **`Optional[X]` 等价于 `X | None`**，不是「可选参数」的意思。
- **`list[int]` 是「元素为 int 的列表」**，不是「长度为 int 的列表」。
- **`Any` 会关闭检查**，`object` 不会；不确定时先用 `object`。

### 动手

1. 给第 13 课的 `compose` 写完整注解（提示：`Callable[[A], B]` 需要 `TypeVar`，可以先写成 `Callable`）。
2. 给一个「读 JSON 配置」的函数写注解，返回 `dict[str, object]`，并说明为什么不用 `dict[str, Any]`。
3. 用 `reveal_type()`（mypy）或编辑器悬停，观察三个变量的推断类型。

### 验收清单

- [ ] 能写出 `Optional`、`Union`、`Callable`、`Iterable` 四类注解
- [ ] 知道注解不会在运行时阻止错误参数
- [ ] 能解释 `Any` 与 `object` 的区别，并优先选择 `object`

## 第 16 课 · mypy 实战与类型边界

> 本节目标：能为一个小模块建立 mypy 检查，处理第三方库缺失注解、`cast` 与 `# type: ignore` 的边界，并知道哪些错误必须靠测试。

### 讲解

最小工作流：

```bash
python -m pip install mypy
python -m mypy app/ --strict
```

典型报错与处理：

```python
from typing import cast

data: dict[str, object] = {"count": 3}
n = data["count"] + 1          # error: Unsupported operand types for + ("object" and "int")

n = cast(int, data["count"]) + 1   # 你向检查器保证类型
```

`cast` 不做任何运行时转换，写错了只会在运行时炸；能不用就不用，优先用 `isinstance` 收窄：

```python
v = data["count"]
if isinstance(v, int):
    n = v + 1
```

第三方库没有类型存根时，可以装 `types-requests` 之类的包，或在 `pyproject.toml` 里配置：

```toml
[tool.mypy]
python_version = "3.12"
strict = true
ignore_missing_imports = true
```

### 延伸：类型检查器看不见的四件事

- 除零：`a / b` 里 `b == 0` 是运行时错误，注解无能为力。
- 越界：`list[int]` 只说明元素类型，`xs[5]` 会不会 `IndexError` 检查器不知道。
- 外部输入：`json.load()` 返回 `Any`，标成 `dict[str, int]` 只是你的断言，不是事实。
- `cast` 撒谎：`cast(int, "abc")` 检查器全信，运行时是 `str`。

```python
from typing import cast
val = cast(int, "not an int")    # 静态通过，运行时是 str
print(type(val))                 # <class 'str'>
```

原书的结论是「静态检查 + 测试双轨」：类型解决「形状对不对」，测试解决「行为对不对」。真正的入口校验（HTTP 请求、配置文件、命令行）交给 pydantic 这类运行时校验库，别指望注解。

### 关键点

- **`--strict` 是起点不是终点**：它打开 `disallow_untyped_defs` 等选项，老项目要逐步迁移。
- **`# type: ignore` 要带原因**：`# type: ignore[arg-type]  # 第三方库签名有误`，方便以后清理。
- **类型检查抓不到**：除零、越界、业务规则、并发竞态、`cast` 撒谎。
- **CI 里跑 mypy** 才有约束力；只在本地偶尔跑，等于没有。

### 动手

1. 给本单元写的 3 个函数加注解，跑 `mypy --strict`，把报错逐条修掉。
2. 故意写一个 `cast(int, "abc")`，观察 mypy 通过但运行时崩溃。
3. 为一个使用第三方库的文件配置 `ignore_missing_imports`，并记录为什么这样做有风险。

### 验收清单

- [ ] 能在本地跑通一次 `mypy --strict`

- [ ] 能列出至少三类 mypy 抓不到、必须靠测试覆盖的错误
