## 单元导入

「Python 风格的对象」不是长得像，而是**能用语言提供的方式被使用**：`repr()` 打得出可读形式、`==` 比较值、`hash()` 能进集合、`len()`/`for`/`[]`/`in` 都成立。

本单元从一个 `Vector` 类出发，逐层实现这些协议。你会看到：协议不是一堆要背的方法名，而是一组「你实现一个，解释器就白送你一串功能」的接口。

学完本单元，你应该能：

- 写出 `repr` 与 `str` 分工明确、可重建对象的类；
- 让值对象同时满足 `==`、`hash`、不可变三者自洽；
- 实现 `__len__`、`__getitem__`、`__iter__`、`__contains__`，并处理切片；
- 用 `__format__` 支持自定义格式，用 `classmethod` 提供备选构造器。

## 第 21 课 · 对象表示：repr、str 与 format

> 本节目标：能区分 `repr` 与 `str` 的使用场景，写出可重建对象的 `repr`，并用 `__format__` 支持自定义格式说明符。

### 讲解

- `repr()`：面向开发者，目标是「准确、可重建」，调试器和交互式解释器都用它。
- `str()`：面向用户，目标是「可读」；没定义时回退到 `repr()`。

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Point({self.x!r}, {self.y!r})"

    def __str__(self):
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(repr(p))    # Point(3, 4)   ← 能直接粘回解释器
print(str(p))     # (3, 4)
print(f"{p!r}")   # Point(3, 4)
```

`__format__` 决定 `f"{obj:spec}"` 的行为。默认实现会转给 `str.format`，自定义后可以支持单位、精度、极坐标等：

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __format__(self, spec):
        if spec == "p":                       # 极坐标
            import math
            r = math.hypot(self.x, self.y)
            a = math.degrees(math.atan2(self.y, self.x))
            return f"{r:.2f}∠{a:.1f}°"
        return f"({self.x:{spec}}, {self.y:{spec}})"

v = Vector(3, 4)
print(f"{v:.1f}")   # (3.0, 4.0)
print(f"{v:p}")     # 5.00∠53.1°
```

### 延伸：__format__ 收到的是原样 spec

`f"{x:>8.2f}"` 里的 `>8.2f` 会原样传给 `x.__format__`，所以实现时不能假设格式固定：

```python
class Money:
    def __init__(self, v): self.v = v
    def __format__(self, spec):
        if not spec:                    # 空 spec 必须有默认行为
            return f"¥{self.v:.2f}"
        return format(self.v, spec)     # 交给 float

print(f"{Money(3.5)}")              # ¥3.50
print(f"{Money(3.5):.1f}")          # 3.5
print(f"{Money(3.5):>10}")          #        3.5   ← 货币符号丢了
print(f"{str(Money(3.5)):>10}")     #       ¥3.50  ← 先转字符串再对齐
```

第三行是真实陷阱：`>10` 原样交给 `float`，得到 `'       3.5'`，货币符号没了。两种处理方式——要么在 `__format__` 里把 spec 拆成「数字部分 + 对齐部分」分别处理，要么文档里写明只支持数字格式，对齐时用 `str()` 包一层。空 spec 一定要有默认分支，否则 `f"{obj}"` 和 `str(obj)` 行为不一致。

### 关键点

- **`repr` 的目标是「能 eval 回来」**：字符串要带引号，用 `!r` 而不是直接拼接。
- **容器打印调用元素的 `repr`**：所以自定义类一定要写 `__repr__`，否则列表里全是 `<object at 0x...>`。
- **`__format__` 要处理空 spec**，否则 `f"{obj}"` 会报错或行为异常。
- **不要在 `__repr__` 里做重计算或抛异常**，日志和调试会因此崩掉。

2. 写一个包含 3 个 `Point` 的列表，打印列表，确认每个元素都是可读的 `repr`。
3. 故意删掉 `__repr__`，观察列表打印结果，再恢复。

## 第 22 课 · 值对象：相等、哈希与不可变

> 本节目标：能让 `__eq__`、`__hash__`、不可变三者自洽，并用 `classmethod` 提供备选构造器与 `__slots__` 控制内存。

### 讲解

值对象的核心契约：**相等的对象哈希值必须相等**。

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        return hash((self.x, self.y))
```

返回 `NotImplemented` 而不是 `False`，是为了让 Python 有机会尝试对方的 `__eq__`（例如 `Point == Mock`）。如果直接返回 `False`，反向比较和子类比较都会被堵死。

备选构造器用 `classmethod`，它拿到的是类而不是实例，子类继承后也能正确工作：

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    @classmethod
    def from_tuple(cls, t):
        return cls(*t)

    @staticmethod
    def origin():
        return Point(0, 0)
```

`__slots__` 去掉实例 `__dict__`，每个实例省几十字节；代价是不能动态加属性，也不能多继承（除了混入）。

### 延伸：__match_args__ 与 __slots__ 的边界

类模式 `case Point(x, y):` 的位置参数顺序由 `__match_args__` 决定，没有它就只能写关键字模式：

```python
class Point:
    __match_args__ = ("x", "y")
    def __init__(self, x, y):
        self.x, self.y = x, y

def where(p):
    match p:
        case Point(0, 0): return "origin"
        case Point(x, 0): return f"x-axis {x}"
        case Point(0, y): return f"y-axis {y}"
        case Point(x, y): return f"({x}, {y})"

print(where(Point(0, 0)), where(Point(1, 2)))    # origin (1, 2)
```

`__slots__` 省的是实例的 `__dict__`：定义后不能再给实例加新属性，也不能和同层 `__dict__` 共存（基类已有 `__dict__` 时它依然存在，省不下来）。它主要省内存，顺带略快，但不是性能银弹；`@dataclass(slots=True)` 在 3.10+ 一步到位。

### 关键点

- **重写 `__eq__` 后 `__hash__` 会被设为 `None`**，类立刻不可哈希；需要哈希就显式重写。
- **可变对象不应可哈希**：列表、字典都不可哈希，因为它们变了哈希就失效。
- **`classmethod` 的第一个参数是 `cls`**，`staticmethod` 没有隐式参数；备选构造器用前者。
- **`__slots__` 只省实例字典**，不含类属性；继承时要重复声明或留 `__dict__`。

### 动手

2. 用 `from_tuple` 与 `origin` 两种方式创建实例，验证子类调用返回子类实例。
3. 给 `Point` 加 `__slots__`，用 `sys.getsizeof()` 比较有无 slots 的实例大小。

## 第 23 课 · 序列协议：len、getitem、iter、contains

> 本节目标：能实现一个可迭代、可索引、可切片、可成员测试的容器，并解释每个操作背后调用了哪个方法。

### 讲解

序列协议是一条「按需实现」的链：

| 操作 | 优先调用 | 缺失时的回退 |
|---|---|---|
| `len(x)` | `__len__` | 无 |
| `x[i]` | `__getitem__` | 无 |
| `for i in x` | `__iter__` | 从 0 反复 `__getitem__` 直到 `IndexError` |
| `i in x` | `__contains__` | 遍历 `__iter__` |
| `reversed(x)` | `__reversed__` | 先 `len` 再倒序 `__getitem__` |

```python
class Playlist:
    def __init__(self, songs):
        self._songs = list(songs)

    def __len__(self):
        return len(self._songs)

    def __getitem__(self, i):
        return self._songs[i]          # 切片自动生效，返回 list

    def __iter__(self):
        return iter(self._songs)       # 显式实现，语义更清楚

    def __contains__(self, song):
        return song in self._songs
```

`__getitem__` 收到切片时要决定返回什么类型。返回 `list` 最省事，但会丢失自定义类型；要保留类型就判断 `isinstance(i, slice)` 再包装：

```python
def __getitem__(self, i):
    if isinstance(i, slice):
        return Playlist(self._songs[i])
    return self._songs[i]
```

### 延伸：退化协议能跑，但语义含糊

实现了 `__getitem__` 的对象，`iter()` 会自动退化为「从 0 开始索引直到 `IndexError`」；`in` 也退化为线性扫描：

```python
class Bag:
    def __init__(self, items): self._items = list(items)
    def __getitem__(self, i): return self._items[i]

print(list(Bag([1, 2, 3])))    # [1, 2, 3]，靠退化协议
print(2 in Bag([1, 2, 3]))     # True，逐项比较
```

显式写 `__iter__` 返回 `iter(self._items)` 更好：语义清楚、`in` 能走 `__contains__` 优化、`reversed` 能走 `__reversed__`、`len` 不必再靠猜。退化协议只适合一次性演示或确实只有下标语义的容器（比如稀疏矩阵）。

### 关键点

- **`__getitem__` 同时承担下标与切片**，参数可能是 `int` 也可能是 `slice`。
- **实现 `__iter__` 比依赖旧式迭代更明确**，也能避免每次迭代都从头索引。
- **`__contains__` 不实现也能用**，但复杂度是 O(n)；有更快判断方式时值得自定义。
- **负索引要自己处理**：如果底层不是 list（比如链表），`x[-1]` 不会自动生效。

## 第 24 课 · 实战：实现一个完整的 Vector

> 本节目标：把前 23 课的知识合成一个类：支持构造、相等、哈希、切片、格式化、`repr`，并跑通一组验收测试。

### 讲解

下面是一个够用的 `Vector`，覆盖值对象与序列协议：

```python
import math

class Vector:
    __slots__ = ("_c",)

    def __init__(self, components):
        self._c = tuple(components)

    def __len__(self):
        return len(self._c)

    def __getitem__(self, i):
        if isinstance(i, slice):
            return Vector(self._c[i])
        return self._c[i]

    def __iter__(self):
        return iter(self._c)

    def __repr__(self):
        return f"Vector({list(self._c)!r})"

    def __eq__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return self._c == other._c

    def __hash__(self):
        return hash(self._c)

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(a + b for a, b in zip(self, other))

    def __abs__(self):
        return math.hypot(*self)

    def __format__(self, spec):
        if spec == "p":
            return f"{abs(self):.2f}∠{math.degrees(math.atan2(self[1], self[0])):.1f}°"
        return "(" + ", ".join(f"{v:{spec}}" for v in self) + ")"
```

验收测试：

```python
v = Vector([3, 4])
assert len(v) == 2
assert v[0] == 3
assert isinstance(v[1:], Vector)
assert list(v) == [3, 4]
assert abs(v) == 5.0
assert Vector([3, 4]) == Vector([3, 4])
assert len({Vector([3, 4]), Vector([3, 4])}) == 1
assert f"{v:.1f}" == "(3.0, 4.0)"
print(f"{v:p}")
```

### 延伸：__getattr__ 的递归坑与哈希的缓存

`__getattr__` 只在常规查找失败时触发，适合惰性构造昂贵属性：

```python
class Lazy:
    def __init__(self):
        self._cache = {}
    def __getattr__(self, name):
        if name.startswith("_"):
            raise AttributeError(name)     # 关键：避免递归
        if name not in self._cache:
            self._cache[name] = name.upper()
        return self._cache[name]

print(Lazy().abc)     # ABC
```

两个坑：`__getattr__` 里访问 `self.其他属性` 会无限递归（缺失时又进 `__getattr__`），所以要么先判下划线、要么直接读 `self.__dict__`；`hasattr` 也会触发它，可能把拼错的属性名变成 `True`。

哈希：`__hash__` 应基于不可变字段，字段一变哈希就失效，所以可变对象别定义 `__hash__`。大对象的哈希结果值得缓存（`self._hash = hash((...))`），因为 dict 每次查找都会调用它。

### 关键点

- **用 tuple 存分量**，天然不可变，哈希与相等都简单。
- **`__add__` 返回新对象**，不要原地修改；运算符重载的完整规则在第 8 单元。
- **`__eq__` 要返回 `NotImplemented`**，让比较协议有机会回退。
- **测试要覆盖边界**：空向量、长度不等、切片、哈希去重。
