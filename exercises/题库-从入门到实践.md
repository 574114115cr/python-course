# L1 基础语法（16 题）

## L1-1 变量与类型

**题目**：定义三个变量 `name`（字符串）、`age`（整数）、`height`（浮点数），用 f-string 输出一行：
`姓名：小明，年龄：18，身高：1.75 米`。

**答案**
```python
name = "小明"
age = 18
height = 1.75
print(f"姓名：{name}，年龄：{age}，身高：{height} 米")
```

**解析**：f-string 是 Python 3.6+ 的标准写法，比 `print("...", name)` 更清晰。变量命名用小写 + 下划线，不要用 `1age`、`my name`。

## L1-2 字符串常用方法

**题目**：给定 `msg = "  Python Programming  "`，要求输出：① 去掉两端空白后的字符串；② 全小写；③ 首字母大写；④ 长度。

**答案**
```python
msg = "  Python Programming  "
print(repr(msg.strip()))      # 'Python Programming'
print(msg.strip().lower())   # python programming
print(msg.strip().title())   # Python Programming
print(len(msg))              # 21（含两端空格）
print(len(msg.strip()))      # 19
```

**解析**：`.strip()` 只去两端，不去中间。`.title()` 把每个单词首字母大写。注意 `len` 算的是字符数，不是字节数。

## L1-4 列表基础操作

**题目**：列表 `cats = ["Tom", "Kitty"]`，依次完成：① 末尾加 "Bob"；② 下标 0 插入 "Tuna"；③ 删掉 "Tom"；④ 倒序打印；⑤ 打印长度和排序结果。

## L1-10 PEP 8 格式化实战

**题目**：写出符合 PEP 8 的代码：定义常量 `MAX_USERS = 100`，定义函数 `def  calculate_total( price,rate )`（故意留空格），计算 `price * rate`。然后修正命名。

## L1-11 运算符优先级

**题目**：输出 `2 + 3 * 4`、`(2 + 3) * 4`、`2 ** 3 ** 2`、`10 / 3 // 3` 的值。

**答案**
```python
print(2 + 3 * 4)        # 14
```

## L1-12 猜数游戏（综合）

**题目**：程序随机生成 1–100 的整数，用户猜，每次提示「大了/小了」，直到猜中并统计次数。

```python
import random

secret = random.randint(1, 100)
```

## L1-13 一行日志拆开再拼回去

**题目**：把 `2026-10-26 08:30:15 INFO user=alice action=login` 重排成
`2026-10-26 08:30:15 | alice | login | INFO`：日期和时间合成一列，`user`、`action` 只取值不带键名，
级别挪到最后。

**答案**
```python
line = "2026-10-26 08:30:15 INFO user=alice action=login"
date, clock, level, *rest = line.split()
fields = {}
for item in rest:
    key, _, value = item.partition("=")
    fields[key] = value
print(" | ".join([f"{date} {clock}", fields["user"], fields["action"], level]))
```

**解析**：`split()` 不带参数时按任意空白切，前三个字段直接解包拿走，剩下的 `*rest` 装进列表；
`partition("=")` 只切第一个 `=`，所以值里再出现 `=` 也不会被切坏。最后 `join` 拼回一行——
**先拆成结构、再按需要的顺序组装**，这是日志处理的标准套路。别用 `line.split(" ")`：
连续两个空格会切出一串空串，解包立刻报错。

## L1-14 批量清理文件名

**题目**：给定 `["backup_report_2026.txt", "backup_data_2025.txt", "report_2026.csv"]`，
去掉前缀 `backup_`、丢掉不是 `.txt` 的、再去掉 `.txt` 后缀，得到干净的名字列表。

**答案**
```python
names = ["backup_report_2026.txt", "backup_data_2025.txt", "report_2026.csv"]
clean = []
for name in names:
    name = name.removeprefix("backup_")
    if not name.endswith(".txt"):
        continue
    clean.append(name.removesuffix(".txt"))
print(clean)
```

**解析**：`removeprefix` / `removesuffix` 是 3.9+ 的方法，只动**开头或结尾这一处**；
换成 `replace("backup_", "")` 会把名字中间出现的同款字符串一起换掉，`replace(".txt", "")` 更糟——
`a.txt.bak` 会被改成 `a.bak`。**判断顺序要留心**：先筛后缀再剥前缀，还是反过来，
在「前缀里本身含 `.txt`」这类名字上结果不同。

## L1-15 sorted 与 sort 到底差在哪

**题目**：成绩列表 `[72, 95, 60, 88]`，分别用 `sorted()` 和 `.sort()` 排序，
把「原列表有没有变」「返回值是什么」全打印出来。

**答案**
```python
scores = [72, 95, 60, 88]
new = sorted(scores)
print("sorted 返回新列表：", new)
print("原列表没变：", scores)
scores.sort(reverse=True)
print("sort 原地改：", scores)
result = scores.sort()
print("sort 的返回值：", result)
```

**解析**：`sorted()` 接受任何可迭代对象，返回**新列表**，原对象不动；
`list.sort()` 只能用在列表上，**原地**排序，返回值是 `None`。
所以 `new = scores.sort()` 拿不到排好的结果，`new` 是 `None`——
这就是「排完序变成 None」这个经典 bug 的来历。两者都支持 `key=` 与 `reverse=`。

## L1-16 `[[0] * 3] * 2` 的陷阱

**题目**：想造一个 2 行 3 列的零矩阵。先写 `grid = [[0] * 3] * 2`，把 `grid[0][0]` 改成 1，
看发生了什么；再给出正确写法并把两者对比出来。

**答案**
```python
grid = [[0] * 3] * 2
grid[0][0] = 1
print("浅复制：", grid)

fixed = [[0] * 3 for _ in range(2)]
fixed[0][0] = 1
print("推导式：", fixed)
print("浅复制两行是同一对象：", grid[0] is grid[1])
print("推导式两行是同一对象：", fixed[0] is fixed[1])
```

**解析**：`[x] * 2` 复制的是**引用**，两行其实是同一个列表对象（`grid[0] is grid[1]` 为 `True`），
改第一行第二行跟着变。用列表推导式 `[[0] * 3 for _ in range(2)]`，每轮循环都新建一个内层列表，
两行才是独立对象。同样的坑还有 `[{}] * n`、`[[]] * n`——凡是「外面乘一个数」的写法都要警惕。

# L2 循环与条件（24 题）

## L2-1 for 循环累加

**题目**：计算 1–100 的和；再计算 1–100 中偶数的和。

**答案**
```python
total = 0
for n in range(1, 101):
    total += n
print(total)                       # 5050

even = sum(n for n in range(1, 101) if n % 2 == 0)
print(even)                        # 2550
```


**解析**：`range(1, 101)` 右端不包含，所以正好到 100；累加前一定要把 `total` 初始化成 0，否则第一行就 `NameError`。偶数和可以用 `sum(生成器)` 一行完成，比手写循环短且不容易错。5050 是 1–100 的和，可用高斯公式 `(1+100)*100/2` 验算。

## L2-3 列表推导式

**题目**：1–20 中 3 的倍数，平方后输出；把所有名字首字母大写。

**答案**
```python
print([n ** 2 for n in range(1, 21) if n % 3 == 0])
# [9, 36, 81, 144, 225, 324]

names = ["tom", "kitty", "bob"]
print([n.capitalize() for n in names])
# ['Tom', 'Kitty', 'Bob']
```


**解析**：推导式的顺序是 `[表达式 for 变量 in 可迭代对象 if 条件]`，`if` 写在最后；先按条件筛，再算 `n ** 2`，所以 1–20 里只有 6 个 3 的倍数。`capitalize()` 只把首字母大写、其余转小写，`title()` 则会把每个单词首字母都大写。

## L2-4 嵌套列表

**题目**：给定 `matrix = [[1,2],[3,4]]`，输出所有元素之和；用推导式把每个元素翻倍。

**答案**
```python
matrix = [[1, 2], [3, 4]]
print(sum(sum(row) for row in matrix))          # 10
doubled = [[v * 2 for v in row] for row in matrix]
print(doubled)                                  # [[2, 4], [6, 8]]
```


**解析**：外层 `sum` 吃的是生成器，内层 `sum(row)` 先把每行加起来。嵌套推导式的书写顺序与嵌套 `for` 一致：外层 `for row` 在前、内层 `for v` 在后，写反了维度就错。

## L2-5 切片引用陷阱（重点）

**题目**：说明下面三段代码的输出差异：
```python
a = [1, 2, 3, 4, 5]
b = a[:]      # 猜测1
b[0] = 99
print(a)

c = a         # 猜测2
c[0] = 77
print(a)
```

**答案**
```python
a = [1, 2, 3, 4, 5]

b = a[:]
b[0] = 99
print(a)          # [1, 2, 3, 4, 5]  ← 切片是新列表

c = a
c[0] = 77
print(a)          # [77, 2, 3, 4, 5] ← 赋值是同一个对象的别名

import copy
d = a.copy()
d[0] = 100
print(a)          # [77, 2, 3, 4, 5]  ← 复制用 .copy()
```

**解析**：列表存的是**对象引用**。赋值 = 换个名字指同一个列表；切片/`.copy()` = 新建列表但元素仍共享。要深复制用 `copy.deepcopy()`。

## L2-7 逻辑运算符优先级

**题目**：给定 `a=10, b=5, c=0`，输出 `(a>b and b>c)`、`(a>b or b>c)`、`not (a>b)`、`a>b>c` 的值。

**答案**
```python
a, b, c = 10, 5, 0
print((a > b) and (b > c))   # True
print((a > b) or (b > c))    # True
print(not (a > b))           # False
print(a > b > c)             # True（等价于 a>b and b>c，Python 支持链式比较）
```


**解析**：优先级是 `not` > `and` > `or`，所以 `a > b and b > c` 不用再加括号也成立。`a > b > c` 是链式比较，等价于 `a > b and b > c`，但 `b` 只求值一次。`or` 有短路特性：左边为真就不再计算右边。

## L2-8 in 与 not in

**题目**：给定 `users = ["alice","bob","carol"]`，判断 `"dave"` 是否在列表中；用 `not in` 判断。

**答案**
```python
users = ["alice", "bob", "carol"]
print("dave" in users)        # False
print("dave" not in users)    # True
if "bob" in users:
    print("存在 bob")
```


**解析**：`in` 对列表是逐个比较（O(n)），对字典和集合是哈希查找（O(1)），元素多时差别很大。`not in` 就是 `in` 取反，比 `not ('x' in y)` 更好读。注意大小写敏感：`'Bob' in users` 是 False。

## L2-9 while 与标志

**题目**：反复要求输入正整数，输入非正数则退出并输出总和。

**答案**
```python
active = True
total = 0
while active:
    raw = input("输入正整数（q 退出）：").strip()
    if raw.lower() == "q":
        active = False
    else:
        try:
            n = int(raw)
        except ValueError:
            print("请输入数字")
            continue
        if n <= 0:
            print("必须是正数，已退出")
            break
        total += n
print("总和：", total)
```


**解析**：`input()` 拿到的永远是字符串，`int()` 转换失败会抛 `ValueError`，不 `try` 住程序直接崩。`active = False` 是「正常结束」，`break` 是「立即退出」——两者都能跳出循环，但语义不同，混用时要想清楚哪一个才是「异常路径」。

## L2-10 break / continue

**题目**：1–50 中，跳过 3 的倍数，遇到 7 的倍数时打印 `break at 7`，同时跳过偶数。

**答案**
```python
for n in range(1, 51):
    if n % 3 == 0:
        continue
    if n % 2 == 0:
        continue
    if n % 7 == 0:
        print("break at", n)
        break
    print(n)
```


**解析**：`continue` 只跳过本次循环剩下的语句，`break` 直接结束整个循环。这里偶数判断写在 7 的倍数之前，所以只有奇数才可能触发 `break`；实际输出是 1、5 之后在 7 处退出，`break at 7` 打印的就是 7。

## L2-11 while 处理列表

**题目**：不断让用户输入名字并追加到列表，输入空串停止；最后逆序打印。

**答案**
```python
names = []
while True:
    entry = input("输入名字（空串结束）：").strip()
    if not entry:
        break
    names.append(entry)
for n in sorted(names, reverse=True):
    print(n)
```

**解析**：`not entry` 能同时挡住 `""`、`"   "`、`[]`，比 `== ""` 更稳。

## L2-12 投票统计

**题目**：反复询问候选人姓名并计票，输入 `#` 结束。输出票数并按票数降序排列。

**答案**
```python
from collections import Counter

votes = {}
while True:
    name = input("候选人（# 结束）：").strip()
    if name == "#":
        break
    if not name:
        continue
    votes[name] = votes.get(name, 0) + 1

for name, count in Counter(votes).most_common():
    print(f"{name}: {count} 票")
```

**解析**：`dict.get(k, 0)` 是计数的标准写法。`most_common()` 直接给出降序结果。

## L2-22 列表套字典：班级平均与最高分

**题目**：学生记录是列表套字典（姓名、班级、分数），求每个班的平均分、以及全体的最高分。

**答案**
```python

    {"name": "小明", "cls": "A", "score": 88},
    {"name": "小红", "cls": "A", "score": 95},
```

## L2-23 把一个值删干净

## L2-24 while + input 登记报名

**题目**：循环读入「姓名 项目」直到空行；同一个人再次报名要**覆盖**之前的项目，最后打印名单。


## L3-6 递归

**题目**：写递归函数 `factorial(n)` 求阶乘；再写 `fib(n)` 求斐波那契第 n 项。

**答案**
```python
def factorial(n):
    if n < 0:
        raise ValueError("n 不能为负")
    if n <= 1:
        return 1
    return n * factorial(n - 1)


def fib(n, memo=None):
    if n <= 0:
        return 0
    if n == 1:
        return 1
    if memo is None:
        memo = {}
    if n not in memo:
        memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
    return memo[n]


print(factorial(5))   # 120
print(fib(30))        # 832040
```

**解析**：递归必须有**终止条件**。朴素 fib(30) 要算 160 万次，加 memo 后只有 30 次。

## L3-7 函数闭包与装饰器

**题目**：写一个 `timer` 装饰器，打印函数执行耗时。

**答案**
```python
import time
from functools import wraps


def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        cost = time.perf_counter() - start
        print(f"{func.__name__} 耗时 {cost:.6f}s")
        return result
    return wrapper


@timer
def slow_sum(n):
    return sum(range(n))


slow_sum(1_000_000)
```

**解析**：`*args, **kwargs` 让装饰器能包住任何函数；`@wraps` 保留原函数元信息。

```python
        print(f"里程表：{self.odometer_reading} 英里")

    def update_odometer(self, miles: int) -> None:
        self.odometer_reading = miles

    def increment_odometer(self, miles: int) -> None:
        self.odometer_reading += miles


c = Car("Toyota", "Corolla", 2022)
c.read_odometer()
c.increment_odometer(500)
c.read_odometer()          # 500
```


**解析**：`odometer_reading` 在 `__init__` 里赋默认值，每个实例各自持有一份，改一辆车不影响另一辆。真实场景里 `update_odometer` 要加「里程不能往回拨」的保护：先判断 `miles >= self.odometer_reading` 再赋值，否则等于允许改表。

## L4-3 属性私有化

**题目**：给 `BankAccount` 加私有余额 `__balance`，提供存款、取款（余额不足抛异常）、查询方法。

**答案**
```python
class InsufficientFunds(Exception):
    """余额不足。"""


class BankAccount:
    def __init__(self, owner: str, balance: float = 0):
        self.owner = owner
        self.__balance = balance       # 名称改写，外部访问不到

    @property
    def balance(self) -> float:
        return self.__balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self.__balance += amount

    def withdraw(self, amount: float) -> float:
        if amount > self.__balance:
            raise InsufficientFunds(f"余额不足：{self.balance}")
        self.__balance -= amount
        return self.__balance


acc = BankAccount("小明", 100)
acc.deposit(50)
print(acc.balance)             # 150.0
print(acc.withdraw(30))        # 120.0
try:
    acc.withdraw(9999)
except InsufficientFunds as e:
    print(e)                   # 余额不足：120.0
```

**解析**：`__` 前缀是**约定式私有**（非真私有），`@property` 让方法能像属性一样用 `acc.balance` 访问。

```python
class NegativeAgeError(ValueError):
    """年龄不能为负。继承 ValueError 便于统一捕获。"""


class Student:
    def __init__(self, name: str, age: int):
        if age < 0:
            raise NegativeAgeError(f"{name} 的年龄不能为负：{age}")
        self.name = name
        self.age = age

    def __str__(self) -> str:

except NegativeAgeError as e:
```

## L4-9 从 car.py 导入 Car 与 ElectricCar

**题目**：`car.py` 里有 `Car` 与 `ElectricCar`。写出四种导入写法并说明区别，
然后用其中一种把两辆车都创建出来并打印描述。

**答案**
```python
# car.py
class Car:
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

    def describe(self):
        return f"{self.year} {self.make} {self.model}"


class ElectricCar(Car):
    def __init__(self, make, model, year):
        super().__init__(make, model, year)
        self.battery = 75

    def describe(self):

```

```python
ev = ElectricCar("特斯拉", "Model 3", 2023)

print(ev.describe())
```

**解析**：四种写法分别是 `import car`（用 `car.Car()`）、`from car import Car`（用 `Car()`）、

## L4-10 抽奖：不重复且可复现

**题目**：20 位学员随机抽 5 位中奖者，要求不重复；固定 `seed`，使每次运行结果一致。

**答案**
```python
import random

people = [f"学员{i:02d}" for i in range(1, 21)]
random.seed(42)
winners = random.sample(people, 5)
print("中奖：", winners)
print("人数：", len(winners), "去重后：", len(set(winners)))
random.seed(42)
print("同 seed 能复现：", random.sample(people, 5) == winners)
```

**解析**：`random.sample(people, 5)` 是**无放回**抽样，天然不重复；
用 `random.choice` 循环 5 次会有重复，还得自己去重。`len(set(...))` 是事后验不重复的最快写法。
固定 `seed` 之后序列可复现，方便截图、写测试；**线上真抽奖千万不要固定 seed**。
`random.shuffle` 也能做，但它会打乱原列表，之后再抽前 5 个。

## L5-6 统计词频存成 JSON

## L5-9 综合：统计日志里的错误

**题目**：读 `app.log`，统计每个级别（INFO/WARNING/ERROR）出现次数，按次数从高到低打印；文件不存在时给出友好提示。

**答案**
```python
from collections import Counter

LEVELS = ("INFO", "WARNING", "ERROR")


def count_levels(path):
    """统计日志各级别出现次数，返回 Counter。"""
    result = Counter()
    try:
        with open(path, encoding="utf-8") as f:
            for line in f:
                for lv in LEVELS:
                    if lv in line:
                        result[lv] += 1
                        break
    except FileNotFoundError:
        print(f"找不到日志文件：{path}")
        return Counter()
    return result


if __name__ == "__main__":
    counts = count_levels("app.log")
    for level, n in counts.most_common():
        print(f"{level:<8}{n}")
```

**解析**：`Counter.most_common()` 直接给出「按次数降序」；`FileNotFoundError` 是最常见的异常，必须处理，否则第一次跑就崩。

```python
            running = False

    screen.fill((230, 240, 250))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**解析**：`clock.tick(60)` 限帧，不写会跑满 CPU；`pygame.display.flip()` 才真正把这一帧推上屏幕；没有事件循环，窗口会「未响应」。

## L6-2 事件驱动：按住方向键移动飞船

**题目**：用 KEYDOWN/KEYUP 维护移动标志，方向键控制左右移动，不能移出屏幕。

**答案**
```python
import pygame

class Ship:
    def __init__(self, screen, settings):
        self.screen = screen
        self.settings = settings
        self.moving_right = False
        self.moving_left = False
        self.rect = pygame.Rect(0, 0, 60, 40)
        self.x = float(self.rect.centerx)

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_RIGHT:
                self.moving_right = True
            elif event.key == pygame.K_LEFT:
                self.moving_left = True
        elif event.type == pygame.KEYUP:
            if event.key == pygame.K_RIGHT:
                self.moving_right = False
            elif event.key == pygame.K_LEFT:
                self.moving_left = False

    def update(self):
        if self.moving_right and self.rect.right < self.screen.get_rect().right:
            self.x += self.settings.ship_speed
        if self.moving_left and self.rect.left > 0:
            self.x -= self.settings.ship_speed
        self.rect.centerx = self.x
```

**解析**：移动必须靠「标志 + 每帧 update」，不能直接写在 KEYDOWN 里——按住键只会触发一次 KEYDOWN，靠事件移动会一顿一顿。

**题目**：用元组 `(x, y, w, h)` 表示矩形，写 `hit(a, b)` 判断是否相交。测试相交与不相交各一组。

**答案**
```python
def hit(a, b):
    ax, ay, aw, ah = a
    bx, by, bw, bh = b
    return (ax < bx + bw and ax + aw > bx and
            ay < by + bh and ay + ah > by)


print(hit((10, 10, 20, 20), (25, 25, 20, 20)))
print(hit((10, 10, 20, 20), (50, 50, 20, 20)))
```

**解析**：四个条件必须同时成立：a 的左 < b 的右、a 的右 > b 的左、a 的上 < b 的下、a 的下 > b 的上。用 `<` 和 `>` 而不是 `<=`/`>=`，是为了让「刚好贴边」不算碰撞——子弹擦着边缘飞过不该算命中。

## L6-34 舰队整体下移与反向

**题目**：给一组外星人的 x 坐标，整体横移 `dx`；只要有一个超出左右边距，就全部下移 `dy` 并让 `dx` 反向。返回 `(xs, dx, dy)`（dy 为 0 表示没下移）。

**答案**
```python
def move_fleet(xs, dx, dy, screen_w, margin=40):
    new = [x + dx for x in xs]
    if min(new) < margin or max(new) > screen_w - margin:
        return [x for x in xs], -dx, dy
    return new, dx, 0


xs = [100, 200, 300]
print(move_fleet(xs, 10, 20, 800))
print(move_fleet([700, 760], 10, 20, 800))
```

**解析**：先算出整组新坐标再判断，比「边移边判」简单，也不会出现一半移了、一半没移。触边时**不移动 x**（退回原值）、只反向并下移，否则舰队会贴着边缘抖动。

**题目**：击落一只加 `points` 分；每累计 3 只升一级，升级时 `points` 乘 1.5 取整。连打 5 只，输出每次的分数、等级、剩余计数。

## L6-36 最高分：只在新高时写盘

**题目**：用 `json.dumps/loads` 模拟存取最高分；只有新分数更高才写，读不到时兜底 0。

**答案**
```python
import json

disk = ""


def load_high(raw):
    try:
        return int(json.loads(raw)["score"])
    except (ValueError, KeyError, TypeError):
        return 0


def save_high(raw, score):
    if score > load_high(raw):
        return json.dumps({"score": score})
    return raw


for s in (120, 90, 200):

    print(s, "->", disk, "当前纪录", load_high(disk))
```

**解析**：`except` 同时接住三种坏数据：空串（`ValueError`）、没有 `score` 键（`KeyError`）、值是字符串（`TypeError`）。只在新高时写，避免每局都覆写磁盘——这也是「少写一次就少一次坏文件的机会」。

## L6-42 分页抓取：失败跳过、结果合并

**题目**：模拟抓 3 页，第 2 页失败；每页带 `items`。要求失败重试 1 次仍失败就跳过，最后合并所有成功的条目并统计。

**答案**
```python
pages = {
    1: {"items": ["a", "b"]},
    2: None,
    3: {"items": ["c"]},
}


def fetch(page):
    data = pages[page]
    if data is None:
        raise RuntimeError(f"第 {page} 页失败")
    return data["items"]


merged, failed = [], []
for p in (1, 2, 3):
    for attempt in (1, 2):
        try:
            merged.extend(fetch(p))
            break
        except RuntimeError:
            if attempt == 2:
                failed.append(p)

print("合并", merged)
print("失败页", failed)
```

**解析**：重试写在 `for attempt` 里，`break` 只在成功时执行；`attempt == 2` 时才记失败页，避免「第一次失败就记一笔」。真实爬虫还要加 `time.sleep` 限速，否则会被封 IP。

## L6-43 URL 正则 → 视图名

**题目**：用 `re.fullmatch` 写三条路由：`/`、`/topics/<数字>/`、`/new_entry/<数字>/`，返回视图名；写出匹配表。

**答案**
```python
import re

RULES = [
    (r"/", "index"),
    (r"/topics/(\d+)/", "topic"),
    (r"/new_entry/(\d+)/", "new_entry"),
]


def resolve(path):
    for pattern, name in RULES:
        m = re.fullmatch(pattern, path)
        if m:
            return name, m.groups()
    return "404", ()


for p in ("/", "/topics/3/", "/new_entry/12/", "/topics/abc/"):
    print(p, "->", resolve(p))
```

**解析**：`fullmatch` 而不是 `match`：`match` 只要求前缀匹配，`/topics/3/extra` 会被误判成 `topic`。捕获组 `(\d+)` 拿到的就是数据库主键，后面按 id 查对象。

```python
class SafeDict(dict):

def render(template, ctx):
```
