# L1 基础语法（12 题）

## L1-1 变量与类型

**题目**：定义三个变量 `name`（字符串）、`age`（整数）、`height`（浮点数），用 f-string 输出一行：
`姓名：小明，年龄：18，身高：1.75 米`。

**答案**
```python
name = "小明"
age = 18
height = 1.75
print(f"姓名：{name}，年龄：{age}，身高：{height} 米")
```

**解析**：f-string 是 Python 3.6+ 的标准写法，比 `print("...", name)` 更清晰。变量命名用小写 + 下划线，不要用 `1age`、`my name`。

## L1-2 字符串常用方法

**题目**：给定 `msg = "  Python Programming  "`，要求输出：① 去掉两端空白后的字符串；② 全小写；③ 首字母大写；④ 长度。

**答案**
```python
msg = "  Python Programming  "
print(repr(msg.strip()))      # 'Python Programming'
print(msg.strip().lower())   # python programming
print(msg.strip().title())   # Python Programming
print(len(msg))              # 21（含两端空格）
print(len(msg.strip()))      # 19
```

**解析**：`.strip()` 只去两端，不去中间。`.title()` 把每个单词首字母大写。注意 `len` 算的是字符数，不是字节数。

## L1-3 f-string 格式化

**题目**：给定 `price = 3.14159`、`qty = 7`，输出：`单价 3.14（保留两位），总价 21.99`。

**答案**
```python
price = 3.14159
qty = 7
total = price * qty
print(f"单价 {price:.2f}，总价 {total:.2f}")
```

**解析**：`:.2f` 是固定两位小数。若想千分位用 `{:,.2f}`；百分比用 `{0.25:.1%}`。

## L1-4 列表基础操作

**题目**：列表 `cats = ["Tom", "Kitty"]`，依次完成：① 末尾加 "Bob"；② 下标 0 插入 "Tuna"；③ 删掉 "Tom"；④ 倒序打印；⑤ 打印长度和排序结果。

**答案**
```python
cats = ["Tom", "Kitty"]
cats.append("Bob")
cats.insert(0, "Tuna")
cats.remove("Tom")
print(cats)              # ['Tuna', 'Kitty', 'Bob']
print(len(cats))         # 3
print(sorted(cats))      # ['Bob', 'Kitty', 'Tuna']
cats.reverse()
print(cats)              # ['Bob', 'Kitty', 'Tuna']
```

**解析**：`sorted()` 不改原列表（临时排序），`.sort()` 原地排序返回 None —— 这是最常见的坑。

## L1-7 数字类型陷阱

**题目**：输出 `1/3`、两个浮点相加是否等于 0.3、`0.1+0.2==0.3` 的结果。

**答案**
```python
print(1 / 3)                  # 0.3333333333333333
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False
print(abs((0.1 + 0.2) - 0.3) < 1e-9)   # True（正确比较方式）
```

## L1-8 字符串与列表互转

**题目**：给定 `tags = "python, 入门, 2026"`，输出去掉空格并大写的列表；再用逗号拼回字符串。

**答案**
```python
tags = "python, 入门, 2026"
```

**解析**：`.split(",")` 切分 → 列表处理 → `.join()` 拼回。这是数据清洗最常用的一行套路。

## L1-10 PEP 8 格式化实战

**题目**：写出符合 PEP 8 的代码：定义常量 `MAX_USERS = 100`，定义函数 `def  calculate_total( price,rate )`（故意留空格），计算 `price * rate`。然后修正命名。

**答案**
```python
MAX_USERS = 100   # 常量全大写

def calculate_total(price, rate):      # 参数两侧各一个空格，函数名与括号间不加空格

print(calculate_total(100, 0.13))       # 113.0
```

## L1-11 运算符优先级

**题目**：输出 `2 + 3 * 4`、`(2 + 3) * 4`、`2 ** 3 ** 2`、`10 / 3 // 3` 的值。

**答案**
```python
print(2 + 3 * 4)        # 14
print((2 + 3) * 4)      # 20
print(2 ** 3 ** 2)      # 512（右结合，2**(3**2)）
print(10 / 3 // 3)      # 1.0
print(divmod(10, 3))    # (3, 1)
```

**解析**：`**` 右结合且优先级最高；`//` 向下取整；`/` 真除法返回 float。

## L1-12 猜数游戏（综合）

**题目**：程序随机生成 1–100 的整数，用户猜，每次提示「大了/小了」，直到猜中并统计次数。

**答案**
```python
import random

secret = random.randint(1, 100)
count = 0
while True:
    try:
        guess = int(input("猜一个 1-100 的数："))
    except ValueError:
        print("请输入整数")
        continue
    count += 1
    if guess < secret:
        print("小了")
    elif guess > secret:
        print("大了")
    else:
        print(f"猜对了！共 {count} 次")
        break
```

**解析**：必须处理非数字输入，否则 `int()` 抛 `ValueError` 直接崩。这是单元 6 的预演。

# L2 循环与条件（16 题）

## L2-1 for 循环累加

**题目**：计算 1–100 的和；再计算 1–100 中偶数的和。

**答案**
```python
total = 0
for n in range(1, 101):
    total += n
print(total)                       # 5050

even = sum(n for n in range(1, 101) if n % 2 == 0)
print(even)                        # 2550
```


**解析**：`range(1, 101)` 右端不包含，所以正好到 100；累加前一定要把 `total` 初始化成 0，否则第一行就 `NameError`。偶数和可以用 `sum(生成器)` 一行完成，比手写循环短且不容易错。5050 是 1–100 的和，可用高斯公式 `(1+100)*100/2` 验算。

---

## L2-2 range 的三种用法

**题目**：输出 `range(5)`、`range(2, 10, 3)` 转成列表的结果。

**答案**
```python
print(list(range(5)))          # [0, 1, 2, 3, 4]
print(list(range(2, 10, 3)))   # [2, 5, 8]
```

**解析**：`range(start, stop, step)`，含 start 不含 stop。

## L2-3 列表推导式

**题目**：1–20 中 3 的倍数，平方后输出；把所有名字首字母大写。

**答案**
```python
print([n ** 2 for n in range(1, 21) if n % 3 == 0])
# [9, 36, 81, 144, 225, 324]

names = ["tom", "kitty", "bob"]
print([n.capitalize() for n in names])
# ['Tom', 'Kitty', 'Bob']
```


**解析**：推导式的顺序是 `[表达式 for 变量 in 可迭代对象 if 条件]`，`if` 写在最后；先按条件筛，再算 `n ** 2`，所以 1–20 里只有 6 个 3 的倍数。`capitalize()` 只把首字母大写、其余转小写，`title()` 则会把每个单词首字母都大写。

## L2-4 嵌套列表

**题目**：给定 `matrix = [[1,2],[3,4]]`，输出所有元素之和；用推导式把每个元素翻倍。

**答案**
```python
matrix = [[1, 2], [3, 4]]
print(sum(sum(row) for row in matrix))          # 10
doubled = [[v * 2 for v in row] for row in matrix]
print(doubled)                                  # [[2, 4], [6, 8]]
```


**解析**：外层 `sum` 吃的是生成器，内层 `sum(row)` 先把每行加起来。嵌套推导式的书写顺序与嵌套 `for` 一致：外层 `for row` 在前、内层 `for v` 在后，写反了维度就错。

## L2-5 切片引用陷阱（重点）

**题目**：说明下面三段代码的输出差异：
```python
a = [1, 2, 3, 4, 5]
b = a[:]      # 猜测1
b[0] = 99
print(a)

c = a         # 猜测2
c[0] = 77
print(a)
```

**答案**
```python
a = [1, 2, 3, 4, 5]

b = a[:]
b[0] = 99
print(a)          # [1, 2, 3, 4, 5]  ← 切片是新列表

c = a
c[0] = 77
print(a)          # [77, 2, 3, 4, 5] ← 赋值是同一个对象的别名

import copy
d = a.copy()
d[0] = 100
print(a)          # [77, 2, 3, 4, 5]  ← 复制用 .copy()
```

**解析**：列表存的是**对象引用**。赋值 = 换个名字指同一个列表；切片/`.copy()` = 新建列表但元素仍共享。要深复制用 `copy.deepcopy()`。

## L2-7 逻辑运算符优先级

**题目**：给定 `a=10, b=5, c=0`，输出 `(a>b and b>c)`、`(a>b or b>c)`、`not (a>b)`、`a>b>c` 的值。

**答案**
```python
a, b, c = 10, 5, 0
print((a > b) and (b > c))   # True
print((a > b) or (b > c))    # True
print(not (a > b))           # False
print(a > b > c)             # True（等价于 a>b and b>c，Python 支持链式比较）
```


**解析**：优先级是 `not` > `and` > `or`，所以 `a > b and b > c` 不用再加括号也成立。`a > b > c` 是链式比较，等价于 `a > b and b > c`，但 `b` 只求值一次。`or` 有短路特性：左边为真就不再计算右边。

## L2-8 in 与 not in

**题目**：给定 `users = ["alice","bob","carol"]`，判断 `"dave"` 是否在列表中；用 `not in` 判断。

**答案**
```python
users = ["alice", "bob", "carol"]
print("dave" in users)        # False
print("dave" not in users)    # True
if "bob" in users:
    print("存在 bob")
```


**解析**：`in` 对列表是逐个比较（O(n)），对字典和集合是哈希查找（O(1)），元素多时差别很大。`not in` 就是 `in` 取反，比 `not ('x' in y)` 更好读。注意大小写敏感：`'Bob' in users` 是 False。

## L2-9 while 与标志

**题目**：反复要求输入正整数，输入非正数则退出并输出总和。

**答案**
```python
active = True
total = 0
while active:
    raw = input("输入正整数（q 退出）：").strip()
    if raw.lower() == "q":
        active = False
    else:
        try:
            n = int(raw)
        except ValueError:
            print("请输入数字")
            continue
        if n <= 0:
            print("必须是正数，已退出")
            break
        total += n
print("总和：", total)
```


**解析**：`input()` 拿到的永远是字符串，`int()` 转换失败会抛 `ValueError`，不 `try` 住程序直接崩。`active = False` 是「正常结束」，`break` 是「立即退出」——两者都能跳出循环，但语义不同，混用时要想清楚哪一个才是「异常路径」。

## L2-10 break / continue

**题目**：1–50 中，跳过 3 的倍数，遇到 7 的倍数时打印 `break at 7`，同时跳过偶数。

**答案**
```python
for n in range(1, 51):
    if n % 3 == 0:
        continue
    if n % 2 == 0:
        continue
    if n % 7 == 0:
        print("break at", n)
        break
    print(n)
```


**解析**：`continue` 只跳过本次循环剩下的语句，`break` 直接结束整个循环。这里偶数判断写在 7 的倍数之前，所以只有奇数才可能触发 `break`；实际输出是 1、5 之后在 7 处退出，`break at 7` 打印的就是 7。

## L2-11 while 处理列表

**题目**：不断让用户输入名字并追加到列表，输入空串停止；最后逆序打印。

**答案**
```python
names = []
while True:
    entry = input("输入名字（空串结束）：").strip()
    if not entry:
        break
    names.append(entry)
for n in sorted(names, reverse=True):
    print(n)
```

**解析**：`not entry` 能同时挡住 `""`、`"   "`、`[]`，比 `== ""` 更稳。

## L2-12 投票统计

**题目**：反复询问候选人姓名并计票，输入 `#` 结束。输出票数并按票数降序排列。

**答案**
```python
from collections import Counter

votes = {}
while True:
    name = input("候选人（# 结束）：").strip()
    if name == "#":
        break
    if not name:
        continue
    votes[name] = votes.get(name, 0) + 1

for name, count in Counter(votes).most_common():
    print(f"{name}: {count} 票")
```

**解析**：`dict.get(k, 0)` 是计数的标准写法。`most_common()` 直接给出降序结果。

## L2-13 斐波那契

**题目**：输出前 20 项斐波那契数列（1, 1, 2, 3, 5, ...）。

**答案**
```python
a, b = 1, 1
seq = []
for _ in range(20):
    seq.append(a)
    a, b = b, a + b
print(seq)
```


**解析**：`a, b = b, a + b` 是元组打包与解包：右边先整体算完再赋值，所以不需要临时变量；写成 `a = b` 再 `b = a + b` 会用到已被覆盖的 `a`，数列就错了。前 20 项的最后一项是 6765。

## L2-14 猜数字游戏（带次数限制）

**题目**：随机数 1–100，最多猜 7 次，每次提示大了/小了，超出次数公布答案。

```python
import random

secret = random.randint(1, 100)

    if guess == secret:

else:

```

**解析**：for-else 里的 `else` 在**循环未被 break** 时执行，非常适合「尝试 N 次失败」的场景。

## L2-15 九九乘法表

**题目**：输出完整九九乘法表（对齐输出，右对齐宽度 4）。

**答案**
```python
for i in range(1, 10):
    line = ""
    for j in range(1, i + 1):
        line += f"{j}*{i}={i*j:<2}  "
    print(line.rstrip())
```


**解析**：外层 `i` 控制行，内层 `j` 到 `i` 为止，所以输出是下三角。`{i*j:<2}` 让乘积左对齐占 2 位，再补两个空格对齐各列；`rstrip()` 去掉行尾多余空格，否则最后一列右边会拖一串空白。

## L2-16 文本词频统计

**题目**：给定一句英文，输出出现次数最多的前 3 个词（忽略大小写）。

**答案**
```python
from collections import Counter

text = "the quick brown fox jumps over the lazy dog the fox"
words = [w.lower().strip(".,!?") for w in text.split()]
for word, n in Counter(words).most_common(3):
    print(word, n)
```

---

**解析**：`Counter` 对任何可迭代对象计数，`most_common(3)` 直接给出次数最多的 3 个。必须先 `lower()` 再 `strip('.,!?')`，否则 `the` 和 `the.` 会被算成两个词。真实文本建议用 `re.findall(r"[a-z']+", text.lower())` 代替 `split()`，能处理连字符和多余标点。

# L3 函数（8 题）

## L3-1 参数传递三种方式

**题目**：写函数 `describe(name, age=18, city="北京")`，分别用位置实参、关键字实参、混合方式调用。

**答案**
```python
def describe(name, age=18, city="北京"):
    return f"{name}，{age} 岁，来自 {city}"


print(describe("小明"))                        # 全默认
print(describe("小明", 20))                     # 位置实参
print(describe(age=25, name="小红"))             # 关键字实参
print(describe("小刚", city="上海"))             # 混合：跳过 age
```

**解析**：有关键字实参时，后面的**所有**参数都得用关键字。

## L3-2 返回值：字典与可选参数

**题目**：函数 `build_person(name, age=None, **extra)`，未传 age 时默认 `'未知'`，额外信息合并返回字典。

**答案**
```python
def build_person(name, age=None, **extra):
    person = {"name": name, "age": age if age is not None else "未知"}
    person.update(extra)
    return person
```

## L3-3 列表传参：改 vs 不改

**题目**：两个函数，一个给列表每个元素翻倍（原地），一个返回新列表（不改原列表）。

**答案**

```python
        nums[i] *= 2

    for n in nums:
        result.append(n * 2)
    return result

double_inplace(a)
```

## L3-6 递归

**题目**：写递归函数 `factorial(n)` 求阶乘；再写 `fib(n)` 求斐波那契第 n 项。

**答案**
```python
def factorial(n):
    if n < 0:
        raise ValueError("n 不能为负")
    if n <= 1:
        return 1
    return n * factorial(n - 1)


def fib(n, memo=None):
    if n <= 0:
        return 0
    if n == 1:
        return 1
    if memo is None:
        memo = {}
    if n not in memo:
        memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
    return memo[n]


print(factorial(5))   # 120
print(fib(30))        # 832040
```

**解析**：递归必须有**终止条件**。朴素 fib(30) 要算 160 万次，加 memo 后只有 30 次。

## L3-7 函数闭包与装饰器

**题目**：写一个 `timer` 装饰器，打印函数执行耗时。

**答案**
```python
import time
from functools import wraps


def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        cost = time.perf_counter() - start
        print(f"{func.__name__} 耗时 {cost:.6f}s")
        return result
    return wrapper


@timer
def slow_sum(n):
    return sum(range(n))


slow_sum(1_000_000)
```

**解析**：`*args, **kwargs` 让装饰器能包住任何函数；`@wraps` 保留原函数元信息。

## L4-3 属性私有化

**题目**：给 `BankAccount` 加私有余额 `__balance`，提供存款、取款（余额不足抛异常）、查询方法。

**答案**
```python
class InsufficientFunds(Exception):
    """余额不足。"""


class BankAccount:
    def __init__(self, owner: str, balance: float = 0):
        self.owner = owner
        self.__balance = balance       # 名称改写，外部访问不到

    @property
    def balance(self) -> float:
        return self.__balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self.__balance += amount

    def withdraw(self, amount: float) -> float:
        if amount > self.__balance:
            raise InsufficientFunds(f"余额不足：{self.balance}")
        self.__balance -= amount
        return self.__balance


acc = BankAccount("小明", 100)
acc.deposit(50)
print(acc.balance)             # 150.0
print(acc.withdraw(30))        # 120.0
try:
    acc.withdraw(9999)
except InsufficientFunds as e:
    print(e)                   # 余额不足：120.0
```

**解析**：`__` 前缀是**约定式私有**（非真私有），`@property` 让方法能像属性一样用 `acc.balance` 访问。

## L4-6 实例作为属性（组合）

**题目**：`Customer` 类持有 `ShoppingCart` 实例，`add_item()` 时自动加进购物车。

**答案**

```python
class Product:
    def __init__(self, name: str, price: float):
        self.name = name
        self.price = price

    def __repr__(self) -> str:
        return f"Product({self.name!r}, {self.price!r})"


class ShoppingCart:
    def __init__(self):
        self.items: list[Product] = []

    def add(self, product: Product) -> None:
        self.items.append(product)

    @property
    def total(self) -> float:
        return round(sum(p.price for p in self.items), 2)


class Customer:
    def __init__(self, name: str):
        self.name = name
        self.cart = ShoppingCart()       # 实例作属性

    def add_to_cart(self, product: Product) -> None:
        self.cart.add(product)

c.add_to_cart(Product("笔", 3.5))
c.add_to_cart(Product("本", 12.0))
print(c.cart.total)      # 15.5
```

## L4-7 自定义异常类

**题目**：定义 `NegativeAgeError`，在 `Student.__init__` 中 age 为负时抛出。

**答案**
```python
class NegativeAgeError(ValueError):
    """年龄不能为负。继承 ValueError 便于统一捕获。"""


class Student:
    def __init__(self, name: str, age: int):
        if age < 0:
            raise NegativeAgeError(f"{name} 的年龄不能为负：{age}")
        self.name = name
        self.age = age

    def __str__(self) -> str:
        return f"Student({self.name}, {self.age})"


try:
    s = Student("小明", -5)
except NegativeAgeError as e:
    print("错误：", e)
```


**解析**：自定义异常继承 `ValueError`（或 `Exception`），这样 `except ValueError` 也能顺带捕获它，便于统一处理。异常信息里带上具体值（`{age}`），排查时不用回头加打印。`__str__` 决定 `print(student)` 输出什么。

## L5-6 统计词频存成 JSON

## L5-9 综合：统计日志里的错误

**题目**：读 `app.log`，统计每个级别（INFO/WARNING/ERROR）出现次数，按次数从高到低打印；文件不存在时给出友好提示。

**答案**
```python
from collections import Counter

LEVELS = ("INFO", "WARNING", "ERROR")


def count_levels(path):
    """统计日志各级别出现次数，返回 Counter。"""
    result = Counter()
    try:
        with open(path, encoding="utf-8") as f:
            for line in f:
                for lv in LEVELS:
                    if lv in line:
                        result[lv] += 1
                        break
    except FileNotFoundError:
        print(f"找不到日志文件：{path}")
        return Counter()
    return result


if __name__ == "__main__":
    counts = count_levels("app.log")
    for level, n in counts.most_common():
        print(f"{level:<8}{n}")
```

**解析**：`Counter.most_common()` 直接给出「按次数降序」；`FileNotFoundError` 是最常见的异常，必须处理，否则第一次跑就崩。

## L6-2 事件驱动：按住方向键移动飞船

**题目**：用 KEYDOWN/KEYUP 维护移动标志，方向键控制左右移动，不能移出屏幕。

**答案**
```python
import pygame

class Ship:
    def __init__(self, screen, settings):
        self.screen = screen
        self.settings = settings
        self.moving_right = False
        self.moving_left = False
        self.rect = pygame.Rect(0, 0, 60, 40)
        self.x = float(self.rect.centerx)

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_RIGHT:
                self.moving_right = True
            elif event.key == pygame.K_LEFT:
                self.moving_left = True
        elif event.type == pygame.KEYUP:
            if event.key == pygame.K_RIGHT:
                self.moving_right = False
            elif event.key == pygame.K_LEFT:
                self.moving_left = False

    def update(self):
        if self.moving_right and self.rect.right < self.screen.get_rect().right:
            self.x += self.settings.ship_speed
        if self.moving_left and self.rect.left > 0:
            self.x -= self.settings.ship_speed
        self.rect.centerx = self.x
```

**解析**：移动必须靠「标志 + 每帧 update」，不能直接写在 KEYDOWN 里——按住键只会触发一次 KEYDOWN，靠事件移动会一顿一顿。

## L6-27 DEBUG=False 后的三处必改

**题目**：把 `DEBUG` 改成 `False` 后站点 400/样式全丢，列出必改项。

**答案**
```python
DEBUG = False
ALLOWED_HOSTS = ["your-app.example.com", "127.0.0.1"]
STATIC_ROOT = BASE_DIR / "staticfiles"
```
另外：跑 `collectstatic`；自定义 `404.html` 与 `500.html`（放在模板根目录）。

**解析**：`ALLOWED_HOSTS` 为空时一律 400；不收集静态文件则样式 404；自定义错误页只在 `DEBUG=False` 时生效，本地看不到属正常。

## L6-30 陌生项目定位 bug

**题目**：接手一个没写过的 500 行项目，要定位一个 bug，按顺序写出步骤。

**答案**
```
1. 跑起来，稳定复现（记下操作步骤与输入）
2. 读 traceback 最后一行 → 找到报错文件与行号
3. 在该行前后打印关键变量，确认是「值不对」还是「分支没进」
4. 缩小到最小复现（只保留必要代码）
5. 改一处，重跑最小复现
6. 补一条测试，防止回归
```

**解析**：没复现就改代码是瞎改；修完不补测试，同一个 bug 会再回来。
