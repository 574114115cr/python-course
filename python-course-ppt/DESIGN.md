## SVG 中文字体（必读 · 踩过的坑）
渲染器的**默认 SVG 字体不含中文字形**。实验结论（对照 7 种写法渲染）：

| 写法 | 结果 |
|---|---|
| `fontFamily='Inter'` | 中文全变「□□」 |
| 不写 fontFamily | 中文全变「□□」 |
| 中文开头但不写字体 | 中文全变「□□」 |
| `fontFamily='sans-serif'` | 中文全变「□□」 |
| **`fontFamily='Microsoft YaHei'`** | **中文正常** |

**规则：任何含中文的 `<text>` 都必须显式写 `fontFamily='Microsoft YaHei'`。**
纯拉丁文本可继续用 `Inter`（保持西文设计语言）。
用 `../tools/fix_svg_cjk_font.py` 批量检查与修复，它只改含中日韩字符的 `<text>`。

注意：同一张 SVG 里会出现「有的中文正常、有的变方框」的假象，
那是渲染尺寸/子集的巧合，不要据此推断规则——**一律按上表处理**。
