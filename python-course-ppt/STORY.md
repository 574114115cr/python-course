# STORY · Python 阶段 0–2 课程大纲

## 受众与用途
- 受众：零基础学习者（教师自用或自学打卡）
- 用途：课程宣讲 + 自学排期 + 教学执行
- 依据：《Python 编程：从入门到实践（第 3 版）》中文版全 20 章（上篇第 1–11 章 + 下篇第 12–20 章）+ 附录 A/B/D

## 叙事主线
「22 个单元 → 每单元一个闭环 → 两道关卡 → 三个阶段」
不是罗列章节，而是回答四个问题：怎么学、每周做什么、什么时候算过关、过关之后是什么。

整份 deck 的叙事结构是 **地基 → 项目 → 工程化** 三段：
阶段 1 让人「能写」，阶段 2 让人「能交付」，阶段 3 让人「交付得可靠」。

## 核心数据（贯穿全篇的锚点）
- 22 单元 / 111 节课 / 约 29 周 / 2 道关卡 / 3 个大项目
